[Date/Time Field Modifiers](./datetime-keywords.md#datetime-field-modifiers) shows the tokens that serve various modifier purposes.

**Date/Time Field Modifiers**

| Identifier | Description |
| --- | --- |
| `AM` | Time is before 12:00 |
| `AT` | Ignored |
| `JULIAN`, `JD`, `J` | Next field is Julian Date |
| `ON` | Ignored |
| `PM` | Time is on or after 12:00 |
| `T` | Next field is time |
