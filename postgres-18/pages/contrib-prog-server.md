# Server Applications

Some applications run on the PostgreSQL server itself. Currently, no such applications are included in the `contrib` directory. See also [PostgreSQL Server Applications](./reference.md#postgresql-server-applications) for information about server applications that are part of the core PostgreSQL distribution.
