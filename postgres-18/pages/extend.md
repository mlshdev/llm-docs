# Extending SQL

In the sections that follow, we will discuss how you can extend the PostgreSQL SQL query language by adding:

- functions (starting in [User-Defined Functions](./xfunc.md))
- aggregates (starting in [User-Defined Aggregates](./xaggr.md))
- data types (starting in [User-Defined Types](./xtypes.md))
- operators (starting in [User-Defined Operators](./xoper.md))
- operator classes for indexes (starting in [Interfacing Extensions to Indexes](./xindex.md))
- packages of related objects (starting in [Packaging Related Objects into an Extension](./extend-extensions.md))
