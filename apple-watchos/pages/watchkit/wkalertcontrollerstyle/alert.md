# WKAlertControllerStyle.alert (Swift)

**Framework:** WatchKit  
**Kind:** Case  
**Availability:** watchOS 2.0+

An alert sheet with stacked buttons. The alert sheet includes a default Cancel button at the bottom of the sheet. You can add other buttons, which are placed above the Cancel button.

## Declaration

```swift
case alert
```

## See Also

### Constants

- [WKAlertControllerStyle.sideBySideButtonsAlert](sidebysidebuttonsalert.md): An alert sheet with side-by-side buttons.
- [WKAlertControllerStyle.actionSheet](actionsheet.md): An action sheet style. Action sheets are modal sheets that can be dismissed using the Cancel button in the top-left corner of the sheet. You can also add one or two custom buttons to perform related tasks.
