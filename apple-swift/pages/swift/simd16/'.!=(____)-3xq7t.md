# .!=(\_:\_:)

**Framework:** Swift

**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · macOS 11.0+ · tvOS 14.0+ · visionOS 1.0+ · watchOS 7.0+

Pointwise compare not equal to.

## Declaration

```swift
static func .!= (a: SIMD16<Scalar>, b: SIMD16<Scalar>) -> SIMDMask<SIMD16<Scalar>.MaskStorage>
```

<a id="discussion"></a>

## Discussion

Each lane of the result is true if that lane of a is not equal to the corresponding lane of b, and false otherwise.

Equivalent to:

```swift
var result = SIMDMask<MaskStorage>()
for i in 0..<16 {
  result[i] = (a[i] != b[i])
}
```
