# isPatternWhitespace

**Framework:** Swift  
**Kind:** Instance Property  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

A Boolean value indicating whether the scalar is recommended to be treated as whitespace when parsing patterns represented in source code.

```swift
var isPatternWhitespace: Bool { get }
```

## Discussion

This property corresponds to the “Pattern_White_Space” property in the [Unicode Standard](http://www.unicode.org/versions/latest/).
