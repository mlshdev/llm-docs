# \*(\_:\_:)

**Framework:** Swift  
**Kind:** Operator  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Multiplies two values and produces their product, rounding to a representable value.

## Declaration

```swift
static func * (lhs: Float, rhs: Float) -> Float
```

## Parameters

- `lhs`: The first value to multiply.
- `rhs`: The second value to multiply.

<a id="discussion"></a>

## Discussion

The multiplication operator (`*`) calculates the product of its two arguments. For example:

```swift
let x = 7.5
let y = x * 2.25
// y == 16.875
```

The `*` operator implements the multiplication operation defined by the [IEEE 754 specification](http://ieeexplore.ieee.org/servlet/opac?punumber=4610933).
