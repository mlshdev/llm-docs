# Sequence Implementations

**Framework:** Swift  
**Kind:** API Collection

## Topics

### Type Aliases

- [Range.Element](element.md): Conforms when `Bound` conforms to `Strideable` and `Bound.Stride` conforms to `SignedInteger`. A type representing the sequence’s elements.
- [Range.Iterator](iterator.md): Conforms when `Bound` conforms to `Strideable` and `Bound.Stride` conforms to `SignedInteger`. A type that provides the sequence’s iteration interface and encapsulates its iteration state.
