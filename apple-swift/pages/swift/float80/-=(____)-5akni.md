# -=(\_:\_:)

**Framework:** Swift  
**Kind:** Operator  
**Availability:** macOS 10.10+

Subtracts the second value from the first and stores the difference in the left-hand-side variable.

## Declaration

```swift
static func -= (lhs: inout Self, rhs: Self)
```

## Parameters

- `lhs`: A numeric value.
- `rhs`: The value to subtract from `lhs`.
