# -=(\_:\_:)

**Framework:** Swift  
**Kind:** Operator  
**Availability:** macOS 10.10+

Subtracts the second value from the first and stores the difference in the left-hand-side variable, rounding to a representable value.

- `rhs`: The value to subtract from `lhs`.
