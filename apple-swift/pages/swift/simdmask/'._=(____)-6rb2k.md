# .|=(\_:\_:)

**Framework:** Swift  
**Kind:** Operator  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Replaces `a` with the pointwise logical disjunction of `a` and `b`.

## Declaration

```swift
static func .|= (a: inout SIMDMask<Storage>, b: Bool)
```
