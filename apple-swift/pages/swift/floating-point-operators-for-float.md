# Floating-Point Operators for Float

**Framework:** Swift  
**Kind:** API Collection

Perform arithmetic and bitwise operations or compare values.

## Topics

### Arithmetic

- [+(\_:\_:)](float/+%28____%29.md): Adds two values and produces their sum, rounded to a representable value.
- [-(\_:\_:)](float/-%28____%29.md): Subtracts one value from another and produces their difference, rounded to a representable value.
- [\*(\_:\_:)](float/_%28____%29.md): Multiplies two values and produces their product, rounding to a representable value.
- [/(\_:\_:)](float/_%28____%29~55ad8cd5.md): Returns the quotient of dividing the first value by the second, rounded to a representable value.

### Arithmetic with Assignment

- [+=(\_:\_:)](float/+=%28____%29.md): Adds two values and stores the result in the left-hand-side variable, rounded to a representable value.
- [-=(\_:\_:)](float/-=%28____%29.md): Subtracts the second value from the first and stores the difference in the left-hand-side variable, rounding to a representable value.
- [\*=(\_:\_:)](float/_=%28____%29.md): Multiplies two values and stores the result in the left-hand-side variable, rounding to a representable value.
- [/=(\_:\_:)](float/_=%28____%29~c58d17c0.md): Divides the first value by the second and stores the quotient in the left-hand-side variable, rounding to a representable value.

### Comparison

- [==(\_:\_:)](float/==%28____%29-12hdt.md): Returns a Boolean value indicating whether two values are equal.
- [!=(\_:\_:)](float/!=%28____%29.md): Returns a Boolean value indicating whether two values are not equal.
- [\<(\_:\_:)](float/_%28____%29-7lwp7.md): Returns a Boolean value indicating whether the value of the first argument is less than that of the second argument.
- [\<=(\_:\_:)](float/_=%28____%29-5yoz5.md)
- [\>(\_:\_:)](float/_%28____%29-552jr.md)
- [\>=(\_:\_:)](float/_=%28____%29-9o6ha.md)

### Negation

- [-(\_:)](float/-%28__%29.md): Calculates the additive inverse of a value.
- [+(\_:)](float/+%28__%29.md): Returns the given number unchanged.

### Range Expressions

- [..\<(\_:)](float/'.._%28__%29.md): Returns a partial range up to, but not including, its upper bound.
- [...(\_:)](float/'...%28__%29-4mm65.md): Returns a partial range up to, and including, its upper bound.
- [...(\_:)](float/'...%28__%29-6ct5t.md): Returns a partial range extending upward from a lower bound.
