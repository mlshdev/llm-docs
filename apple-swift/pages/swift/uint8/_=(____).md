# \*=(\_:\_:)

**Framework:** Swift  
**Kind:** Operator  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Multiplies two values and stores the result in the left-hand-side variable.

## Declaration

```swift
static func *= (lhs: inout UInt8, rhs: UInt8)
```

## Parameters

- `lhs`: The first value to multiply.
- `rhs`: The second value to multiply.

<a id="discussion"></a>

## Discussion

The product of the two arguments must be representable in the arguments’ type. In the following example, the result of `21 * 21` is greater than the maximum representable `Int8` value:

```swift
var x: Int8 = 21
x *= 21
// Overflow error
```

> **Note**

> Overflow checking is not performed in `-Ounchecked` builds.
