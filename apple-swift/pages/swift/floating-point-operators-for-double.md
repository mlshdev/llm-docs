# Floating-Point Operators for Double

**Framework:** Swift  
**Kind:** API Collection

Perform arithmetic and bitwise operations or compare values.

## Topics

### Arithmetic

- [+(\_:\_:)](double/+%28____%29.md): Adds two values and produces their sum, rounded to a representable value.
- [-(\_:\_:)](double/-%28____%29.md): Subtracts one value from another and produces their difference, rounded to a representable value.
- [\*(\_:\_:)](double/_%28____%29.md): Multiplies two values and produces their product, rounding to a representable value.
- [/(\_:\_:)](double/_%28____%29~d3ed5c55.md): Returns the quotient of dividing the first value by the second, rounded to a representable value.

### Arithmetic with Assignment

- [+=(\_:\_:)](double/+=%28____%29.md): Adds two values and stores the result in the left-hand-side variable, rounded to a representable value.
- [-=(\_:\_:)](double/-=%28____%29.md): Subtracts the second value from the first and stores the difference in the left-hand-side variable, rounding to a representable value.
- [\*=(\_:\_:)](double/_=%28____%29.md): Multiplies two values and stores the result in the left-hand-side variable, rounding to a representable value.
- [/=(\_:\_:)](double/_=%28____%29~9411f4ba.md): Divides the first value by the second and stores the quotient in the left-hand-side variable, rounding to a representable value.

### Comparison

- [==(\_:\_:)](double/==%28____%29-12hdv.md): Returns a Boolean value indicating whether two values are equal.
- [!=(\_:\_:)](double/!=%28____%29.md): Returns a Boolean value indicating whether two values are not equal.

### Negation

- [-(\_:)](double/-%28__%29.md): Calculates the additive inverse of a value.
- [+(\_:)](double/+%28__%29.md): Returns the given number unchanged.

### Range Expressions

- [...(\_:)](double/'...%28__%29-4mm67.md): Returns a partial range up to, and including, its upper bound.
- [...(\_:)](double/'...%28__%29-6ct5v.md): Returns a partial range extending upward from a lower bound.
