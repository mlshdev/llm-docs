**Framework:** Swift  
**Kind:** API Collection

Work with text using Unicode-safe strings.

### Strings and Characters

- [String](string.md): A Unicode string value that is a collection of characters.
- [Character](character.md): A single extended grapheme cluster that approximates a user-perceived character.

- [RegexComponent](regexcomponent.md): A type that represents a regular expression.
- [CustomConsumingRegexComponent](customconsumingregexcomponent.md)
