# XCUI_UI_TESTING_AVAILABLE (Swift)

**Framework:** XCUIAutomation  
**Kind:** Global Variable  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS · Xcode 16.3+

Indicates whether the current environment supports UI testing.

## Declaration

```swift
var XCUI_UI_TESTING_AVAILABLE: Int32 { get }
```

<a id="Discussion"></a>

## Discussion

This macro returns `1` if the current environment supports UI testing; otherwise, it returns `0`.
