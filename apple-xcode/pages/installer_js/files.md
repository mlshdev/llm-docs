# Files

**Interface language:** Data

**Framework:** Installer JS

An object that provides methods for accessing files.

<a id="overview"></a>

## Overview

This object is accessed using the `system.files` property.

## Topics

### Accessing Files

- [fileExistsAtPath](files/1812173-fileexistsatpath.md): Indicates whether the given path identifies an existent file.
- [plistAtPath](files/1812182-plistatpath.md): Provides the contents of a given plist file.
- [bundleAtPath](files/1812190-bundleatpath.md): Provides the contents of the info plist file of the identified bundle.
