# gestalt

**Interface language:** Data

**Framework:** Installer JS

Provides gestalt information that corresponds to the given selector.

## Declaration

```
gestalt(selector)
```

## Parameters

- `selector`: String specifying the selector for the data to retrieve.

<a id="return_value"></a>

## Return Value

Data for the given selector.

<a id="overview"></a>

## Overview

For example, the expression in [Listing 1](1812304-gestalt.md#2556491) returns `'1040'` in OS X v10.4.0:

<a id="2556491"></a>

**Listing 1**

```javascript
system.gestalt('sysv').toString(16)
```

See [Gestalt Manager](https://developer.apple.com/documentation/coreservices/carbon_core/gestalt_manager) for detailed information.

> **Warning**

> The underlying Gestalt Manager API is deprecated; use [version](1812284-version.md) and [sysctl](1812308-sysctl.md) instead of this function.
