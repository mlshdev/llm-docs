# propertiesOf

**Interface language:** Data

**Framework:** Installer JS

Provides an array containing the properties of a given object.

## Declaration

```
propertiesOf(object)
```

## Parameters

- `object`: An object.

<a id="return_value"></a>

## Return Value

An array with the properties of `object`.
