# log

**Interface language:** Data

**Framework:** Installer JS

Generates an Installer log entry with the `JS:` prefix.

## Declaration

```
log(logString)
```

## Parameters

- `logString`: Log-entry text.

<a id="overview"></a>

## Overview

For some objects, this function may print data that is unavailable or formatted differently when accessed in JavaScript code. To ensure that only data accessible in JavaScript code is shown in the log entry, invoke this function as shown in [Listing 1](1812348-log.md#2556493):

<a id="2556493"></a>

**Listing 1**

Logging JavaScript expressions

```javascript
system.log(foo + ' ')
```

Such invocation forces the JavaScript interpreter to evaluate the expression and pass a String object to the function.
