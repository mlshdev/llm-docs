# setItem(\_:forPeripheral:)

**Framework:** Playground Bluetooth  
**Kind:** Instance Method  
**Availability:** Xcode 10.2+ · Swift Playgrounds 2.0+

Sets all of the information about the specified peripheral at once.

## Parameters
