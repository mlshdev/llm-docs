# Issue.Severity

**Framework:** Swift Testing  
**Kind:** Enumeration  
**Availability:** Swift 6.3+ · Xcode 26.4+

An enumeration representing the level of severity of a recorded issue.

## Declaration

```swift
enum Severity
```

<a id="overview"></a>

## Overview

The supported levels, in increasing order of severity, are:

- [Issue.Severity.warning](severity-swift.enum/warning.md)
- [Issue.Severity.error](severity-swift.enum/error.md)

## Topics

### Enumeration Cases

- [Issue.Severity.error](severity-swift.enum/error.md): The severity level for an issue which represents an error in a test.
- [Issue.Severity.warning](severity-swift.enum/warning.md): The severity level for an issue which should be noted but is not necessarily an error.
