# Nil and Non-Nil Assertions (Swift)

**Framework:** XCTest  
**Kind:** API Collection

Check whether a test condition has, or doesn’t have, a value.

## Topics

### Tests for a Nil Condition

- [XCTAssertNil(\_:\_:file:line:)](xctassertnil%28____file_line_%29.md): Asserts that an expression is `nil`.

### Tests for a Non-Nil Condition

- [XCTAssertNotNil(\_:\_:file:line:)](xctassertnotnil%28____file_line_%29.md): Asserts that an expression is not `nil`.
- [XCTUnwrap(\_:\_:file:line:)](xctunwrap%28____file_line_%29.md): Asserts that an expression is not `nil,` and returns the unwrapped value.
