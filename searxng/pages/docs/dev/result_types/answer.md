# Answer Results

The [area answer results](https://docs.searxng.org/dev/result_types/index.html#area-answer-results) is an area in which additional information can
be displayed.

<a id="api-searx-result-types-answer"></a>

#### `answer(self, query: str) -> list[BaseAnswer]`

Function that returns a list of answers to the question/query.
