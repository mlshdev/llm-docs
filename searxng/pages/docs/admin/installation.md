# Installation

*You're spoilt for choice*, choose your preferred method of installation.

- \[installation container]\(#installation container)
- \[installation scripts]\(#installation scripts)
- \[installation basic]\(#installation basic)

The \[installation basic]\(#installation basic) is an excellent illustration of *how a SearXNG
instance is build up* (see \[architecture uWSGI]\(#architecture uWSGI)).  If you do not have any
special preferences, it's recommended to use the \[installation container]\(#installation container) or the
\[installation scripts]\(#installation scripts).

.. attention:

```text
SearXNG is growing rapidly, you should regularly read our :ref:`migrate and
stay tuned` section.  If you want to upgrade an existing instance, you
should read this section first!

```
