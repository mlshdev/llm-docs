# Installation

*You're spoilt for choice*, choose your preferred method of installation.

- [installation container](https://docs.searxng.org/admin/installation-docker.html#installation-container)
- [installation scripts](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts)
- [installation basic](https://docs.searxng.org/admin/installation-searxng.html#installation-basic)

The [installation basic](https://docs.searxng.org/admin/installation-searxng.html#installation-basic) is an excellent illustration of *how a SearXNG
instance is build up* (see [architecture uWSGI](https://docs.searxng.org/admin/architecture.html#architecture-uwsgi)).  If you do not have any
special preferences, it's recommended to use the [installation container](https://docs.searxng.org/admin/installation-docker.html#installation-container) or the
[installation scripts](https://docs.searxng.org/admin/installation-scripts.html#installation-scripts).

> **Attention**
> SearXNG is growing rapidly, you should regularly read our [migrate and stay tuned](https://docs.searxng.org/admin/update-searxng.html#migrate-and-stay-tuned) section.  If you want to upgrade an existing instance, you
> should read this section first!
