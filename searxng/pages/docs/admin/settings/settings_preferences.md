# `preferences:`

<a id="api-searx-settings-settingspref"></a>

#### `SettingsPref(msgspec.Struct, kw_only=True, forbid_unknown_fields=True)`

Options for configuring the preferences

```yaml

  lock:
    - favicon_resolver
    - image_proxy
    - method
# ...
```
