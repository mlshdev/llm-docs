# Profile Concatenation Values

**Framework:** Application Services

Specify values to use when concatenating profiles.

## Topics

### Constants

- [kNoTransform](../knotransform.md): Not used.
- [kUseAtoB](../kuseatob.md): Use 'A2B\*' tag from this profile or equivalent
- [kUseBtoA](../kusebtoa.md): Use 'B2A\*' tag from this profile or equivalent
- [kUseBtoB](../kusebtob.md): Use 'pre\*' tag from this profile or equivalent
- [kDeviceToPCS](../kdevicetopcs.md): Device Dependent to Device Independent
- [kPCSToDevice](../kpcstodevice.md): Device Independent to Device Dependent
- [kPCSToPCS](../kpcstopcs.md): Independent, through device's gamut
- [kUseProfileIntent](../kuseprofileintent.md): For renderingIntent in NCMConcatProfileSpec
