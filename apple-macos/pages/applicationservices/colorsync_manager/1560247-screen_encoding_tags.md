# Screen Encoding Tags

**Framework:** Application Services

Specify tags to use for screen encodings.

## Topics

### Constants

- [cmPrtrDefaultScreens](../cmprtrdefaultscreens.md): Use printer default screens; can have an associated value of `0` for `false` or `1` for `true`.
- [cmLinesPer](../cmlinesper.md): Lines per unit; can have an associated value of `0` for lines per centimeter or `1` for lines per inch.
