# PostScript Data Formats

**Framework:** Application Services

Specify constants that indicate the format of PostScript data.

<a id="overview"></a>

## Overview

The ColorSync Manager provides these constant declarations to specify the format of PostScript data.

## Topics

### Constants

- [cmPS7bit](../cmps7bit.md): The data is 7-bit safe—therefore the data could be in 7-bit ASCII encoding or in ASCII base-85 encoding.
- [cmPS8bit](../cmps8bit.md): The data is 8-bit safe—therefore the data could be in 7-bit or 8-bit ASCII encoding.
