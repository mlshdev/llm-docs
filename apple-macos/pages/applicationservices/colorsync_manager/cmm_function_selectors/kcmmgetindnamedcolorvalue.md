# kCMMGetIndNamedColorValue

**Interface language:** Objective-C

**Framework:** Application Services

In response to this request code, your CMM extracts device and PCS color values for a specific named color index from the profile whose reference is passed in the `prof` parameter. For more information, see the function [CMGetIndNamedColorValue](../1805059-cmgetindnamedcolorvalue.md).
