# kCMMGetNamedColorName

**Interface language:** Objective-C

**Framework:** Application Services

In response to this request code, your CMM extracts a named color name for a specific named color index from the profile whose reference is passed in the `prof` parameter. For more information, see the function [CMGetNamedColorName](../1805072-cmgetnamedcolorname.md).
