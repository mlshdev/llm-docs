# kCMMGetNamedColorIndex

**Interface language:** Objective-C

**Framework:** Application Services

In response to this request code, your CMM extracts a named color index for a specific color name from the profile whose reference is passed in the `prof` parameter. For more information, see the function [CMGetNamedColorIndex](../1805065-cmgetnamedcolorindex.md).
