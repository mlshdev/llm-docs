# kCMMGetNamedColorInfo

**Interface language:** Objective-C

**Framework:** Application Services

In response to this request code, your CMM extracts named color data from the profile whose reference is passed in the `srcProf` parameter. For more information, see the function [CMGetNamedColorInfo](../1805047-cmgetnamedcolorinfo.md).
