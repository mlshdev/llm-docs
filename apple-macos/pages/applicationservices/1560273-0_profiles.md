# Element Tags and Signatures for Version 1.0 Profiles

**Interface language:** Objective-C

**Framework:** Application Services  
**Kind:** Enumeration  
**Availability:** macOS 10.0+

Define tags and signatures used for version 1.0 profiles.

## Topics

### Constants

- [cmCS1ChromTag](1560273-0_profiles/cmcs1chromtag.md): The tag signature for the profile chromaticities tag whose element data specifies the XYZ chromaticities for the six primary and secondary colors (red, green, blue, cyan, magenta, and yellow).
- [cmCS1TRCTag](1560273-0_profiles/cmcs1trctag.md): The tag signature for profile tonal response curve data for the associated device.
- [cmCS1NameTag](1560273-0_profiles/cmcs1nametag.md): The tag signature for the profile name string. This is an international string consisting of a Macintosh script code followed by a 63-byte text string identifying the profile.
- [cmCS1CustTag](1560273-0_profiles/cmcs1custtag.md): Private data for a custom CMM.
