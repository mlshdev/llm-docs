# Global Variables (Swift)

**Framework:** Application Services  
**Kind:** API Collection

## Topics

### Constants

- [kAXAttachmentTextAttribute](../kaxattachmenttextattribute.md): An `AXUIElementRef` value for the accessibility object representing the text attachment.
- [kAXAutocorrectedTextAttribute](../kaxautocorrectedtextattribute.md): A `CFBooleanRef` value that indicates whether the text was autocorrected.
- [kAXBackgroundColorTextAttribute](../kaxbackgroundcolortextattribute.md): A `CGColorRef` value that describes the background color.
- [kAXFontFamilyKey](../kaxfontfamilykey.md): Optional key of the [kAXFontTextAttribute](../kaxfonttextattribute.md) dictionary for the font family name in a `CFStringRef`.
- [kAXFontNameKey](../kaxfontnamekey.md): Required key of the [kAXFontTextAttribute](../kaxfonttextattribute.md) dictionary for the font name in a `CFStringRef`.
- [kAXFontSizeKey](../kaxfontsizekey.md): Required key of the [kAXFontTextAttribute](../kaxfonttextattribute.md) dictionary for the font size in a `CFNumberRef`.
- [kAXFontTextAttribute](../kaxfonttextattribute.md): A dictionary (a `CFDictionaryRef`) of two or more font keys.
- [kAXForegroundColorTextAttribute](../kaxforegroundcolortextattribute.md): A `CGColorRef` value that describes the foreground color.
- [kAXLinkTextAttribute](../kaxlinktextattribute.md): An `AXUIElementRef` value used to access the object to which the specified range of text links.
- [kAXMarkedMisspelledTextAttribute](../kaxmarkedmisspelledtextattribute.md): A `CFBooleanRef` value that indicates whether the text is visibly shown as misspelled (for example, with a squiggle underneath the text).
- [kAXMisspelledTextAttribute](../kaxmisspelledtextattribute.md): A `CFBooleanRef` value that indicates whether the text is misspelled.
- [kAXNaturalLanguageTextAttribute](../kaxnaturallanguagetextattribute.md): A `CFStringRef` value that indicates the language in which the text will be spoken aloud by the system.
- [kAXReplacementStringTextAttribute](../kaxreplacementstringtextattribute.md): A `CFStringRef` value that indicates the string that will replace the text.
- [kAXShadowTextAttribute](../kaxshadowtextattribute.md): A `CFBooleanRef` value that indicates whether the text displays shadow.
- [kAXStrikethroughColorTextAttribute](../kaxstrikethroughcolortextattribute.md): A `CGColorRef` value that describes the color of the strikethrough.
- [kAXStrikethroughTextAttribute](../kaxstrikethroughtextattribute.md): A `CFBooleanRef` value that indicates whether the text displays strikethrough.
- [kAXSuperscriptTextAttribute](../kaxsuperscripttextattribute.md): A `CFNumberRef` value that indicates whether the text is superscript (value \> 0) or subscript (value \< 0).
- [kAXUnderlineColorTextAttribute](../kaxunderlinecolortextattribute.md): A `CGColorRef` value that describes the color of the underlining.
- [kAXUnderlineTextAttribute](../kaxunderlinetextattribute.md): A `CFNumberRef` value that describes the underline style (see [AXUnderlineStyle](../axunderlinestyle.md) for possible values).
- [kAXVisibleNameKey](../kaxvisiblenamekey.md): Optional key of the [kAXFontTextAttribute](../kaxfonttextattribute.md) dictionary for the font display name in a `CFStringRef`.
