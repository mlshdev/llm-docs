# kTSMHiliteCaretPosition

**Framework:** Core Services

Specify text highlighting information.

<a id="overview"></a>

## Overview

This enumeration is available starting in OS X v10.4. Use these constants in place of the constants defined in `kCaretPosition`.

## Topics

### Constants

- [kTSMHiliteCaretPosition](https://developer.apple.com/documentation/coreservices/ktsmhilitecaretposition): Specifies caret position.
- [kTSMHiliteRawText](https://developer.apple.com/documentation/coreservices/ktsmhiliterawtext): Specifies range of raw text.
- [kTSMHiliteSelectedRawText](https://developer.apple.com/documentation/coreservices/ktsmhiliteselectedrawtext): Specifies range of selected raw text.
- [kTSMHiliteConvertedText](https://developer.apple.com/documentation/coreservices/ktsmhiliteconvertedtext): Specifies range of converted text.
- [kTSMHiliteSelectedConvertedText](https://developer.apple.com/documentation/coreservices/ktsmhiliteselectedconvertedtext): Specifies range of selected converted text.
- [kTSMHiliteBlockFillText](https://developer.apple.com/documentation/coreservices/ktsmhiliteblockfilltext): Specifies block fill highlight style.
- [kTSMHiliteOutlineText](https://developer.apple.com/documentation/coreservices/ktsmhiliteoutlinetext): Specifies outline highlight style.
- [kTSMHiliteSelectedText](https://developer.apple.com/documentation/coreservices/ktsmhiliteselectedtext): Specifies selected highlight style.
- [kTSMHiliteNoHilite](https://developer.apple.com/documentation/coreservices/ktsmhilitenohilite): Specifies range of non-highlighted text.
