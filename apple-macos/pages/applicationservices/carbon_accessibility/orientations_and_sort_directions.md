# Orientations and Sort Directions (Swift)

**Framework:** Application Services  
**Kind:** API Collection

Define the values for the orientation and sort-direction attributes of some accessibility objects.

<a id="overview"></a>

## Overview

See `kAXOrientationAttribute` and `kAXSortDirectionAttribute` for more information on the attributes for which you can use these values.

## Topics

### Constants

- [kAXHorizontalOrientationValue](../kaxhorizontalorientationvalue.md): This object is oriented horizontally.
- [kAXVerticalOrientationValue](../kaxverticalorientationvalue.md): This object is oriented vertically.
- [kAXUnknownOrientationValue](../kaxunknownorientationvalue.md): The orientation of this object is unknown.
- [kAXAscendingSortDirectionValue](../kaxascendingsortdirectionvalue.md): This object’s contents are sorted in ascending order.
- [kAXUnknownSortDirectionValue](../kaxunknownsortdirectionvalue.md): The sort order of this object is unknown.
