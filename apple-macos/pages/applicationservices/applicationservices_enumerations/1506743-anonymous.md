# Anonymous

**Framework:** Application Services

## Topics

### Constants

- [kPMQualityBest](../kpmqualitybest.md): Specifies to get the best print quality for all objects and photos on a page.
- [kPMQualityDraft](../kpmqualitydraft.md): Specifies to print at the highest speed, with the amount of ink used as a secondary consideration.
- [kPMQualityHighest](../kpmqualityhighest.md): Specifies to use the highest print quality available to the printer.
- [kPMQualityInkSaver](../kpmqualityinksaver.md): Specifies to use a mode that saves ink, even if it slows printing.
- [kPMQualityLowest](../kpmqualitylowest.md): Specifies to use the lowest print quality available to the printer.
- [kPMQualityNormal](../kpmqualitynormal.md): Specifies a general usage mode that balances quality and speed.
- [kPMQualityPhoto](../kpmqualityphoto.md): Specifies to optimize the quality of photos on the page, with speed not a concern.
