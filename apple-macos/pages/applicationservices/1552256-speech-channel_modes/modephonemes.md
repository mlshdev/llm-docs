# modePhonemes

**Interface language:** Objective-C

**Framework:** Application Services  
**Kind:** Enumeration Case  
**Availability:** macOS 10.0+

Used with [soInputMode](../1552228-speech-channel_information_constants/soinputmode.md) to indicate that the speech channel is in phoneme-processing mode. When in phoneme-processing mode, a text buffer is interpreted to be a series of characters representing various phonemes and prosodic controls.

## Declaration

```objectivec
modePhonemes = 'PHON'
```
