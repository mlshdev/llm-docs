# Current Voice Keys

**Interface languages:** Swift, Objective-C

**Framework:** Application Services  
**Kind:** API Collection

Keys used with the `kSpeechCurrentVoiceProperty` property to specify information about the current voice.

## Topics

### Constants

- [kSpeechVoiceCreator](../kspeechvoicecreator.md): The synthesizer that is required to use the voice.
- [kSpeechVoiceID](../kspeechvoiceid.md): The voice ID of the voice for the synthesizer (every voice on a synthesizer has a unique ID).
