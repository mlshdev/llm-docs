# Phoneme Symbols Keys

**Interface languages:** Swift, Objective-C

**Framework:** Application Services  
**Kind:** API Collection

Keys used with the `kSpeechPhonemeSymbolsProperty` property to provide information about the phoneme being processed.

## Topics

### Constants

- [kSpeechPhonemeInfoOpcode](../kspeechphonemeinfoopcode.md): The opcode of the phoneme.
- [kSpeechPhonemeInfoSymbol](../kspeechphonemeinfosymbol.md): The symbol used to represent the phoneme.
- [kSpeechPhonemeInfoExample](../kspeechphonemeinfoexample.md): An example word that illustrates the use of the phoneme.
- [kSpeechPhonemeInfoHiliteStart](../kspeechphonemeinfohilitestart.md): The character offset into the example word that identifies the location of the beginning of the phoneme.
- [kSpeechPhonemeInfoHiliteEnd](../kspeechphonemeinfohiliteend.md): The character offset into the example word that identifies the location of the end of the phoneme.
