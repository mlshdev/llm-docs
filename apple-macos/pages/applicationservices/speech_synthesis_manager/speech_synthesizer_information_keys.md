# Speech Synthesizer Information Keys

**Interface languages:** Swift, Objective-C

**Framework:** Application Services  
**Kind:** API Collection

Keys used with the `kSpeechSynthesizerInfoProperty` property to get information about the synthesizer.

## Topics

### Constants

- [kSpeechSynthesizerInfoIdentifier](../kspeechsynthesizerinfoidentifier.md): The identifier of the speech synthesizer.
- [kSpeechSynthesizerInfoVersion](../kspeechsynthesizerinfoversion.md): The version of the speech synthesizer.
- [kSpeechSynthesizerInfoManufacturer](../kspeechsynthesizerinfomanufacturer.md): The identification of a synthesizer engine (see the `synthManufacturer` field in [SpeechVersionInfo](../speechversioninfo.md)).
