# Error Callback User-Information String

**Interface languages:** Swift, Objective-C

**Framework:** Application Services  
**Kind:** API Collection

Specifies information about the text being synthesized when an error occurs.

## Topics

### Constants

- [kSpeechErrorCallbackSpokenString](../kspeecherrorcallbackspokenstring.md): The text being synthesized when the error occurred.
- [kSpeechErrorCallbackCharacterOffset](../kspeecherrorcallbackcharacteroffset.md): The character index in the text being synthesized when the error occurred (the string representing the text is in [kSpeechErrorCallbackSpokenString](../kspeecherrorcallbackspokenstring.md)).
