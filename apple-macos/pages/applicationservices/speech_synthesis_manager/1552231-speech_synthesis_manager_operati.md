# Speech Synthesis Manager Operating System Types

**Framework:** Application Services

The `OSType` definitions used by the Speech Synthesis Manager.

## Topics

### Constants

- [kTextToSpeechSynthType](../ktexttospeechsynthtype.md): The type of a synthesizer component.
- [kTextToSpeechVoiceType](../ktexttospeechvoicetype.md): The type of a voice resource.
- [kTextToSpeechVoiceFileType](../ktexttospeechvoicefiletype.md): The type of a voice file. Typically. files containing a single voice are of type `kTextToSpeechVoiceFileType`.
- [kTextToSpeechVoiceBundleType](../ktexttospeechvoicebundletype.md): The type of a voice bundle file. Typically, files containing multiple voices are of type `kTextToSpeechVoiceBundleType`.
