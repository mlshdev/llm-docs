# PMRect

**Interface language:** Objective-C

**Framework:** Application Services

A data structure that describes a rectangle using four double-precision coordinates.

## Declaration

```objectivec
struct PMRect {
   double top;
   double left;
   double bottom;
   double right;
};
```

## Topics

### Fields

- [top](../pmrect/1461523-top.md): The vertical coordinate for the upper-left point of the rectangle.
- [left](../pmrect/1459041-left.md): The horizontal coordinate for the upper-left point of the rectangle.
- [bottom](../pmrect/1458973-bottom.md): The vertical coordinate for the lower-right point of the rectangle.
- [right](../pmrect/1459337-right.md): The horizontal coordinate for the lower-right point of the rectangle.
