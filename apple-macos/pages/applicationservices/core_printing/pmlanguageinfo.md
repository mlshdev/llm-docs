# PMLanguageInfo

**Interface language:** Objective-C

**Framework:** Application Services

A data structure that contains level, version, and release information for the imaging language used by a printer driver.

## Declaration

```objectivec
struct PMLanguageInfo {
   Str32 level;
   Str32 version;
   Str32 release;
};
```
