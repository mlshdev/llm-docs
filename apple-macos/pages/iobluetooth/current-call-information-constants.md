# Current Call Information Constants (Swift)

**Framework:** IOBluetooth  
**Kind:** API Collection

Get information about a phone call on a hands-free Bluetooth device.

## Topics

### Call Information

- [IOBluetoothHandsFreeCallDirection](iobluetoothhandsfreecalldirection.md): A value that indicates whether a call is incoming or outgoing.
- [IOBluetoothHandsFreeCallIndex](iobluetoothhandsfreecallindex.md): The index of the call, starting with `1`.
- [IOBluetoothHandsFreeCallMode](iobluetoothhandsfreecallmode.md): The type of call data.
- [IOBluetoothHandsFreeCallMultiparty](iobluetoothhandsfreecallmultiparty.md): A value that indicates whether the call is multiple-party.
- [IOBluetoothHandsFreeCallStatus](iobluetoothhandsfreecallstatus.md): The current state of the call.

### Remote Number Information

- [IOBluetoothHandsFreeCallNumber](iobluetoothhandsfreecallnumber.md): The caller’s phone number.
- [IOBluetoothHandsFreeCallType](iobluetoothhandsfreecalltype.md): The format of the caller’s phone number.
- [IOBluetoothHandsFreeCallName](iobluetoothhandsfreecallname.md): The name of the caller.

## See Also

### Receiving Call Status

- [handsFree(\_:incomingCallFrom:)](iobluetoothhandsfreedevicedelegate/handsfree%28__incomingcallfrom_%29.md): Tells the delegate there’s an incoming call on the connected Bluetooth hands-free phone or headset.
- [handsFree(\_:currentCall:)](iobluetoothhandsfreedevicedelegate/handsfree%28__currentcall_%29.md): Sends the delegate information about the current call.
