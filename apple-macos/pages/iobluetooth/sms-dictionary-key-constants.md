# SMS Dictionary Key Constants (Swift)

**Framework:** IOBluetooth  
**Kind:** API Collection

Read the parts of an SMS message.

## Topics

### Sender Information

- [IOBluetoothPDUOriginatingAddress](iobluetoothpduoriginatingaddress.md): The phone number for the sender of the text message.
- [IOBluetoothPDUOriginatingAddressType](iobluetoothpduoriginatingaddresstype.md): The format of the phone number for the sender of the text message.
- [IOBluetoothPDUServicCenterAddress](iobluetoothpduserviccenteraddress.md): The phone number for the service center that stored and then delivered the message.
- [IOBluetoothPDUServiceCenterAddressType](iobluetoothpduservicecenteraddresstype.md): The format of the phone number for the service center.

### Message Information

- [IOBluetoothPDUProtocolID](iobluetoothpduprotocolid.md): The protocol of the text message content.
- [IOBluetoothPDUUserData](iobluetoothpduuserdata.md): The content of the text message.
- [IOBluetoothPDUTimestamp](iobluetoothpdutimestamp.md): The time the text message was sent.
- [IOBluetoothPDUType](iobluetoothpdutype.md): The GSM type of the text message.
- [IOBluetoothPDUEncoding](iobluetoothpduencoding.md): The encoding for the text message.

## See Also

### Receiving SMS Information
