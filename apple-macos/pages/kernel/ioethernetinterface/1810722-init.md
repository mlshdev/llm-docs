# init

**Interface language:** Objective-C

**Framework:** Kernel

Initializes an IOEthernetInterface instance.

## Declaration

```objectivec
virtual bool init(
 IONetworkController *controller ); 
```

## Parameters

- `controller`: A network controller object that will service the interface object being initialized.

<a id="return_value"></a>

## Return Value

Returns true on success, false otherwise.

<a id="overview"></a>

## Overview

Instance variables are initialized, and an arpcom structure is allocated.
