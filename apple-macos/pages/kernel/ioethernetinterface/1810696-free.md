# free

**Interface language:** Objective-C

**Framework:** Kernel

Frees the IOEthernetInterface instance.

## Declaration

```objectivec
virtual void free(); 
```

<a id="overview"></a>

## Overview

The memory allocated for the arpcom structure is released, followed by a call to super::free().
