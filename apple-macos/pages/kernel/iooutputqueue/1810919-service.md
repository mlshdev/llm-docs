# service

**Interface language:** Objective-C

**Framework:** Kernel

Services the queue.

## Declaration

```objectivec
virtual bool service(
 IOOptionBits options = 0) = 0; 
```

## Parameters

- `options`: Options for the service request.

## Return Value
