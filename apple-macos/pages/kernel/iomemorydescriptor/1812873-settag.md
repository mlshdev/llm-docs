# setTag

**Interface language:** Objective-C

**Framework:** Kernel

Set the tag for the memory descriptor.

## Declaration

```objectivec
virtual void setTag(
 IOOptionBitstag ); 
```

## Parameters

- `tag`: The tag.

<a id="overview"></a>

## Overview

This method sets the tag for the memory descriptor. Tag bits are not interpreted by IOMemoryDescriptor.
