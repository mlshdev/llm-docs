# init

**Interface language:** Objective-C

**Framework:** DriverKit, Kernel  
**Kind:** Instance Method  
**Availability:** DriverKit 19.0+ · macOS 10.15.2+

Handles the basic initialization of the dispatch source.

## Declaration

```objectivec
virtual bool init(void);
```

<a id="return_value"></a>

## Return Value

`true` if initialization was successful, or `false` if an error occurred.

<a id="discussion"></a>

## Discussion

Don't call this method directly. Call [Create](3438201-create.md) when you want to create a new interrupt dispatch source.

## See Also

### Configuring the Interrupt Source

- [Create](3438201-create.md): Create a dispatch source that reports hardware-related interrupts generated by the specified service provider.
- [free](3438202-free.md): Performs any final cleanup for the dispatch source.
- [SetHandler](https://developer.apple.com/documentation/driverkit/iointerruptdispatchsource/sethandler): Set the handler block to run when the interrupt fires.
