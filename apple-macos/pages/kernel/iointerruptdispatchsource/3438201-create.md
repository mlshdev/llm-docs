# Create

**Interface language:** Objective-C

**Framework:** DriverKit, Kernel  
**Kind:** Type Method  
**Availability:** DriverKit 19.0+ · macOS 10.15.2+

Create a dispatch source that reports hardware-related interrupts generated by the specified service provider.

## Declaration

```objectivec
static kern_return_t Create(IOService *provider, uint32_t index, IODispatchQueue *queue, IOInterruptDispatchSource **source);
```

## Parameters

- `provider`: The [IOService](https://developer.apple.com/documentation/driverkit/ioservice) object representing the hardware device that generated the interrupt.
- `index`: The index for the interrupt.
- `queue`: The dispatch queue on which to run any handler blocks.
- `source`: A variable for storing the dispatch source. On return, this variable contains the retained object. You are responsible for releasing this object.

<a id="return_value"></a>

## Return Value

[kIOReturnSuccess](https://developer.apple.com/documentation/driverkit/kioreturnsuccess) on success, or another value if an error occurs. See [Error Codes](https://developer.apple.com/documentation/driverkit/error-codes).

<a id="discussion"></a>

## Discussion

Creates a new interrupt source for the specified provider object. After creating the dispatch source, call the [SetHandler](https://developer.apple.com/documentation/driverkit/iointerruptdispatchsource/sethandler) method to specify the action to perform when interrupts occur.

## See Also

### Configuring the Interrupt Source

- [init](3438203-init.md): Handles the basic initialization of the dispatch source.
- [free](3438202-free.md): Performs any final cleanup for the dispatch source.
- [SetHandler](https://developer.apple.com/documentation/driverkit/iointerruptdispatchsource/sethandler): Set the handler block to run when the interrupt fires.
