# unlock

**Interface language:** Objective-C

**Framework:** Kernel

Releases the debugger lock.

## Declaration

```objectivec
static void unlock(
 IODebuggerLockState state ); 
```

<a id="overview"></a>

## Overview

This method releases the debugger lock if the kIODebuggerLockTaken flag is set in the argument.
