# enable

**Interface language:** Objective-C

**Framework:** Kernel

Sets the enable state of the notification request.

## Declaration

```objectivec
virtual void enable(
 boolwas ) = 0; 
```

## Parameters

- `was`: The enable state of the notifier to restore.

## Overview
