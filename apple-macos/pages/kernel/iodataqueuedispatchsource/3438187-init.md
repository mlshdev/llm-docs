# init

**Interface language:** Objective-C

**Framework:** DriverKit, Kernel  
**Kind:** Instance Method  
**Availability:** DriverKit 19.0+ · macOS 10.15.2+

Handles the basic initialization of the dispatch source.

## Declaration

```objectivec
virtual bool init(void);
```

<a id="return_value"></a>

## Return Value

`true` if initialization was successful, or `false` if an error occurred.

<a id="discussion"></a>

## Discussion

Don't call this method directly. Call [Create](3438177-create.md) when you want to create a new data-queue dispatch source.

## See Also

### Configuring the Dispatch Source

- [Create](3438177-create.md): Creates a dispatch source that you use as a shared-memory data queue.
- [free](3438186-free.md): Performs any final cleanup for the data-queue dispatch source.
