# Authorization Constants (Swift)

**Framework:** Service Management  
**Kind:** API Collection

Constants that describe the ability to authorize helper executables or modify daemon applications.

## Topics

### Constants

- [kSMRightBlessPrivilegedHelper](ksmrightblessprivilegedhelper.md): The authorization rights key for approving and installing a privileged helper tool.
- [kSMRightBlessPrivilegedHelper](ksmrightblessprivilegedhelper.md): The authorization rights key for approving and installing a privileged helper tool.
- [kSMRightModifySystemDaemons](ksmrightmodifysystemdaemons.md): The authorization rights key for modifying system daemons.
- [kSMRightModifySystemDaemons](ksmrightmodifysystemdaemons.md): The authorization rights key for modifying system daemons.

### Management
