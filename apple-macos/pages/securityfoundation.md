# Security Foundation (Swift)

**Framework:** Security Foundation  
**Kind:** Framework  
**Availability:** Mac Catalyst 13.0+ · macOS 10.3+

Restrict a user’s access to particular features in your Mac app or daemon.

<a id="overview"></a>

## Overview

This document was previously titled *Authorization Services Objective-C Reference,* and it replaced the `SFAuthorization` chapter of the *Security Objective-C API* document. The other chapters of that document have been replaced by [Security Interface](securityinterface.md).

The Security Foundation framework contains a single class, [SFAuthorization](securityfoundation/sfauthorization.md), which allows you to restrict a user’s access to particular features in your Mac app or daemon.

## Topics

### Classes

- [SFAuthorization](securityfoundation/sfauthorization.md): A class that allows you to restrict a user’s access to particular features in your Mac app or daemon.
