# MSR Permissions (Swift)

**Framework:** Hypervisor  
**Kind:** API Collection

An enumeration that describes possible Model-Specific Register (MSR) permisssions.

## Topics

### Permissions

- [HV_MSR_NONE](hv_msr_none.md): The Model-Specific Register (MSR) no-access permission.
- [HV_MSR_READ](hv_msr_read.md): The Model-Specific Register (MSR) read permission.
- [HV_MSR_WRITE](hv_msr_write.md): The Model-Specific Register (MSR) write permission.
