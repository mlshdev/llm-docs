- [IKImageBrowserCellsHighlightedTitleAttributesKey](ikimagebrowsercellshighlightedtitleattributeskey.md): A key for the highlighted title attribute for an item in the image browser view.
- [IKImageBrowserCellsOutlineColorKey](ikimagebrowsercellsoutlinecolorkey.md): A key for the outline color for an item in the image browser view.
- [IKImageBrowserCellsSubtitleAttributesKey](ikimagebrowsercellssubtitleattributeskey.md): A key for a subtitle attribute for an item in the image browser view.
- [IKImageBrowserCellsTitleAttributesKey](ikimagebrowsercellstitleattributeskey.md): A key for title attribute of an item in the image browser view.

- [IKImageBrowserGroupStyleKey](ikimagebrowsergroupstylekey.md): A key for the style of a group.
- [IKImageBrowserGroupTitleKey](ikimagebrowsergrouptitlekey.md): A key for the title of a group.
- [IKImageBrowserSelectionColorKey](ikimagebrowserselectioncolorkey.md): A key for the color that indicates a selection.
- [IKImageStateInvalid](ikimagestateinvalid.md): The thumbnail is invalid. For example, an unsupported image is provided.
- [IKImageStateNoImage](ikimagestatenoimage.md): Returned until a thumbnail has been created from the represented object.
- [IKImageStateReady](ikimagestateready.md): The receiver’s represented object has been set and the cell is ready to display.
- [IKOverlayTypeBackground](ikoverlaytypebackground.md): A background.
- [IKOverlayTypeImage](ikoverlaytypeimage.md): An image.
- [IKPictureTakerAllowsEditingKey](ikpicturetakerallowseditingkey.md): A key for allowing image editing.
- [IKPictureTakerAllowsFileChoosingKey](ikpicturetakerallowsfilechoosingkey.md): A key for allowing the user to choose a file.
- [IKPictureTakerAllowsVideoCaptureKey](ikpicturetakerallowsvideocapturekey.md): A key for allowing video capture.
- [IKPictureTakerImageTransformsKey](ikpicturetakerimagetransformskey.md): A n image transformation key. The associated value is an `NSDictionary` object that can be serialized.
- [IKPictureTakerInformationalTextKey](ikpicturetakerinformationaltextkey.md): A key for informational text. The associated value is an `NSString` or `NSAttributedString` object whose default value is `"Drag Image Here"`.
- [IKPictureTakerOutputImageMaxSizeKey](ikpicturetakeroutputimagemaxsizekey.md): A key for the maximum size of the output image. The associated value is an `NSValue` object (`NSSize`).
- [IKPictureTakerRemainOpenAfterValidateKey](ikpicturetakerremainopenaftervalidatekey.md): A key that determines if the picture taker UI should remain open after the user selects done.
- [IKPictureTakerShowAddressBookPicture](ikpicturetakershowaddressbookpicture.md): Deprecated.
- [IKPictureTakerShowAddressBookPictureKey](ikpicturetakershowaddressbookpicturekey.md): A key for showing the address book picture.
- [IKPictureTakerShowEffectsKey](ikpicturetakershoweffectskey.md): A key for showing effects.
- [IKPictureTakerShowEmptyPicture](ikpicturetakershowemptypicture.md): Deprecated.
- [IKPictureTakerShowEmptyPictureKey](ikpicturetakershowemptypicturekey.md): A key for showing an empty picture. The associated value is an `NSImage` object. The default value is `nil`. If set to an image, the picture taker automatically shows an image at the end of the Recent Pictures pop-up menu. that means “no picture.”
- [IKPictureTakerShowRecentPictureKey](ikpicturetakershowrecentpicturekey.md)
- [IKPictureTakerUpdateRecentPictureKey](ikpicturetakerupdaterecentpicturekey.md): A key for allowing a recent picture to be updated.
- [IKSlideshowAudioFile](ikslideshowaudiofile.md): A key specifying the audio file played during the slideshow.
- [IKSlideshowModeImages](ikslideshowmodeimages.md): All items in the slideshow are images.
- [IKSlideshowModeOther](ikslideshowmodeother.md): There are a mixture of items in the slideshow (image, PDF, text, HTML, and so on).
- [IKSlideshowModePDF](ikslideshowmodepdf.md): All items in the slideshow are PDF documents.
- [IKSlideshowPDFDisplayBox](ikslideshowpdfdisplaybox.md): A key for the PDF display box.
- [IKSlideshowPDFDisplayMode](ikslideshowpdfdisplaymode.md): A key for the PDF display mode.
- [IKSlideshowPDFDisplaysAsBook](ikslideshowpdfdisplaysasbook.md): A key for displaying the slideshow as a book. The associated value is a `Boolean` data type.
- [IKSlideshowScreen](ikslideshowscreen.md): A key specifying the screen on which the slideshow is displayed.
- [IKSlideshowStartIndex](ikslideshowstartindex.md): A key for the slideshow item index. The associated value is an index.
- [IKSlideshowStartPaused](ikslideshowstartpaused.md): A key for starting in a paused state. The associated value is a `Boolean` data type.
- [IKSlideshowWrapAround](ikslideshowwraparound.md): A key for starting the slideshow over after the last slide shows. The associated value is a `Boolean` data type.
- [IKToolModeAnnotate](iktoolmodeannotate.md): The annotation tool.
- [IKToolModeCrop](iktoolmodecrop.md): The crop tool.
- [IKToolModeMove](iktoolmodemove.md): The move tool.
- [IKToolModeNone](iktoolmodenone.md): No tool is set.
- [IKToolModeRotate](iktoolmoderotate.md): The rotation tool.
- [IKToolModeSelect](iktoolmodeselect.md): The selection tool.
- [IKToolModeSelectEllipse](iktoolmodeselectellipse.md): The selection ellipse.
- [IKToolModeSelectLasso](iktoolmodeselectlasso.md): The selection lasso.
- [IKToolModeSelectRect](iktoolmodeselectrect.md): Same as `IKToolModeSelect`.
- [IKUIFlavorAllowFallback](ikuiflavorallowfallback.md): Substitute controls of another size. The associated value is a Boolean value. If the filter cannot provide a view for the requested size and a fallback is allowed, the filter can use controls of a different size.
- [IKUISizeFlavor](ikuisizeflavor.md): A key for the size of the controls in a filter view. The associated value can be [IKUISizeMini](ikuisizemini.md), [IKUISizeSmall](ikuisizesmall.md), or [IKUISizeRegular](ikuisizeregular.md).
- [IKUISizeMini](ikuisizemini.md): A very small control.
- [IKUISizeRegular](ikuisizeregular.md): A standard size control.
- [IKUISizeSmall](ikuisizesmall.md): A small control.
- [IKUImaxSize](ikuimaxsize.md): The maximum size of a filter view.
- [IK_ApertureBundleIdentifier](ik_aperturebundleidentifier.md): The Aperature application—`com.apple.Aperture`.
- [IK_MailBundleIdentifier](ik_mailbundleidentifier.md): The Mail application—`com.apple.mail`.
- [IK_PhotosBundleIdentifier](ik_photosbundleidentifier.md)
- [IK_iPhotoBundleIdentifier](ik_iphotobundleidentifier.md): The iPhoto application—`com.apple.iPhoto`.
