# Deprecated Annotations

**Interface languages:** Swift, Objective-C

**Framework:** Quartz

These symbols are deprecated and should no longer be used.

## Topics

### Deprecated Annotation Types

- [PDFAnnotationButtonWidget](https://developer.apple.com/documentation/pdfkit/pdfannotationbuttonwidget): Deprecated. A `PDFAnnotationButtonWidget` object provides user interactivity on a page of a PDF document. There are three types of buttons available: push button, radio button, and checkbox.
- [PDFAnnotationChoiceWidget](https://developer.apple.com/documentation/pdfkit/pdfannotationchoicewidget): Deprecated. A `PDFAnnotationChoiceWidget` object provides user interactivity on a page of a PDF document, in the form of pop-up menus and lists.
- [PDFAnnotationCircle](https://developer.apple.com/documentation/pdfkit/pdfannotationcircle): Deprecated.
- [PDFAnnotationFreeText](https://developer.apple.com/documentation/pdfkit/pdfannotationfreetext): Deprecated. A `PDFAnnotationFreeText` object displays text on a page.
- [PDFAnnotationInk](https://developer.apple.com/documentation/pdfkit/pdfannotationink): Deprecated.
- [PDFAnnotationLine](https://developer.apple.com/documentation/pdfkit/pdfannotationline): Deprecated. A `PDFAnnotationLine` object displays a single line on a page.
- [PDFAnnotationLink](https://developer.apple.com/documentation/pdfkit/pdfannotationlink): Deprecated.
- [PDFAnnotationMarkup](https://developer.apple.com/documentation/pdfkit/pdfannotationmarkup): Deprecated. A `PDFAnnotationMarkup` object appears as highlighting, underlining, or a strikethrough style applied to the text of a document.
- [PDFAnnotationPopup](https://developer.apple.com/documentation/pdfkit/pdfannotationpopup): Deprecated. A `PDFAnnotationPopup` object provides user interactivity on a PDF page in the form of a pop-up menu.
- [PDFAnnotationSquare](https://developer.apple.com/documentation/pdfkit/pdfannotationsquare): Deprecated. A rectangle annotation on a page.
- [PDFAnnotationStamp](https://developer.apple.com/documentation/pdfkit/pdfannotationstamp): Deprecated. A `PDFAnnotationStamp` object allows you to display a word or phrase, such as “Confidential,” in a PDF page.
- [PDFAnnotationText](https://developer.apple.com/documentation/pdfkit/pdfannotationtext): Deprecated. A `PDFAnnotationText` object displays as an icon (such as a “sticky note”) attached to a specified point in the PDF document.
- [PDFAnnotationTextWidget](https://developer.apple.com/documentation/pdfkit/pdfannotationtextwidget): Deprecated. A `PDFAnnotationTextWidget` object allows you to manage the appearance and content of text fields.
