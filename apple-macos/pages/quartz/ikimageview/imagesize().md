# imageSize() (Swift)

**Framework:** Quartz  
**Kind:** Instance Method  
**Availability:** macOS 10.5+

Returns the size of the image in the image view.

## Declaration

```swift
func imageSize() -> NSSize
```

<a id="return-value"></a>

## Return Value

The size of the image.

<a id="Discussion"></a>

## Discussion

The image size changes whenever an image is rotates or cropped.
