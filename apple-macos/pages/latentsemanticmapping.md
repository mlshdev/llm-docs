# Latent Semantic Mapping (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** Framework  
**Availability:** Mac Catalyst 13.1+ · macOS 10.5+

Classify text and other token-based content into developer-defined categories.

<a id="overview"></a>

## Overview

The Latent Semantic Mapping framework classifies texts based on latent semantic information. The C-based functions of this API are designed to be language-independent and are Unicode-based.

For other natural language processing functionality, see [Natural Language](https://developer.apple.com/documentation/naturallanguage).

## Topics

### Text Classification

- [LSMMap](latentsemanticmapping/lsmmap.md): A map between a set of categories and related text.
- [LSMText](latentsemanticmapping/lsmtext.md): An input text.
- [LSMResult](latentsemanticmapping/lsmresult.md): A result of a lookup in a map.

### Error Handling

- [Error Codes](latentsemanticmapping/error-codes.md): Error codes in Latent Semantic Mapping.
