# ITLibPlaylistKind.genius (Swift)

**Framework:** iTunes Library  
**Kind:** Case  
**Availability:** Mac Catalyst 14.0+ · macOS 10.13+

A playlist iTunes creates of songs that go well with a song the user specifies.

## Declaration

```swift
case genius
```

## See Also

### Playlist Kinds

- [ITLibPlaylistKind.regular](regular.md): A standard playlist that the user or iTunes creates, such as *Music*, *Movies*, *Pop Mix*, or *My Awesome Playlist*.
- [ITLibPlaylistKind.smart](smart.md): A playlist with contents that iTunes generates by evaluating a set of rules, such as *90s Music* or *Songs from 1999*.
- [ITLibPlaylistKind.folder](folder.md): A playlist folder that the user or iTunes creates, such as *My Playlist Folder* or *Genius Mixes*.
- [ITLibPlaylistKind.geniusMix](geniusmix.md): An ongoing playlist in a particular genre—like a commercial-free radio station playing the user’s favorite songs—that iTunes creates from music in the user’s iTunes library.
