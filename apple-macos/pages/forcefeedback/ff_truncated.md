# FF_TRUNCATED (Swift)

**Framework:** Force Feedback  
**Kind:** Global Variable  
**Availability:** Mac Catalyst 13.0+ · macOS 10.2+

## Declaration

```swift
var FF_TRUNCATED: HRESULT { get }
```

## Discussion
