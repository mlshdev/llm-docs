# FFPERIODIC (Swift)

**Framework:** Force Feedback  
**Kind:** Structure  
**Availability:** Mac Catalyst 13.0+ · macOS 10.2+

A structure containing type-specific information for certain effects.

## Declaration

```swift
struct FFPERIODIC
```

<a id="overview"></a>

## Overview

Used with the SINE, SQUARE, TRIANGLE, SAWTOOTHUP, and SAWTOOTHDOWN effects.

A pointer to a single FFPERIODIC structure for an effect is passed in the lpvTypeSpecificParams member of the FFEFFECT structure. A Force Feedback plugIn cannot provide support for all values in the **dwPhase** member. In this case, the value is rounded off to the nearest supported value.

## Topics

### Initializers

- [init()](ffperiodic/init%28%29.md)
- [init(dwMagnitude:lOffset:dwPhase:dwPeriod:)](ffperiodic/init%28dwmagnitude_loffset_dwphase_dwperiod_%29.md)

### Instance Properties

- [dwMagnitude](ffperiodic/dwmagnitude.md): Magnitude of the effect, in the range from 0 through 10,000. If an envelope is applied to this effect, the value represents the magnitude of the sustain. If no envelope is applied, the value represents the amplitude of the entire effect.
- [dwPeriod](ffperiodic/dwperiod.md): Period of the effect, in microseconds.
- [dwPhase](ffperiodic/dwphase.md): Position in the cycle of the periodic effect at which playback begins, in the range from 0 through 35,999.
- [lOffset](ffperiodic/loffset.md): Offset of the effect. The range of forces generated by the effect is **lOffset** minus **dwMagnitude** to **lOffset** plus **dwMagnitude**. The value of the **lOffset** member is also the baseline for any envelope that is applied to the effect.
