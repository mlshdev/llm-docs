# Search Field

**Interface languages:** Swift, Objective-C

**Framework:** AppKit  
**Kind:** API Collection

Provide a text field that is optimized for text-based search interfaces.

## Topics

### View

- [NSSearchField](nssearchfield.md): A text field optimized for performing text-based searches.

### Cell

- [NSSearchFieldCell](nssearchfieldcell.md): The programmatic interface for text fields that are used for text-based searches.

### Search and Replace

- [NSTextFinder](nstextfinder.md): An optional search-and-replace find interface inside a view, usually a scroll view.
- [NSTextFinderBarContainer](nstextfinderbarcontainer.md): A protocol that provides a container in which the find bar is displayed.
- [NSTextFinderClient](nstextfinderclient.md): A set of methods implemented by objects that support searching using the [NSTextFinder](nstextfinder.md) class and the in-window text find bar.
