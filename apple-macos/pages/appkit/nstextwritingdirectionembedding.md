# NSTextWritingDirectionEmbedding (Swift)

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+ (deprecated in 10.11)

Text is embedded in text with another writing direction.

> Use [NSWritingDirectionFormatType.embedding](nswritingdirectionformattype/embedding.md) instead.

## Declaration

```swift
var NSTextWritingDirectionEmbedding: Int { get }
```

<a id="Discussion"></a>

## Discussion

For example, an English quotation in the middle of an Arabic sentence could be marked as being embedded left-to-right text.
