# NSView.BackgroundStyle.emphasized (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS 10.5+

A style that adds emphasis to the background using an alternate color or visual effect.

## Declaration

```swift
case emphasized
```

<a id="Discussion"></a>

## Discussion

You might use this style to show selection. You might need to alter the appearance of the cell’s content to achieve the needed emphasis.

## See Also

### Getting the Background Styles

- [NSView.BackgroundStyle.normal](normal.md): A style that reflects the predominant color scheme of the view’s appearance.
- [NSView.BackgroundStyle.raised](raised.md): A style that makes the background appear higher than the content drawn on it.
- [NSView.BackgroundStyle.lowered](lowered.md): A style that makes the background appear lower than the content drawn on it.
