# Linkage Elements (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Constants that specify links between accessibility elements.

## Topics

### Constants

- [linkedUIElements](nsaccessibility-swift.struct/attribute/linkeduielements.md): Deprecated. The elements with which this element is related (`NSArray`).
- [titleUIElement](nsaccessibility-swift.struct/attribute/titleuielement.md): An element that represents another element’s static text title (`id`).
- [servesAsTitleForUIElements](nsaccessibility-swift.struct/attribute/servesastitleforuielements.md): The elements for which this element serves as the title (`NSArray`).
