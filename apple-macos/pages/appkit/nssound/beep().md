# beep()

**Framework:** AppKit  
**Kind:** Type Method  
**Availability:** macOS 10.9+ · Swift 4.0+

Plays the system beep.

## Declaration

```swift
static func beep()
```

<a id="Discussion"></a>

## Discussion

Users can select a sound to be played as the system beep in the Sound pane of System Preferences.
