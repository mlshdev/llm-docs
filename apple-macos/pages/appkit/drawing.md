# Drawing (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Draw shapes, images, and other content on the screen.

## Topics

### Drawing Contexts

- [NSGraphicsContext](nsgraphicscontext.md): An object that represents a graphics context.

### Shapes and Paths

- [NSBezierPath](nsbezierpath.md): An object that can create paths using PostScript-style commands.
- [Convenience Functions](convenience-functions.md): Draw rectangles and other primitive shapes using these convenience functions.

### Strings

- [NSStringDrawingContext](nsstringdrawingcontext.md): An object that manages metrics for drawing attributed strings.
- [NSStringDrawingOptions](https://developer.apple.com/documentation/uikit/nsstringdrawingoptions): Constants that specify the rendering options for drawing a string.

### Gradients

- [NSGradient](nsgradient.md): An object that can draw gradient fill colors

### Shadows

- [NSShadow](nsshadow.md): An object you use to specify attributes to create and style a drop shadow during drawing operations.

### Graphics, Drawing, Color, and Printing
