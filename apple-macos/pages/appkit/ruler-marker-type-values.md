# Ruler Marker Type Values (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Values that indicate the marker type of an element.

<a id="overview"></a>

## Overview

Use these values with an accessibility element’s [markerType](nsaccessibility-swift.struct/attribute/markertype.md) property.

## Topics

### Constants

- [leftTabStop](nsaccessibility-swift.struct/rulermarkertypevalue/lefttabstop.md): Deprecated. Left tab stop.
- [rightTabStop](nsaccessibility-swift.struct/rulermarkertypevalue/righttabstop.md): Right tab stop.
- [centerTabStop](nsaccessibility-swift.struct/rulermarkertypevalue/centertabstop.md): Center tab stop.
- [decimalTabStop](nsaccessibility-swift.struct/rulermarkertypevalue/decimaltabstop.md): Decimal tab stop.
- [headIndent](nsaccessibility-swift.struct/rulermarkertypevalue/headindent.md): Head indent marker.
- [tailIndent](nsaccessibility-swift.struct/rulermarkertypevalue/tailindent.md): Tail indent marker.
- [firstLineIndent](nsaccessibility-swift.struct/rulermarkertypevalue/firstlineindent.md): First line indent marker.
- [unknown](nsaccessibility-swift.struct/rulermarkertypevalue/unknown.md): Unknown marker type.
