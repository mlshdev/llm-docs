# thicknessRequiredInRuler (Swift)

**Framework:** AppKit  
**Kind:** Instance Property  
**Availability:** macOS

The amount of the receiver’s image that’s displayed above or to the left of the ruler view’s baseline.

## Declaration

```swift
var thicknessRequiredInRuler: CGFloat { get }
```

<a id="Discussion"></a>

## Discussion

The amount of the receiver’s image that’s displayed above or to the left of the ruler view’s baseline, the height for a horizontal ruler or width for a vertical ruler.

### Setting the image

- [image](image.md): The receiver’s image.
- [imageOrigin](imageorigin.md): The point in the receiver’s image that is positioned at the receiver’s location on the ruler view.
- [imageRectInRuler](imagerectinruler.md): The rectangle occupied by the receiver’s image.
