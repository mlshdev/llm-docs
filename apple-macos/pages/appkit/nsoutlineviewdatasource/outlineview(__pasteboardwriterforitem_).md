# outlineView(\_:pasteboardWriterForItem:) (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS 10.7+

Implement this method to enable the table to be an `NSDraggingSource` that supports dragging multiple items.

## Declaration

```swift
@MainActor optional func outlineView(_ outlineView: NSOutlineView, pasteboardWriterForItem item: Any) -> (any NSPasteboardWriting)?
```

## Parameters

- `outlineView`: The outline view in which the drag begins.
- `item`: The item for which to return a pasteboard writer.

<a id="return-value"></a>

## Return Value

A custom object that implements `NSPasteboardWriting` protocol (or simply use `NSPasteboardItem`).

<a id="Discussion"></a>

## Discussion

If this method is implemented, then [outlineView(\_:writeItems:to:)](outlineview%28__writeitems_to_%29.md) is not called.
