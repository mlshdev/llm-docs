# App-Specific Attributes (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Attributes that are specific to the app object.

## Topics

### Constants

- [focusedUIElement](nsaccessibility-swift.struct/attribute/focuseduielement.md): Deprecated. The element with the current focus (`id`).
- [focusedWindow](nsaccessibility-swift.struct/attribute/focusedwindow.md): The app’s window that has current focus (`id`).
- [frontmost](nsaccessibility-swift.struct/attribute/frontmost.md): A flag that indicates whether the app is frontmost (`NSNumber`).
- [hidden](nsaccessibility-swift.struct/attribute/hidden.md): A flag that indicates whether the app is hidden (`NSNumber`).
- [mainWindow](nsaccessibility-swift.struct/attribute/mainwindow.md): The app’s main window (`id`).
- [menuBar](nsaccessibility-swift.struct/attribute/menubar.md): The app’s menu bar (`id`).
- [windows](nsaccessibility-swift.struct/attribute/windows.md): The app’s windows (`NSArray`).
- [extrasMenuBar](nsaccessibility-swift.struct/attribute/extrasmenubar.md): The app extras menu bar (`id`).
