# Miscellaneous Attributes (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Miscellaneous attributes that can apply to various types of elements.

## Topics

### Constants

- [clearButton](nsaccessibility-swift.struct/attribute/clearbutton.md): Deprecated. The element that represents the clear button in a search field (`id`).
- [columnTitles](nsaccessibility-swift.struct/attribute/columntitles.md): The elements that represent the column titles (`NSArray`).
- [decrementButton](nsaccessibility-swift.struct/attribute/decrementbutton.md): The element that represents a stepper’s decrement button (`id`).
- [document](nsaccessibility-swift.struct/attribute/document.md): The URL for the file represented by the element (`NSString`).
- [edited](nsaccessibility-swift.struct/attribute/edited.md): A flag that indicates whether the element has been modified (`NSNumber`).
- [expanded](nsaccessibility-swift.struct/attribute/expanded.md): A flag that indicates whether the element is expanded (`NSNumber`).
- [filename](nsaccessibility-swift.struct/attribute/filename.md): The filename associated with the element (`NSString`).
- [header](nsaccessibility-swift.struct/attribute/header.md): The element that represents a table view’s header (`id`).
- [horizontalScrollBar](nsaccessibility-swift.struct/attribute/horizontalscrollbar.md): The element that represents a scroll view’s horizontal scroll bar (`id`).
- [incrementButton](nsaccessibility-swift.struct/attribute/incrementbutton.md): The element that represents a stepper’s increment button (`id`).
- [index](nsaccessibility-swift.struct/attribute/index.md): The index of the row or column represented by the element (`NSValue`).
- [nextContents](nsaccessibility-swift.struct/attribute/nextcontents.md): The elements representing the contents that follow the current divider element, such as a subview adjacent to a split view’s splitter element (`NSArray`).
- [orientation](nsaccessibility-swift.struct/attribute/orientation.md): The element’s orientation.
- [overflowButton](nsaccessibility-swift.struct/attribute/overflowbutton.md): The element that represents a toolbar’s overflow button (`id`).
- [previousContents](nsaccessibility-swift.struct/attribute/previouscontents.md): The elements representing the contents that precede the current divider element, such as a subview adjacent to a split view’s splitter bar element (`NSArray`).
- [searchButton](nsaccessibility-swift.struct/attribute/searchbutton.md): The element that represents the search button in a search field (`id`).
- [searchMenu](nsaccessibility-swift.struct/attribute/searchmenu.md): The element that represents the menu in a search field (`id`).
- [selected](nsaccessibility-swift.struct/attribute/selected.md): A flag that indicates whether the element is selected (`NSNumber`).
- [splitters](nsaccessibility-swift.struct/attribute/splitters.md): The views and splitter bar in a split view (`NSArray`).
- [tabs](nsaccessibility-swift.struct/attribute/tabs.md): The tab elements in a tab view (`NSArray`).
- [url](nsaccessibility-swift.struct/attribute/url.md): The URL associated with the element (`NSURL`).
- [verticalScrollBar](nsaccessibility-swift.struct/attribute/verticalscrollbar.md): The element that represents the vertical scroll bar in a scroll view (`id`).
- [warningValue](nsaccessibility-swift.struct/attribute/warningvalue.md): The warning value in a level indicator (typically, `NSNumber`).
- [criticalValue](nsaccessibility-swift.struct/attribute/criticalvalue.md): The critical value in a level indicator (typically, `NSNumber`).
- [placeholderValue](nsaccessibility-swift.struct/attribute/placeholdervalue.md): The placeholder value for a control, such as a text field (`NSString`).
- [containsProtectedContent](nsaccessibility-swift.struct/attribute/containsprotectedcontent.md): A flag that indicates whether the object contains protected content.
- [identifier](nsaccessibility-swift.struct/attribute/identifier.md): The identity of the element (`NSString`).
