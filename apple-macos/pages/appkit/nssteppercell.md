# NSStepperCell (Swift)

**Framework:** AppKit  
**Kind:** Class  
**Availability:** macOS

An `NSStepperCell` object controls the appearance and behavior of an [NSStepper](nsstepper.md) object.

## Declaration

```swift
class NSStepperCell
```

## Topics

### Specifying value range

- [maxValue](nssteppercell/maxvalue.md): The maximum value for the receiver.
- [minValue](nssteppercell/minvalue.md): The minimum value for the receiver.
- [increment](nssteppercell/increment.md): The amount by which the receiver will change per increment or decrement.

### Specifying how stepper cell responds

- [autorepeat](nssteppercell/autorepeat.md): A Boolean value indicating how the receiver responds to mouse events.
- [valueWraps](nssteppercell/valuewraps.md): A Boolean value indicating whether the receiver wraps around the minimum and maximum values.
