# NSMiterLineJoinStyle

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+ (deprecated in 11.0)

Specifies a miter line shape of the joints between connected segments of a stroked path.

> Use [NSLineJoinStyleMiter](nsbezierpath/linejoinstyle-swift.enum/miter.md) instead.
