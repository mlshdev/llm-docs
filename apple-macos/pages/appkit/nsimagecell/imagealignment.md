# imageAlignment (Swift)

**Framework:** AppKit  
**Kind:** Instance Property  
**Availability:** macOS

The alignment of the receiver’s image relative to its frame.

## Declaration

```swift
var imageAlignment: NSImageAlignment { get set }
```

<a id="Discussion"></a>

## Discussion

For a list of possible values, see [NSImageAlignment](../nsimagealignment.md). The default value is `NSImageAlignCenter`.

## See Also

### Related Documentation

- [NSImageCell](../nsimagecell.md): An `NSImageCell` object displays a single image (encapsulated in an [NSImage](../nsimage.md) object) in a frame. This class provides methods for choosing the frame and for aligning and scaling the image to fit the frame.

### Aligning and Scaling the Image

- [imageScaling](imagescaling.md): The scaling mode used to fit the receiver’s image into the frame.
