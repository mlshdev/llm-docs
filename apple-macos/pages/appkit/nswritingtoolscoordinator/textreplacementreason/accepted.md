# NSWritingToolsCoordinator.TextReplacementReason.accepted (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS 27.0+

An option to replace the text in your view when a grammar suggestion is accepted.

## Declaration

```swift
case accepted
```

<a id="discussion"></a>

## Discussion

When the user interacts with a grammar issue and the UI is shown, and the option to accept a suggestion is chosen, this reason will be used. Update your view’s text storage without animating the change.
