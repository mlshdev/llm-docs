# unscript(\_:) (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS

This action method removes any superscripting or subscripting from selected text (or all text if the receiver is a plain text object).

## Declaration

```swift
func unscript(_ sender: Any?)
```
