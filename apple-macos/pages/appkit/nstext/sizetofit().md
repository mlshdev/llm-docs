# sizeToFit() (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS

Resizes the receiver to fit its text.

## Declaration

```swift
func sizeToFit()
```

<a id="Discussion"></a>

## Discussion

The text view will not be sized any smaller than its minimum size, however.

## See Also

### Constraining size

- [maxSize](maxsize.md): The receiver’s maximum size.
- [minSize](minsize.md): The receiver’s minimum size.
- [isVerticallyResizable](isverticallyresizable.md): A Boolean that controls whether the receiver changes its height to fit the height of its text.
- [isHorizontallyResizable](ishorizontallyresizable.md): A Boolean that controls whether the receiver changes its width to fit the width of its text.
