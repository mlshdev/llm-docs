# NSTimeoutDocumentOption

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS

The time, in seconds, to wait for a document to finish loading.

## Declaration

```objectivec
extern NSAttributedStringDocumentReadingOptionKey NSTimeoutDocumentOption;
```

<a id="discussion"></a>

## Discussion

The value is an [NSNumber](https://developer.apple.com/documentation/foundation/nsnumber) object containing a float. The previous string constant was `@"Timeout"`.
