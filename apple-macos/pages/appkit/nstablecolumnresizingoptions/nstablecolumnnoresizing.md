# NSTableColumnNoResizing

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Enumeration Case  
**Availability:** macOS

Prevents the table column from resizing.

## Declaration

```objectivec
NSTableColumnNoResizing
```
