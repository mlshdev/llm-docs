# Grid View Attributes (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Attributes that are used with grid views, such as thumbnails and media browsers that present a grid of items. The children of a grid are ordered.

## Topics

### Constants

- [columnCount](nsaccessibility-swift.struct/attribute/columncount.md): Deprecated. The number of columns in the grid (`NSNumber` as `intValue`).
- [orderedByRow](nsaccessibility-swift.struct/attribute/orderedbyrow.md): A flag that indicates whether the grid is in row major or column major order.
- [rowCount](nsaccessibility-swift.struct/attribute/rowcount.md): The number of rows in the grid (`NSNumber` as `intValue`).
