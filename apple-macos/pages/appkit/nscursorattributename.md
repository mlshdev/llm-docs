# NSCursorAttributeName

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS

The cursor object.

## Declaration

```objectivec
extern NSAttributedStringKey NSCursorAttributeName;
```

<a id="discussion"></a>

## Discussion

The value of this attribute is an [NSCursor](nscursor.md) object. The default value is the cursor returned by the [IBeamCursor](nscursor/ibeam.md) method.
