# absoluteX (Swift)

**Framework:** AppKit  
**Kind:** Instance Property  
**Availability:** macOS

The absolute x coordinate of a pointing device on its tablet at full tablet resolution.

## Declaration

```swift
var absoluteX: Int { get }
```

<a id="Discussion"></a>

## Discussion

For the coordinate to be valid, this event must be generated by a tablet pointing device (otherwise the property is set to `0`). This property is valid only for mouse events with a subtype of `NSTabletPointEventSubtype` and for events of type `NSTabletPoint`. Use this value if you want to scale from tablet location to screen location yourself; otherwise use the class method [mouseLocation](mouselocation.md) or the instance method [locationInWindow](locationinwindow.md).
