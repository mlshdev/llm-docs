# NSWritingToolsBehavior.default (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS 15.0+

An option to let the system determine the best way to enable Writing Tools for the view.

## Declaration

```swift
case `default`
```

<a id="Discussion"></a>

## Discussion

The system chooses a complete, limited, or none experience based on the device-level support for the feature.

## See Also

### Getting the Writing Tools behaviors

- [NSWritingToolsBehavior.none](none.md): An option to prevent Writing Tools from modifying the text in the view.
- [NSWritingToolsBehavior.complete](complete.md): An option to provide the complete Writing Tools experience for the text view.
- [NSWritingToolsBehavior.limited](limited.md): An option to provide a limited, overlay-panel experience for the text view.
