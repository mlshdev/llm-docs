# bitsPerSample (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS

The corresponding value is an `NSNumber` object containing an integer that gives the bit depth of the window’s raster image (2-bit, 8-bit, and so forth).

## Declaration

```swift
static let bitsPerSample: NSDeviceDescriptionKey
```
