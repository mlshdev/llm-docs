# isPaneSplitter

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS 10.0+ (deprecated in 10.6)

The type of pane splitter.

> This functionality is no longer relevant and there is no alternative method.

## Declaration

```objectivec
- (BOOL) isPaneSplitter;
```

<a id="return-value"></a>

## Return Value

[true](https://developer.apple.com/documentation/swift/true) if the split view’s splitter is a bar that goes across the split view; [false](https://developer.apple.com/documentation/swift/false) if the splitter is a thumb on the regular background pattern.
