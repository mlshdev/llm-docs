# NSCollectionElementCategory.interItemGap (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** Mac Catalyst 13.1+ · macOS 10.11+

The element is an inter-item gap. An inter-item gap element is a custom visual indicator that is displayed between items when dropping items into the collection view.

## Declaration

```swift
case interItemGap
```

## See Also

### Constants

- [NSCollectionElementCategory.item](item.md): The element is an item. Items represent the main content of your collection view.
- [NSCollectionElementCategory.supplementaryView](supplementaryview.md): The element is a supplementary view. Use supplementary views for single views that contain some data but are associated with an entire section. For example, use them to specify header or footer views for a section.
- [NSCollectionElementCategory.decorationView](decorationview.md): The element is a decoration view. Decoration views represent visual adornments that do not contain any data of their own.
