# Browser View

**Interface languages:** Swift, Objective-C

**Framework:** AppKit  
**Kind:** API Collection

Provide a column-based interface for viewing and navigating hierarchical information.

## Topics

### View

- [NSBrowser](nsbrowser.md): An interface that displays a hierarchically organized list of data items that can be navigated and selected.

### Management

- [NSBrowserDelegate](nsbrowserdelegate.md): A set of methods that a browser delegate implements to manage selection, scrolling, sizing, and other behavior.

### Cell

- [NSBrowserCell](nsbrowsercell.md): The user interface of a browser.

- [Table View](table-view.md): Display custom data in rows and columns.
