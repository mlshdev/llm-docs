# setAcceptsArrowKeys:

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS 10.0+ (deprecated in 10.6)

Specifies whether the browser allows navigation using the arrow keys.

> There is no replacement.

## Declaration

```objectivec
- (void) setAcceptsArrowKeys:(BOOL) flag;
```

## Parameters

- `flag`: [true](https://developer.apple.com/documentation/swift/true) to enable the use of the arrow keys for navigating within and between browsers; otherwise, [false](https://developer.apple.com/documentation/swift/false).
