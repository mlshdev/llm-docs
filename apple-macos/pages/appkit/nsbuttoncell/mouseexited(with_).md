# mouseExited(with:) (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS

Erases the button’s border.

## Declaration

```swift
func mouseExited(with event: NSEvent)
```

## Parameters

- `event`: The event object generated by the mouse movement.

<a id="Discussion"></a>

## Discussion

This method is called only when the pointer moves off the button and the value of [showsBorderOnlyWhileMouseInside](showsborderonlywhilemouseinside.md) is [true](https://developer.apple.com/documentation/swift/true).
