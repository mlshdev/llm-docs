# mouseEntered(with:) (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS

Draws the button’s border.

## Declaration

```swift
func mouseEntered(with event: NSEvent)
```

## Parameters

- `event`: The event object generated by the mouse movement.

<a id="Discussion"></a>

## Discussion

This method is called only when the pointer moves onto the button and the value of [showsBorderOnlyWhileMouseInside](showsborderonlywhilemouseinside.md) is [true](https://developer.apple.com/documentation/swift/true).

### Handling Events and Action Messages
