# NSAppKitVersionNumberWithDeferredWindowDisplaySupport

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS

The specific version of the AppKit framework that introduced support for deferred window display.

## Declaration

```objectivec
static const NSAppKitVersion NSAppKitVersionNumberWithDeferredWindowDisplaySupport;
```

<a id="Discussion"></a>

## Discussion

Developers should not need to use this constant unless they are writing applications for OS X v10.5 and earlier.
