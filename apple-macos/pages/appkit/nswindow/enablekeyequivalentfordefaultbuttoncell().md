# enableKeyEquivalentForDefaultButtonCell() (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS

Reenables the default button cell’s key equivalent, so it performs a click when the user presses Return (or Enter).

## Declaration

```swift
func enableKeyEquivalentForDefaultButtonCell()
```

## See Also

### Managing Default Buttons

- [defaultButtonCell](defaultbuttoncell.md): The button cell that performs as if clicked when the window receives a Return (or Enter) key event.
- [disableKeyEquivalentForDefaultButtonCell()](disablekeyequivalentfordefaultbuttoncell%28%29.md): Disables the default button cell’s key equivalent, so it doesn’t perform a click when the user presses Return (or Enter).
