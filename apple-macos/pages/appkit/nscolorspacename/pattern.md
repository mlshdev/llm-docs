# pattern (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS

Pattern image (tiled)

## Declaration

```swift
static let pattern: NSColorSpaceName
```

<a id="Discussion"></a>

## Discussion

Identifies a pattern color space, which is simply an image that is repeated over and over again in a tiled pattern.

### Color Space Names

- [calibratedWhite](calibratedwhite.md): Calibrated color space with white and alpha components (pure white is 1.0)
