# activateAllWindows (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS

By default, activation brings only the main and key windows forward.  If you specify NSApplicationActivateAllWindows, all of the application’s windows are brought forward.
