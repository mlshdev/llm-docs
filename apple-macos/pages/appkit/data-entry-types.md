# Data Entry Types (Swift)

**Framework:** AppKit  
**Kind:** API Collection

# Data Entry Types (Objective-C)

**Framework:** AppKit  
**Kind:** API Collection

These constants specify how a cell formats numeric data.

<a id="overview"></a>

## Overview

These constants are used by [setEntryType:](nscell/setentrytype_.md) and [entryType](nscell/entrytype.md).

## Topics

### Constants

- [NSIntType](nsinttype.md): Deprecated. Must be between `INT_MIN` and `INT_MAX`.
- [NSPositiveIntType](nspositiveinttype.md): Deprecated. Must be between 1 and `INT_MAX`.
- [NSFloatType](nsfloattype.md): Deprecated. Must be between `–FLT_MAX` and `FLT_MAX`.
- [NSPositiveFloatType](nspositivefloattype.md): Deprecated. Must be between `FLT_MIN` and `FLT_MAX`.
- [NSDoubleType](nsdoubletype.md): Deprecated. Must be between `–FLT_MAX` and `FLT_MAX`.
- [NSPositiveDoubleType](nspositivedoubletype.md): Deprecated. Must be between `FLT_MIN` and `FLT_MAX`.
- [NSAnyType](nsanytype.md): Deprecated. Any value is allowed.
