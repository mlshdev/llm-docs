# rightAnchor (Swift)

**Framework:** AppKit  
**Kind:** Instance Property  
**Availability:** macOS 10.11+

A layout anchor representing the right edge of the layout guide’s frame.

## Declaration

```swift
var rightAnchor: NSLayoutXAxisAnchor { get }
```

<a id="Discussion"></a>

## Discussion

Use this anchor to create constraints with the layout guide’s right edge. You can combine this anchor only with a subset of the [NSLayoutXAxisAnchor](https://developer.apple.com/documentation/uikit/nslayoutxaxisanchor) anchors. You can combine a [rightAnchor](rightanchor.md) with another `rightAnchor`, a `leftAnchor`, or a `centerXAnchor`. For more information, see [NSLayoutAnchor](https://developer.apple.com/documentation/uikit/nslayoutanchor).
