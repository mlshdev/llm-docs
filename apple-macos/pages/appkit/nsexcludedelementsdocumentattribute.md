# NSExcludedElementsDocumentAttribute

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS

The HTML elements to exclude in generated HTML.

## Declaration

```objectivec
extern NSAttributedStringDocumentAttributeKey NSExcludedElementsDocumentAttribute;
```

<a id="discussion"></a>

## Discussion

An [NSArray](https://developer.apple.com/documentation/foundation/nsarray) object containing [NSString](https://developer.apple.com/documentation/foundation/nsstring) objects, representing HTML elements not to be used in generated HTML.
