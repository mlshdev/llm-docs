# drawsBackground (Swift)

**Framework:** AppKit  
**Kind:** Instance Property  
**Availability:** macOS

A Boolean that indicates whether the matrix draws its background.

## Declaration

```swift
var drawsBackground: Bool { get set }
```

<a id="Discussion"></a>

## Discussion

When the value of this property is [true](https://developer.apple.com/documentation/swift/true), the matrix draws its background (the space between the cells).

## See Also

### Modifying Graphics Attributes

- [backgroundColor](backgroundcolor.md): The background color of the matrix (the space between the cells).
- [cellBackgroundColor](cellbackgroundcolor.md): The background color of the matrix’s cells.
- [drawsCellBackground](drawscellbackground.md): A Boolean that indicates whether the matrix draws the background within each of its cells.
