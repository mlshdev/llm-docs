# Actions (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Standard actions that accessibility objects can perform.

## Topics

### Constants

- [confirm](nsaccessibility-swift.struct/action/confirm.md): Deprecated. An action that simulates pressing Return in the object, such as a text field.
- [decrement](nsaccessibility-swift.struct/action/decrement.md): An action that decrements the value of the object.
- [delete](nsaccessibility-swift.struct/action/delete.md): An action that deletes the value of the object.
- [increment](nsaccessibility-swift.struct/action/increment.md): An action that increments the value of the object.
- [pick](nsaccessibility-swift.struct/action/pick.md): An action that selects the object, such as a menu item.
- [press](nsaccessibility-swift.struct/action/press.md): An action that simulates clicking an object, such as a button.
- [cancel](nsaccessibility-swift.struct/action/cancel.md): An action that cancels the operation.
- [raise](nsaccessibility-swift.struct/action/raise.md): An action that simulates bringing a window forward by clicking on its title bar.
- [scrollToVisibleAction](nsaccessibility-swift.struct/action/scrolltovisibleaction.md)
- [showAlternateUI](nsaccessibility-swift.struct/action/showalternateui.md): An action that shows an alternate UI, for example, during a mouse-hover event.
- [showDefaultUI](nsaccessibility-swift.struct/action/showdefaultui.md): An action that shows the original or default UI; for example, during a mouse-hover event.
- [showMenu](nsaccessibility-swift.struct/action/showmenu.md): An action that simulates showing a menu by clicking on it.
