# NSWritingDirectionFormatType.override (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS 10.11+

Enables character types with inherent directionality to be overridden when required for special cases, such as for part numbers made of mixed English, digits, and Hebrew letters to be written from right to left.

## Declaration

```swift
case override
```

## See Also

### Constants

- [NSWritingDirectionFormatType.embedding](embedding.md): Text is embedded in text with another writing direction. For example, an English quotation in the middle of an Arabic sentence could be marked as being embedded left-to-right text.
