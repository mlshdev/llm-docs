# NSBindingName (Swift)

**Framework:** AppKit  
**Kind:** Structure  
**Availability:** macOS

Values that specify a binding for certain methods.

## Declaration

```swift
struct NSBindingName
```

<a id="Discussion"></a>

## Discussion

The following values are used to specify a binding to [bind(\_:to:withKeyPath:options:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/bind%28_:to:withkeypath:options:%29), [infoForBinding(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/infoforbinding%28_:%29), [unbind(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/unbind%28_:%29) and [valueClassForBinding(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/valueclassforbinding%28_:%29). See [Cocoa Bindings Reference](https://developer.apple.com/library/archive/documentation/Cocoa/Reference/CocoaBindingsRef/CocoaBindingsRef.html#//apple_ref/doc/uid/10000189i) for more information.
