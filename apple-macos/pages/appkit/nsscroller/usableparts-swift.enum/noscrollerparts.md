# NSScroller.UsableParts.noScrollerParts (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

Specifies that the scroller has neither a knob nor scroll buttons, only the knob slot.

> This enum is not needed in macOS 10.7 and later.
