# Mode Masks

**Interface languages:** Swift, Objective-C

**Framework:** AppKit  
**Kind:** API Collection

Constants that represent the available font panel mode masks.

<a id="overview"></a>

## Overview

The [validModesForFontPanel:](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/validmodesforfontpanel:) method returns these constants.

## Topics

### Constants

- [NSFontPanelFaceModeMask](nsfontpanelfacemodemask.md): Display the typeface column.
- [NSFontPanelSizeModeMask](nsfontpanelsizemodemask.md): Display the font size column.
- [NSFontPanelCollectionModeMask](nsfontpanelcollectionmodemask.md): Display the font collections column.
- [NSFontPanelUnderlineEffectModeMask](nsfontpanelunderlineeffectmodemask.md): Display the underline popup menu.
- [NSFontPanelStrikethroughEffectModeMask](nsfontpanelstrikethrougheffectmodemask.md): Display the strike-through popup menu.
- [NSFontPanelTextColorEffectModeMask](nsfontpaneltextcoloreffectmodemask.md): Display the text color button.
- [NSFontPanelDocumentColorEffectModeMask](nsfontpaneldocumentcoloreffectmodemask.md): Display the document color button.
- [NSFontPanelShadowEffectModeMask](nsfontpanelshadoweffectmodemask.md): Display the shadow effects button.
- [NSFontPanelAllEffectsModeMask](nsfontpanelalleffectsmodemask.md): Display all the effects user interface items.
- [NSFontPanelStandardModesMask](nsfontpanelstandardmodesmask.md): Display the standard default font panel—that is, including the collections, typeface, and size columns.
- [NSFontPanelAllModesMask](nsfontpanelallmodesmask.md): Display all the available adornments.
