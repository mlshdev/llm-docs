# NSButton.ButtonType.radio (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

A button that displays a single selected value from group of possible choices.

## Declaration

```swift
case radio
```

<a id="Discussion"></a>

## Discussion

A radio button is similar to a [NSButton.ButtonType.switch](switch.md) button, but it constrains the selection to a single button within a group.

Radio buttons are ideal for choosing one value from a small number of options.

This option corresponds to the Radio type in Interface Builder’s Attributes Inspector.
