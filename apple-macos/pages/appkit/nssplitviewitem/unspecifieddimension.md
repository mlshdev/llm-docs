# unspecifiedDimension (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS 10.11+

A constant that resets a dimension’s value.

## Declaration

```swift
class let unspecifiedDimension: CGFloat
```

<a id="Discussion"></a>

## Discussion

Use this constant with any sizing-related [NSSplitViewItem](../nssplitviewitem.md) property to reset its value to the standard system default.

## See Also

### Managing the item thickness

- [automaticMaximumThickness](automaticmaximumthickness.md): The maximum thickness of the split view item when it resizes due to automatic sizing.
- [preferredThicknessFraction](preferredthicknessfraction.md): The preferred thickness of the split view item relative to the split view.
- [minimumThickness](minimumthickness.md): The minimum thickness of the split view item.
- [maximumThickness](maximumthickness.md): The maximum thickness of the split view item.
