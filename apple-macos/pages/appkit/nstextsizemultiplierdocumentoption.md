# NSTextSizeMultiplierDocumentOption

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS

The scale factor for font sizes.

## Declaration

```objectivec
extern NSAttributedStringDocumentReadingOptionKey NSTextSizeMultiplierDocumentOption;
```

<a id="discussion"></a>

## Discussion

[NSNumber](https://developer.apple.com/documentation/foundation/nsnumber) containing float, default `1.0`; for HTML only, corresponding to WebView’s `textSizeMultiplier`.
