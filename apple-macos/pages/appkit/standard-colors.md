# Standard colors (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Retrieve the standard color objects for common colors like red, blue, green, black, white, and more.

<a id="overview"></a>

## Overview

For design guidance, see [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/macos/visual-design/color#system-colors).

## Topics

### Adaptable system colors

- [systemBlue](nscolor/systemblue.md): Returns a color object for blue that automatically adapts to vibrancy and accessibility settings.
- [systemBrown](nscolor/systembrown.md): Returns a color object for brown that automatically adapts to vibrancy and accessibility settings.

- [systemGreen](nscolor/systemgreen.md): Returns a color object for green that automatically adapts to vibrancy and accessibility settings.

- [systemMint](nscolor/systemmint.md): Returns a color object for mint that automatically adapts to vibrancy and accessibility settings.
- [systemOrange](nscolor/systemorange.md): Returns a color object for orange that automatically adapts to vibrancy and accessibility settings.
- [systemPink](nscolor/systempink.md): Returns a color object for pink that automatically adapts to vibrancy and accessibility settings.
- [systemPurple](nscolor/systempurple.md): Returns a color object for purple that automatically adapts to vibrancy and accessibility settings.
- [systemRed](nscolor/systemred.md): Returns a color object for red that automatically adapts to vibrancy and accessibility settings.
- [systemTeal](nscolor/systemteal.md): Returns a color object for teal that automatically adapts to vibrancy and accessibility settings.
- [systemYellow](nscolor/systemyellow.md): Returns a color object for yellow that automatically adapts to vibrancy and accessibility settings.

### Transparent color

- [clear](nscolor/clear.md): Returns a color object whose grayscale and alpha values are both `0.0`.

### Fixed colors

- [black](nscolor/black.md): Returns a color object whose grayscale value is `0.0` and whose alpha value is `1.0`.
- [blue](nscolor/blue.md): Returns a color object whose RGB value is `0.0`, `0.0`, `1.0` and whose alpha value is `1.0`.
- [brown](nscolor/brown.md): Returns a color object whose RGB value is `0.6`, `0.4`, `0.2` and whose alpha value is `1.0`.
- [cyan](nscolor/cyan.md): Returns a color object whose RGB value is `0.0`, `1.0`, `1.0` and whose alpha value is `1.0`.
- [darkGray](nscolor/darkgray.md): Returns a color object whose grayscale value is `1/3` and whose alpha value is `1.0`.
- [gray](nscolor/gray.md): Returns a color object whose grayscale value is `0.5` and whose alpha value is `1.0`.
- [green](nscolor/green.md): Returns a color object whose RGB value is `0.0`, `1.0`, `0.0` and whose alpha value is `1.0`.
- [lightGray](nscolor/lightgray.md): Returns a color object whose grayscale value is `2/3` and whose alpha value is `1.0`.
- [magenta](nscolor/magenta.md): Returns a color object whose RGB value is `1.0`, `0.0`, `1.0` and whose alpha value is `1.0`.
- [orange](nscolor/orange.md): Returns a color object whose RGB value is `1.0`, `0.5`, `0.0` and whose alpha value is `1.0`.
- [purple](nscolor/purple.md): Returns a color object whose RGB value is `0.5`, `0.0`, `0.5` and whose alpha value is `1.0`.
- [red](nscolor/red.md): Returns a color object whose RGB value is `1.0`, `0.0`, `0.0` and whose alpha value is `1.0`.
- [white](nscolor/white.md): Returns a color object whose grayscale and alpha values are both `1.0`.
- [yellow](nscolor/yellow.md): Returns a color object whose RGB value is `1.0`, `1.0`, `0.0` and whose alpha value is `1.0`.
