# NSAlert.Style.informational (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

An alert style to inform someone about a current or impending event.

## Declaration

```swift
case informational
```

<a id="Discussion"></a>

## Discussion

Use this style of alert when the alert’s content is less severe than [NSAlert.Style.warning](warning.md).

> **Note**

>  This alert style has the same visual appearance as [NSAlert.Style.warning](warning.md).

## See Also

### Enumeration Cases

- [NSAlert.Style.critical](critical.md): An alert style to inform someone about a critical event.
- [NSAlert.Style.warning](warning.md): An alert style to warn someone about a current or impending event.
