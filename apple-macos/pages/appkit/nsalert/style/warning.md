# NSAlert.Style.warning (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

An alert style to warn someone about a current or impending event.

## Declaration

```swift
case warning
```

<a id="Discussion"></a>

## Discussion

Use this style of alert when the alert’s content is more severe than [NSAlert.Style.informational](informational.md) but less severe than [NSAlert.Style.critical](critical.md). This is the default alert style.

## See Also

### Enumeration Cases

- [NSAlert.Style.critical](critical.md): An alert style to inform someone about a critical event.
- [NSAlert.Style.informational](informational.md): An alert style to inform someone about a current or impending event.
