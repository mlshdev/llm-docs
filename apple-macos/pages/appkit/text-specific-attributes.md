# Text-Specific Attributes (Swift)

**Framework:** AppKit  
**Kind:** API Collection

Attributes that are specific to text.

## Topics

### Constants

- [insertionPointLineNumber](nsaccessibility-swift.struct/attribute/insertionpointlinenumber.md): Deprecated. The line number containing the insertion point (`NSNumber`).
- [numberOfCharacters](nsaccessibility-swift.struct/attribute/numberofcharacters.md): The number of characters in the text (`NSNumber`).
- [selectedText](nsaccessibility-swift.struct/attribute/selectedtext.md): The currently selected text (`NSString`).
- [selectedTextRange](nsaccessibility-swift.struct/attribute/selectedtextrange.md): The range of selected text (`NSValue`).
- [selectedTextRanges](nsaccessibility-swift.struct/attribute/selectedtextranges.md): An array of `NSValue` (`rangeValue`) ranges of selected text (`NSArray`).
- [sharedCharacterRange](nsaccessibility-swift.struct/attribute/sharedcharacterrange.md): The (`rangeValue`) part of shared text in this view (`NSValue`).
- [sharedTextUIElements](nsaccessibility-swift.struct/attribute/sharedtextuielements.md): The elements with which the text of this element is shared (`NSArray`).
- [visibleCharacterRange](nsaccessibility-swift.struct/attribute/visiblecharacterrange.md): The range of visible text (`NSValue`).
