# NSButtLineCapStyle

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+ (deprecated in 11.0)

Specifies a butt line cap style for endpoints for an open path when stroked.

> Use [NSLineCapStyleButt](nsbezierpath/linecapstyle-swift.enum/butt.md) instead.
