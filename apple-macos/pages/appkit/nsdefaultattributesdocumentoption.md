# NSDefaultAttributesDocumentOption

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+

The default attributes to apply to plain files.

## Declaration

```objectivec
extern NSAttributedStringDocumentReadingOptionKey NSDefaultAttributesDocumentOption;
```

<a id="discussion"></a>

## Discussion

For plain text documents; [NSDictionary](https://developer.apple.com/documentation/foundation/nsdictionary) containing attributes to be applied to plain files. The previous string constant was `@"DefaultAttributes"`.
