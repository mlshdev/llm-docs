# NSFocusRingType.none (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

No focus ring.

## Declaration

```swift
case none
```

<a id="Discussion"></a>

## Discussion

If you set the focus ring type to this value, [NSView](../nsview.md) and [NSCell](../nscell.md) do not draw any focus ring.
