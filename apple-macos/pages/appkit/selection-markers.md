# Selection Markers

**Interface languages:** Swift, Objective-C

**Framework:** AppKit  
**Kind:** API Collection

The following constants are used to describe special cases for a controller’s selection.

## Topics

### Constants

- [NSMultipleValuesMarker](nsmultiplevaluesmarker.md): Deprecated. This marker indicates that a key’s value contains multiple values that differ.
- [NSNoSelectionMarker](nsnoselectionmarker.md): Deprecated. This marker indicates that the controller’s selection is currently empty.
- [NSNotApplicableMarker](nsnotapplicablemarker.md): Deprecated. This marker indicates that an object is not key-value coding compliant for the requested key.
