# NSColor.ColorType.catalog (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

Colors that are retrieved from an asset catalog.

## Declaration

```swift
case catalog
```

<a id="Discussion"></a>

## Discussion

Colors of this type have values for the [catalogNameComponent](../catalognamecomponent.md) and [colorNameComponent](../colornamecomponent.md) properties. A color of this type may also have device- and appearance-specific representations, allowing you to convert it to other types.

## See Also

### Color Types

- [NSColor.ColorType.componentBased](componentbased.md): Colors that include floating-point color components and a color space.
- [NSColor.ColorType.pattern](pattern.md): Colors that include an image to be used as a pattern.
