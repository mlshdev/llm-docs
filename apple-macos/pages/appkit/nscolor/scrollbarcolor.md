# scrollBarColor (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS 10.0+ (deprecated in 11.0)

The system color used for scroll “bars”—that is, for the groove in which a scroller’s knob moves

> Use [NSScroller](../nsscroller.md) instead.

## Declaration

```swift
class var scrollBarColor: NSColor { get }
```

<a id="return-value"></a>

## Return Value

The system color used for scroll bars. For more information, see [NSColor](../nscolor.md).
