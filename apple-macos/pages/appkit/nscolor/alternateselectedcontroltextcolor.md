# alternateSelectedControlTextColor (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS

The color to use for text in a selected control.

## Declaration

```swift
class var alternateSelectedControlTextColor: NSColor { get }
```

<a id="Discussion"></a>

## Discussion

This color is the table and list view equivalent to the [selectedControlTextColor](selectedcontroltextcolor.md) color, which is used for controls in other views.

For more information, see [NSColor](../nscolor.md).
