# controlLightHighlightColor (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS 10.0+ (deprecated in 11.0)

The system color used for light highlights in controls.

> Use a color that matches the semantics being used.

## Declaration

```swift
class var controlLightHighlightColor: NSColor { get }
```

<a id="return-value"></a>

## Return Value

Of the two light borders that run along the top and left of controls, representing reflections from a light source in the upper left, the color of the outer, brighter border. For more information, see [NSColor](../nscolor.md).
