# textColor (Swift)

**Framework:** AppKit  
**Kind:** Type Property  
**Availability:** macOS

The color to use for text.

## Declaration

```swift
class var textColor: NSColor { get }
```

<a id="Discussion"></a>

## Discussion

When text is selected, its color changes to the return value of [selectedTextColor](selectedtextcolor.md).
