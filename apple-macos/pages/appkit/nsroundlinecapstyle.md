# NSRoundLineCapStyle

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+ (deprecated in 11.0)

Specifies a round line cap style for endpoints for an open path when stroked.

> Use [NSLineCapStyleRound](nsbezierpath/linecapstyle-swift.enum/round.md) instead.
