# endRefreshing() (Swift)

**Framework:** AppKit  
**Kind:** Instance Method  
**Availability:** macOS 27.0+

Tells the refresh controller that a refresh operation has ended.

## Declaration

```swift
func endRefreshing()
```

<a id="discussion"></a>

## Discussion

Call this method when your refresh operation completes. The refresh controller returns to its default appearance and exits the refreshing state.
