# NSRoundLineJoinStyle

**Interface language:** Objective-C

**Framework:** AppKit  
**Kind:** Global Variable  
**Availability:** macOS 10.0+ (deprecated in 11.0)

Specifies a round line shape of the joints between connected segments of a stroked path.

> Use [NSLineJoinStyleRound](nsbezierpath/linejoinstyle-swift.enum/round.md) instead.
