# NSAnimation.Curve.easeInOut (Swift)

**Framework:** AppKit  
**Kind:** Case  
**Availability:** macOS

Describes an S-curve in which the animation slowly speeds up and then slows down near the end of the animation. This constant is the default.

## Declaration

```swift
case easeInOut
```

## See Also

### Constants

- [NSAnimation.Curve.easeIn](easein.md): Describes an animation that slows down as it reaches the end.
- [NSAnimation.Curve.easeOut](easeout.md): Describes an animation that slowly speeds up from the start.
- [NSAnimation.Curve.linear](linear.md): Describes an animation in which there is no change in frame rate.
