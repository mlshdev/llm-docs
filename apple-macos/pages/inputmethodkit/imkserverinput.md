# IMKServerInput (Swift)

**Framework:** InputMethodKit

`IMKServerInput` is an informal protocol that defines methods for receiving text events. This is intentionally not a formal protocol because there are three ways to receive events. An input method chooses one of the following approaches and implements the appropriate methods:

<a id="overview"></a>

## Overview

- Key binding. In this approach the system tries to map each key-down event to an action method that the input method has implemented.  If successful (action method found), the system calls `didCommandBySelector:client:`.  If unsuccessful (action method not found), the system calls `inputText:client:`.  For this approach you need to implement [inputText(\_:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/inputtext%28_:client:%29) and [didCommand(by:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/didcommand%28by:client:%29).
- Text data only. In this approach, you opt to receive all key events without the key binding, and then unpack  the relevant text data.   Key events are broken down into the Unicodes, the key code that generated them, and modifier flags.  This data is then sent to the [inputText(\_:key:modifiers:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/inputtext%28_:key:modifiers:client:%29) method, which you need to implement.
- Handle all events. In this approach, you receive events directly from the Text Services Manager as [NSEvent](../appkit/nsevent.md) objects. You must implement [handle(\_:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/handle%28_:client:%29) method.

## Topics

### Supporting Key Binding

- [inputText(\_:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/inputtext%28_:client:%29): Handles key down events that do not map to an action method.
- [didCommand(by:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/didcommand%28by:client:%29): Processes a command generated by user action such as typing certain keys or pressing the mouse button.

### Unpacking Text Data

- [inputText(\_:key:modifiers:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/inputtext%28_:key:modifiers:client:%29): Receives Unicode, the key code that generated it, and any modifier flags.

### Receiving Events Directly from the Text Services Manager

- [handle(\_:client:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/handle%28_:client:%29): Handles key down and mouse events.

### Committing a Composition

- [commitComposition(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/commitcomposition%28_:%29): Informs the controller that the composition should be committed.

### Getting Input Strings and Candidates

- [composedString(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/composedstring%28_:%29): Return the current composed string.
- [originalString(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/originalstring%28_:%29): Return the string that consists of the precomposed Unicode characters.
- [candidates(\_:)](https://developer.apple.com/documentation/objectivec/nsobject-swift.class/candidates%28_:%29): Returns an array of candidates.

### Constants

- [Info Dictionary Keys](info-dictionary-keys.md): Constants for keys used to look up information in the info dictionary.

## See Also

### Protocols

- [IMKMouseHandling](imkmousehandling.md): The `IMKMouseHandling` protocol defines methods that your input method can implement to handle mouse events.
- [IMKStateSetting](imkstatesetting.md): The `IMKStateSetting` protocol defines methods for setting or accessing values that indicate the state of an input method.
