# kLSMMapHashText (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** Global Variable  
**Availability:** Mac Catalyst · macOS

An option that specifies to transform the text so it’s not human-readable.

## Declaration

```swift
var kLSMMapHashText: Int { get }
```

<a id="Discussion"></a>

## Discussion

If you specify this option when storing the map, this option hashes the map if it hasn’t been hashed yet.

## See Also

### Constants

- [kLSMMapPairs](klsmmappairs.md): An option that specifies to use pairs in addition to single words.
- [kLSMMapTriplets](klsmmaptriplets.md): An option that specifies to use triplets and pairs in addition to single words.
