# Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Latent Semantic Mapping  
**Kind:** API Collection

Error codes in Latent Semantic Mapping.

## Topics

### Errors

- [kLSMMapOutOfState](klsmmapoutofstate.md): An error code that indicates you can’t issue the call in the current map state.
- [kLSMMapNoSuchCategory](klsmmapnosuchcategory.md): An error code that indicates an invalid category.
- [kLSMMapWriteError](klsmmapwriteerror.md): An error code that indicates a map writing error.
- [kLSMMapBadPath](klsmmapbadpath.md): An error code that indicates the specified URL doesn’t exist.
- [kLSMMapBadCluster](klsmmapbadcluster.md): An error code that indicates the specified clusters are invalid.
- [kLSMMapOverflow](klsmmapoverflow.md): An error code that indicates you can’t add more data to the map.
