# Parsing Flags (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** API Collection

Options for parsing words to add to the text.

<a id="overview"></a>

## Overview

Specify these options for [LSMTextAddWords(\_:\_:\_:\_:)](lsmtextaddwords%28________%29.md).

## Topics

### Constants

- [kLSMTextApplySpamHeuristics](klsmtextapplyspamheuristics.md): An option that specifies the parser should attempt to find words in hostile text.
- [kLSMTextPreserveAcronyms](klsmtextpreserveacronyms.md): An option that specifies the parser shouldn’t map all-uppercase words to lowercase.
- [kLSMTextPreserveCase](klsmtextpreservecase.md): An option that specifies the parser shouldn’t change any words to lowercase.

## See Also

### Adding to the Text

- [LSMTextAddToken(\_:\_:)](lsmtextaddtoken%28____%29.md): Adds an arbitrary binary token to the text.
- [LSMTextAddWord(\_:\_:)](lsmtextaddword%28____%29.md): Adds a word to the text.
- [LSMTextAddWords(\_:\_:\_:\_:)](lsmtextaddwords%28________%29.md): Breaks a string into words using the specified locale, and adds the words to the text.
