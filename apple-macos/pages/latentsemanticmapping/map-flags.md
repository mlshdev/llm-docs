# Map Flags (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** API Collection

Options for creating a map.

<a id="overview"></a>

## Overview

Specify these options for [LSMMapCreate(\_:\_:)](lsmmapcreate%28____%29.md). These options can improve mapping accuracy, but may result in a potentially significant increase in memory use.

## Topics

### Constants

- [kLSMMapPairs](klsmmappairs.md): An option that specifies to use pairs in addition to single words.
- [kLSMMapTriplets](klsmmaptriplets.md): An option that specifies to use triplets and pairs in addition to single words.
- [kLSMMapHashText](klsmmaphashtext.md): An option that specifies to transform the text so it’s not human-readable.

## See Also

### Creating a Map

- [LSMMapCreate(\_:\_:)](lsmmapcreate%28____%29.md): Creates a new Latent Semantic Mapping map.
