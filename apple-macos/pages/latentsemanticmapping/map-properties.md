# Map Properties (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** API Collection

Special properties that determine a map’s behavior.

<a id="overview"></a>

## Overview

Latent Semantic Mapping interprets the following keys. All other keys starting with `LSM` are reserved.

## Topics

### Properties

- [kLSMAlgorithmKey](klsmalgorithmkey.md): A key that specifies which algorithm to use.
- [kLSMAlgorithmDense](klsmalgorithmdense.md): A value that specifies to perform a singular value decomposition (SVD) on a dense matrix.
- [kLSMAlgorithmSparse](klsmalgorithmsparse.md): A value that specifies to perform a singular value decomposition (SVD) on a sparse matrix.
- [kLSMPrecisionKey](klsmprecisionkey.md): A key that specifies the precision to use.
- [kLSMPrecisionFloat](klsmprecisionfloat.md): A value that specifies to use float arithmetic.
- [kLSMPrecisionDouble](klsmprecisiondouble.md): A value that specifies to use double arithmetic.
- [kLSMDimensionKey](klsmdimensionkey.md): A key that specifies the number of singular values to compute.
- [kLSMIterationsKey](klsmiterationskey.md): A key that specifies the number of iterations to compute.
- [kLSMSweepAgeKey](klsmsweepagekey.md): A key that specifies the number of days between sweeping generations.
- [kLSMSweepCutoffKey](klsmsweepcutoffkey.md): A key that specifies the minimum count to keep entry.

## See Also

### Managing a Map’s Properties

- [LSMMapSetProperties(\_:\_:)](lsmmapsetproperties%28____%29.md): Sets a dictionary of properties for the map.
- [LSMMapGetProperties(\_:)](lsmmapgetproperties%28__%29.md): Gets a dictionary of properties for the map.
