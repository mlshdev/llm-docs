# Clustering Flags (Swift)

**Framework:** Latent Semantic Mapping  
**Kind:** API Collection

Options for creating clusters.

<a id="overview"></a>

## Overview

Specify these options for [LSMMapCreateClusters(\_:\_:\_:\_:\_:)](lsmmapcreateclusters%28__________%29.md).

## Topics

### Constants

- [kLSMClusterCategories](klsmclustercategories.md): An option that specifies to cluster categories.
- [kLSMClusterWords](klsmclusterwords.md): An option that specifies to cluster words.
- [kLSMClusterTokens](klsmclustertokens.md): An option that specifies to cluster binary tokens.
- [kLSMClusterKMeans](klsmclusterkmeans.md): An option that specifies to cluster using a k-means algorithm.
- [kLSMClusterAgglomerative](klsmclusteragglomerative.md): An option that specifies to cluster using an agglomerative algorithm.

## See Also

### Starting Classification Mode

- [LSMMapCompile(\_:)](lsmmapcompile%28__%29.md): Compiles the map into executable form and puts it into mapping mode, preparing it for the classification of texts.
- [LSMMapCreateClusters(\_:\_:\_:\_:\_:)](lsmmapcreateclusters%28__________%29.md): Computes a set of clusters that group similar categories or words.
- [LSMMapApplyClusters(\_:\_:)](lsmmapapplyclusters%28____%29.md): Groups categories or words (tokens) into the specified sets of clusters.
