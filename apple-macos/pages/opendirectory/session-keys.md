# Session Keys

**Interface languages:** Swift, Objective-C

**Framework:** Open Directory  
**Kind:** API Collection

Keys used when specifying session information.

## Topics

### Constants

- [kODSessionDefault](kodsessiondefault.md): The default session. Used if there is no need to create a specific reference.
- [kODSessionProxyAddress](kodsessionproxyaddress.md): The address to connect to via proxy. The value is of type `CFString`.
- [kODSessionProxyPort](kodsessionproxyport.md): The port to connect to via proxy. The value is of type `CFNumber`.
- [kODSessionProxyUsername](kodsessionproxyusername.md): The username to connect with via proxy. The value is of type `CFString`.
- [kODSessionProxyPassword](kodsessionproxypassword.md): The password to connect with via proxy. The value is of type `CFString`.
