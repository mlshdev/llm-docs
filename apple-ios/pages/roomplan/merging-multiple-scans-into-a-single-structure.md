# Merging multiple scans into a single structure

**Framework:** RoomPlan  
**Kind:** Sample Code  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · Xcode 16.2+

Export a 3D model that consists of multiple rooms captured in the same physical vicinity.

<a id="Overview"></a>

## Overview

> **Note**

> This sample code project is associated with WWDC23 session 10192: [Explore enhancements to RoomPlan](https://developer.apple.com/wwdc23/10192/).

<a id="Configure-the-sample-code-project"></a>

### Configure the sample code project

Before you run the sample code project in Xcode, set the run destination to an iOS 17 device with a LiDAR Scanner.
