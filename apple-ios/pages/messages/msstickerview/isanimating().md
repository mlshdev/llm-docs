# isAnimating() (Swift)

**Framework:** Messages  
**Kind:** Instance Method  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+

Returns a Boolean value that indicates whether the sticker is animating.

## Declaration

```swift
func isAnimating() -> Bool
```

<a id="return-value"></a>

## Return Value

Returns [true](https://developer.apple.com/documentation/swift/true) if the sticker is animating; otherwise, [false](https://developer.apple.com/documentation/swift/false).

## See Also

### Controlling Sticker Animation

- [animationDuration](animationduration.md): The amount of time it takes to complete the sticker’s animation.
- [startAnimating()](startanimating%28%29.md): Starts the sticker’s animation, beginning with the first frame.
- [stopAnimating()](stopanimating%28%29.md): Stops the sticker’s animation.
