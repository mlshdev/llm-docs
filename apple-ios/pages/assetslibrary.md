# Assets Library (Swift)

**Framework:** Assets Library  
**Kind:** Framework  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 14.0+

Access the assets in a user’s media library.

<a id="overview"></a>

## Overview

Use the Assets Library framework to access the pictures and videos managed by the Photos application.

> **Important**

>  The Assets Library framework is deprecated as of iOS 9.0. Instead, use the [PhotoKit](https://developer.apple.com/documentation/photokit) framework, which in iOS 8.0 and later provides more features and better performance for working with a user’s photo library.

## Overview

Use the Assets Library framework to access the pictures and videos managed by the Photos application.

> **Important**

>  The Assets Library framework is deprecated as of iOS 9.0. Instead, use the [PhotoKit](https://developer.apple.com/documentation/photokit) framework, which in iOS 8.0 and later provides more features and better performance for working with a user’s photo library.

## Topics

### Classes

- [ALAsset](assetslibrary/alasset.md): Deprecated. An `ALAsset` object represents a photo or a video managed by the Photo application.
- [ALAssetRepresentation](assetslibrary/alassetrepresentation.md): Deprecated. An `ALAssetRepresentation` object encapsulates one of the representations of a given [ALAsset](assetslibrary/alasset.md) object.
- [ALAssetsFilter](assetslibrary/alassetsfilter.md): Deprecated. `ALAssetsFilter` encapsulates filtering criteria to be used when retrieving assets from a group.
- [ALAssetsGroup](assetslibrary/alassetsgroup.md): Deprecated. An `ALAssetsGroup` object represents an ordered set of the assets managed by the Photos application. The order of the elements is the same as the user sees in the Photos application. An asset can belong to multiple assets groups.
- [ALAssetsLibrary](assetslibrary/alassetslibrary.md): Deprecated. An instance of `ALAssetsLibrary` provides access to the videos and photos that are under the control of the Photos application.
