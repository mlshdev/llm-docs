# token

**Framework:** Managed Settings  
**Kind:** Instance Property  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+

## Declaration


## Discussion

Use  a token to share information about an app with other devices in the same Family Sharing group.
