# activate(on:eventHandler:) (Swift)

**Framework:** AccessorySetupKit  
**Kind:** Instance Method  
**Availability:** iOS 18.0+ · iPadOS 18.0+

Activate the session and start delivering events to an event handler.

## Declaration

```swift
func activate(on queue: dispatch_queue_t, eventHandler: @escaping (ASAccessoryEvent) -> Void)
```

## Parameters

- `queue`: The dispatch the session uses to deliver events to `eventHandler`.
- `eventHandler`: A closure or block that receives events generated by the session. Each callback to the event handler provides an [ASAccessoryEvent](../asaccessoryevent.md) as a parameter, and expects no return value.
