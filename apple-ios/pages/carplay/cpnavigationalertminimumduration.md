# CPNavigationAlertMinimumDuration (Swift)

**Framework:** CarPlay  
**Kind:** Global Variable  
**Availability:** iOS 12.0+ · iPadOS 12.0+ · Mac Catalyst 14.0+

A constant that defines the minimum amount of time that an alert is visible.

## Declaration

```swift
var CPNavigationAlertMinimumDuration: TimeInterval { get }
```

<a id="Discussion"></a>

## Discussion

The minimum duration is in effect when [duration](cpnavigationalert/duration.md) is not zero.

## See Also

### Getting the Alert Duration

- [duration](cpnavigationalert/duration.md): The amount of time, in seconds, that the alert is visible.
