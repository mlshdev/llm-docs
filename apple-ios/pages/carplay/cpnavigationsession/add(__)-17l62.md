# add(\_:) (Swift)

**Framework:** CarPlay  
**Kind:** Instance Method  
**Availability:** iOS 17.4+ · iPadOS 17.4+ · Mac Catalyst 17.4+

Adds one or more maneuvers, in chronological order, to the navigation session.

## Declaration

```swift
func add(_ maneuvers: [CPManeuver])
```

<a id="Discussion"></a>

### Discussion

Use this method to set all maneuvers in [upcomingManeuvers](upcomingmaneuvers.md). The app needs to provide as many maneuvers as possible, as soon as they are available.
