# Rename A Group In Your Current Organization

Rename a group in your current organization without changing its members.

`PATCH /v2/organization/groups/{id}`

**Rename a group in your current organization**

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string; minimum length: `1`): Group ID.

**Request body** (required)

- Media type: `application/json`
  - Schema (object)
    - `name` (required; string; minimum length: `1`; maximum length: `191`; pattern: `[^\t-\r  - ]`): Group name with at least one non-whitespace character; surrounding whitespace is trimmed.
  - Example `group`: `{"name":"Research"}`

  - Media type: `application/json`

      - `name` (required; string): Group name.
      - `memberCount` (required; integer; minimum: `0`): Number of group memberships.
      - `createdAt` (required; string; format: date-time)
      - `updatedAt` (required; string; format: date-time): Group update time; membership changes need not update it.
    - Example `group`: `{"id":"group_123","name":"Research","memberCount":3,"createdAt":"2026-10-13T12:00:00Z","updatedAt":"2026-10-15T12:00:00Z"}`
