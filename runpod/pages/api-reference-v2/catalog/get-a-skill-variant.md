# Get A Skill Variant

Retrieve one variant of a Runpod skill as Markdown.

`GET /v2/catalog/skills/{id}/variants/{variantId}`

**Get a skill variant**

Returns one variant of a skill as raw Markdown. Returns `404` when
the skill or variant does not exist or the variant has not been
synced yet.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string): Skill ID, as returned by `GET /v2/catalog/skills`.
  - Example: `02-comfyui-pod`
- `variantId` (path; required; string): Variant ID, as returned by `GET /v2/catalog/skills/{id}`.
  - Example: `variant-b-prebuilt`

**Responses**

- `200`: The variant's steps, as Markdown.
  - Header `RateLimit` (string): Live quota state for the caller, per the IETF ratelimit-headers draft.
  - Header `RateLimit-Policy` (string): The quota policy behind `RateLimit`, per the IETF ratelimit-headers draft.
  - Media type: `text/markdown; charset=utf-8`
    - Schema (string)
    - Example `variant`: `# Prebuilt image 1. Create a pod from the ComfyUI template.`
