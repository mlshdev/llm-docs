# Update A Container Registry Credential

Rotate the username and password of a Runpod container registry credential in place, without repointing the Pods, templates, and Serverless endpoints that use it.

`PATCH /v2/registries/{id}`

**Update a container registry credential**

Replaces the username and password stored in a container registry
credential. The ID and `name` stay the same, so every pod, template,
and Serverless endpoint that references the credential keeps
referencing it and needs no change.

Send both `username` and `password`, even when only one of them
changed. They are stored together and are write-only, so there is no
stored value to keep for an omitted field.

The new credentials apply to image pulls that start after the update.
Running pods and workers keep the image they already pulled.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string)
  - Example: `reg_abc`

**Request body** (required)

- Media type: `application/json`
  - Schema (object)
    - `password` (required; string; minimum length: `1`; maximum length: `16384`): New registry password (write-only, not returned in responses)
    - `username` (required; string; minimum length: `1`; maximum length: `191`): Registry username to store with the new password (write-only, not returned in responses)
  - Example `rotatePassword`: `{"username":"runpod-user","password":"new-correct-horse-battery-staple"}`
