# Create A Cost Center

Create a Runpod cost center and optionally attribute pods, clusters, serverless endpoints, and network volumes to it.

`POST /v2/cost-centers`

**Create a cost center**

Creates a cost center — a named label that groups resource spend so it can be broken out in billing. Pass `resources` to attribute resources at creation time; attaching is all-or-nothing, and a resource that already belongs to another cost center is rejected rather than moved.

**Authentication:** `bearerAuth`

**Request body** (required)

- Media type: `application/json`
  - Schema (object)
    - `value` (required; string; minimum length: `1`; maximum length: `50`; pattern: `^\s*\S`): Leading and trailing whitespace is trimmed.
    - `resources` (array; maximum items: `100`): Resources to attribute to the new cost center.
      - `items` (object)
        - `id` (required; string; minimum length: `1`)
        - `type` (required; string; enum: `POD`, `CLUSTER`, `SERVERLESS_ENDPOINT`, `NETWORK_VOLUME`): Kind of resource a cost center or tag can be attached to.
  - Example `bare`: `{"value":"team-ml"}`
  - Example `withResources`: `{"value":"team-ml","resources":[{"id":"p9k2m4n6q8","type":"POD"},{"id":"nv_7h3x1q","type":"NETWORK_VOLUME"}]}`
