# Remove A Resource From A Cost Center

Remove a Runpod pod, cluster, serverless endpoint, or network volume from a cost center.

`DELETE /v2/cost-centers/{id}/{resourceType}/{resourceId}`

**Remove a resource from a cost center**

Removes a resource's attribution to a cost center. The resource itself
is untouched. Returns 404 when the cost center does not exist or the
resource is not attributed to it, so repeating a DELETE that succeeded
returns 404.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string; minimum length: `1`): Cost center identifier.
- `resourceType` (path; required; string; enum: `POD`, `CLUSTER`, `SERVERLESS_ENDPOINT`, `NETWORK_VOLUME`): Kind of resource.
- `resourceId` (path; required; string; minimum length: `1`): Resource identifier.
