# Attribute A Resource To A Cost Center

Attribute a Runpod pod, cluster, serverless endpoint, or network volume to a cost center.

`PUT /v2/cost-centers/{id}/{resourceType}/{resourceId}`

**Attribute a resource to a cost center**

Attributes a resource to a cost center. Repeating the request is a
no-op. A resource belongs to at most one cost center; one already
attributed elsewhere is rejected with 409 rather than moved.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string; minimum length: `1`): Cost center identifier.
- `resourceType` (path; required; string; enum: `POD`, `CLUSTER`, `SERVERLESS_ENDPOINT`, `NETWORK_VOLUME`): Kind of resource.
- `resourceId` (path; required; string; minimum length: `1`): Resource identifier.
