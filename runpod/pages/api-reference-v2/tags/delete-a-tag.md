# Delete A Tag

Delete a Runpod tag and remove it from every resource it is attached to.

`DELETE /v2/tags/{id}`

**Delete a tag**

Deletes a tag and removes it from every resource it is attached to. The resources themselves are unchanged, and nothing needs to be detached first. Returns 404 when the tag does not exist, is already deleted, is not the caller's, or is reserved: a cost center ID is a reserved tag, so delete it through `DELETE /v2/cost-centers/{id}`.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string; minimum length: `1`): Tag identifier.
