# Update A Tag

Change the key or value of a Runpod tag. Resources it is attached to keep it.

`PATCH /v2/tags/{id}`

**Update a tag**

Changes a tag's key, value, or both. The tag keeps its ID and stays attached to the same resources. Returns 404 when the tag does not exist or is not the caller's.

**Authentication:** `bearerAuth`

**Parameters**

- `id` (path; required; string; minimum length: `1`): Tag identifier.

**Request body** (required)

- Media type: `application/json`
  - Schema (object): The fields to change; omitted fields are unchanged. Resources the tag is attached to stay attached.
    - `key` (string; minimum length: `1`; maximum length: `191`; pattern: `[^\t-\r  - ]`): Tag key, 1–191 characters as sent, with at least one that is not whitespace. Leading and trailing whitespace is ignored. Keys under the reserved `runpod:` prefix, in any letter case, are rejected.
    - `value` (string; maximum length: `191`): Tag value, at most 191 characters. May be empty. Stored exactly as sent, whitespace included.
  - Example `value`: `{"value":"prod"}`
  - Example `keyAndValue`: `{"key":"environment","value":"prod"}`

**Responses**

  - Header `RateLimit` (string): Live quota state for the caller, per the IETF ratelimit-headers draft.
  - Header `RateLimit-Policy` (string): The quota policy behind `RateLimit`, per the IETF ratelimit-headers draft.
  - Media type: `application/json`
    - Schema (object)
      - `id` (required; string): Shared by every resource the tag is attached to.
      - `key` (required; string): Returned exactly as stored.
      - `value` (required; string): Returned exactly as stored. May be empty.
      - `createdAt` (required; string; format: date-time)
      - `updatedAt` (required; string; format: date-time)
    - Example `tag`: `{"id":"clz1x9k4a0000qw3h8s7d2f1g","key":"environment","value":"prod","createdAt":"2026-11-04T09:00:00Z","updatedAt":"2026-11-04T09:30:00Z"}`
