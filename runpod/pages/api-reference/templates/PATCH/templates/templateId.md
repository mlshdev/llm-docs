# Update a template

`PATCH /templates/{templateId}`

**Update a template**

Update a template. Use this API reference to review authentication, request parameters, response fields, and errors for this Runpod operation.

**Parameters**

- `templateId` (path, required): ID of template that needs to be updated.

**Request body**: Update a template.

**Responses**

- `200`: Successful operation.
- `400`: Invalid input.
