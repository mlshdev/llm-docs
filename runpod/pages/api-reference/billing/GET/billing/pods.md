# Pod billing history

`GET /billing/pods`

**Pod billing history**

Retrieve billing information about your Pods. Review authentication, request parameters, response fields, and errors for this Runpod API operation.

**Parameters**

- `bucketSize` (query)
- `endTime` (query)
- `gpuTypeId` (query)
- `grouping` (query)
- `podId` (query)
- `startTime` (query)

**Responses**

- `200`: Successful operation.
