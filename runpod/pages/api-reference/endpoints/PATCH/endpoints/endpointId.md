# Update an endpoint

`PATCH /endpoints/{endpointId}`

**Update an endpoint**

Update an endpoint. Use this API reference to review authentication, request parameters, response fields, and errors for this Runpod operation.

**Parameters**

- `endpointId` (path, required): ID of endpoint that needs to be updated.

**Request body**: Update an endpoint.

**Responses**

- `200`: Successful operation.
- `400`: Invalid input.
