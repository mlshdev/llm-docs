# sbx login

Sign in to Docker

**Usage:** `sbx login [flags]`

## Options

| Option | Default | Description |
| --- | --- | --- |
| `--password-stdin` |  | Read password or access token from stdin |
| `--username` |  | Docker username for non-interactive login |

## Global options

| Option | Default | Description |
| --- | --- | --- |
| `-D`, `--debug` |  | Enable debug logging |
