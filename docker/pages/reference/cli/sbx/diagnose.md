# sbx diagnose

Diagnose common issues with your sbx installation

**Usage:** `sbx diagnose`

## Options

| Option | Default | Description |
| --- | --- | --- |
| `-o`, `--output` |  | Output format: "json" or "github-issue" |
| `--upload` |  | Upload diagnostics to Docker support |

## Global options

| Option | Default | Description |
| --- | --- | --- |
| `-D`, `--debug` |  | Enable debug logging |
