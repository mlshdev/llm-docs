# docker dhi customization build list

List builds of a customization

**Usage:** `docker dhi customization build list <customization-id>`

## Description

List all builds of a Docker Hardened Images customization by its ID

## Options

| Option   | Default | Description           |
| -------- | ------- | --------------------- |
| `--json` |         | Output in JSON format |

## Global options

| Option  | Default | Description                                |
| ------- | ------- | ------------------------------------------ |
| `--org` |         | Docker Hub organization (overrides config) |
