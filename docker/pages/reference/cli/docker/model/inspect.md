# docker model inspect

Display detailed information on one model

**Usage:** `docker model inspect MODEL`

## Description

Display detailed information on one model

## Options

| Option           | Default | Description                    |
| ---------------- | ------- | ------------------------------ |
| `--openai`       |         | List model in an OpenAI format |
| `-r`, `--remote` |         | Show info for remote models    |
