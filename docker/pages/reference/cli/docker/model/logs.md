# docker model logs

Fetch the Docker Model Runner logs

**Usage:** `docker model logs [OPTIONS]`

## Description

Fetch the Docker Model Runner logs

## Options

| Option | Default | Description |
| --- | --- | --- |
| `-f`, `--follow` |  | View logs with real-time streaming |
| `--no-engines` |  | Exclude inference engine logs from the output |
