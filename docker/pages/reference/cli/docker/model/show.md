# docker model show

Show information for a model

**Usage:** `docker model show MODEL`

## Description

Display detailed information about a model in a human-readable format.

## Options

| Option | Default | Description |
| --- | --- | --- |
| `-r`, `--remote` |  | Show info for remote models |
