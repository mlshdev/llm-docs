# docker desktop kubernetes status

Get the status of the Kubernetes cluster managed by Docker Desktop

**Usage:** `docker desktop kubernetes status`

## Options

| Option     | Default  | Description                                          |
| ---------- | -------- | ---------------------------------------------------- |
| `--format` | `pretty` | Format the output. Accepted values are: pretty, json |
