# docker compose unpause

Unpause services

**Usage:** `docker compose unpause [SERVICE...]`

## Description

Unpauses paused containers of a service

## Global options

| Option      | Default | Description                     |
| ----------- | ------- | ------------------------------- |
| `--dry-run` |         | Execute command in dry run mode |
