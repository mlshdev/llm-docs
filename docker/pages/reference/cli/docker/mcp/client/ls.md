# docker mcp client ls

List client configurations

**Usage:** `docker mcp client ls`

## Description

List client configurations

## Options

| Option           | Default | Description                                                                         |
| ---------------- | ------- | ----------------------------------------------------------------------------------- |
| `-g`, `--global` |         | Change the system wide configuration or the clients setup in your current git repo. |
| `--json`         |         | Print as JSON.                                                                      |
