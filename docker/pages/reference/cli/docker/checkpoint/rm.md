# docker checkpoint rm

Remove a checkpoint

**Usage:** `docker checkpoint rm [OPTIONS] CONTAINER CHECKPOINT`

**Aliases:** docker checkpoint rm, docker checkpoint remove

> \[!NOTE]
> This command is experimental.

## Description

Remove a checkpoint
