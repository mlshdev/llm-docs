# Plans

Docker plans attach to an individual account, an organization, or a specific
product. Plans make up your subscription.

- Docker Personal and Docker Pro are subscriptions for individual accounts.
- Docker Team and Docker Business are subscriptions for organization
  accounts.
- Product plans let you subscribe to a Docker product without altering
  your account type plan.

Each plan page covers usage entitlements, billing cycle, and management
options.

## Choose a plan

Compare billing models and tiers before you subscribe.

| Plans                                                                                                            | Billing model                                                                      | Types                                                     |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------- |
| [Docker](https://docs.docker.com/subscription-billing/plans/docker/)                                             | Flat-rate plans for individual and organization accounts                           | Docker Personal, Docker Pro, Docker Team, Docker Business |
| [Docker Hardened Images (DHI)](https://docs.docker.com/subscription-billing/plans/dhi/)                          | Annual plans billed per repository. DHI Community is free.                         | DHI Community, DHI Select, DHI Enterprise                 |
| [Gordon](https://docs.docker.com/subscription-billing/plans/gordon/)                                             | Monthly plans that raise your Gordon usage allowance                               | Gordon Plus, Gordon Max, Gordon Ultra                     |
| [Docker Agentic Platform](https://docs.docker.com/subscription-billing/plans/docker-agentic-platform/)           | Pay-as-you-go cloud compute, billed monthly                                        | Pay-as-you-go                                             |
| [AI Governance](https://docs.docker.com/subscription-billing/plans/ai-governance/)                               | Licenses purchased through Docker sales.                                           | AI Governance                                             |
| [Docker Verified Publisher (DVP)](https://docs.docker.com/subscription-billing/plans/docker-verified-publisher/) | Flat-rate annual plans. DVP Growth lets you add consuming domains in blocks of 25. | DVP Starter, DVP Growth                                   |

## Add units to a plan {#top-up-your-plan}

Add seats, minutes, or other units without changing the plan type.

| Unit                                                                                                                     | Description                                                                             | Examples                                 |
| ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- | ---------------------------------------- |
| [Seats](https://docs.docker.com/accounts/organization/manage/manage-seats/)                                              | Each seat extends entitlements to one more member.                                      | Docker Team, Docker Business             |
| [Licenses](https://docs.docker.com/accounts/organization/manage/manage-licenses/)                                        | Access to specific products or features.                                                | AI Governance, Docker Offload            |
| [Minutes](https://docs.docker.com/subscription-billing/plans/docker/#docker-build-cloud-minutes)                         | Build and test runtime capacity, sold in blocks and consumed within the billing period. | Docker Build Cloud, Testcontainers Cloud |
| [Repositories](https://docs.docker.com/subscription-billing/plans/dhi/)                                                  | Additional container repositories covered by security scanning and analysis features.   | DHI                                      |
| [Consuming domains](https://docs.docker.com/subscription-billing/plans/docker-verified-publisher/#add-consuming-domains) | Additional consuming domains tracked in publisher analytics.                            | DVP Growth                               |

## Product catalog

- [Docker](https://docs.docker.com/subscription-billing/plans/docker/): Personal and organization plans, including build and runtime minutes.
- [Gordon plans](https://docs.docker.com/subscription-billing/plans/gordon/): Usage plans that increase your Gordon allowance.
- [Docker Agentic Platform](https://docs.docker.com/subscription-billing/plans/docker-agentic-platform/): Pay-as-you-go cloud compute for individual accounts.
- [Docker Hardened Images (DHI)](https://docs.docker.com/subscription-billing/plans/dhi/): Hardened image repositories for organization accounts.
- [AI Governance](https://docs.docker.com/subscription-billing/plans/ai-governance/): Licenses for organization-wide AI policy enforcement.
- [Docker Verified Publisher (DVP)](https://docs.docker.com/subscription-billing/plans/docker-verified-publisher/): Publisher analytics and reporting plans for organization accounts.
