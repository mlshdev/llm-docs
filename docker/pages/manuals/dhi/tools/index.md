# Tools

Docker Hardened Images can be accessed and managed through several interfaces.
Choose the tool that fits your workflow.

- [Use Docker Hub](https://docs.docker.com/dhi/tools/hub/): Browse the DHI catalog on Docker Hub to search repositories, inspect image metadata, and view SBOMs, CVEs, and attestations.
- [CLI](https://docs.docker.com/dhi/tools/cli/): Install and use the `docker dhi` command-line interface to browse the catalog, inspect images, and manage mirrors from your terminal.
- [MCP server](https://docs.docker.com/dhi/tools/mcp/): Connect an AI assistant to the DHI catalog to search repositories, inspect images, retrieve SBOMs, and check CVEs using plain language.
- [Use the DHI Terraform provider](https://docs.docker.com/dhi/tools/terraform/): Use the DHI Terraform provider to manage mirrors and automate DHI configuration as infrastructure as code.
- [Use the DHI API](https://docs.docker.com/dhi/tools/api/): Query Docker Hardened Images data programmatically using the DHI GraphQL API.
