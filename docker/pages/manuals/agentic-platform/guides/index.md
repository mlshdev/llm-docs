# Docker Agentic Platform guides

Choose a workflow to put a cloud sandbox to work:

- [Share an application](https://docs.docker.com/agentic-platform/guides/share-app/) through a public HTTPS URL, then withdraw access.
- [Develop remotely](https://docs.docker.com/agentic-platform/guides/remote-development/) with VS Code or Cursor over SSH.
- [Continue local work in the cloud](https://docs.docker.com/agentic-platform/guides/local-handoff/) and retrieve the results.

For account setup, start with [Get started](https://docs.docker.com/agentic-platform/get-started/).
For command options, see [Use cloud sandboxes](https://docs.docker.com/ai/sandboxes/cloud/usage/).
