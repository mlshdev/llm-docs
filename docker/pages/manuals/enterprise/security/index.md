# Security for enterprises

[Hardened Docker Desktop](https://docs.docker.com/enterprise/security/hardened-desktop/)
provides security features that help organizations secure developer
environments, including Settings Management, Enhanced Container Isolation,
Registry Access Management, and related controls.

- [Hardened Docker Desktop](https://docs.docker.com/enterprise/security/hardened-desktop/): Security features that strengthen developer environments.
- [Enforce sign-in](https://docs.docker.com/enterprise/security/enforce-sign-in/): Configure sign-in for members of your teams and organizations.
