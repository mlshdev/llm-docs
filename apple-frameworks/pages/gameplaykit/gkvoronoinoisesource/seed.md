# seed (Swift)

**Framework:** GameplayKit  
**Kind:** Instance Property  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+

The value that determines the specific configuration of noise produced by the noise source.

## Declaration

```swift
var seed: Int32 { get set }
```

<a id="Discussion"></a>

## Discussion

Like the [seed](../gkarc4randomsource/seed.md) value of a random source, a noise source’s seed value determines the pseudorandom aspect of noise generated by the noise source. Changing the seed value produces different overall structure to the generated noise, while changing other parameters produces variation upon that structure.

## See Also

### Managing Noise Generation Parameters

- [frequency](frequency.md): A value that determines the number and size of cells in generated noise.
- [displacement](displacement.md): The range of random values to assign to each cell in generated noise.
- [isDistanceEnabled](isdistanceenabled.md): A Boolean value that specifies whether generated noise values incorporate the distance from each point to the nearest seed point.
