# GKCheckerboardNoiseSource (Swift)

**Framework:** GameplayKit  
**Kind:** Class  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+

A procedural noise generator whose output is an alternating square pattern.

## Declaration

```swift
class GKCheckerboardNoiseSource
```

<a id="overview"></a>

## Overview

Checkerboard noise can be useful as an input to [GKNoise](gknoise.md) methods that create noise by combining other noise objects through various operations.

![](https://developer.apple.com/images/com.apple.gameplaykit/media-2556325@2x.png)

Like all [GKNoiseSource](gknoisesource.md) subclasses, a checkerboard noise source represents a noise generation algorithm and its parameters. To make use of a noise source, first create [GKNoise](gknoise.md) object from it (and optionally apply operations to that noise object or combine it with other noise objects). Then create a [GKNoiseMap](gknoisemap.md) object from your noise object, generating a concrete field of values that you can sample from directly or visualize using the [SKTexture](../spritekit/sktexture.md) or `SKTileMap` class.

## Topics

### Creating a Noise Source

- [init(squareSize:)](gkcheckerboardnoisesource/init%28squaresize_%29.md): Initializes a checkerboard noise source with the specified square size.
- [checkerboardNoise(withSquareSize:)](gkcheckerboardnoisesource/checkerboardnoise%28withsquaresize_%29.md): Creates a checkerboard noise source with the specified square size.

### Managing Noise Generation Parameters

- [squareSize](gkcheckerboardnoisesource/squaresize.md): The size (both width and height) of squares in the generated checkerboard pattern.
