# init() (Swift)

**Framework:** GameplayKit  
**Kind:** Initializer  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 9.0+ · visionOS 1.0+

Initializes a random source from a nondeterministic seed.

## Declaration

```swift
convenience init()
```

<a id="return-value"></a>

## Return Value

A new, independent random source.

<a id="Discussion"></a>

## Discussion

Calling this method seeds the random source with a sequence of bytes sampled from a high-entropy system source. To later replicate the sequence of numbers generated by this source, read the [seed](seed.md) property and use the resulting value to initialize another random source with the [init(seed:)](init%28seed_%29.md) initializer.

For more information, see [GameplayKit Programming Guide](https://developer.apple.com/library/archive/documentation/General/Conceptual/GameplayKit_Guide/index.html#//apple_ref/doc/uid/TP40015172).
