# GKCylindersNoiseSource (Swift)

**Framework:** GameplayKit  
**Kind:** Class  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+

A procedural noise generator whose output is a 3D field of concentric cylindrical shells.

## Declaration

```swift
class GKCylindersNoiseSource
```

<a id="overview"></a>

## Overview

All noise sources generate infinite 3D fields of noise values, but this fact is especially relevant to cylinder noise: by rotating a noise object in 3D, you can sample the noise in ways that “slice” across or along the cylinders. Use this technique (combined with other noise sources and noise processing operations) to create effects such as wood-grain textures.

![](https://developer.apple.com/images/com.apple.gameplaykit/media-2556326@2x.png)

Like all [GKNoiseSource](gknoisesource.md) subclasses, a cylinder noise source represents a noise generation algorithm and its parameters. To make use of a noise source, first create [GKNoise](gknoise.md) object from it (and optionally apply operations to that noise object or combine it with other noise objects). Then create a [GKNoiseMap](gknoisemap.md) object from your noise object, generating a concrete field of values that you can sample from directly or visualize using the [SKTexture](../spritekit/sktexture.md) or `SKTileMap` class.
