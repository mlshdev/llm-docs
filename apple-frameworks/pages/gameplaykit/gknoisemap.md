# GKNoiseMap (Swift)

**Framework:** GameplayKit  
**Kind:** Class  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+

A sample of procedural noise data from which you can read noise values directly or create noise textures.

## Declaration

```swift
class GKNoiseMap
```

<a id="overview"></a>

## Overview

Working with procedural noise involves three main steps, one of each of the three major GameplayKit noise classes:

1. Noise sources (the [GKNoiseSource](gknoisesource.md) class cluster) represent the core algorithms and parameters for generating noise. You choose a general style of noise by instantiating and configuring one of the concrete [GKNoiseSource](gknoisesource.md) subclasses.
2. Noise objects ([GKNoise](gknoise.md) instances) represent the field of noise generated by a noise source. You create a noise object from a noise source, and can then process it or combine it with other noise objects to create more complex noise patterns. Noise objects are lightweight: GameplayKit defers the computation of generating noise and applying noise processing operations until you’re ready to create output.
3. [GKNoiseMap](gknoisemap.md) objects are the concrete output of noise generation and processing. Creating a noise map performs the computation described by the [GKNoiseSource](gknoisesource.md) and [GKNoise](gknoise.md) objects you create it from, filling a 2D grid of a specific size with noise values based on a slice of the noise object’s 3D noise field.

You can apply noise maps in many different ways. Some examples include :

- Creating texture images resembling natural phenomena such as clouds, stone surfaces, and wood grain. You can also use noise textures as normal maps to make surfaces appear more natural under lighting. (See the [SKTexture](../spritekit/sktexture.md) [init(noiseMap:)](../spritekit/sktexture/init%28noisemap_%29.md) method.)
- Generating procedural game-world maps resembling natural terrain. You can create game world of infinite size by using procedural noise as its underlying representation, and manage storage and memory efficiently by creating noise maps (and their visual representations) only for the area around a player’s current position. (See the `SKTileMap` class.)
- Adding a degree of randomness to otherwise smooth movements. For example, you can make game characters move in a jittery manner, or apply a hand-held motion effect to a game camera.

The content of a noise map is a field of floating-point values that, by default, range from `-1.0` to `1.0`. You can access these values individually with the [value(at:)](gknoisemap/value%28at_%29.md) and [interpolatedValue(at:)](gknoisemap/interpolatedvalue%28at_%29.md) methods, or create SpriteKit resources from the entire noise map’s values with the methods mentioned above.

A noise map is finite and two-dimensional, but the the noise you sample to create it is three-dimensional and infinite in extent. You can create interesting effects by transforming noise in three dimensions before creating a noise map. For example:

- By using a cylindrical noise source and applying the [rotate(by:)](gknoise/rotate%28by_%29.md) method, you can sample a slice through the cylinders that creates a wood-grain effect.
- By using a Perlin noise source and applying the [move(by:)](gknoise/move%28by_%29.md) method between multiple samples, you can animate a noise map that simulates the way clouds form, billow, and dissipate over time.

## Topics

### Creating a Noise Map

- [init(\_:)](gknoisemap/init%28__%29.md): Initializes a noise map by sampling from the specified noise object.
- [init(\_:size:origin:sampleCount:seamless:)](gknoisemap/init%28__size_origin_samplecount_seamless_%29.md): Creates a noise map by sampling from the specified noise object.
- [init()](gknoisemap/init%28%29.md): Initializes a noise map with a constant noise value of zero throughout.

### Accessing Noise Values

- [value(at:)](gknoisemap/value%28at_%29.md): Returns the value at the specified position in the noise map’s discrete sample grid.
- [interpolatedValue(at:)](gknoisemap/interpolatedvalue%28at_%29.md): Returns the value at the specified position in the noise map, interpolating results for positions not on the discrete sample grid.
- [setValue(\_:at:)](gknoisemap/setvalue%28__at_%29.md): Sets the value at the specified position in the noise map.

### Inspecting a Noise Map

- [size](gknoisemap/size.md): The size of the “slice” of noise samples contained in the noise map relative to the unit coordinate space of the noise object it was created from.
- [origin](gknoisemap/origin.md): The position of the “slice” of noise samples contained in the noise map relative to the unit coordinate space of the noise object it was created from.
- [sampleCount](gknoisemap/samplecount.md): The width and height of integer grid for which the noise map contains sampled noise values.
- [isSeamless](gknoisemap/isseamless.md): A Boolean value indicating whether the noise map’s output can repeat seamlessly in all directions.
