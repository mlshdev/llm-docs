# nextInt(upperBound:) (Swift)

**Framework:** GameplayKit  
**Kind:** Instance Method  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 9.0+ · visionOS 1.0+

Generates and returns a new random integer within the bounds of the distribution and less than the specified limit.

## Declaration

```swift
func nextInt(upperBound: Int) -> Int
```

## Parameters

- `upperBound`: A limit on the values of random numbers to generate.

<a id="return-value"></a>

## Return Value

A new random integer less than the value of the `upperBound` parameter.

<a id="Discussion"></a>

## Discussion

Randomly generated integers are in the range specified by the distribution’s [lowestValue](lowestvalue.md) and [highestValue](highestvalue.md) properties (inclusive). The actual upper bound on numbers generated by this method is the lesser of the [highestValue](highestvalue.md) property and the `upperBound` parameter.

When using the [GKRandomDistribution](../gkrandomdistribution.md) directly, generated numbers are uniform within this range. Subclasses of [GKRandomDistribution](../gkrandomdistribution.md) can alter the relative probability of generating any particular number within the distribution’s range.
