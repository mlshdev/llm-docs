# d20() (Swift)

**Framework:** GameplayKit  
**Kind:** Type Method  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 9.0+ · visionOS 1.0+

Creates a random distribution equivalent to a twenty-sided die.

## Declaration

```swift
class func d20() -> Self
```

<a id="return-value"></a>

## Return Value

A uniform random distribution that produces values in the range `[1, 20]`.

<a id="Discussion"></a>

## Discussion

The newly created distribution uses its own [GKRandomSource](../gkrandomsource.md) instance, so the random behavior of the distribution is independent from that of other randomizers.

## See Also

### Creating Specific Random Distributions

- [d6()](d6%28%29.md): Creates a random distribution equivalent to a six-sided die.
- [init(forDieWithSideCount:)](init%28fordiewithsidecount_%29.md): Creates a random distribution equivalent to a die with the specified number of sides.
