# keylineTint(\_:)

**Framework:** WidgetKit  
**Kind:** Instance Method  
**Availability:** iOS 16.1+ · iPadOS 16.1+

Applies a subtle tint color to the surrounding border of a Live Activity that appears in the Dynamic Island.


## Parameters

- `color`: The tint color to use.
