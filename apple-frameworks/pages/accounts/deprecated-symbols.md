# Deprecated Symbols

**Interface languages:** Swift, Objective-C

**Framework:** Accounts  
**Kind:** API Collection

Avoid using deprecated symbols in your apps.

## Topics

### Account Type Strings

- [ACAccountTypeIdentifierFacebook](acaccounttypeidentifierfacebook.md): Deprecated. Identifier for the Facebook account type.
- [ACAccountTypeIdentifierLinkedIn](acaccounttypeidentifierlinkedin.md): Deprecated. Identifier for the LinkedIn account type.
- [ACAccountTypeIdentifierSinaWeibo](acaccounttypeidentifiersinaweibo.md): Deprecated. Identifier for the Sina Weibo account type.
- [ACAccountTypeIdentifierTencentWeibo](acaccounttypeidentifiertencentweibo.md): Deprecated. Identifier for the Tencent Weibo account type.
- [ACAccountTypeIdentifierTwitter](acaccounttypeidentifiertwitter.md): Deprecated. Identifier for the Twitter account type.

### Account Keys

- [ACFacebookAppIdKey](acfacebookappidkey.md): Deprecated. The Facebook App ID, as it appears on the Facebook website.
- [ACFacebookAudienceEveryone](acfacebookaudienceeveryone.md): Deprecated. Posts are visible to everyone.
- [ACFacebookAudienceFriends](acfacebookaudiencefriends.md): Deprecated. Posts are visible only to friends.
- [ACFacebookAudienceKey](acfacebookaudiencekey.md): Deprecated. Only required when posting permissions are requested.
- [ACFacebookAudienceOnlyMe](acfacebookaudienceonlyme.md): Deprecated. Posts are visible to the user only.
- [ACFacebookPermissionsKey](acfacebookpermissionskey.md): Deprecated. The array of strings of permissions to request (for example, `email`, `publish_stream`, and so on).
- [ACLinkedInAppIdKey](aclinkedinappidkey.md): Deprecated. The LinkedIn App ID, as it appears on the LinkedIn website.
- [ACLinkedInPermissionsKey](aclinkedinpermissionskey.md): Deprecated. The array of strings of permissions to request.
- [ACTencentWeiboAppIdKey](actencentweiboappidkey.md): Deprecated. The Tencent Weibo App ID, as it appears on the Tencent Weibo website.
