# \*(\_:\_:)

**Framework:** Foundation  
**Kind:** Operator  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+ · watchOS 3.0+

Multiply a scalar value by a measurement.

## Declaration

```swift
static func * (lhs: Double, rhs: Measurement<UnitType>) -> Measurement<UnitType>
```

## Parameters

- `lhs`: A double-precision floating-point number to multiply.
- `rhs`: A measurement to multiply.

<a id="return-value"></a>

## Return Value

A measurement of value `lhs * rhs.value` with the same unit as `rhs`.
