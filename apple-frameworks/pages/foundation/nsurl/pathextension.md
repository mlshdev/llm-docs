# pathExtension (Swift)

**Framework:** Foundation  
**Kind:** Instance Property  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 13.1+ · macOS 10.6+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The path extension. (read-only)

## Declaration

```swift
var pathExtension: String? { get }
```

<a id="return-value"></a>

## Return Value

The path extension of the receiver, or `nil` if [path](path.md) is `nil`.

<a id="Discussion"></a>

## Discussion

This property contains the path extension, unescaped using the [replacingPercentEscapes(using:)](../nsstring/replacingpercentescapes%28using_%29.md) method. For example, in the URL `file:///path/to/file.txt`, the path extension is `txt`.

# pathExtension (Objective-C)

## Declaration

```objectivec
@property (copy, readonly, nullable) NSString * pathExtension;
```

<a id="return-value"></a>

## Return Value

The path extension of the receiver, or `nil` if [path](path.md) is `nil`.

<a id="Discussion"></a>

## Discussion

This property contains the path extension, unescaped using the [stringByReplacingPercentEscapesUsingEncoding:](../nsstring/replacingpercentescapes%28using_%29.md) method. For example, in the URL `file:///path/to/file.txt`, the path extension is `txt`.
