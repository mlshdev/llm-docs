# Encoding and Decoding Attributed String Keys (Swift)

**Framework:** Foundation  
**Kind:** API Collection

Protocols adopted by attribute keys to encode or decode data.

## Topics

### Encoding and Decoding Keys

- [DecodableAttributedStringKey](decodableattributedstringkey.md): A protocol that defines how an attribute key decodes its value.
- [EncodableAttributedStringKey](encodableattributedstringkey.md): A protocol that defines how an attribute key encodes its value.
- [CodableAttributedStringKey](codableattributedstringkey.md): A type alias used by attribute keys that are both encodable and decodable.

### Markdown Keys

- [MarkdownDecodableAttributedStringKey](markdowndecodableattributedstringkey.md): A protocol that defines how an attribute key decodes a value that corresponds to Markdown syntax.

### Encoding and Decoding
