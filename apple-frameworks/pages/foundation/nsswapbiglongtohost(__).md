# NSSwapBigLongToHost(\_:) (Swift)

**Framework:** Foundation  
**Kind:** Function  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.0+ · macOS 10.0+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Swaps the bytes of a number.

## Declaration

```swift
func NSSwapBigLongToHost(_ x: UInt) -> UInt
```

<a id="Discussion"></a>

## Discussion

Converts the big-endian value in `x` to the current endian format and returns the resulting value. If it is necessary to swap the bytes of `x`, this function calls [NSSwapLong(\_:)](nsswaplong%28__%29.md) to perform the swap.
