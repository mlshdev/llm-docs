# +(\_:\_:)

**Framework:** Foundation  
**Kind:** Operator  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 8.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Adds two decimal numbers.

## Declaration

```swift
static func + (lhs: Decimal, rhs: Decimal) -> Decimal
```

## Parameters

- `lhs`: A value to add.
- `rhs`: Another value to add.

<a id="return-value"></a>

## Return Value

The result of adding `lhs` and `rhs`.

<a id="Discussion"></a>

## Discussion

If the result of this operation requires more precision than the `Decimal` type can provide, the result is rounded using the [NSDecimalNumber.RoundingMode.plain](../nsdecimalnumber/roundingmode/plain.md) rounding mode. To specify a different rounding mode, use the [NSDecimalAdd(\_:\_:\_:\_:)](../nsdecimaladd%28________%29.md) function instead.
