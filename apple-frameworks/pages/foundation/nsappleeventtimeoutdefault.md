# NSAppleEventTimeOutDefault (Swift)

**Framework:** Foundation  
**Kind:** Global Variable  
**Availability:** Mac Catalyst 13.0+ · macOS 10.0+

Specifies that an event-processing operation should continue until a timeout occurs based on a value determined by the Apple Event Manager (about 1 minute). Not currently used by applications.

## Declaration

```swift
let NSAppleEventTimeOutDefault: Double
```

## See Also

### Constants

- [NSAppleEventTimeOutNone](nsappleeventtimeoutnone.md): Specifies that the application is willing to wait indefinitely for the current operation to complete. Not currently used by applications.
