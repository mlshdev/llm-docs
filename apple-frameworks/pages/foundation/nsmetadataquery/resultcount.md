# resultCount (Swift)

**Framework:** Foundation  
**Kind:** Instance Property  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+ · macOS 10.4+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The number of results returned by the query. (read-only)

## Declaration

```swift
var resultCount: Int { get }
```

<a id="Discussion"></a>

## Discussion

For performance reasons, you should use this method, rather than invoking `count` on [results](results.md).
