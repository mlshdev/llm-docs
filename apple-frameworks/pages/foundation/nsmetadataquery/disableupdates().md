# disableUpdates() (Swift)

**Framework:** Foundation  
**Kind:** Instance Method  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+ · macOS 10.4+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Disables updates to the query results.

## Declaration

```swift
func disableUpdates()
```

<a id="Discussion"></a>

## Discussion

Unless you use [enumerateResults(\_:)](enumerateresults%28__%29.md) or [enumerateResults(options:using:)](enumerateresults%28options_using_%29.md), you should invoke this method before iterating over query results that could change due to live updates.
