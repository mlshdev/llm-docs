# ndefMessagePayload (Swift)

**Framework:** Foundation  
**Kind:** Instance Property  
**Availability:** iOS 12.0+ · iPadOS 12.0+ · Mac Catalyst 13.1+

The NDEF message read by the system in the background.

## Declaration

```swift
var ndefMessagePayload: NFCNDEFMessage { get }
```

<a id="Discussion"></a>

## Discussion

For user activities not generated by background tag reading, [ndefMessagePayload](ndefmessagepayload.md) returns a message that contains only one [NFCNDEFPayload](https://developer.apple.com/documentation/corenfc/nfcndefpayload) record. That record has a [typeNameFormat](https://developer.apple.com/documentation/corenfc/nfcndefpayload/typenameformat) of [NFCTypeNameFormat.empty](https://developer.apple.com/documentation/corenfc/nfctypenameformat/empty). For more information, see [Adding Support for Background Tag Reading](https://developer.apple.com/documentation/corenfc/adding-support-for-background-tag-reading).
