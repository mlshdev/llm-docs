# Byte Order (Swift)

**Framework:** Foundation  
**Kind:** API Collection

Recognize constants that specify a byte-order format.

<a id="overview"></a>

## Overview

These constants are returned by [NSHostByteOrder()](nshostbyteorder%28%29.md).

## Topics

### Constants

- [NS_BigEndian](ns_bigendian.md): The byte order is big endian.
- [NS_LittleEndian](ns_littleendian.md): The byte order is little endian.
- [NS_UnknownByteOrder](ns_unknownbyteorder.md): The byte order is unknown.

## See Also

### Constants

- [NSSwappedDouble](nsswappeddouble.md): Opaque structure containing endian-independent `double` value.
- [NSSwappedFloat](nsswappedfloat.md): Opaque type containing an endian-independent `float` value.
