# topMargin

**Framework:** Foundation  
**Kind:** Type Property  
**Availability:** macOS 10.0+

The top margin of the document.

## Declaration

```swift
static let topMargin: NSAttributedString.DocumentAttributeKey
```

<a id="Discussion"></a>

## Discussion

The value of this attribute is an [NSNumber](../../nsnumber.md) object containing a float, in points.

The string constant in macOS 10.3 and earlier is `@"TopMargin"`.
