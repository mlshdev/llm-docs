# strikethroughColor

**Framework:** Foundation  
**Kind:** Type Property  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · macOS 10.0+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The color of the strikethrough.

## Declaration

```swift
static let strikethroughColor: NSAttributedString.Key
```

<a id="Discussion"></a>

## Discussion

The value of this attribute is a [UIColor](../../../uikit/uicolor.md) object. The default value is `nil`, indicating same as foreground color.
