# shadow

**Framework:** Foundation  
**Kind:** Type Property  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · Mac Catalyst 13.1+ · macOS 10.0+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The shadow of the text.

## Declaration

```swift
static let shadow: NSAttributedString.Key
```

<a id="Discussion"></a>

## Discussion

The value of this attribute is an [NSShadow](https://developer.apple.com/documentation/appkit/nsshadow) object. The default value of this property is `nil`.
