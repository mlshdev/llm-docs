# NSAppleEvent Timeouts

**Interface languages:** Swift, Objective-C

**Framework:** Foundation  
**Kind:** API Collection

The following constants should not be used and may eventually be removed.

## Topics

### Constants

- [NSAppleEventTimeOutDefault](nsappleeventtimeoutdefault.md): Specifies that an event-processing operation should continue until a timeout occurs based on a value determined by the Apple Event Manager (about 1 minute). Not currently used by applications.
- [NSAppleEventTimeOutNone](nsappleeventtimeoutnone.md): Specifies that the application is willing to wait indefinitely for the current operation to complete. Not currently used by applications.
