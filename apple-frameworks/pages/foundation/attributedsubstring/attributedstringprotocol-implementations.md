# AttributedStringProtocol Implementations

**Framework:** Foundation  
**Kind:** API Collection

## Topics

### Instance Properties

- [characters](characters.md): The characters of the attributed string, as a view into the underlying string.
- [endIndex](endindex.md): A substring’s past-the-end position — the position one greater than the last valid subscript argument.
- [runs](runs.md): The attributed runs of the attributed string, as a view into the underlying string.
- [startIndex](startindex.md): The position of the first character in a nonempty attributed substring.
- [unicodeScalars](unicodescalars.md): The Unicode scalars of the attributed string, as a view into the underlying string.
- [utf16](utf16.md): A view of the attributed substring’s contents as a collection of UTF-16 code units.
- [utf8](utf8.md): A view of the attributed substring’s contents as a collection of UTF-8 code units.
