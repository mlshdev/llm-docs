# NSMetadataQueryAttributeValueTuple (Swift)

**Framework:** Foundation  
**Kind:** Class  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+ · macOS 10.4+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The `NSMetadataQueryAttributeValueTuple` class represents attribute-value tuples, which are objects that contain the attribute name and value of a metadata attribute.

## Declaration

```swift
class NSMetadataQueryAttributeValueTuple
```

<a id="overview"></a>

## Overview

Attribute-value tuples are returned by `NSMetadataQuery` objects as the results in the value lists. Each attribute/value tuple contains the attribute name, the value, and the number of instances of that value that exist for the attribute name.

## Topics

### Getting Query Attribute/Value Information

- [attribute](nsmetadataqueryattributevaluetuple/attribute.md): The attribute name for the tuple’s value.
- [count](nsmetadataqueryattributevaluetuple/count.md): The number of instances of the value for the tuple’s attribute.
- [value](nsmetadataqueryattributevaluetuple/value.md): The value of the tuple’s attribute.
