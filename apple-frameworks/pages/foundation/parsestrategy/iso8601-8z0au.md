# iso8601

**Framework:** Foundation  
**Kind:** Type Property  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 12.0+ · tvOS 15.0+ · visionOS 1.0+ · watchOS 8.0+

A style for formatting a date in accordance with the ISO-8601 standard.

## Declaration

static var iso8601: Date.ISO8601FormatStyle { get }

<a id="discussion"></a>

## Discussion

Use the dot-notation form of this type property when the call point allows the use of [Date.ISO8601FormatStyle](../date/iso8601formatstyle.md); in other words, when the value type is `Date`. Typically, you use this with the [formatted(\_:)](../date/formatted%28__%29.md) method of `Date`.
