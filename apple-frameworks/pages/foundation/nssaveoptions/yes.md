# NSSaveOptions.yes (Swift)

**Framework:** Foundation  
**Kind:** Case  
**Availability:** Mac Catalyst 13.0+ · macOS 10.0+

Indicates a modified document should be saved on closing without asking the user.

## Declaration

```swift
case yes
```

## See Also

### Constants

- [NSSaveOptions.no](no.md): Indicates a modified document should not be saved on closing.
- [NSSaveOptions.ask](ask.md): Indicates the user should be asked before saving any modified documents on closing. When no option is specified, this is the default.
