# objectForm

**Interface language:** Objective-C

**Framework:** Foundation  
**Kind:** Instance Property  
**Availability:** iOS 15.0+ (deprecated in 17.0) · iPadOS 15.0+ (deprecated in 17.0) · Mac Catalyst 15.0+ (deprecated in 17.0) · macOS 12.0+ (deprecated in 14.0) · tvOS 15.0+ (deprecated in 17.0) · visionOS 1.0+ (deprecated in 1.0) · watchOS 8.0+ (deprecated in 10.0)

The object pronoun form to apply when using this custom pronoun behavior.

## Declaration

```objectivec
@property (nonatomic, copy, nullable) NSString * objectForm;
```

<a id="Discussion"></a>

## Discussion

In the English phrase “ask him,” the pronoun “him” exhibits the object form.
