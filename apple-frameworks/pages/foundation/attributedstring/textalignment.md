# AttributedString.TextAlignment

**Framework:** Foundation  
**Kind:** Enumeration  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

The explicit alignment of text within its container.

## Declaration

```swift
enum TextAlignment
```

<a id="overview"></a>

## Overview

Alignment defines the horizontal position of each line within its container.

## Topics

### Enumeration Cases

- [AttributedString.TextAlignment.center](textalignment/center.md): The horizontal center of each line is aligned to the horizontal center of the container.
- [AttributedString.TextAlignment.left](textalignment/left.md): The left edge of each line is aligned to the left edge of the container.
- [AttributedString.TextAlignment.right](textalignment/right.md): The right edge of each line is aligned to the right edge of the container.
