# Keys for Address Components (Swift)

**Framework:** Foundation  
**Kind:** API Collection

The following constants identify the possible keys returned in the [addressComponents](nstextcheckingresult/addresscomponents.md) dictionary.

## Topics

### Constants

- [name](nstextcheckingkey/name.md): A key that corresponds to the name component of the address.
- [jobTitle](nstextcheckingkey/jobtitle.md): A key that corresponds to the job component of the address.
- [organization](nstextcheckingkey/organization.md): A key that corresponds to the organization component of the address.
- [street](nstextcheckingkey/street.md): A key that corresponds to the street address component of the address.
- [city](nstextcheckingkey/city.md): A key that corresponds to the city component of the address.
- [state](nstextcheckingkey/state.md): A key that corresponds to the state or province component of the address.
- [zip](nstextcheckingkey/zip.md): A key that corresponds to the zip code or postal code component of the address.
- [country](nstextcheckingkey/country.md): A key that corresponds to the country or region component of the address.
- [phone](nstextcheckingkey/phone.md): A key that corresponds to the phone number component of the address.

## See Also

### Constants

- [Keys for Transit Components](keys-for-transit-components.md): The following constants identify the possible keys returned in the components dictionary.
- [NSTextCheckingResult.CheckingType](nstextcheckingresult/checkingtype.md): These constants specify the type of checking the methods should do. They are returned by [resultType](nstextcheckingresult/resulttype.md).
- [NSTextCheckingTypes](nstextcheckingtypes.md): Defines the types of checking that are available. These values can be combined using the C-bitwise OR operator. The system supports its own internal types, and the user can extend those types by subclassing `NSTextCheckingResult` and adding their own custom types.
