# IndexPath.Index

**Framework:** Foundation  
**Kind:** Type Alias  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 8.0+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

A type that points to a particular node in an index path, similar to an array index.

## Declaration

```swift
typealias Index = Array<Int>.Index
```

### Manipulating Indexes

- [startIndex](startindex.md): The index of the first node in the index path.
- [endIndex](endindex.md): One past the index of the last node in the index path.
- [index(after:)](index%28after_%29.md): Returns the index that follows the given index.
- [index(before:)](index%28before_%29.md): Returns the index that precedes the given index.
- [IndexPath.Indices](indices.md): A type that represents a group of nodes in an index path.
