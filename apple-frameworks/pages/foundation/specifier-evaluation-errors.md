# NSScriptObjectSpecifier—Specifier Evaluation Errors

**Interface languages:** Swift, Objective-C

**Framework:** Foundation  
**Kind:** API Collection

`NSScriptObjectSpecifier` provides the following constants for error codes for specific problems evaluating specifiers:

## Topics

### Constants

- [NSNoSpecifierError](nsnospecifiererror.md): No error encountered.
- [NSNoTopLevelContainersSpecifierError](nsnotoplevelcontainersspecifiererror.md): Someone called `evaluate` with `nil`.
- [NSContainerSpecifierError](nscontainerspecifiererror.md): Error evaluating container specifier.
- [NSUnknownKeySpecifierError](nsunknownkeyspecifiererror.md): Receivers do not understand the key.
- [NSInvalidIndexSpecifierError](nsinvalidindexspecifiererror.md): Index out of bounds.
- [NSInternalSpecifierError](nsinternalspecifiererror.md): Other internal error.
- [NSOperationNotSupportedForKeySpecifierError](nsoperationnotsupportedforkeyspecifiererror.md): Attempt made to perform an unsupported operation on some key.
