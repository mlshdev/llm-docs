# ListFormatStyle.Width

**Framework:** Foundation  
**Kind:** Enumeration  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 12.0+ · tvOS 15.0+ · visionOS 1.0+ · watchOS 8.0+

The type representing the width of a list.

## Declaration

```swift
enum Width
```

<a id="overview"></a>

## Overview

The possible values of a [width](width-swift.property.md) are `standard`, `short`, and `narrow`.

## Topics

### Widths

- [ListFormatStyle.Width.standard](width-swift.enum/standard.md): Specifies a standard list style.
- [ListFormatStyle.Width.short](width-swift.enum/short.md): Specifies a short list style.
- [ListFormatStyle.Width.narrow](width-swift.enum/narrow.md): Specifies a narrow list style, the shortest list style.
