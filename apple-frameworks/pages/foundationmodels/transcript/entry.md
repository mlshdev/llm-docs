## Overview

An individual entry in a transcript may represent instructions from you to the model, a prompt from a user, tool calls, or a response generated by the model.

## Topics

### Entry cases

- [Transcript.Entry.instructions(\_:)](entry/instructions%28__%29.md): Instructions, typically provided by you, the developer.
- [Transcript.Entry.prompt(\_:)](entry/prompt%28__%29.md): A prompt, typically sourced from an end user.
- [Transcript.Entry.response(\_:)](entry/response%28__%29.md): A response from the model.
- [Transcript.Entry.reasoning(\_:)](entry/reasoning%28__%29.md): Reasoning from the model.
- [Transcript.Response](response.md): A response from the model.
- [Transcript.Entry.toolCalls(\_:)](entry/toolcalls%28__%29.md): A tool call containing a tool name and the arguments to invoke it with.
- [Transcript.ToolCalls](toolcalls.md): A collection tool calls generated by the model.
- [Transcript.ToolCall](toolcall.md): A tool call generated by the model containing the name of a tool and arguments to pass to it.
- [Transcript.Entry.toolOutput(\_:)](entry/tooloutput%28__%29.md): An tool output provided back to the model.
- [Transcript.ToolOutput](tooloutput.md): A tool output provided back to the model.
