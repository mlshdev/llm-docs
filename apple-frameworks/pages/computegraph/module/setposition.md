# module::setPosition

**Framework:** Compute Graph  
**Kind:** Function  
**Availability:** macOS · Reality Composer Pro

Sets the position of an element to the specified coordinates.

## Declaration

```swift
void module::setPosition(float3 position)
```

## Parameters

- `position`: The new position coordinates in 3D space

<a id="discussion"></a>

## Discussion

Use this function to move an element to a specific location in 3D space, replacing its current position.
