# File System Metadata Attribute Keys (Swift)

**Framework:** Core Services  
**Kind:** API Collection

Metadata attribute keys that describe the file system attributes for a file.

## Topics

### Constants

- [kMDItemDisplayName](../../kmditemdisplayname.md): The localized version of the file name. A CFString.
- [kMDItemFSContentChangeDate](../../kmditemfscontentchangedate.md): The date the file contents last changed. A CFDate.
- [kMDItemFSCreationDate](../../kmditemfscreationdate.md): The date and time that the file was created. A CFDate.
- [kMDItemFSInvisible](../../kmditemfsinvisible.md): Indicates whether the file is invisible. A CFBoolean.
- [kMDItemFSIsExtensionHidden](../../kmditemfsisextensionhidden.md): Indicates whether the file extension of the file is hidden. A CFBoolean.
- [kMDItemFSLabel](../../kmditemfslabel.md): Index of the Finder label of the file. Possible values are 0 through 7. A CFNumber.
- [kMDItemFSName](../../kmditemfsname.md): The file name of the item. A CFString.
- [kMDItemFSNodeCount](../../kmditemfsnodecount.md): Number of files in a directory. A CFNumber.
- [kMDItemFSOwnerGroupID](../../kmditemfsownergroupid.md): The group ID of the owner of the file. A CFNumber.
- [kMDItemFSOwnerUserID](../../kmditemfsowneruserid.md): The user ID of the owner of the file. A CFNumber.
- [kMDItemFSSize](../../kmditemfssize.md): The size, in bytes, of the file on disk. A CFNumber.
- [kMDItemPath](../../kmditempath.md): The complete path to the file. A CFString.
