# Video Metadata Attribute Keys

**Interface languages:** Swift, Objective-C

**Framework:** Core Services  
**Kind:** API Collection

Metadata attribute keys that are common to video files.

## Topics

### Constants

- [kMDItemAudioBitRate](../../kmditemaudiobitrate.md): The audio bit rate. A CFNumber.
- [kMDItemCodecs](../../kmditemcodecs.md): The codecs used to encode/decode the media. A CFArray of CFStrings.
- [kMDItemDeliveryType](../../kmditemdeliverytype.md): The delivery type. Values are “Fast start” or “RTSP”. A CFString.
- [kMDItemMediaTypes](../../kmditemmediatypes.md): The media types present in the content. A CFArray of CFStrings.
- [kMDItemStreamable](../../kmditemstreamable.md): Whether the content is prepared for streaming. A CFBoolean.
- [kMDItemTotalBitRate](../../kmditemtotalbitrate.md): The total bit rate, audio and video combined, of the media. A CFNumber.
- [kMDItemVideoBitRate](../../kmditemvideobitrate.md): The video bit rate. A CFNumber.
- [kMDItemDirector](../../kmditemdirector.md): Directory of the movie. A CFString.
- [kMDItemProducer](../../kmditemproducer.md): Producer of the content. A CFString.
- [kMDItemGenre](../../kmditemgenre.md): Genre of the movie. A CFString.
- [kMDItemPerformers](../../kmditemperformers.md): Performers in the movie. A CFArray of CFStrings.
- [kMDItemOriginalFormat](../../kmditemoriginalformat.md): Original format of the movie. A CFString.
- [kMDItemOriginalSource](../../kmditemoriginalsource.md): Original source of the movie. A CFString.
