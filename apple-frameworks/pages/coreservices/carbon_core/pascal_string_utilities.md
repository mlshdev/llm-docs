# Pascal String Utilities

**Interface language:** Objective-C

**Framework:** Core Services  
**Kind:** API Collection

Performing common string manipulations on Pascal strings.

> In macOS 10.4 and later, use Foundation and Core Foundation APIs instead. You can use the [CFStringCreateWithPascalString(\_:\_:\_:)](../../corefoundation/cfstringcreatewithpascalstring%28______%29.md) function to convert from Pascal strings to [CFString](../../corefoundation/cfstring.md) objects, which are toll-free bridged to [NSString](../../foundation/nsstring.md).  For more information, see [String Programming Guide](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/Strings/introStrings.html#//apple_ref/doc/uid/10000035i).
