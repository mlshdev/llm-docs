# Mathematical and Logical Utilities

**Interface language:** Objective-C

**Framework:** Core Services  
**Kind:** API Collection

Perform mathematical and logical operations.

> Many of the functions provided are unnecessary now that most compilers natively support 64-bit numeric types. In macOS 10, use Foundation and Darwin APIs instead.
