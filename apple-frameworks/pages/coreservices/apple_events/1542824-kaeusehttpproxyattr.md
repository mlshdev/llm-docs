# kAEUseHTTPProxyAttr

**Framework:** Core Services

Web Services Proxy support—these constants should be added as attributes of the event that is being sent (not as part of the direct object).

## Topics

### Constants

- [kAEUseHTTPProxyAttr](../kaeusehttpproxyattr.md): A value of type `typeBoolean`. Specifies whether to manually specify the proxy host and port. Defaults to `true`.
- [kAEHTTPProxyPortAttr](../kaehttpproxyportattr.md): A value of type `typeSInt32`.
- [kAEHTTPProxyHostAttr](../kaehttpproxyhostattr.md): A value of type `typeChar` or `typeUTF8Text`.
