# kLSHandlerOptionsDefault

**Interface language:** Objective-C

**Framework:** Core Services  
**Kind:** Enumeration Case  
**Availability:** Mac Catalyst 13.1+ (deprecated in 13.1) · macOS 10.4+ (deprecated in 10.11)

When set, causes Launch Services to use a contentitem’s creator (when available) to select a handler. This is thedefault setting.

## Declaration

```objectivec
kLSHandlerOptionsDefault = 0
```
