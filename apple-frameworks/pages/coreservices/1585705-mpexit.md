# MPExit

**Interface language:** Objective-C

**Framework:** Core Services  
**Kind:** Function  
**Availability:** macOS 10.0+ (deprecated in 10.7)

Allows a task to terminate itself

## Declaration

```objectivec
void MPExit(OSStatus status);
```

## Parameters

- `status`: An application-defined value that indicates termination status. This value is sent to the termination message queue in place of the task’s result code.

<a id="discussion"></a>

## Discussion

When called from within a preemptive task, the task terminates, and the value indicated by the parameter `status` is sent to the termination message queue you specified in  [MPCreateTask](1585779-mpcreatetask.md). Note that you cannot call `MPExit` from outside a preemptive task.
