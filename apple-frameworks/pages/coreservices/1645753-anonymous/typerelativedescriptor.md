# typeRelativeDescriptor

**Interface language:** Objective-C

**Framework:** Core Services  
**Kind:** Enumeration Case  
**Availability:** Mac Catalyst 13.0+ · macOS 10.0+

Specifies a descriptor whose data consists of one of the constants `kAENext` or `kAEPrevious`, which are described in [AEDisposeToken](../1446783-aedisposetoken.md). Used with `formRelativePosition`.
