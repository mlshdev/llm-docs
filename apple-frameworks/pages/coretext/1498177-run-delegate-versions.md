# Run Delegate Versions (Swift)

**Framework:** Core Text  
**Kind:** API Collection

The version of the run delegate.

<a id="overview"></a>

## Overview

Set the version field of the [CTRunDelegateCallbacks](ctrundelegatecallbacks.md) structure to `kCTRunDelegateCurrentVersion` when creating a CTRunDelegate object with a call to [CTRunDelegateCreate(\_:\_:)](ctrundelegatecreate%28____%29.md).

## Topics

### Constants

- [kCTRunDelegateVersion1](kctrundelegateversion1.md): Version 1 of the run delegate.
- [kCTRunDelegateCurrentVersion](kctrundelegatecurrentversion.md): The current version of the run delegate.
