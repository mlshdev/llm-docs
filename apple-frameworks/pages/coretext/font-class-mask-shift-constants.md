# Font Class Mask Shift Constants

**Interface languages:** Swift, Objective-C

**Framework:** Core Text  
**Kind:** API Collection

These constants represent the font class mask shift.

## Topics

### Constants

- [kCTFontClassMaskShift](kctfontclassmaskshift.md): Value used to shift the font class to the uppermost four bits of the symbolic traits.
