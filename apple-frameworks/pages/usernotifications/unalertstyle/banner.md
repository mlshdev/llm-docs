# UNAlertStyle.banner (Swift)

**Framework:** User Notifications  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 10.14+ · visionOS 1.0+

Banner alerts.

## Declaration

```swift
case banner
```

<a id="Discussion"></a>

## Discussion

Alerts are displayed as a slide-down banner. Banners appear for a short time and then disappear automatically if the user does nothing.

## See Also

### Presentation Styles

- [UNAlertStyle.none](none.md): No alert.
- [UNAlertStyle.alert](alert.md): Modal alerts.
