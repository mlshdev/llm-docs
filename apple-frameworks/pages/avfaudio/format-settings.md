# Format Settings

**Interface languages:** Swift, Objective-C

**Framework:** AVFAudio  
**Kind:** API Collection

The audio settings that apply to all audio formats that the audio player and recorder classes support.

## Topics

### Settings

- [AVFormatIDKey](avformatidkey.md): An integer value that represents the format of the audio data.
- [AVSampleRateKey](avsampleratekey.md): A floating point value that represents the sample rate, in hertz.
- [AVNumberOfChannelsKey](avnumberofchannelskey.md): An integer value that represents the number of channels.

## See Also

### Formats

- [AVAudioFormat](avaudioformat.md): An object that describes the representation of an audio format.
- [AVAudioChannelLayout](avaudiochannellayout.md): An object that describes the roles of a set of audio channels.
- [AVChannelLayoutKey](avchannellayoutkey.md)
- [Linear PCM Format Settings](linear-pcm-format-settings.md): The audio settings that apply to linear PCM audio formats.
