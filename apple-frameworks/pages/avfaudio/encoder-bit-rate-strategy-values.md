# Encoder Bit Rate Strategy Values

**Interface languages:** Swift, Objective-C

**Framework:** AVFAudio  
**Kind:** API Collection

The constants that represent the possible bit rate strategy values.

<a id="overview"></a>

## Overview

You use these values with [AVEncoderBitRateStrategyKey](avencoderbitratestrategykey.md).

## Topics

### Strategies

- [AVAudioBitRateStrategy_Constant](avaudiobitratestrategy_constant.md): A value that represents a constant bit rate strategy.
- [AVAudioBitRateStrategy_LongTermAverage](avaudiobitratestrategy_longtermaverage.md): A value that represents an average bit rate strategy.
- [AVAudioBitRateStrategy_VariableConstrained](avaudiobitratestrategy_variableconstrained.md): A value that represents a constrained variable bit rate strategy.
- [AVAudioBitRateStrategy_Variable](avaudiobitratestrategy_variable.md): A value that represents a variable bit rate strategy.
