# AVAudioSession.RecordPermission.undetermined (Swift)

**Framework:** AVFAudio  
**Kind:** Case  
**Availability:** iOS 8.0+ (deprecated in 17.0) · iPadOS 8.0+ (deprecated in 17.0) · Mac Catalyst 13.1+ (deprecated in 17.0) · visionOS 1.0+ (deprecated in 1.0) · watchOS 4.0+ (deprecated in 10.0)

A value that indicates that the user hasn’t granted or denied recording permission.

## Declaration

```swift
case undetermined
```

<a id="Discussion"></a>

## Discussion

A permission of [AVAudioSession.RecordPermission.undetermined](undetermined.md) typically means that your app hasn’t requested, or is in the process of requesting, recording permission.

## See Also

### Record Permissions

- [AVAudioSession.RecordPermission.denied](denied.md): Deprecated. A value that indicates that the user has denied recording permission.
- [AVAudioSession.RecordPermission.granted](granted.md): Deprecated. A value that indicates that the user has granted recording permission.
