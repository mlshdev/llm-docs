# Cellular Call States

**Interface languages:** Swift, Objective-C

**Framework:** Core Telephony  
**Kind:** API Collection

States of cellular calls; one of dialing, incoming, connected, or disconnected.

## Topics

### Constants

- [CTCallStateDialing](ctcallstatedialing.md): Deprecated. The call state, before establishing the connection, when the user initiates the call.
- [CTCallStateIncoming](ctcallstateincoming.md): Deprecated. The call state, before establishing the connection, when a call is incoming but not yet answered by the user.
- [CTCallStateConnected](ctcallstateconnected.md): Deprecated. The call state when fully establishing the call for all parties involved.
- [CTCallStateDisconnected](ctcallstatedisconnected.md): Deprecated. The call state upon call termination.
