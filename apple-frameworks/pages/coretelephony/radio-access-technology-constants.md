# Radio Access Technology Constants

**Interface languages:** Swift, Objective-C

**Framework:** Core Telephony  
**Kind:** API Collection

Constants that describe the current radio access technology.

## Topics

### Constants

- [CTRadioAccessTechnologyGPRS](ctradioaccesstechnologygprs.md): The General Packet Radio Service (GPRS) radio access technology.
- [CTRadioAccessTechnologyEdge](ctradioaccesstechnologyedge.md): The Enhanced Data rates for GSM Evolution (EDGE) radio access technology.
- [CTRadioAccessTechnologyWCDMA](ctradioaccesstechnologywcdma.md): The Wideband Code Division Multiple Access (WCDMA) radio access technology.
- [CTRadioAccessTechnologyHSDPA](ctradioaccesstechnologyhsdpa.md): The High-Speed Downlink Packet Access (HSDPA) radio access technology.
- [CTRadioAccessTechnologyHSUPA](ctradioaccesstechnologyhsupa.md): The High-Speed Uplink Packet Acess (HSUPA) radio access technology.
- [CTRadioAccessTechnologyCDMA1x](ctradioaccesstechnologycdma1x.md): The Code Division Multiple Access (CDMA) 1x radio access technology.
- [CTRadioAccessTechnologyCDMAEVDORev0](ctradioaccesstechnologycdmaevdorev0.md): The Code Division Multiple Access (CDMA) Evolution-Data Optimized (EV-DO) Rev. 0 radio access technology.
- [CTRadioAccessTechnologyCDMAEVDORevA](ctradioaccesstechnologycdmaevdoreva.md): The Code Division Multiple Access (CDMA) Evolution-Data Optimized (EV-DO) Rev. A radio access technology.
- [CTRadioAccessTechnologyCDMAEVDORevB](ctradioaccesstechnologycdmaevdorevb.md): The Code Division Multiple Access (CDMA) Evolution-Data Optimized (EV-DO) Rev. B radio access technology.
- [CTRadioAccessTechnologyeHRPD](ctradioaccesstechnologyehrpd.md): The Enhanced High Rate Packet Data (eHRPD) radio access technology.
- [CTRadioAccessTechnologyLTE](ctradioaccesstechnologylte.md): The Long-Term Evolution (LTE) radio access technology.
- [CTRadioAccessTechnologyNRNSA](ctradioaccesstechnologynrnsa.md): The 5G New Radio Non-Standalone (NRNSA) radio access technology.
- [CTRadioAccessTechnologyNR](ctradioaccesstechnologynr.md): The 5G New Radio (NR) radio access technology.
