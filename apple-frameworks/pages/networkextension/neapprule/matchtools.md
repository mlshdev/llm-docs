# matchTools (Swift)

**Framework:** Network Extension  
**Kind:** Instance Property  
**Availability:** macOS 10.15.4+

An array of app rule objects that restrict the rule so it only matches network traffic generated from helper processes.

## Declaration

```swift
var matchTools: [NEAppRule]? { get set }
```

<a id="Discussion"></a>

## Discussion

Use this property to restrict this rule so it only matches network traffic that the matching app generates and all helper tool processes that the matching app spawns.

For example, to match network traffic generated by the `curl` command line tool run from `Terminal.app`, do the following:

1. Create an [NEAppRule](../neapprule.md) for `Terminal.app`.
2. Set the app rule’s [matchTools](matchtools.md) property to an array that contains an [NEAppRule](../neapprule.md) for the `curl` command line tool.

Set this property to `nil` (the default) to match all network traffic generated by the matching app and all helper tool processes spawned by the matching app.

## See Also

### Accessing app rule properties

- [matchSigningIdentifier](matchsigningidentifier.md): The signing identifier of the app that matches the rule.
- [matchDesignatedRequirement](matchdesignatedrequirement.md): The designated requirement of the app that matches the rule.
- [matchPath](matchpath.md): The file system path of the app that matches the rule.
- [matchDomains](matchdomains.md): The hostname domains that match the rule.
