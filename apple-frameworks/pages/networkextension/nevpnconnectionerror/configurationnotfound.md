# NEVPNConnectionError.configurationNotFound (Swift)

**Framework:** Network Extension  
**Kind:** Case  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · Mac Catalyst 16.0+ · macOS 13.0+ · tvOS 17.0+ · visionOS 1.0+

An error code that indicates the VPN connection failed because the system couldn’t find a configuration.

## Declaration

```swift
case configurationNotFound
```
