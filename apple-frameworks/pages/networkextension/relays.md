# Relays

**Interface languages:** Swift, Objective-C

**Framework:** Network Extension  
**Kind:** API Collection

Create and manage a system-wide network relay configuration that uses built-in proxying for TCP and UDP traffic over HTTP/3 and HTTP/2.

## Topics

### Essentials

- [Network Extensions Entitlement](../bundleresources/entitlements/com.apple.developer.networking.networkextension.md): The APIs an app can use to customize networking features.

### Relay configuration

- [NERelayManager](nerelaymanager.md): An object you use to create and manage a network relay configuration.
- [NERelay](nerelay.md): A single relay server configuration that you can chain together with other relays.
