# Video Pixel Formats

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Constants that identify video pixel formats.

## Topics

### Constants

- [kCMPixelFormat_16BE555](kcmpixelformat_16be555.md): A type that describes 16-bit big-endian 5-5-5.
- [kCMPixelFormat_16BE565](kcmpixelformat_16be565.md): A type that describes 16-bit big-endian 5-6-5.
- [kCMPixelFormat_16LE555](kcmpixelformat_16le555.md): A type that describes 16-bit little-endian 5-5-5.
- [kCMPixelFormat_16LE5551](kcmpixelformat_16le5551.md): A type that describes 16-bit little-endian 5-5-5-1.
- [kCMPixelFormat_16LE565](kcmpixelformat_16le565.md): A type that describes 16-bit little-endian 5-6-5.
- [kCMPixelFormat_24RGB](kcmpixelformat_24rgb.md): A type that describes 24-bit RGB.
- [kCMPixelFormat_32ARGB](kcmpixelformat_32argb.md): A type that describes 32-bit ARGB.
- [kCMPixelFormat_32BGRA](kcmpixelformat_32bgra.md): A type that describes 32-bit BGRA.
- [kCMPixelFormat_422YpCbCr10](kcmpixelformat_422ypcbcr10.md): A type that describes component Y’CbCr 10-bit 4:2:2.
- [kCMPixelFormat_422YpCbCr16](kcmpixelformat_422ypcbcr16.md): A type that describes component Y’CbCr 10,12,14,16-bit 4:2:2.
- [kCMPixelFormat_422YpCbCr8](kcmpixelformat_422ypcbcr8.md): A type that describes component Y’CbCr 8-bit 4:2:2 ordered Cb Y’0 Cr Y’1.
- [kCMPixelFormat_422YpCbCr8_yuvs](kcmpixelformat_422ypcbcr8_yuvs.md): A type that describes component Y’CbCr 8-bit 4:2:2 ordered Y’0 Cb Y’1 Cr.
- [kCMPixelFormat_4444YpCbCrA8](kcmpixelformat_4444ypcbcra8.md): A type that describes component Y’CbCrA 8-bit 4:4:4:4.
- [kCMPixelFormat_444YpCbCr10](kcmpixelformat_444ypcbcr10.md): A type that describes component Y’CbCr 10-bit 4:4:4
- [kCMPixelFormat_444YpCbCr8](kcmpixelformat_444ypcbcr8.md): A type that describes component Y’CbCr 8-bit 4:4:4.
- [kCMPixelFormat_8IndexedGray_WhiteIsZero](kcmpixelformat_8indexedgray_whiteiszero.md): A type that describes 8-bit indexed gray, white is zero.
