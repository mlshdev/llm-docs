# MPEG-2-conformant Formats

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Constants that identify MPEG-2 formats.

## Topics

### Constants

- [kCMFormatDescriptionConformsToMPEG2VideoProfile](kcmformatdescriptionconformstompeg2videoprofile.md): The value is a number that specifies the MPEG2 video profile.
- [kCMFormatDescriptionExtension_TemporalQuality](kcmformatdescriptionextension_temporalquality.md): The value is a number.
- [kCMFormatDescriptionExtension_SpatialQuality](kcmformatdescriptionextension_spatialquality.md): The value is a number.
- [kCMFormatDescriptionExtension_Version](kcmformatdescriptionextension_version.md): The value is a number.
- [kCMFormatDescriptionExtension_RevisionLevel](kcmformatdescriptionextension_revisionlevel.md): The value is a number.
- [kCMFormatDescriptionExtension_Vendor](kcmformatdescriptionextension_vendor.md): The value is a string of four character codes.
- [kCMFormatDescriptionVendor_Apple](kcmformatdescriptionvendor_apple.md): A string that speicifies Apple as the vendor.
