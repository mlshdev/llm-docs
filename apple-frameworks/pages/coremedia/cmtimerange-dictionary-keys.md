# Dictionary Keys (Swift)

**Framework:** Core Media  
**Kind:** API Collection

Keys to use when working with dictionary representations of a time range.

<a id="overview"></a>

## Overview

To convert a `CMTimeRange` to and from a `CFDictionary`, see [CMTimeRangeCopyAsDictionary(\_:allocator:)](cmtimerangecopyasdictionary%28__allocator_%29.md) and [CMTimeRangeMakeFromDictionary(\_:)](cmtimerangemakefromdictionary%28__%29.md).

## Topics

### Constants

- [kCMTimeRangeStartKey](kcmtimerangestartkey.md): The key for the start field of a time range.
- [kCMTimeRangeDurationKey](kcmtimerangedurationkey.md): The key for the timescale of a time range.

## See Also

### Constants
