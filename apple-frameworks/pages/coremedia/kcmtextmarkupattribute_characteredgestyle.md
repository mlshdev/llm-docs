# kCMTextMarkupAttribute_CharacterEdgeStyle (Swift)

**Framework:** Core Media  
**Kind:** Global Variable  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 6.0+

A style for character edges.

## Declaration

```swift
let kCMTextMarkupAttribute_CharacterEdgeStyle: CFString
```

<a id="Discussion"></a>

## Discussion

This attribute’s value must be one of the constants listed below that control the shape of the edges of drawn characters. The default value is [kCMTextMarkupCharacterEdgeStyle_None](kcmtextmarkupcharacteredgestyle_none.md).

## Topics

### Edge Styles

- [kCMTextMarkupCharacterEdgeStyle_None](kcmtextmarkupcharacteredgestyle_none.md): No edge style.
- [kCMTextMarkupCharacterEdgeStyle_Raised](kcmtextmarkupcharacteredgestyle_raised.md): A raised edge style.
- [kCMTextMarkupCharacterEdgeStyle_Depressed](kcmtextmarkupcharacteredgestyle_depressed.md): A depressed edge style.
- [kCMTextMarkupCharacterEdgeStyle_Uniform](kcmtextmarkupcharacteredgestyle_uniform.md): A uniform border style.
- [kCMTextMarkupCharacterEdgeStyle_DropShadow](kcmtextmarkupcharacteredgestyle_dropshadow.md): A drop shadow style.
