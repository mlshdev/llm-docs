# Metadata Registry Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Error codes that indicate metadata registry errors.

## Topics

### Constants

- [kCMMetadataDataTypeRegistryError_AllocationFailed](kcmmetadatadatatyperegistryerror_allocationfailed.md): An error that indicates the allocation fails.
- [kCMMetadataDataTypeRegistryError_BadDataTypeIdentifier](kcmmetadatadatatyperegistryerror_baddatatypeidentifier.md): An error that indicates a bad datatype identifier.
- [kCMMetadataDataTypeRegistryError_DataTypeAlreadyRegistered](kcmmetadatadatatyperegistryerror_datatypealreadyregistered.md): An error that indicates the datatype is in a registered state.
- [kCMMetadataDataTypeRegistryError_MultipleConformingBaseTypes](kcmmetadatadatatyperegistryerror_multipleconformingbasetypes.md): An error that indicates that type you provide has more than one base data type.
- [kCMMetadataDataTypeRegistryError_RequiredParameterMissing](kcmmetadatadatatyperegistryerror_requiredparametermissing.md): An error that indicates a parameter the function requires is empty.
- [kCMMetadataDataTypeRegistryError_RequiresConformingBaseType](kcmmetadatadatatyperegistryerror_requiresconformingbasetype.md): An error that indicates the data type you specify requires a conforming data type that resolves to a base data type.
