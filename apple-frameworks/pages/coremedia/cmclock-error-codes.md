# CMClock Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Constants that represent the errors in Core Media clock operations.

## Topics

### Constants

- [kCMClockError_MissingRequiredParameter](kcmclockerror_missingrequiredparameter.md): A clock error that indicates a parameter is missing.
- [kCMClockError_InvalidParameter](kcmclockerror_invalidparameter.md): A clock error that indicates a parameter isn’t valid.
- [kCMClockError_AllocationFailed](kcmclockerror_allocationfailed.md): A clock error that indicates the memory allocation fails.
- [kCMClockError_UnsupportedOperation](kcmclockerror_unsupportedoperation.md): A clock error that indicates the operation isn’t supported.
