# CMSync error codes

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Constants that represent error codes Core Media sync operations return.

## Topics

### Constants

- [kCMSyncError_MissingRequiredParameter](kcmsyncerror_missingrequiredparameter.md): A sync error that indicates a parameter is missing.
- [kCMSyncError_InvalidParameter](kcmsyncerror_invalidparameter.md): A sync error that indicates a parameter isn’t valid.
- [kCMSyncError_AllocationFailed](kcmsyncerror_allocationfailed.md): A sync error that indicates the memory allocation fails.
- [kCMSyncError_RateMustBeNonZero](kcmsyncerror_ratemustbenonzero.md): A sync error that indicates the rate is nonzero.
