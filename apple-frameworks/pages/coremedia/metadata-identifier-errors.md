# Metadata Identifier Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Error codes that indicate metadata identifier errors.

## Topics

### Constants

- [kCMMetadataIdentifierError_AllocationFailed](kcmmetadataidentifiererror_allocationfailed.md): An error that indicates an allocation fails.
- [kCMMetadataIdentifierError_BadIdentifier](kcmmetadataidentifiererror_badidentifier.md): An error that indicates the identifier isn’t valid.
- [kCMMetadataIdentifierError_BadKey](kcmmetadataidentifiererror_badkey.md): An error that indicates a key isn’t valid.
- [kCMMetadataIdentifierError_BadKeyLength](kcmmetadataidentifiererror_badkeylength.md): An error that indicates that a key doesn’t have the correct length.
- [kCMMetadataIdentifierError_BadKeySpace](kcmmetadataidentifiererror_badkeyspace.md): An error that indicates the keyspace isn’t valid.
- [kCMMetadataIdentifierError_BadKeyType](kcmmetadataidentifiererror_badkeytype.md): An error that indicates a key has a bad type.
- [kCMMetadataIdentifierError_BadNumberKey](kcmmetadataidentifiererror_badnumberkey.md): An error that indicates the number for a key isn’t valid.
- [kCMMetadataIdentifierError_NoKeyValueAvailable](kcmmetadataidentifiererror_nokeyvalueavailable.md): An error that indicates a request for a key value in the anonymous keyspace.
- [kCMMetadataIdentifierError_RequiredParameterMissing](kcmmetadataidentifiererror_requiredparametermissing.md): An error that indicates a parameter the function requires is empty.
