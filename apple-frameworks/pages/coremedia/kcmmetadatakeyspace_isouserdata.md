# kCMMetadataKeySpace_ISOUserData (Swift)

**Framework:** Core Media  
**Kind:** Global Variable  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.1+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 6.0+

Metadata keyspace for MPEG-4 User Data keys.

## Declaration

```swift
let kCMMetadataKeySpace_ISOUserData: CFString
```

<a id="Discussion"></a>

## Discussion

This keyspace defines its key values to be expressed as `OSType`s (a.k.a. `FourCharCode`s). As such, keys must be four bytes in length.
