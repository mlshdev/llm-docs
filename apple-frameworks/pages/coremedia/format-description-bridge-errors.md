# Format Description Bridge Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Core Media  
**Kind:** API Collection

Bridge errors the system returns from format description calls.

## Topics

### Constants

- [kCMFormatDescriptionBridgeError_InvalidParameter](kcmformatdescriptionbridgeerror_invalidparameter.md): A bridge error that indicates that the function recieves an empty value for a parameter it requires.
- [kCMFormatDescriptionBridgeError_AllocationFailed](kcmformatdescriptionbridgeerror_allocationfailed.md): A bridge error that indicates when an allocation fails.
- [kCMFormatDescriptionBridgeError_IncompatibleFormatDescription](kcmformatdescriptionbridgeerror_incompatibleformatdescription.md): A bridge error that indicates the format description has an unknown format.
- [kCMFormatDescriptionBridgeError_InvalidFormatDescription](kcmformatdescriptionbridgeerror_invalidformatdescription.md): A bridge error that indicates the format description isn’t valid.
- [kCMFormatDescriptionBridgeError_InvalidSerializedSampleDescription](kcmformatdescriptionbridgeerror_invalidserializedsampledescription.md): A bridge error that indicates that the sample isn’t valid.
- [kCMFormatDescriptionBridgeError_InvalidSlice](kcmformatdescriptionbridgeerror_invalidslice.md): A bridge error that indicates the slice isn’t valid.
- [kCMFormatDescriptionBridgeError_UnsupportedSampleDescriptionFlavor](kcmformatdescriptionbridgeerror_unsupportedsampledescriptionflavor.md): A bridge error that indicates the sample isn’t supported for the format flavor you specify.
