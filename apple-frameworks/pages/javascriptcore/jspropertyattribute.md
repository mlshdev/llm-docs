# JSPropertyAttribute

**Framework:** JavaScriptCore  
**Kind:** API Collection

A JavaScript property attribute.

## Topics

### Constants

- [kJSPropertyAttributeNone](kjspropertyattributenone.md): An attribute that specifies that a property has no special attributes.
- [kJSPropertyAttributeReadOnly](kjspropertyattributereadonly.md): An attribute that specifies that a property is read-only.
- [kJSPropertyAttributeDontEnum](kjspropertyattributedontenum.md): An attribute that specifies that property enumerators and JavaScript for-in loops don’t enumerate a property.
- [kJSPropertyAttributeDontDelete](kjspropertyattributedontdelete.md): An attribute that specifies that the delete operation fails on a property.
