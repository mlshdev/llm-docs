# JSClassAttribute

**Framework:** JavaScriptCore  
**Kind:** API Collection

A JavaScript class attribute.

## Topics

### Constants

- [kJSClassAttributeNone](kjsclassattributenone.md): An attribute that specifies that a class has no special attributes.
- [kJSClassAttributeNoAutomaticPrototype](kjsclassattributenoautomaticprototype.md): An attribute that specifies that a class doesn’t automatically generate a shared prototype for its instance objects.
