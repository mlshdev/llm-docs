# TIFF Image Properties

**Interface languages:** Swift, Objective-C

**Framework:** Image I/O  
**Kind:** API Collection

Metadata keys for the Tagged Image File Format (TIFF).

## Topics

### Dictionary

- [kCGImagePropertyTIFFDictionary](kcgimagepropertytiffdictionary.md): A dictionary of key-value pairs for an image that uses Tagged Image File Format (TIFF).

### Image Quality

- [kCGImagePropertyTIFFCompression](kcgimagepropertytiffcompression.md): The compression scheme used on the image data.
- [kCGImagePropertyTIFFPhotometricInterpretation](kcgimagepropertytiffphotometricinterpretation.md): The color space of the image data.
- [kCGImagePropertyTIFFTransferFunction](kcgimagepropertytifftransferfunction.md): The transfer function, in tabular format, used to map pixel components from a nonlinear form into a linear form.

### Canvas Details

- [kCGImagePropertyTIFFOrientation](kcgimagepropertytifforientation.md): The image orientation.
- [kCGImagePropertyTIFFXResolution](kcgimagepropertytiffxresolution.md): The number of pixels per resolution unit in the image width direction.
- [kCGImagePropertyTIFFYResolution](kcgimagepropertytiffyresolution.md): The number of pixels per resolution unit in the image height direction.
- [kCGImagePropertyTIFFResolutionUnit](kcgimagepropertytiffresolutionunit.md): The units of resolution.
- [kCGImagePropertyTIFFWhitePoint](kcgimagepropertytiffwhitepoint.md): The white point of the image.
- [kCGImagePropertyTIFFPrimaryChromaticities](kcgimagepropertytiffprimarychromaticities.md): The chromaticities of the primaries of the image.
- [kCGImagePropertyTIFFTileLength](kcgimagepropertytifftilelength.md)
- [kCGImagePropertyTIFFTileWidth](kcgimagepropertytifftilewidth.md)

### Descriptive Information

- [kCGImagePropertyTIFFDocumentName](kcgimagepropertytiffdocumentname.md): The document name.
- [kCGImagePropertyTIFFImageDescription](kcgimagepropertytiffimagedescription.md): The image description.
- [kCGImagePropertyTIFFArtist](kcgimagepropertytiffartist.md): The artist who created the image.
- [kCGImagePropertyTIFFCopyright](kcgimagepropertytiffcopyright.md): Copyright information.
- [kCGImagePropertyTIFFDateTime](kcgimagepropertytiffdatetime.md): The date and time that the image was created.
- [kCGImagePropertyTIFFMake](kcgimagepropertytiffmake.md): The name of the manufacturer of the camera or input device.
- [kCGImagePropertyTIFFModel](kcgimagepropertytiffmodel.md): The camera or input device model.
- [kCGImagePropertyTIFFSoftware](kcgimagepropertytiffsoftware.md): The name and version of the software used for image creation.
- [kCGImagePropertyTIFFHostComputer](kcgimagepropertytiffhostcomputer.md): The computer or operating system used when the image was created.
