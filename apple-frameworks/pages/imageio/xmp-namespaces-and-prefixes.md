# XMP Namespaces and Prefixes (Swift)

**Framework:** Image I/O  
**Kind:** API Collection

Discover the public namespaces and prefixes that exist in XMP metadata tags.

## Topics

### Public Namespaces

- [kCGImageMetadataNamespaceDublinCore](kcgimagemetadatanamespacedublincore.md): The namespace for the Dublin Core Metadata Element Set.
- [kCGImageMetadataNamespaceExif](kcgimagemetadatanamespaceexif.md): The namespace for the Exchangeable Image File (EXIF) format.
- [kCGImageMetadataNamespaceExifAux](kcgimagemetadatanamespaceexifaux.md): The namespace for EXIF auxiliary keys.
- [kCGImageMetadataNamespaceExifEX](kcgimagemetadatanamespaceexifex.md): The namespace for the exifEX format.
- [kCGImageMetadataNamespaceIPTCCore](kcgimagemetadatanamespaceiptccore.md): The namespace for the IPTC format.
- [kCGImageMetadataNamespacePhotoshop](kcgimagemetadatanamespacephotoshop.md): The namespace for Photoshop image metadata.
- [kCGImageMetadataNamespaceTIFF](kcgimagemetadatanamespacetiff.md): The namespace for TIFF image metadata.
- [kCGImageMetadataNamespaceXMPBasic](kcgimagemetadatanamespacexmpbasic.md): The namespace for the Extensible Metadata Platform (XMP) format.
- [kCGImageMetadataNamespaceXMPRights](kcgimagemetadatanamespacexmprights.md): The namespace for XMP metadata that conveys legal restrictions associated with a resource.

### Public Prefixes

- [kCGImageMetadataPrefixDublinCore](kcgimagemetadataprefixdublincore.md): The prefix string for tags in the Dublin Core Metadata Element Set.
- [kCGImageMetadataPrefixExif](kcgimagemetadataprefixexif.md): The prefix string for tags in the Exchangeable Image File (EXIF) metadata.
- [kCGImageMetadataPrefixExifAux](kcgimagemetadataprefixexifaux.md): The prefix string for tags in the EXIF auxiliary metadata collection.
- [kCGImageMetadataPrefixExifEX](kcgimagemetadataprefixexifex.md): The prefix string for tags in the exifEX metadata.
- [kCGImageMetadataPrefixIPTCCore](kcgimagemetadataprefixiptccore.md): The prefix string for tags in the IPTC metadata.
- [kCGImageMetadataPrefixPhotoshop](kcgimagemetadataprefixphotoshop.md): The prefix string for tags in the Photoshop image metadata.
- [kCGImageMetadataPrefixTIFF](kcgimagemetadataprefixtiff.md): The prefix string for tags in the TIFF image metadata.
- [kCGImageMetadataPrefixXMPBasic](kcgimagemetadataprefixxmpbasic.md): The prefix string for tags in the XMP metadata.
- [kCGImageMetadataPrefixXMPRights](kcgimagemetadataprefixxmprights.md): The prefix string for tags in the XMP metadata that convey legal restrictions for the resource.

## See Also

### XMP Metadata

- [CGImageMetadata](cgimagemetadata.md): An immutable object that contains the XMP metadata associated with an image.
- [CGMutableImageMetadata](cgmutableimagemetadata.md): An opaque type for adding or modifying image metadata.
- [CGImageMetadataTag](cgimagemetadatatag.md): An immutable type that contains information about a single piece of image metadata.
- [kCFErrorDomainCGImageMetadata](kcferrordomaincgimagemetadata.md): The domain for metadata-related errors that originate in the Image I/O framework.
- [CGImageMetadataErrors](cgimagemetadataerrors.md): Constants for errors that occur when getting or setting metadata information.
