# GIF Image Properties

**Interface languages:** Swift, Objective-C

**Framework:** Image I/O  
**Kind:** API Collection

Metadata keys for the Graphics Interchange Format (GIF).

## Topics

### Dictionary

- [kCGImagePropertyGIFDictionary](kcgimagepropertygifdictionary.md): A dictionary of key-value pairs for an image that uses Graphics Interchange Format (GIF).

### Image Properties

- [kCGImagePropertyGIFCanvasPixelHeight](kcgimagepropertygifcanvaspixelheight.md): The height of the main image, in pixels.
- [kCGImagePropertyGIFCanvasPixelWidth](kcgimagepropertygifcanvaspixelwidth.md): The width of the main image, in pixels.
- [kCGImagePropertyGIFHasGlobalColorMap](kcgimagepropertygifhasglobalcolormap.md): A Boolean value that indicates whether the GIF has a global color map.
- [kCGImagePropertyGIFImageColorMap](kcgimagepropertygifimagecolormap.md): The image color map.

### Sequence Timing

- [kCGImagePropertyGIFFrameInfoArray](kcgimagepropertygifframeinfoarray.md): An array of dictionaries that contain timing information for the image sequence.
- [kCGImagePropertyGIFDelayTime](kcgimagepropertygifdelaytime.md): The number of seconds to wait before displaying the next image in an animated sequence, clamped to a minimum of 100 milliseconds.
- [kCGImagePropertyGIFUnclampedDelayTime](kcgimagepropertygifunclampeddelaytime.md): The number of seconds to wait before displaying the next image in an animated sequence.
- [kCGImagePropertyGIFLoopCount](kcgimagepropertygifloopcount.md): The number of times to repeat an animated sequence.
