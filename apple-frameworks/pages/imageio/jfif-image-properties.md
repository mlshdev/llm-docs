# JFIF Image Properties

**Interface languages:** Swift, Objective-C

**Framework:** Image I/O  
**Kind:** API Collection

Metadata keys for the JPEG File Interchange Format (JFIF).

## Topics

### Dictionary

- [kCGImagePropertyJFIFDictionary](kcgimagepropertyjfifdictionary.md): A dictionary of key-value pairs for an image that uses JPEG File Interchange Format (JFIF).

### Quality Information

- [kCGImagePropertyJFIFXDensity](kcgimagepropertyjfifxdensity.md): The x pixel density.
- [kCGImagePropertyJFIFYDensity](kcgimagepropertyjfifydensity.md): The y pixel density.
- [kCGImagePropertyJFIFDensityUnit](kcgimagepropertyjfifdensityunit.md): The units for the x and y density fields.
- [kCGImagePropertyJFIFIsProgressive](kcgimagepropertyjfifisprogressive.md): Whether there are versions of the image of increasing quality.

### Version Information

- [kCGImagePropertyJFIFVersion](kcgimagepropertyjfifversion.md): The version of JFIF.
