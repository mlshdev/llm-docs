# CIFF Image Properties

**Interface languages:** Swift, Objective-C

**Framework:** Image I/O  
**Kind:** API Collection

Metadata keys for the Camera Image File Format (CIFF) image format.

## Topics

### Dictionary

- [kCGImagePropertyCIFFDictionary](kcgimagepropertyciffdictionary.md): A dictionary of key-value pairs for an image that uses Camera Image File Format (CIFF).

### Image Details

- [kCGImagePropertyCIFFDescription](kcgimagepropertyciffdescription.md): The camera description.
- [kCGImagePropertyCIFFImageName](kcgimagepropertyciffimagename.md): The image name.
- [kCGImagePropertyCIFFImageFileName](kcgimagepropertyciffimagefilename.md): The image file name.
- [kCGImagePropertyCIFFImageSerialNumber](kcgimagepropertyciffimageserialnumber.md): The image serial number.

### Exposure

- [kCGImagePropertyCIFFWhiteBalanceIndex](kcgimagepropertyciffwhitebalanceindex.md): The white balance index.
- [kCGImagePropertyCIFFFlashExposureComp](kcgimagepropertyciffflashexposurecomp.md): The flash exposure compensation.
- [kCGImagePropertyCIFFMeasuredEV](kcgimagepropertyciffmeasuredev.md): The measured exposure value.
- [kCGImagePropertyCIFFMeteringMode](kcgimagepropertyciffmeteringmode.md): The metering mode.

### Shutter Information

- [kCGImagePropertyCIFFReleaseTiming](kcgimagepropertyciffreleasetiming.md): The priority for shutter release timing—shutter or focus.
- [kCGImagePropertyCIFFSelfTimingTime](kcgimagepropertyciffselftimingtime.md): The time in milliseconds until shutter release when using the self-timer.
- [kCGImagePropertyCIFFReleaseMethod](kcgimagepropertyciffreleasemethod.md): The method of shutter release—single-shot or continuous.
- [kCGImagePropertyCIFFContinuousDrive](kcgimagepropertyciffcontinuousdrive.md): The continuous drive mode.
- [kCGImagePropertyCIFFShootingMode](kcgimagepropertyciffshootingmode.md): The shooting mode.

### Lens and Focus

- [kCGImagePropertyCIFFFocusMode](kcgimagepropertycifffocusmode.md): The focus mode.
- [kCGImagePropertyCIFFLensMaxMM](kcgimagepropertycifflensmaxmm.md): The maximum lens length in millimeters.
- [kCGImagePropertyCIFFLensMinMM](kcgimagepropertycifflensminmm.md): The minimum lens length in millimeters.
- [kCGImagePropertyCIFFLensModel](kcgimagepropertycifflensmodel.md): The lens model.

### Camera Information

- [kCGImagePropertyCIFFFirmware](kcgimagepropertycifffirmware.md): The firmware version of the camera.
- [kCGImagePropertyCIFFOwnerName](kcgimagepropertyciffownername.md): The name of the camera’s owner.
- [kCGImagePropertyCIFFCameraSerialNumber](kcgimagepropertyciffcameraserialnumber.md): The camera serial number.
- [kCGImagePropertyCIFFRecordID](kcgimagepropertyciffrecordid.md): The number of images taken since the camera shipped.
