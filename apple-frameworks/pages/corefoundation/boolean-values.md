# Boolean Values

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

CFBoolean evaluates to either true or false values where `kCFBooleanTrue` is the true, and `kCFBooleanFalse` is the false value.

## Topics

### Constants

- [kCFBooleanTrue](kcfbooleantrue.md): Boolean true value.
- [kCFBooleanFalse](kcfbooleanfalse.md): Boolean false value.
