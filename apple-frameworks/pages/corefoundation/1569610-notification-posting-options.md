# Notification Posting Options (Swift)

**Framework:** Core Foundation  
**Kind:** API Collection

Possible options when posting notifications.

<a id="overview"></a>

## Overview

Use these constants when calling the [CFNotificationCenterPostNotificationWithOptions(\_:\_:\_:\_:\_:)](cfnotificationcenterpostnotificationwithoptions%28__________%29.md) function.

## Topics

### Constants

- [kCFNotificationDeliverImmediately](kcfnotificationdeliverimmediately.md): Delivers the notification immediately.
- [kCFNotificationPostToAllSessions](kcfnotificationposttoallsessions.md): Delivers the notification to all sessions.

## See Also

### Constants

- [CFNotificationSuspensionBehavior](cfnotificationsuspensionbehavior.md): Suspension flags that indicate how distributed notifications should be handled when the receiving application is in the background.
