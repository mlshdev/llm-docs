# Predefined CFCharacterSet Selector Values (Swift)

**Framework:** Core Foundation  
**Kind:** API Collection

Identifiers for the available predefined CFCharacterSet objects.

<a id="overview"></a>

## Overview

Use these constants with the [CFCharacterSetGetPredefined(\_:)](cfcharactersetgetpredefined%28__%29.md) function to get one of the predefined character sets.

## Topics

### Constants

- [CFCharacterSetPredefinedSet.control](cfcharactersetpredefinedset/control.md): Control character set (Unicode General Category Cc and Cf).
- [CFCharacterSetPredefinedSet.whitespace](cfcharactersetpredefinedset/whitespace.md): Whitespace character set (Unicode General Category Zs and U0009 CHARACTER TABULATION).
- [CFCharacterSetPredefinedSet.whitespaceAndNewline](cfcharactersetpredefinedset/whitespaceandnewline.md): Whitespace and Newline character set (Unicode General Category Z\*, `U000A ~ U000D`, and `U0085`).
- [CFCharacterSetPredefinedSet.decimalDigit](cfcharactersetpredefinedset/decimaldigit.md): Decimal digit character set.
- [CFCharacterSetPredefinedSet.letter](cfcharactersetpredefinedset/letter.md): Letter character set (Unicode General Category L\* & M\*).
- [CFCharacterSetPredefinedSet.lowercaseLetter](cfcharactersetpredefinedset/lowercaseletter.md): Lowercase character set (Unicode General Category Ll).
- [CFCharacterSetPredefinedSet.uppercaseLetter](cfcharactersetpredefinedset/uppercaseletter.md): Uppercase character set (Unicode General Category Lu and Lt).
- [CFCharacterSetPredefinedSet.nonBase](cfcharactersetpredefinedset/nonbase.md): Non-base character set (Unicode General Category M\*).
- [CFCharacterSetPredefinedSet.decomposable](cfcharactersetpredefinedset/decomposable.md): Canonically decomposable character set.
- [CFCharacterSetPredefinedSet.alphaNumeric](cfcharactersetpredefinedset/alphanumeric.md): Alpha Numeric character set (Unicode General Category L\*, M\*, & N\*).
- [CFCharacterSetPredefinedSet.punctuation](cfcharactersetpredefinedset/punctuation.md): Punctuation character set (Unicode General Category P\*).
- [CFCharacterSetPredefinedSet.capitalizedLetter](cfcharactersetpredefinedset/capitalizedletter.md): Titlecase character set (Unicode General Category Lt).
- [CFCharacterSetPredefinedSet.symbol](cfcharactersetpredefinedset/symbol.md): Symbol character set (Unicode General Category S\*).
- [CFCharacterSetPredefinedSet.newline](cfcharactersetpredefinedset/newline.md): Newline character set (`U000A ~ U000D`, `U0085`, `U2028`, and `U2029`).
- [CFCharacterSetPredefinedSet.illegal](cfcharactersetpredefinedset/illegal.md): Illegal character set.
