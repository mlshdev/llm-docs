# HTTP URL Properties

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

Properties for HTTP URL resources.

<a id="overview"></a>

## Overview

In addition to the above properties, each field within an HTTP request or response header is itself a property. You can specify a header field by using the field name as the property name.

## Topics

### Constants

- [kCFURLHTTPStatusCode](kcfurlhttpstatuscode.md): Deprecated. A `CFNumber` object holding the status code of an HTTP request.
- [kCFURLHTTPStatusLine](kcfurlhttpstatusline.md): Deprecated. A `CFString` object holding the status line of an HTTP request.
