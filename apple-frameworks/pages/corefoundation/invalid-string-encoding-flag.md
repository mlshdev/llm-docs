# Invalid String Encoding Flag

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

Special value returned from functions to indicate a string encoding that is not supported or recognized by CFString.

## Topics

### Constants

- [kCFStringEncodingInvalidId](kcfstringencodinginvalidid.md): Used as a function result to identify an encoding that is not supported or recognized by CFString.
