# Default Run Loop Mode (Swift)

**Framework:** Core Foundation  
**Kind:** API Collection

Default run loop mode.

## Topics

### Constants

- [defaultMode](cfrunloopmode/defaultmode.md): Run loop mode that should be used when a thread is in its default, or idle, state, waiting for an event. This mode is used when the run loop is started with [CFRunLoopRun()](cfrunlooprun%28%29.md).

## See Also

### Constants

- [CFRunLoopRunInMode Exit Codes](cfrunloopruninmode_exit_codes.md): Return codes for `CFRunLoopRunInMode`, identifying the reason the run loop exited.
- [Common Mode Flag](common-mode-flag.md): A run loop pseudo-mode that manages objects monitored in the “common” modes.
