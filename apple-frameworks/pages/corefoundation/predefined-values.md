# Predefined Values

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

CFNumber provides some predefined number values.

## Topics

### Constants

- [kCFNumberNaN](kcfnumbernan.md): “Not a Number.” This value is often the result of an invalid operation, such as the square-root of a negative number.
- [kCFNumberNegativeInfinity](kcfnumbernegativeinfinity.md): Designates a negative infinity value.
- [kCFNumberPositiveInfinity](kcfnumberpositiveinfinity.md): Designates a positive infinity value.
