# File Resource Types

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

Possible values for the [kCFURLFileResourceTypeKey](kcfurlfileresourcetypekey.md) key.

## Topics

### Constants

- [kCFURLFileResourceTypeBlockSpecial](kcfurlfileresourcetypeblockspecial.md): The resource is a block special file.
- [kCFURLFileResourceTypeCharacterSpecial](kcfurlfileresourcetypecharacterspecial.md): The resource is a character special file.
- [kCFURLFileResourceTypeDirectory](kcfurlfileresourcetypedirectory.md): The resource is a directory.
- [kCFURLFileResourceTypeNamedPipe](kcfurlfileresourcetypenamedpipe.md): The resource is a named pipe.
- [kCFURLFileResourceTypeRegular](kcfurlfileresourcetyperegular.md): The resource is a regular file.
- [kCFURLFileResourceTypeSocket](kcfurlfileresourcetypesocket.md): The resource is a socket.
- [kCFURLFileResourceTypeSymbolicLink](kcfurlfileresourcetypesymboliclink.md): The resource is a symbolic link.
- [kCFURLFileResourceTypeUnknown](kcfurlfileresourcetypeunknown.md): The resource’s type is unknown.
