# Predefined Time Interval Values

**Interface languages:** Swift, Objective-C

**Framework:** Core Foundation  
**Kind:** API Collection

Time intervals between the absolute reference date and certain other dates.

## Topics

### Constants

- [kCFAbsoluteTimeIntervalSince1970](kcfabsolutetimeintervalsince1970.md): The time interval between 1 January 1970 and the reference date 1 January 2001 00:00:00 GMT.
- [kCFAbsoluteTimeIntervalSince1904](kcfabsolutetimeintervalsince1904.md): The time interval between 1 January 1904 and the reference date 1 January 2001 00:00:00 GMT.
