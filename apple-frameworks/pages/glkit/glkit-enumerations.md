# GLKit Enumerations (Swift)

**Framework:** GLKit  
**Kind:** API Collection

## Topics

### Enumerations

- [GLKFogMode](glkfogmode.md): A mode that describes how the fog component is calculated for the fragment.
- [GLKLightingType](glklightingtype.md): A constant that describes how lighting is calculated by an effect.
- [GLKTextureEnvMode](glktextureenvmode.md): The mode used to combine the texture with other color components.
- [GLKTextureInfoAlphaState](glktextureinfoalphastate.md): Values that describe the alpha information stored in a source image’s pixel data.
- [GLKTextureInfoOrigin](glktextureinfoorigin.md): The location of the origin in the original source image.
- [GLKTextureLoaderError.Code](glktextureloadererror-swift.struct/code.md): Values to be returned when a texture loader encounters an error.
- [GLKTextureTarget](glktexturetarget.md): The kind of texture pointed to by the property.
- [GLKViewDrawableColorFormat](glkviewdrawablecolorformat.md): The format of the color renderbuffer.
- [GLKViewDrawableDepthFormat](glkviewdrawabledepthformat.md): The format of the depth renderbuffer.
- [GLKViewDrawableMultisample](glkviewdrawablemultisample.md): The format of the multisampling buffer.
- [GLKViewDrawableStencilFormat](glkviewdrawablestencilformat.md): The format of the stencil renderbuffer.
