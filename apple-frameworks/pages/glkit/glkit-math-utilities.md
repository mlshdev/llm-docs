# GLKit Math Utilities (Swift)

**Framework:** GLKit  
**Kind:** API Collection

<a id="Overview"></a>

## Overview

Math routines without a specific type associated with them.

## Topics

### Converting Angles

- [GLKMathDegreesToRadians(\_:)](glkmathdegreestoradians%28__%29.md): Converts an angle measured in degrees to radians.
- [GLKMathRadiansToDegrees(\_:)](glkmathradianstodegrees%28__%29.md): Converts an angle measured in radians to degrees.

### Projecting Vectors

- [GLKMathProject(\_:\_:\_:\_:)](glkmathproject%28________%29.md): Projects a point in object space into the window coordinate system.
- [GLKMathUnproject(\_:\_:\_:\_:\_:)](glkmathunproject%28__________%29.md): Projects a point in view space into object space.

### Obtaining String Descriptions

- [NSStringFromGLKMatrix2(\_:)](nsstringfromglkmatrix2%28__%29.md): Returns a string that represents the contents of a matrix.
- [NSStringFromGLKMatrix3(\_:)](nsstringfromglkmatrix3%28__%29.md): Returns a string that represents the contents of a matrix.
- [NSStringFromGLKMatrix4(\_:)](nsstringfromglkmatrix4%28__%29.md): Returns a string that represents the contents of a matrix.
- [NSStringFromGLKVector2(\_:)](nsstringfromglkvector2%28__%29.md): Returns a string that represents the contents of a vector.
- [NSStringFromGLKVector3(\_:)](nsstringfromglkvector3%28__%29.md): Returns a string that represents the contents of a vector.
- [NSStringFromGLKVector4(\_:)](nsstringfromglkvector4%28__%29.md): Returns a string that represents the contents of a vector.
- [NSStringFromGLKQuaternion(\_:)](nsstringfromglkquaternion%28__%29.md): Returns a string that represents the contents of a quaternion.
