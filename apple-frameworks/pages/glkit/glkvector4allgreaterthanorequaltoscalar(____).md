# GLKVector4AllGreaterThanOrEqualToScalar(\_:\_:) (Swift)

**Framework:** GLKit  
**Kind:** Function  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · macOS 10.8+ · tvOS 9.0+

Returns a Boolean value that states whether all the components of the source vector are greater than or equal to a scalar value.

## Declaration

```swift
func GLKVector4AllGreaterThanOrEqualToScalar(_ vector: GLKVector4, _ value: Float) -> Bool
```

## Parameters

- `vector`: A vector.
- `value`: A scalar.

<a id="return-value"></a>

## Return Value

[true](https://developer.apple.com/documentation/swift/true) if all of the vector’s components are greater than or equal to the scalar value, [false](https://developer.apple.com/documentation/swift/false) otherwise.
