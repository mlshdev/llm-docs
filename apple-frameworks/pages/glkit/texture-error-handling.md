# Texture Error Handling (Swift)

**Framework:** GLKit  
**Kind:** API Collection

Strings used when handling error messages returned from a texture loading method.

## Topics

### Constants

- [GLKTextureLoaderErrorDomain](glktextureloadererrordomain.md): Deprecated. The error domain used by GLKit when returning texture loading errors.
