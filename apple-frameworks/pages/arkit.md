# ARKit (Swift)

**Framework:** ARKit  
**Kind:** Framework  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · visionOS 1.0+

Integrate hardware sensing features to produce augmented reality apps and games.

## Mentioned In

- [Validating a Model for Motion Capture](arkit/validating-a-model-for-motion-capture.md)
- [Recording and Replaying AR Session Data](arkit/recording-and-replaying-ar-session-data.md)

<a id="overview"></a>

## Overview

*Augmented reality* (AR) describes user experiences that add 2D or 3D elements to the live view from a device’s sensors in a way that makes those elements appear to inhabit the real world. ARKit combines device motion tracking, world tracking, scene understanding, and display conveniences to simplify building an AR experience.

![An illustration showing a robot and a futuristic greenhouse.](https://developer.apple.com/images/com.apple.arkit/arkit-hero.png)
