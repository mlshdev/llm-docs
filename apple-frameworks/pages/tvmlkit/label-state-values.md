# Label State Values

**Interface languages:** Swift, Objective-C

**Framework:** TVMLKit

How text is displayed when an element is in focus.

<a id="overview"></a>

## Overview

```
NSString *const TVTextHighlightStyleShowOnHighlight;
NSString *const TVTextHighlightStyleMarqueeOnHighlight;
NSString *const TVTextHighlightStyleMarqueeAndShowOnHighlight;
```

## Topics

### Constants

- [TVTextHighlightStyleShowOnHighlight](tvtexthighlightstyleshowonhighlight.md): Any text that is longer than the available space will scroll across the screen.
- [TVTextHighlightStyleMarqueeOnHighlight](tvtexthighlightstylemarqueeonhighlight.md): Any text that is longer than the available space is truncated.
- [TVTextHighlightStyleMarqueeAndShowOnHighlight](tvtexthighlightstylemarqueeandshowonhighlight.md): The text will scroll across the screen if the text is longer than the available space.
