# EABluetoothAccessoryPickerCompletion (Swift)

**Framework:** External Accessory  
**Kind:** Type Alias  
**Availability:** iOS 3.0+ · iPadOS 3.0+ · Mac Catalyst 13.0+ · macOS 10.13+ · tvOS 10.0+ · visionOS 1.0+

The completion block for the Bluetooth picker.

## Declaration

```swift
typealias EABluetoothAccessoryPickerCompletion = ((any Error)?) -> Void
```

<a id="Discussion"></a>

## Discussion

You use this block to process results generated by the [showBluetoothAccessoryPicker(withNameFilter:completion:)](eaaccessorymanager/showbluetoothaccessorypicker%28withnamefilter_completion_%29.md) method. The block receives an [NSError](../foundation/nserror.md) object as its only parameter. If no error occurred, this parameter is set to `nil`.

## See Also

### Presenting the Bluetooth Picker

- [showBluetoothAccessoryPicker(withNameFilter:completion:)](eaaccessorymanager/showbluetoothaccessorypicker%28withnamefilter_completion_%29.md): Displays an alert that allows the user to pair the device with a Bluetooth accessory.
- [EABluetoothAccessoryPickerError](eabluetoothaccessorypickererror.md): Error codes returned by the Bluetooth accessory picker.
- [EABluetoothAccessoryPickerError.Code](eabluetoothaccessorypickererror/code.md): The error codes that may be passed in an error object for the Bluetooth picker completion block.
