# MLDataTable.Aggregator

**Framework:** Create ML  
**Kind:** Structure  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 10.14+ · tvOS 16.0+ · visionOS 1.0+

A collection of column operations you can use with a data table’s `group` method.

## Declaration

```swift
struct Aggregator
```

<a id="overview"></a>

## Overview

Use one or more [MLDataTable.Aggregator](aggregator.md) instances when you use the [group(columnsNamed:aggregators:)](group%28columnsnamed_aggregators_%29.md) method. Each aggregator performs a sequence of one or more [MLDataTable.Aggregator.Operations](aggregator/operations-swift.enum.md) for a single column. Each operation makes a new column in the new data table generated by the method.
