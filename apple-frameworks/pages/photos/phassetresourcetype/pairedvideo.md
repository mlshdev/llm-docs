# PHAssetResourceType.pairedVideo (Swift)

**Framework:** Photos  
**Kind:** Case  
**Availability:** iOS 9.1+ · iPadOS 9.1+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 10.0+ · visionOS 1.0+

Provides the original video data component of a Live Photo asset.

## Declaration

```swift
case pairedVideo
```

<a id="Discussion"></a>

## Discussion

This asset resource type appears when fetching the asset resources associated with a Live Photo asset.
