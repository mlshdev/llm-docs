# PHCollectionListSubtype.momentListYear (Swift)

**Framework:** Photos  
**Kind:** Case  
**Availability:** iOS 8.0+ (deprecated in 13.0) · iPadOS 8.0+ (deprecated in 13.0) · Mac Catalyst 13.1+ · tvOS 10.0+ (deprecated in 13.0) · visionOS 1.0+ (deprecated in 1.0)

The collection list is a moment year, grouping all moments from one or more calendar years.

> Will be removed in a future release

## Declaration

```swift
case momentListYear
```

<a id="Discussion"></a>

## Discussion

This subtype applies only to collection lists whose type is [PHCollectionListType.momentList](../phcollectionlisttype/momentlist.md).
