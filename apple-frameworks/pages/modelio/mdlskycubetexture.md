# MDLSkyCubeTexture (Swift)

**Framework:** Model I/O  
**Kind:** Class  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 9.0+ · visionOS 1.0+

A generator of texel data that creates cube textures using a physically realistic simulation of the sunlit sky.

## Declaration

```swift
class MDLSkyCubeTexture
```

<a id="overview"></a>

## Overview

The sky textures generated by this class can can be useful as environment maps or light probes in rendering. Like other procedural [MDLTexture](mdltexture.md) subclasses, the [MDLSkyCubeTexture](mdlskycubetexture.md) class generates texel data only when that data is first referenced, and then caches it for future use.
