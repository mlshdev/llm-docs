# Asset File Types

**Interface languages:** Swift, Objective-C

**Framework:** Model I/O  
**Kind:** API Collection

Uniform Type Identifiers for file formats supported by the Model I/O framework.

## Topics

### Constants

- [kUTTypeAlembic](kuttypealembic.md): The Alembic file format (common extension `.abc`).
- [kUTType3dObject](kuttype3dobject.md): The Object file format (common extension `.obj`).
- [kUTTypePolygon](kuttypepolygon.md): The Polygon file format (common extension `.ply`).
- [kUTTypeStereolithography](kuttypestereolithography.md): The Stereolithography file format (common extension `.stl`), also known as the Standard Tessellated Geometry format.
- [kUTTypeUniversalSceneDescription](kuttypeuniversalscenedescription.md): The Universal Scene Description file format (common extension `.usd`).
