# animationSpeed (Swift)

**Framework:** SpriteKit  
**Kind:** Instance Property  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.1+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 1.0+

The rate at which a noise or turbulence field node changes.

## Declaration

```swift
var animationSpeed: Float { get set }
```

<a id="Discussion"></a>

## Discussion

A value of `0.0` means that the field should not animate at all.

## See Also

### Configuring Other Field Properties

- [smoothness](smoothness.md): The smoothness of the noise used to generate the forces.
- [direction](direction.md): The direction of a velocity field node.
- [texture](texture.md): A normal texture that specifies the velocities at different points in a velocity field node.
