# SKRepeatMode.clamp (Swift)

**Framework:** SpriteKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

When a sample is calculated, the time value is clamped to the range of time values found in the sequence. For example, if the last keyframe’s time value is `0.5`, a sample at any time value from `0.5` to `1.0` returns the last keyframe’s value.

## Declaration

```swift
case clamp
```

<a id="Discussion"></a>

## Discussion

Given a sequence with the key values of `[5, 1, 10]` and times of `[0, 0.25, 0.5]`, clamp repeat mode produces a set of values that follow straight line when the sample time is greater or equal to `0.5`:

![Playground graph generated by SKKeyframeSequence using clamp repeat mode](https://developer.apple.com/images/com.apple.spritekit/media-2576677@2x.png)

## See Also

### Constants

- [SKRepeatMode.loop](loop.md): When a sample is calculated, the sequence loops back to the beginning of the sequence. For example, if the last keyframe’s time value is `0.5`, then a sample at any time value from `0.5` to `1.0` returns the same value as the sequence did from `0.0` to `0.5`.
