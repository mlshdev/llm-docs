# SKTextureFilteringMode.nearest (Swift)

**Framework:** SpriteKit  
**Kind:** Case  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · tvOS · visionOS 1.0+ · watchOS 2.0+

Each pixel is drawn using the nearest point in the texture. This mode is faster, but the results are often pixelated.
