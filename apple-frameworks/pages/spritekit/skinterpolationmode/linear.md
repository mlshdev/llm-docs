# SKInterpolationMode.linear (Swift)

**Framework:** SpriteKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

Values between two keyframes are interpolated linearly.

## Declaration

```swift
case linear
```

<a id="Discussion"></a>

## Discussion

Given a sequence with the key values of `[5, 1, 10, 0]` and times of `[0, 0.25, 0.5, 1]`, linear interpolation produces a set of values that follow a series of straight lines between each keyframe.

![Playground graph generated by SKKeyframeSequence using linear interpolation](https://developer.apple.com/images/com.apple.spritekit/media-2852036@2x.png)

## See Also

### Constants

- [SKInterpolationMode.spline](spline.md): Values between two keyframes using a spline curve.
- [SKInterpolationMode.step](step.md): Values between two keyframes are not interpolated. Instead, the value is that of the most recent keyframe.
