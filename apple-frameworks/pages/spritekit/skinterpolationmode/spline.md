# SKInterpolationMode.spline (Swift)

**Framework:** SpriteKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

Values between two keyframes using a spline curve.

## Declaration

```swift
case spline
```

## Mentioned In

- [Using Keyframe Sequence to effect Custom Interpolation](../using-keyframe-sequence-to-effect-custom-interpolation.md)

<a id="Discussion"></a>

## Discussion

Given a sequence with the key values of `[5, 1, 10, 0]` and times of `[0, 0.25, 0.5, 1]`, spline interpolation produces a set of values that follow a smooth curve.

![Playground graph generated by SKKeyframeSequence using spline interpolation](https://developer.apple.com/images/com.apple.spritekit/media-2852038@2x.png)

## See Also

### Constants

- [SKInterpolationMode.linear](linear.md): Values between two keyframes are interpolated linearly.
- [SKInterpolationMode.step](step.md): Values between two keyframes are not interpolated. Instead, the value is that of the most recent keyframe.
