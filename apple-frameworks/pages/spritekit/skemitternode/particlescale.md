# particleScale (Swift)

**Framework:** SpriteKit  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

The average initial scale factor of a particle.

## Declaration

```swift
var particleScale: CGFloat { get set }
```

<a id="Discussion"></a>

## Discussion

The default value is `1.0`.
