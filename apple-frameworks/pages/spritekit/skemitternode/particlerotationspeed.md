# particleRotationSpeed (Swift)

**Framework:** SpriteKit  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

The speed at which a particle rotates, expressed in radians per second.

## Declaration

```swift
var particleRotationSpeed: CGFloat { get set }
```

<a id="Discussion"></a>

## Discussion

This is uniform for all particles generated by the emitter. The default value is `0.0`.

## See Also

### Adjusting a Particle’s Rotation

- [particleRotation](particlerotation.md): The average initial rotation of a particle, expressed as an angle in radians.
- [particleRotationRange](particlerotationrange.md): The range of allowed random values for a particle’s initial rotation, expressed as an angle in radians.
