# particleRotation (Swift)

**Framework:** SpriteKit  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

The average initial rotation of a particle, expressed as an angle in radians.

## Declaration

```swift
var particleRotation: CGFloat { get set }
```

<a id="Discussion"></a>

## Discussion

The default value is `0.0`.

## See Also

### Adjusting a Particle’s Rotation

- [particleRotationRange](particlerotationrange.md): The range of allowed random values for a particle’s initial rotation, expressed as an angle in radians.
- [particleRotationSpeed](particlerotationspeed.md): The speed at which a particle rotates, expressed in radians per second.
