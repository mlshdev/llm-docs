# init(size:)

**Framework:** RealityKit  
**Kind:** Initializer  
**Availability:** iOS 27.0+ · iPadOS 27.0+ · tvOS 27.0+ · visionOS 27.0+

Creates a buffer slot descriptor with the given size.

## Declaration

```swift
init(size: Int)
```

## Parameters

- `size`: The size of the buffer slot, in bytes.

## See Also

### Creating a buffer descriptor

- [size](size.md): The minimum size, in bytes, that a buffer slice must have to be bound to this slot.
