# &&(\_:\_:)

**Framework:** RealityKit  
**Kind:** Operator  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 12.0+ · tvOS 26.0+ · visionOS

Returns a predicate which evaluates to `true` if `left` AND `right` evaluate to `true`.
