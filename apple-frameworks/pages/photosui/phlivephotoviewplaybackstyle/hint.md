# PHLivePhotoViewPlaybackStyle.hint (Swift)

**Framework:** PhotosUI  
**Kind:** Case  
**Availability:** iOS 9.1+ · iPadOS 9.1+ · Mac Catalyst 13.1+ · macOS 10.12+ · tvOS 10.0+ · visionOS 1.0+

Plays back only a brief section of the motion content of the Live Photo, without sound.

## Declaration

```swift
case hint
```

## Mentioned In

- [Displaying Live Photos](../../photokit/displaying-live-photos.md)

<a id="Discussion"></a>

## Discussion

This style matches the effect seen in various iOS interface elements for hinting to the user when an asset contains Live Photo content.

## See Also

### Constants

- [PHLivePhotoViewPlaybackStyle.undefined](undefined.md): This value is invalid for use.
- [PHLivePhotoViewPlaybackStyle.full](full.md): Plays back the entire motion and sound content of the Live Photo, including transition effects at the start and end.
