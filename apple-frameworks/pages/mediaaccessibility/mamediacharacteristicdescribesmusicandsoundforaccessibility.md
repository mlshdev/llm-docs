# MAMediaCharacteristicDescribesMusicAndSoundForAccessibility (Swift)

**Framework:** Media Accessibility  
**Kind:** Global Variable  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · tvOS 17.0+ · visionOS 1.0+
