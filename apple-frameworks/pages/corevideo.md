# Core Video (Swift)

**Framework:** Core Video  
**Kind:** Framework  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 13.0+ · macOS 10.4+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 4.0+

Process digital video, including manipulation of individual frames, using a pipeline-based API and support for both Metal and OpenGL.

<a id="overview"></a>

## Overview

Core Video provides a pipeline model for digital video. It simplifies working with video by partitioning the process into discrete steps. This makes it easier for developers to access and manipulate individual frames without having to worry about translating between data types or display synchronization issues. Apps that don’t need to manipulate individual video frames don’t need to use Core Video directly.

## Topics

### Data Processing

- [CVBuffer](corevideo/cvbuffer-nfm.md): An abstract base class that defines how to interact with data buffers.
- [CVImageBuffer](corevideo/cvimagebuffer-q40.md): An interface for managing different types of image data.
- [CVPixelBuffer](corevideo/cvpixelbuffer-q2e.md): An image buffer that holds pixels in main memory.
- [CVPixelBufferPool](corevideo/cvpixelbufferpool-77o.md): A utility object for managing a recyclable set of pixel buffer objects.
- [CVPixelFormatDescription](corevideo/cvpixelformatdescription-42p.md): An API that provides functions and types for defining custom pixel formats.

### Time Management

- [CVTime](corevideo/cvtime-q1e.md): A structure used for storing Core Video time values.
- [CVDisplayLink](corevideo/cvdisplaylink-k0k.md): A high-priority thread that notifies your app when a given display will need each frame.

### Metal

- [CVMetalTextureCache](corevideo/cvmetaltexturecache-q3j.md): A cache used to create and manage Metal texture objects.
- [CVMetalTexture](corevideo/cvmetaltexture-q3g.md): A texture-based image buffer that supplies source image data for use with the Metal framework.
- [CVMetalBufferCache](corevideo/cvmetalbuffercache.md): A cache used to create and manage Metal buffer objects.

### OpenGL

- [CVOpenGLTextureCache](corevideo/cvopengltexturecache-780.md): A cache used to create and manage OpenGL texture objects.
- [CVOpenGLTexture](corevideo/cvopengltexture-782.md): A texture-based image buffer that supplies source image data to OpenGL.
- [CVOpenGLBuffer](corevideo/cvopenglbuffer-77s.md): An image buffer used to store image data in video memory.
- [CVOpenGLBufferPool](corevideo/cvopenglbufferpool-77j.md): A utility object for managing a set of recyclable OpenGL buffer objects.

### OpenGL ES

- [CVOpenGLESTextureCache](corevideo/cvopenglestexturecache-q2r.md): A cache used to create and manage OpenGL ES texture objects.
- [CVOpenGLESTexture](corevideo/cvopenglestexture-q2s.md): A texture-based image buffer that supplies source image data to OpenGL ES.

### Core Video Error Constants

- [Result Codes](corevideo/result-codes.md): Describes the result codes generated by Core Video operations.
- [Data Types](corevideo/data-types.md): Common data types used by the Core Video framework.
- [CVError](corevideo/cverror.md): `CVError` wraps `CVReturn` values to present them as Swift Error values. This type is used for all errors thrown in the CoreVideo framework. All `CVReturn` values are provided as static constants.
