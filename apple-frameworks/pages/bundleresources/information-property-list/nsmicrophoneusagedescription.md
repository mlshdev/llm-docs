# NSMicrophoneUsageDescription

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · macOS 10.14+ · tvOS 17.0+ · visionOS 1.0+ · watchOS 4.0+

A message that tells people why the app is requesting access to the device’s microphone.

## Details

`NSMicrophoneUsageDescription`

## Discussion

> **Important**

>  This key is required if your app uses APIs that access the device’s microphone.
