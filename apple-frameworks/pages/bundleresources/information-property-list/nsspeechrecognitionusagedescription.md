# NSSpeechRecognitionUsageDescription

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · macOS 10.15+ · visionOS 1.0+

A message that tells people why the app is requesting to send user data to Apple’s speech recognition servers.

## Details

`NSSpeechRecognitionUsageDescription`

<a id="Discussion"></a>

## Discussion

> **Important**

>  This key is required if your app uses APIs that send user data to Apple’s speech recognition servers.
