# CoreSpotlightActions

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · visionOS 1.0+

A dictionary that contains details about actions available to users for Spotlight search results.

## Details

`CoreSpotlightActions`

## Topics

### Action Properties

- [CoreSpotlightActionTitle](corespotlightactions/corespotlightactiontitle.md): The user-visible string that Spotlight displays as the title of the action.
- [CoreSpotlightActionSymbolImage](corespotlightactions/corespotlightactionsymbolimage.md): The name of a SF Symbol to display next to the action’s title.
- [CoreSpotlightActionIdentifier](corespotlightactions/corespotlightactionidentifier.md): A string an app defines to identify the action.
