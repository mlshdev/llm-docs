# UIImageName (Swift)

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 14.0+ · iPadOS 14.0+

A custom image that replaces the tab bar during launch.

## Details

`UIImageName`

<a id="Discussion"></a>

## Discussion

Provide a value for this key that’s the name of an image in your asset catalog. You use the same string for the value that you might use when calling the [init(named:)](../../../../../uikit/uiimage/init%28named_%29.md) initializer of [UIImage](../../../../../uikit/uiimage.md).
