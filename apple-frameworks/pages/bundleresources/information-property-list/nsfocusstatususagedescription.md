# NSFocusStatusUsageDescription

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · macOS 12.0+ · watchOS 8.0+

A message that tells people why your app requests access to a person’s focus status.

## Details

`NSFocusStatusUsageDescription`

<a id="Discussion"></a>

## Discussion

Add this key before you use [INFocusStatusCenter](../../intents/infocusstatuscenter.md) to discover a person’s focus status.
