# NSServices

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** macOS 10.0+

The services provided by an app.

## Details

`NSServices`

## Topics

### Invocation

- [NSKeyEquivalent](nsservices/nskeyequivalent.md): A keyboard shortcut that invokes the service menu command.
- [NSMenuItem](nsservices/nsmenuitem.md): Text for a Services menu item.
- [NSMessage](nsservices/nsmessage.md): An instance method that invokes the service.
- [NSPortName](nsservices/nsportname.md): The port that the service monitors for incoming requests.
- [NSTimeout](nsservices/nstimeout.md): The amount of time, in milliseconds, that the system waits for a response from the service.

### Data

- [NSReturnTypes](nsservices/nsreturntypes.md): The data types that the service returns.
- [NSSendTypes](nsservices/nssendtypes.md): The data types that the service can read.
- [NSUserData](nsservices/nsuserdata.md): A service-specific string value.
