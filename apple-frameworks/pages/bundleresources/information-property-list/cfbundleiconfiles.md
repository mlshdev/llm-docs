# CFBundleIconFiles

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 3.2+ · iPadOS 3.2+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

The names of the bundle’s icon image files.

## Details

`CFBundleIconFiles`

<a id="Discussion"></a>

## Discussion

> **Note**

>  For Action extensions, you can specify the [CFBundleSymbolName](cfbundleicons/cfbundleprimaryicon/cfbundlesymbolname.md) key instead of `CFBundleIconFiles` to use a symbol from SF Symbols.
