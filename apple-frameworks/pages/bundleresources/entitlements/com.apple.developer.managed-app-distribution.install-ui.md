# Managed App Installation UI

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 17.2+ · iPadOS 17.2+

An entitlement you enable so your app can use Managed App Distribution.

## Details

`com.apple.developer.managed-app-distribution.install-ui`

## Possible Values

- `managed-app`: The value for normal operation.

## Discussion

To add this entitlement to your app, enable the Managed App Installation UI capability in Xcode.
