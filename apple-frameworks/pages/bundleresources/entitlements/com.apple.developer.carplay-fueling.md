# CarPlay Fueling App

**Interface languages:** Swift, Objective-C

**Framework:** Bundle Resources  
**Kind:** Property List Key  
**Availability:** iOS 16.0+ · iPadOS 16.0+

A Boolean value that indicates whether the CarPlay app provides details about nearby fueling stations.

## Details

`com.apple.developer.carplay-fueling`

## Discussion

You can include this entitlement and the [CarPlay EV Charging App](com.apple.developer.carplay-charging.md) entitlement in the same app.
