# PKEraserTool.EraserType.vector

**Framework:** PencilKit  
**Kind:** Case  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · macOS 11.0+ · visionOS 1.0+

An eraser that removes an entire drawn line.

## Declaration

```swift
case vector
```

<a id="Discussion"></a>

## Discussion

When a vector eraser touches any portion of a drawn line, it removes the entire line.
