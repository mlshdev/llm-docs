# PKEraserTypeVector

**Interface language:** Objective-C

**Framework:** PencilKit  
**Kind:** Enumeration Case  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · macOS 10.15+ · visionOS 1.0+

An eraser that removes an entire drawn line.

## Declaration

```objectivec
PKEraserTypeVector
```

<a id="Discussion"></a>

## Discussion

When a vector eraser touches any portion of a drawn line, it removes the entire line.
