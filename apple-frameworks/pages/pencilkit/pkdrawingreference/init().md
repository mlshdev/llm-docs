# init() (Swift)

**Framework:** PencilKit  
**Kind:** Initializer  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.1+ · macOS 10.15+ · visionOS 1.0+

Creates an empty drawing object.

## Declaration

```swift
init()
```

<a id="return-value"></a>

## Return Value

A new canvas object that doesn’t contain any data.
