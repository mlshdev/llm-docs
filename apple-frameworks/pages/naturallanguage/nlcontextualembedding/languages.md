# languages (Swift)

**Framework:** Natural Language  
**Kind:** Instance Property  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · macOS 14.0+ · tvOS 17.0+ · visionOS 1.0+ · watchOS 10.0+

The languages that the contextual embedding supports.

## Declaration

```swift
var languages: [NLLanguage] { get }
```

<a id="discussion"></a>

## Discussion

Starting in iOS 17 and macOS 14, the framework supports 27 languages across three models:

- Latin — including Croatian, Czech, Danish, Dutch, English, Finnish, French, German, Hungarian, Indonesian, Italian, Norwegian, Polish, Portuguese, Romanian, Slovak, Swedish, Spanish, Turkish, and Vietnamese
- Cyrillic — including Bulgarian, Kazakh, Russian, and Ukrainian
- Chinese, Japanese, and Korean

In iOS 18 and macOS 15, the framework expands language support to include three additional models:

- Arabic
- Indic — including Bangla, Gujarati, Hindi, Kannada, Malayalam, Marathi, Punjabi, Tamil, Telugu, and Urdu
- Thai

## See Also

### Inspecting the contextual embedding

- [dimension](dimension.md): The dimensionality of the embedding vectors generated by the model.
- [hasAvailableAssets](hasavailableassets.md): A Boolean value that indicates whether assets are available on-device.
- [maximumSequenceLength](maximumsequencelength.md): The maximum number of tokens in sequence for which the embedding generates vectors.
- [modelIdentifier](modelidentifier.md): A string that uniquely identifies the embedding model.
- [revision](revision.md): The version number the contextual embedding uses.
- [scripts](scripts.md): The writing systems that the language uses.
