# NLContextualEmbedding (Swift)

**Framework:** Natural Language  
**Kind:** Class  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · macOS 14.0+ · tvOS 17.0+ · visionOS 1.0+ · watchOS 10.0+

A model that computes sequences of embedding vectors for natural language utterances.

## Declaration

```swift
class NLContextualEmbedding
```

<a id="overview"></a>

## Overview

`NLContextualEmbedding` provides a dense vector representation of natural language utterances using models trained with contextualized language understanding. Unlike static word embeddings provided by `NLEmbedding`, contextual embeddings dynamically adjust based on surrounding words, enabling deeper language comprehension.

If you are building text classification or word tagging models, you can use `NLContextualEmbedding` with [Create ML](../createml.md) by selecting [MLTextClassifier.FeatureExtractorType.bertEmbedding](../createml/mltextclassifier/featureextractortype/bertembedding.md) as the feature extraction component in your model. For more information on how to create your own text classification model refer to [Creating a text classifier model](../createml/creating-a-text-classifier-model.md).

> **Note**

> For semantic similarity tasks, consider using [NLEmbedding](nlembedding.md). To learn more on how to implement semantic similarity, refer to [Finding similarities between pieces of text](finding-similarities-between-pieces-of-text.md).

Before configuring your contextual embedding:

- Select a model that’s appropriate for your target language when initializing the embedding.
- Call [requestAssets(completionHandler:)](nlcontextualembedding/requestassets%28completionhandler_%29.md) before computing the embedding to confirm assets are available.

Some models support multiple languages; for example, you can use the same object to compute embeddings for both English and Spanish. However, this isn’t always the case — languages like English and Chinese may require separate models. For more information about supported languages, refer to [languages](nlcontextualembedding/languages.md).
