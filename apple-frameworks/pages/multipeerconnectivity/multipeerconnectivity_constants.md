# MultipeerConnectivity Constants

**Interface languages:** Swift, Objective-C

**Framework:** Multipeer Connectivity  
**Kind:** API Collection

## Topics

### Constants

- [MCErrorDomain](mcerrordomain.md): Deprecated. The `NSError` domain constant. If the `domain` value for an `NSError` object is equal to `MCErrorDomain`, then the error was produced by the Multipeer Connectivity framework itself, as opposed to a lower-level framework on which it depends.
- [kMCSessionMaximumNumberOfPeers](kmcsessionmaximumnumberofpeers.md): Deprecated. The maximum number of peers that a session can support, including the local peer.
- [kMCSessionMinimumNumberOfPeers](kmcsessionminimumnumberofpeers.md): Deprecated. The minimum number of peers that a session can support, including the local peer.
