**Kind:** Global Variable

## Declaration

```swift
var kDNSServiceFlagsWakeOnlyService: UInt32 { get }
```

<a id="Discussion"></a>

## Discussion

This flag is meaningful only in DNSServiceRegister. When set, the service is not registered with a sleep proxy server during sleep.
