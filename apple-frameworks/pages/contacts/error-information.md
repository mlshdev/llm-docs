# Error Information (Swift)

**Framework:** Contacts  
**Kind:** API Collection

Diagnose errors generated by the Contacts framework.

## Topics

### Error domain

- [CNErrorDomain](cnerrordomain.md): The error domain for the Contacts framework.

### Error codes

- [CNError](cnerror.md): Error information that may be returned when using the methods of the Contacts framework.
- [CNError.Code](cnerror/code.md): Error codes that the system may return when you use Contacts framework methods.

### Error data keys

- [CNErrorUserInfoAffectedRecordsKey](cnerroruserinfoaffectedrecordskey.md): The contact, group, and container objects for which the error code applies.
- [CNErrorUserInfoAffectedRecordIdentifiersKey](cnerroruserinfoaffectedrecordidentifierskey.md): String objects for which the error code applies.
- [CNErrorUserInfoValidationErrorsKey](cnerroruserinfovalidationerrorskey.md): An array of validation-related error objects.
- [CNErrorUserInfoKeyPathsKey](cnerroruserinfokeypathskey.md): An array of key paths associated with a given error.

### Exceptions

- [CNContactPropertyNotFetchedExceptionName](cncontactpropertynotfetchedexceptionname.md): Exception thrown when an accessed property was not fetched.
