# CNContainerType.local (Swift)

**Framework:** Contacts  
**Kind:** Case  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · visionOS 1.0+ · watchOS 2.0+

A container for contacts only stored locally on the device.

## Declaration

```swift
case local
```

<a id="Discussion"></a>

## Discussion

There is only one local container for a device.

## See Also

### Constants

- [CNContainerType.exchange](exchange.md): A container for contacts stored in an Exchange folder from an Exchange server.
- [CNContainerType.cardDAV](carddav.md): A container for contacts stored in an CardDAV server, such as iCloud.
- [CNContainerType.unassigned](unassigned.md): A container where the system hasn’t assigned the container type.
