# CNContactNoteKey (Swift)

**Framework:** Contacts  
**Kind:** Global Variable  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · visionOS 1.0+ · watchOS 2.0+

A note associated with a contact.

## Declaration

```swift
let CNContactNoteKey: String
```

<a id="Discussion"></a>

## Discussion

This key takes a string value.

To be able to fetch the [note](cncontact/note.md) property in iOS, your app needs the [com.apple.developer.contacts.notes](../bundleresources/entitlements/com.apple.developer.contacts.notes.md) entitlement.

## See Also

### Notes

- [com.apple.developer.contacts.notes](../bundleresources/entitlements/com.apple.developer.contacts.notes.md): A Boolean value that indicates whether the app may access the notes in contact entries.
