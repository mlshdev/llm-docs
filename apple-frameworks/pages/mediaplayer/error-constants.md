# Error constants (Swift)

**Framework:** Media Player  
**Kind:** API Collection

Error code constants for framework operations.

## Topics

### Error code constants

- [cancelled](mperror/cancelled.md): The system cancels the requested operation before it completes.
- [cloudServiceCapabilityMissing](mperror/cloudservicecapabilitymissing.md): The operation can’t complete because iCloud services aren’t in an enabled state.
- [unknown](mperror/unknown.md): The requested operation can’t complete due to an unknown error.
- [networkConnectionFailed](mperror/networkconnectionfailed.md): The operation fails because the device can’t connect to the network.
- [notFound](mperror/notfound.md): The operation fails because the system can’t find the requested identifier in the current storefront.
- [notSupported](mperror/notsupported.md): The requested operation fails because the system doesn’t support it.
- [permissionDenied](mperror/permissiondenied.md): The operation can’t complete because the user doesn’t have permission for the request.
- [requestTimedOut](mperror/requesttimedout.md): The requested operation times out.
