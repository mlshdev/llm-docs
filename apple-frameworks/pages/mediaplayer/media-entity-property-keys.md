# Media entity property keys (Swift)

**Framework:** Media Player  
**Kind:** API Collection

The property keys used to retrieve metadata for media entities.

<a id="overview"></a>

## Overview

You obtain metadata for a media entity by calling the [value(forProperty:)](mpmediaentity/value%28forproperty_%29.md) method with these property keys. You can also use some properties to build media property predicates, as described in [MPMediaPropertyPredicate](mpmediapropertypredicate.md). These properties are filterable.

## Topics

### Constants

- [MPMediaEntityPropertyPersistentID](mpmediaentitypropertypersistentid.md): The persistent identifier for a media entity.
