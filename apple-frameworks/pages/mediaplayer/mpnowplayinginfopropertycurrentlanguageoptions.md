# MPNowPlayingInfoPropertyCurrentLanguageOptions (Swift)

**Framework:** Media Player  
**Kind:** Global Variable  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.12.2+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 5.0+

The currently active language options for the Now Playing item.

## Declaration

```swift
let MPNowPlayingInfoPropertyCurrentLanguageOptions: String
```

<a id="Discussion"></a>

## Discussion

Value is an array of [MPNowPlayingInfoLanguageOption](mpnowplayinginfolanguageoption.md) items.
