# MPMediaPlaylistPropertyAuthorDisplayName (Swift)

**Framework:** Media Player  
**Kind:** Global Variable  
**Availability:** iOS 9.3+ · iPadOS 9.3+ · Mac Catalyst 13.1+ · macOS · tvOS 9.2+ · visionOS 1.0+ · watchOS 2.2+

App defined name for the playlist.

## Declaration

```swift
let MPMediaPlaylistPropertyAuthorDisplayName: String
```

<a id="Discussion"></a>

## Discussion

This is required for 3rd party apps. Defaults to the app display name when not defined.
