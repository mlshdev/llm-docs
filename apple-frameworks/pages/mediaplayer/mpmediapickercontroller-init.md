# init

**Interface language:** Objective-C

**Framework:** Media Player  
**Kind:** Article

Initializes a media item picker for all media types.

<a id="Return-Value"></a>

## Return Value

A new media item picker.

<a id="Overview"></a>

## Overview

The default media type for a media item picker is [MPMediaTypeAny](mpmediatype/any.md).
