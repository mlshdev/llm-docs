# initWithConfiguration:

**Interface language:** Objective-C

**Framework:** TVUIKit  
**Kind:** Instance Method  
**Availability:** tvOS 15.0+

Creates a media item content view with the configuration you specify.

## Declaration

```objectivec
- (instancetype) initWithConfiguration:(TVMediaItemContentConfiguration *) configuration;
```

## Parameters

- `configuration`: The configuration you specify to supply its styling and content.

<a id="return-value"></a>

## Return Value

A new [TVMediaItemContentView](../tvmediaitemcontentview.md) instance.
