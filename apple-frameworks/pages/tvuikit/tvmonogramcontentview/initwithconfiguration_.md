# initWithConfiguration:

**Interface language:** Objective-C

**Framework:** TVUIKit  
**Kind:** Instance Method  
**Availability:** tvOS 15.0+

Creates a monogram content view with the configuration you specify.

## Declaration

```objectivec
- (instancetype) initWithConfiguration:(TVMonogramContentConfiguration *) configuration;
```

## Parameters

- `configuration`: The configuration you specify to supply its styling and content.

<a id="return-value"></a>

## Return Value

A new [TVMonogramContentView](../tvmonogramcontentview.md) instance.
