# UNNotificationContentExtensionMediaPlayPauseButtonType.none (Swift)

**Framework:** User Notifications UI  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · macOS 11.0+ · visionOS 1.0+

No media button.

## Declaration

```swift
case none
```

<a id="discussion"></a>

## Discussion

Specify this option when you don’t want a media button. This is the default option.

## See Also

### Button Types

- [UNNotificationContentExtensionMediaPlayPauseButtonType.default](default.md): A standard play/pause button.
- [UNNotificationContentExtensionMediaPlayPauseButtonType.overlay](overlay.md): A partially transparent play/pause button that is layered on top of your media content.
