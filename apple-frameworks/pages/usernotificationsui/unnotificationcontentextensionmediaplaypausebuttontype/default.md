# UNNotificationContentExtensionMediaPlayPauseButtonType.default (Swift)

**Framework:** User Notifications UI  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · macOS 11.0+ · visionOS 1.0+

A standard play/pause button.

## Declaration

```swift
case `default`
```

<a id="discussion"></a>

## Discussion

This button is always visible. When tapped, its appearance changes between the play and pause icons and triggers the appropriate play and pause actions.

## See Also

### Button Types

- [UNNotificationContentExtensionMediaPlayPauseButtonType.none](none.md): No media button.
- [UNNotificationContentExtensionMediaPlayPauseButtonType.overlay](overlay.md): A partially transparent play/pause button that is layered on top of your media content.
