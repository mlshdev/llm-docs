# UNNotificationContentExtensionMediaPlayPauseButtonType.overlay (Swift)

**Framework:** User Notifications UI  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · macOS 11.0+ · visionOS 1.0+

A partially transparent play/pause button that is layered on top of your media content.

## Declaration

```swift
case overlay
```

<a id="discussion"></a>

## Discussion

This button draws a play icon over the content initially. When playback begins, the button disappears. Tapping the content again pauses playback and displays the play button again.

## See Also

### Button Types

- [UNNotificationContentExtensionMediaPlayPauseButtonType.none](none.md): No media button.
- [UNNotificationContentExtensionMediaPlayPauseButtonType.default](default.md): A standard play/pause button.
