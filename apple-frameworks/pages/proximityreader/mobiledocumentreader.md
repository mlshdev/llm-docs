## Overview

After creating the `MobileDocumentReader` object, call [prepare(using:)](mobiledocumentreader/prepare%28using_%29.md) to prepare the device for mobile document reading. Use the returned [MobileDocumentReaderSession](mobiledocumentreadersession.md) object to read mobile documents.

You can optionally display your brand’s name and logo during a mobile document read. To do this, your server needs to generate a reader token, then pass the token as an argument to the [prepare(using:)](mobiledocumentreader/prepare%28using_%29.md) method.
