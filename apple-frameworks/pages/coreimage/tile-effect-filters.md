# Tile Effect Filters (Swift)

**Framework:** Core Image  
**Kind:** API Collection

Produce tiled images from source images.

## Topics

### Filters

- [affineClamp()](cifilter-swift.class/affineclamp%28%29.md): Performs a transform on the image and extends the image edges to infinity.
- [affineTile()](cifilter-swift.class/affinetile%28%29.md): Performs a transform on the image and tiles the result.
- [eightfoldReflectedTile()](cifilter-swift.class/eightfoldreflectedtile%28%29.md): Creates an eight-way reflected pattern.
- [fourfoldReflectedTile()](cifilter-swift.class/fourfoldreflectedtile%28%29.md): Creates a four-way reflected pattern.
- [fourfoldRotatedTile()](cifilter-swift.class/fourfoldrotatedtile%28%29.md): Creates a tiled image by rotating a tile in increments of 90 degrees.
- [fourfoldTranslatedTile()](cifilter-swift.class/fourfoldtranslatedtile%28%29.md): Creates a tiled image by applying four translation operations.
- [glideReflectedTile()](cifilter-swift.class/glidereflectedtile%28%29.md): Tiles an image by rotating and reflecting a tile from the image.
- [kaleidoscope()](cifilter-swift.class/kaleidoscope%28%29.md): Creates a 12-way kaleidoscopic image from an image.
- [opTile()](cifilter-swift.class/optile%28%29.md): Produces an effect that mimics a style of visual art that uses optical illusions.
- [parallelogramTile()](cifilter-swift.class/parallelogramtile%28%29.md): Warps the image to create a parallelogram and tiles the result.
- [perspectiveTile()](cifilter-swift.class/perspectivetile%28%29.md): Tiles an image by adjusting the perspective of the image.
- [sixfoldReflectedTile()](cifilter-swift.class/sixfoldreflectedtile%28%29.md): Produces a tiled image from a source image by applying a six-way reflected symmetry.
- [sixfoldRotatedTile()](cifilter-swift.class/sixfoldrotatedtile%28%29.md): Creates a tiled image by rotating in increments of 60 degrees.
- [triangleKaleidoscope()](cifilter-swift.class/trianglekaleidoscope%28%29.md): Create a triangular kaleidoscope effect and then tiles the result.
- [triangleTile()](cifilter-swift.class/triangletile%28%29.md): Tiles a triangular area of an image.
- [twelvefoldReflectedTile()](cifilter-swift.class/twelvefoldreflectedtile%28%29.md): Creates a tiled image by rotating in increments of 30 degrees.
