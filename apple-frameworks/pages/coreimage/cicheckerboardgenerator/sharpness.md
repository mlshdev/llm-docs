# sharpness (Swift)

**Framework:** Core Image  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS

The sharpness of the edges in the pattern.

## Declaration

```swift
var sharpness: Float { get set }
```

<a id="Discussion"></a>

## Discussion

The smaller the value, the more blurry the pattern. Values range from 0.0 to 1.0.

## See Also

### Instance Properties

- [center](center.md): The center of the effect as x and y coordinates.
- [color0](color0.md): A color to use for the first set of squares.
- [color1](color1.md): A color to use for the second set of squares.
- [width](width.md): The width of the squares in the pattern.
