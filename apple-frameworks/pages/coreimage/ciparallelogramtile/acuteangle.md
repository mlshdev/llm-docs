# acuteAngle (Swift)

**Framework:** Core Image  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS

The primary angle for the repeating parallelogram tile.

## Declaration

```swift
var acuteAngle: Float { get set }
```

<a id="Discussion"></a>

## Discussion

Small values create thin diamond tiles, and higher values create fatter parallelogram tiles.

## See Also

### Instance Properties

- [angle](angle.md): The angle, in radians, of the tiled pattern.
- [center](center.md): The x and y position to use as the center of the effect.
- [inputImage](inputimage.md): The image to use as an input image.
- [width](width.md): The width of a tile.
