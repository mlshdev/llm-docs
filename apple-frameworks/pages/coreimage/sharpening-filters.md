# Sharpening Filters (Swift)

**Framework:** Core Image  
**Kind:** API Collection

Apply sharpening to images.

## Topics

### Filters

- [sharpenLuminance()](cifilter-swift.class/sharpenluminance%28%29.md): Applies a sharpening effect to an image.
- [unsharpMask()](cifilter-swift.class/unsharpmask%28%29.md): Increases an image’s contrast between two colors.

### Protocols

- [CISharpenLuminance](cisharpenluminance.md): The properties you use to configure a sharpen luminance filter.
- [CIUnsharpMask](ciunsharpmask.md): The properties you use to configure an unsharp mask filter.
