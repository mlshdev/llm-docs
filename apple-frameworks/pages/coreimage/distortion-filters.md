# Distortion Filters (Swift)

**Framework:** Core Image  
**Kind:** API Collection

Apply distortion to images.

## Topics

### Filters

- [bumpDistortion()](cifilter-swift.class/bumpdistortion%28%29.md): Distorts an image with a concave or convex bump.
- [bumpDistortionLinear()](cifilter-swift.class/bumpdistortionlinear%28%29.md): Linearly distorts an image with a concave or convex bump.
- [circleSplashDistortion()](cifilter-swift.class/circlesplashdistortion%28%29.md): Distorts an image with radiating circles to the periphery of the image.
- [circularWrap()](cifilter-swift.class/circularwrap%28%29.md): Distorts an image by increasing the distance of the center of the image.
- [displacementDistortion()](cifilter-swift.class/displacementdistortion%28%29.md): Applies the grayscale values of the second image to the first image.
- [droste()](cifilter-swift.class/droste%28%29.md): Stylizes an image with the Droste effect.
- [glassDistortion()](cifilter-swift.class/glassdistortion%28%29.md): Distorts an image by applying a glass-like texture.
- [glassLozenge()](cifilter-swift.class/glasslozenge%28%29.md): Creates a lozenge-shaped lens and distorts the image.
- [holeDistortion()](cifilter-swift.class/holedistortion%28%29.md): Distorts an image with a circular area that pushes the image outward.
- [lightTunnel()](cifilter-swift.class/lighttunnel%28%29.md): Distorts an image by generating a light tunnel.
- [ninePartStretched()](cifilter-swift.class/ninepartstretched%28%29.md): Distorts an image by stretching it between two breakpoints.
- [ninePartTiled()](cifilter-swift.class/nineparttiled%28%29.md): Distorts an image by tiling portions of it.
- [pinchDistortion()](cifilter-swift.class/pinchdistortion%28%29.md): Distorts an image by creating a pinch effect with stronger distortion in the center.
- [stretchCrop()](cifilter-swift.class/stretchcrop%28%29.md): Distorts an image by stretching or cropping to fit a specified size.
- [torusLensDistortion()](cifilter-swift.class/toruslensdistortion%28%29.md): Creates a torus-shaped lens to distort the image.
- [twirlDistortion()](cifilter-swift.class/twirldistortion%28%29.md): Distorts an image by rotating pixels around a center point.
- [vortexDistortion()](cifilter-swift.class/vortexdistortion%28%29.md): Distorts an image by using a vortex effect created by rotating pixels around a point.
