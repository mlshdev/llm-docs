# Detector Accuracy Options (Swift)

**Framework:** Core Image  
**Kind:** API Collection

Value options used to specify the desired accuracy of the detector.

## Topics

### Constants

- [CIDetectorAccuracyLow](cidetectoraccuracylow.md): Indicates that the detector should choose techniques that are lower in accuracy, but can be processed more quickly.
- [CIDetectorAccuracyHigh](cidetectoraccuracyhigh.md): Indicates that the detector should choose techniques that are higher in accuracy, even if it requires more processing time.

## See Also

### Constants

- [Detector Types](detector-types.md): Strings used to declare the detector for which you are interested.
- [Detector Configuration Keys](detector-configuration-keys.md): Keys used in the options dictionary to configure a detector.
- [Feature Detection Keys](feature-detection-keys.md): Keys used in the options dictionary for [features(in:options:)](cidetector/features%28in_options_%29.md).
