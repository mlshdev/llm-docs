# kCIAttributeFilterAvailable_Mac (Swift)

**Framework:** Core Image  
**Kind:** Global Variable  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.11+ · tvOS 9.0+ · visionOS 1.0+

The macOS version in which the filter first became available.

## Declaration

```swift
let kCIAttributeFilterAvailable_Mac: String
```

<a id="discussion"></a>

## Discussion

The macOS version in which the filter first became available, specified as an [NSString](../foundation/nsstring.md) object.
