# extent (Swift)

**Framework:** Core Image  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS

A rectangle that defines the extent of the effect.

## Declaration

```swift
var extent: CGRect { get set }
```

## See Also

### Instance Properties

- [center](center.md): The x and y position to use as the center of the effect.
- [scale](scale.md): A value that determines whether the ripple starts as a bulge (a higher value) or a dimple (a lower value).
- [shadingImage](shadingimage.md): An image that looks like a shaded sphere enclosed in a square.
- [width](width.md): The width of the ripple.
