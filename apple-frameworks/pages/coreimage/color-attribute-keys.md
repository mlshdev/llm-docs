# Color Attribute Keys

**Interface languages:** Swift, Objective-C

**Framework:** Core Image  
**Kind:** API Collection

Color types.

## Topics

### Constants

- [kCIAttributeTypeOpaqueColor](kciattributetypeopaquecolor.md): A Core Image color ([CIColor](cicolor.md) object) that specifies red, green, and blue component values. Use this key for colors with no alpha component. If the key is not present, Core Image assumes color with alpha.
- [kCIAttributeTypeGradient](kciattributetypegradient.md): An n-by-1 gradient image used to describe a color ramp.
- [kCIAttributeTypeColor](kciattributetypecolor.md): A Core Image color ([CIColor](cicolor.md) object) that specifies red, green, and blue component values.
