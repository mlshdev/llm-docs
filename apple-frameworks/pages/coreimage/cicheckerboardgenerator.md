# CICheckerboardGenerator (Swift)

**Kind:** Protocol

The properties you use to configure a checkerboard generator filter.


## Topics

### Instance Properties

- [center](cicheckerboardgenerator/center.md): The center of the effect as x and y coordinates.
