# INUpdateMediaAffinityMediaItemUnsupportedReason.regionRestriction (Swift)

**Framework:** Intents  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · tvOS 14.0+ · visionOS 1.0+ · watchOS 7.0+

The app can’t update the user’s affinity for the media because the media isn’t available in the user’s geographic location.

## Declaration

```swift
case regionRestriction
```
