# INRelevantShortcutRole.information (Swift)

**Framework:** Intents  
**Kind:** Case  
**Availability:** iOS 12.0+ · iPadOS 12.0+ · Mac Catalyst 13.1+ · visionOS 1.0+ · watchOS 5.0+

An informational-based relevant shortcut.

## Declaration

```swift
case information
```

<a id="Discussion"></a>

## Discussion

Specify this role for relevant shortcuts that represent information that the user may want to glance at, such as the current weather conditions.
