# INDeleteTasksTaskUnsupportedReason.noTasksInApp (Swift)

**Framework:** Intents  
**Kind:** Case  
**Availability:** iOS 13.0+ (deprecated in 15.0) · iPadOS 13.0+ (deprecated in 15.0) · Mac Catalyst 13.1+ (deprecated in 15.0) · visionOS 1.0+ (deprecated in 1.0) · watchOS 6.0+ (deprecated in 8.0)

No tasks exist in the app.

> INDeleteTasksTaskUnsupportedReason is deprecated. There is no replacement.

## Declaration

```swift
case noTasksInApp
```

<a id="Discussion"></a>

## Discussion

Use this reason when there are no tasks in the app. If tasks exist, but do not match the user’s intent, use [INDeleteTasksTaskUnsupportedReason.noTasksFound](notasksfound.md)
