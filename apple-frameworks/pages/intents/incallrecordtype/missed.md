# INCallRecordType.missed (Swift)

**Framework:** Intents  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 12.0+ · visionOS 1.0+ · watchOS 3.2+

A received call that the user did not answer.

## Declaration

```swift
case missed
```

<a id="Discussion"></a>

## Discussion

Use this constant for calls that were not picked up by the user.
