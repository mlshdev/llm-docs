# INInteractionDirection.unspecified (Swift)

**Framework:** Intents  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · macOS 11.0+ · tvOS 14.0+ · visionOS 1.0+ · watchOS 3.2+

An unspecified direction.

## Declaration

```swift
case unspecified
```

<a id="Discussion"></a>

## Discussion

Choose this value for interactions that do not involve information moving onto or off of the device. This is the default value.
