# CreativeState

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The system state of the creative.

## Declaration

```
string CreativeState
```

## Possible Values

- `VALID`: The state of the creative is valid.
- `INVALID`: The state of the creative is invalid.
