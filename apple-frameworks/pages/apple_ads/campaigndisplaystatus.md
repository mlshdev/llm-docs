# CampaignDisplayStatus

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+ (deprecated in 5.2)

The status of the campaign.

> Apple Ads Campaign Management API is deprecated. Instead, use the [Apple Ads Platform API](https://developer.apple.com/documentation/apple-ads-platform-api).

## Declaration

```
string CampaignDisplayStatus
```

## Possible Values

- `RUNNING`: The campaign is running.
- `ON_HOLD`: The campaign is on hold for one or more reasons.
- `PAUSED`: The campaign is paused by the user.
- `DELETED`: The campaign has been deleted by the user
