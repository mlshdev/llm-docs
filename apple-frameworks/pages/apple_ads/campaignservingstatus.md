# CampaignServingStatus

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The status of the campaign.

## Declaration

```
string CampaignServingStatus
```

## Possible Values

- `RUNNING`: The campaign is running.
- `NOT_RUNNING`: The campaign is not running.
