# AdServingStatus

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The status of whether the ad is serving.

## Declaration

```
string AdServingStatus
```

## Possible Values

- `RUNNING`: The ad is running.
- `NOT_RUNNING`: The ad isn’t running.
