# CampaignStatus

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The status of the campaign.

## Declaration

```
string CampaignStatus
```

## Possible Values

- `ENABLED`: The campaign is enabled.
- `PAUSED`: The campaign is paused.
