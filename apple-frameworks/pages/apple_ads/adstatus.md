# AdStatus

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The user-controlled status of the ad.

## Declaration

```
string AdStatus
```

## Possible Values

- `ENABLED`: The [Ad](ad.md) is enabled.
- `PAUSED`: The [Ad](ad.md) is paused.
