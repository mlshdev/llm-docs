# PaymentModel

**Interface language:** Data

**Framework:** Apple Ads  
**Kind:** Type  
**Availability:** Search Ads 4.0+

The payment model that you set.

## Declaration

```
string PaymentModel
```

## Possible Values

- `PAYG`: A pay-as-you-go payment model.
- `LOC`: A line-of-credit payment model.
