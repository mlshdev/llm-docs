## Topics

### Type Properties

- [low](texturequality/low.md): Aggressively reduces the texture file size. Some visual details may be suppressed to reach the smallest file size.
- [medium](texturequality/medium.md): Further reduces the texture file size. Fine details may not be preserved to reach a small file size.
- [standard](texturequality/standard.md): Reduces the texture file size while preserving most details.
