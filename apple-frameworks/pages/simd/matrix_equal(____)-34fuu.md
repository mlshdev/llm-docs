# matrix_equal(\_:\_:)

**Framework:** simd  
**Kind:** Function  
**Availability:** Swift  (deprecated in 4.0)

Returns true if every element in a matrix is exactly equal to the corresponding element in a second matrix, and otherwise returns false.
