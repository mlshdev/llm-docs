# GCDualSenseAdaptiveTrigger.Mode.weapon (Swift)

**Framework:** Game Controller  
**Kind:** Case  
**Availability:** iOS 14.5+ · iPadOS 14.5+ · Mac Catalyst 14.5+ · macOS 11.3+ · tvOS 14.5+ · visionOS 1.0+

Provides feedback when the user depresses the trigger between the start and the end positions.

## Declaration

```swift
case weapon
```

<a id="Discussion"></a>

## Discussion

This mode emulates the feeling of pulling the trigger on a weapon.

## See Also

### Modes

- [GCDualSenseAdaptiveTrigger.Mode.off](off.md): Provides no adaptive trigger effects.
- [GCDualSenseAdaptiveTrigger.Mode.feedback](feedback.md): Provides feedback when the user depresses the trigger equal to, or greater than, the start position.
- [GCDualSenseAdaptiveTrigger.Mode.vibration](vibration.md): Vibrates when the user depresses the trigger equal to, or greater than, the start position.
- [GCDualSenseAdaptiveTrigger.Mode.slopeFeedback](slopefeedback.md): Provides feedback when the user tilts the trigger between the start and the end positions.
