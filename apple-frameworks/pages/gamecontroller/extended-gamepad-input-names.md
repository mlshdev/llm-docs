# Extended gamepad input names (Swift)

**Framework:** Game Controller  
**Kind:** API Collection

Constants for names of extended gamepad elements.

<a id="overview"></a>

## Overview

Use these constants as the keys when accessing [GCExtendedGamepad](gcextendedgamepad.md) elements by name using the [allElements](gcphysicalinputprofile/allelements.md) property, `subscript(_:)` notation, or similar [GCPhysicalInputProfile](gcphysicalinputprofile.md) APIs.

## Topics

### Shoulder button names

- [GCInputLeftShoulder](gcinputleftshoulder-9assr.md): The name of the left shoulder button.
- [GCInputRightShoulder](gcinputrightshoulder-5lcq1.md): The name of the right shoulder button.

### Trigger names

- [GCInputLeftTrigger](gcinputlefttrigger-80png.md): The name of the left trigger.
- [GCInputRightTrigger](gcinputrighttrigger-96vtj.md): The name of the right trigger.

### Face button names

- [GCInputButtonMenu](gcinputbuttonmenu-196mn.md): The name of the primary menu button element.
- [GCInputButtonHome](gcinputbuttonhome-7xxwm.md): The name of the home or logo button element.
- [GCInputButtonOptions](gcinputbuttonoptions-84kj.md): The name of the secondary menu button.
- [GCInputButtonA](gcinputbuttona-8z15w.md): The name for the controller’s A button.
- [GCInputButtonB](gcinputbuttonb-6z361.md): The name for the controller’s B button.
- [GCInputButtonX](gcinputbuttonx-32i2z.md): The name for the controller’s X button.
- [GCInputButtonY](gcinputbuttony-9x9i9.md): The name for the controller’s Y button.

### Directional pad names

- [GCInputDirectionPad](gcinputdirectionpad-115st.md): The name of the directional pad element.

### Thumbstick names

- [GCInputLeftThumbstick](gcinputleftthumbstick-3hlff.md): The name of the left thumbstick element.
- [GCInputRightThumbstick](gcinputrightthumbstick-8469p.md): The name of the right thumbstick element.
- [GCInputLeftThumbstickButton](gcinputleftthumbstickbutton-7gej3.md): The name of the left thumbstick button element.
- [GCInputRightThumbstickButton](gcinputrightthumbstickbutton-4to77.md): The name of the right thumbstick button element.
