# Xbox controller input names (Swift)

**Framework:** Game Controller  
**Kind:** API Collection

Constants for names of Xbox elements.

<a id="overview"></a>

## Overview

Use these constants as the keys when accessing [GCXboxGamepad](gcxboxgamepad.md) elements by name using the [allElements](gcphysicalinputprofile/allelements.md) property, `subscript(_:)` notation, or similar [GCPhysicalInputProfile](gcphysicalinputprofile.md) APIs.

## Topics

### Xbox controller button names

- [GCInputButtonShare](gcinputbuttonshare-87tha.md): The name of the share button.
- [GCInputXboxPaddleOne](gcinputxboxpaddleone-offv.md): The name for the controller’s P1 paddle button.
- [GCInputXboxPaddleTwo](gcinputxboxpaddletwo-4ya43.md): The name for the controller’s P2 paddle button.
- [GCInputXboxPaddleThree](gcinputxboxpaddlethree-6zcw8.md): The name for the controller’s P3 paddle button.
- [GCInputXboxPaddleFour](gcinputxboxpaddlefour-1obrw.md): The name for the controller’s P4 paddle button.
