# Directional Gamepad Input Names (Swift)

**Framework:** Game Controller  
**Kind:** API Collection

Constants for names of directional pad elements.

## Topics

### Directional Pad Names

- [GCInputDirectionalDpad](gcinputdirectionaldpad.md): The name of the controller’s primary directional pad element.
- [GCInputDirectionalCardinalDpad](gcinputdirectionalcardinaldpad.md): The name of the controller’s optional secondary directional pad element.

### Directional Pad Button Names

- [GCInputDirectionalTouchSurfaceButton](gcinputdirectionaltouchsurfacebutton.md): The name of the controller’s touch surface button.
- [GCInputDirectionalCenterButton](gcinputdirectionalcenterbutton.md): The name of the controller’s optional button on the directional gamepad.
