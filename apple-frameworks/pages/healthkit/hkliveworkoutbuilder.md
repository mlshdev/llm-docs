# HKLiveWorkoutBuilder (Swift)

**Framework:** HealthKit  
**Kind:** Class  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS · watchOS 5.0+

A builder object that constructs a workout incrementally based on live data from an active workout session.

## Declaration

```swift
class HKLiveWorkoutBuilder
```

## Mentioned In

- [Accessing workout zone data](accessing-workout-zone-data.md)
- [Running workout sessions](running-workout-sessions.md)

<a id="overview"></a>

## Overview

Use a live workout builder to create an [HKWorkout](hkworkout.md) sample during an active [HKWorkoutSession](hkworkoutsession.md). For complete instructions on running workout sessions on Apple Watch, see [Running workout sessions](running-workout-sessions.md).

## Topics

### Configuring a live workout builder

- [dataSource](hkliveworkoutbuilder/datasource.md): A data source that provides live data from a workout session automatically.
- [workoutSession](hkliveworkoutbuilder/workoutsession.md): The workout session created by the data source and associated with this builder.
- [delegate](hkliveworkoutbuilder/delegate.md): The live builder’s delegate.

### Monitoring and controlling the workout

- [currentWorkoutActivity](hkliveworkoutbuilder/currentworkoutactivity.md): The current workout activity.
- [shouldCollectWorkoutEvents](hkliveworkoutbuilder/shouldcollectworkoutevents.md): A Boolean value that determines whether the workout builder automatically adds events generated by the workout session.

### Accessing data

- [elapsedTime](hkliveworkoutbuilder/elapsedtime.md): The elapsed time for the workout based on the builder’s current contents, including pauses.

### Receiving zone updates

- [HKLiveWorkoutZoneUpdate](hkliveworkoutzoneupdate.md): A structure that contains information about zone transitions during a live workout session.
