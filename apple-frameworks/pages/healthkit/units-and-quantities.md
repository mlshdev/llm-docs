# Units and quantities

**Interface languages:** Swift, Objective-C

**Framework:** HealthKit  
**Kind:** API Collection

Objects used to specify a quantity for a given unit, and to convert between units.

## Topics

### Units and quantities

- [Defining and converting units and quantities](defining-and-converting-units-and-quantities.md): Create and convert units and quantities.
- [HKQuantity](hkquantity.md): An object that stores a value for a given unit.
- [HKUnit](hkunit.md): A class for managing the units of measure within HealthKit.
- [HKMetricPrefix](hkmetricprefix.md): Prefixes that can be added to SI units to change the order of magnitude.

## See Also

### Basic samples

- [HKCumulativeQuantitySample](hkcumulativequantitysample.md): A sample that represents a cumulative quantity.
- [HKDiscreteQuantitySample](hkdiscretequantitysample.md): A sample that represents a discrete quantity.
