# HKWorkoutEventType.marker (Swift)

**Framework:** HealthKit  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.0+ · macOS 13.0+ · visionOS 1.0+ · watchOS 3.0+

A constant indicating a point of interest during a workout session.

## Declaration

```swift
case marker
```

<a id="Discussion"></a>

## Discussion

Use markers to indicate arbitrary points during a workout (for example, when the user reaches the top of a hill during a run).
