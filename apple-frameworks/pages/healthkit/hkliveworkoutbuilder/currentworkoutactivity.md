# currentWorkoutActivity (Swift)

**Framework:** HealthKit  
**Kind:** Instance Property  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS · watchOS 9.0+

The current workout activity.

## Declaration

```swift
@NSCopying var currentWorkoutActivity: HKWorkoutActivity? { get }
```

<a id="Discussion"></a>

## Discussion

This property contains a workout activity that’s currently in progress, an activity with an [endDate](../hkworkoutactivity/enddate.md) property set to `nil`. If you end the activity — for example, by calling [endCurrentActivity(on:)](../hkworkoutsession/endcurrentactivity%28on_%29.md) or [updateActivity(uuid:end:completion:)](../hkworkoutbuilder/updateactivity%28uuid_end_completion_%29.md) — the system sets this property to `nil` until you begin a new activity.

## See Also

### Monitoring and controlling the workout

- [shouldCollectWorkoutEvents](shouldcollectworkoutevents.md): A Boolean value that determines whether the workout builder automatically adds events generated by the workout session.
