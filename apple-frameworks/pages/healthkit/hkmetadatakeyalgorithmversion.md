# HKMetadataKeyAlgorithmVersion (Swift)

**Framework:** HealthKit  
**Kind:** Global Variable  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 13.0+ · visionOS 1.0+ · watchOS 8.0+

A key that indicates the version number of the algorithm used to calculate the sample’s value.

## Declaration

```swift
let HKMetadataKeyAlgorithmVersion: String
```

<a id="Discussion"></a>

## Discussion

This key takes an [NSNumber](../foundation/nsnumber.md) containing an [NSInteger](../objectivec/nsinteger.md).

> **Note**

>  In watchOS 8, the system uses this key for [heartRateVariabilitySDNN](hkquantitytypeidentifier/heartratevariabilitysdnn.md) and [HKHeartbeatSeriesSample](hkheartbeatseriessample.md) samples generated by Apple Watch.
