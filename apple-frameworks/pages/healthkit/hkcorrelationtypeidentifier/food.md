# food (Swift)

**Framework:** HealthKit  
**Kind:** Type Property  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.0+ · macOS 13.0+ · visionOS 1.0+ · watchOS 2.0+

Food correlation types combine any number of nutritional samples into a single food object.

## Declaration

```swift
static let food: HKCorrelationTypeIdentifier
```

<a id="Discussion"></a>

## Discussion

When creating food samples, specify the type of food using the [HKMetadataKeyFoodType](../hkmetadatakeyfoodtype.md) metadata key.

## See Also

### Related Documentation

- [HKCorrelationTypeIdentifier](../hkcorrelationtypeidentifier.md): The identifiers that create correlation type objects.
- [HKCorrelationType](../hkcorrelationtype.md): A type that identifies samples that group multiple subsamples.
- [HKCorrelation](../hkcorrelation.md): A sample that groups multiple related samples into a single entry.

### Essentials

- [HKMetadataKeyFoodType](../hkmetadatakeyfoodtype.md): The type of food that the HealthKit object represents.
