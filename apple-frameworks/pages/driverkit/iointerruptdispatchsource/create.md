# Create

**Interface language:** Objective-C

**Framework:** DriverKit  
**Kind:** Static Method  
**Availability:** DriverKit · iOS · iPadOS · macOS

Create a dispatch source that reports hardware-related interrupts generated by the specified service provider.

## Declaration

```objectivec
static kern_return_t Create(IOService *provider, uint32_t index, IODispatchQueue *queue, IOInterruptDispatchSource **source);
```

## Parameters

- `provider`: The [IOService](../ioservice.md) object representing the hardware device that generated the interrupt.
- `index`: The index for the interrupt.
- `queue`: The dispatch queue on which to run any handler blocks.
- `source`: A variable for storing the dispatch source. On return, this variable contains the retained object. You are responsible for releasing this object.

<a id="return-value"></a>

## Return Value

[kIOReturnSuccess](../kioreturnsuccess.md) on success, or another value if an error occurs. See [Error Codes](../error-codes.md).

<a id="Discussion"></a>

## Discussion

Creates a new interrupt source for the specified provider object. After creating the dispatch source, call the [SetHandler](sethandler.md) method to specify the action to perform when interrupts occur.

## See Also

### Configuring the Interrupt Source

- [init](init.md): Handles the basic initialization of the dispatch source.
- [free](free.md): Performs any final cleanup for the dispatch source.
- [SetHandler](sethandler.md): Set the handler block to run when the interrupt fires.
