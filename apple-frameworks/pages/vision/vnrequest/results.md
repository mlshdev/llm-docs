# results (Swift)

**Framework:** Vision  
**Kind:** Instance Property  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 13.1+ · macOS 10.13+ · tvOS 11.0+ · visionOS 1.0+

The collection of observation results generated by request processing.

## Declaration

```swift
var results: [VNObservation]? { get }
```

## Mentioned In

- [Detecting Human Body Poses in Images](../detecting-human-body-poses-in-images.md)
- [Recognizing Text in Images](../recognizing-text-in-images.md)

<a id="Discussion"></a>

## Discussion

If the request fails, this property is [nil](../../objectivec/nil-227m0.md). Otherwise, it contains an array of [VNObservation](../vnobservation.md) subclasses specific to the [VNRequest](../vnrequest.md) subclass.

Don’t access this property until the request has finished processing.

## See Also

### Configuring a Request

- [VNRequestCompletionHandler](../vnrequestcompletionhandler.md): A type alias to encapsulate the syntax for the completion handler the system calls after the request finishes processing.
- [completionHandler](completionhandler.md): The completion handler the system invokes after the request finishes processing.
- [preferBackgroundProcessing](preferbackgroundprocessing.md): A hint to minimize the resource burden of the request.
- [revision](revision.md): The specific algorithm or implementation revision that’s used to perform the request.
- [usesCPUOnly](usescpuonly.md): Deprecated. A Boolean signifying that the Vision request should execute exclusively on the CPU.
