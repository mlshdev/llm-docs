# usesCPUOnly (Swift)

**Framework:** Vision  
**Kind:** Instance Property  
**Availability:** iOS 11.0+ (deprecated in 17.0) · iPadOS 11.0+ (deprecated in 17.0) · Mac Catalyst 13.1+ (deprecated in 17.0) · macOS 10.13+ (deprecated in 14.0) · tvOS 11.0+ (deprecated in 17.0) · visionOS 1.0+ (deprecated in 1.0)

A Boolean signifying that the Vision request should execute exclusively on the CPU.

## Declaration

```swift
var usesCPUOnly: Bool { get set }
```

<a id="Discussion"></a>

## Discussion

This value defaults to [false](https://developer.apple.com/documentation/swift/false) to signify that the Vision request is free to leverage the GPU to accelerate its processing.
