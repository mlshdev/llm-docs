# Applying visual effects to foreground subjects

**Interface languages:** Swift, Objective-C

**Framework:** Vision  
**Kind:** Sample Code  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · Xcode 15.0+

Segment the foreground subjects of an image and composite them to a new background with visual effects.

<a id="Overview"></a>

## Overview

> **Note**

> This sample code project is associated with WWDC23 session 10176: [Lift subjects from images in your app](https://developer.apple.com/wwdc23/10176/).

<a id="Configure-the-sample-code-project"></a>

### Configure the sample code project

Before you run the sample code project in Xcode, set the run destination to an iOS 17 device.
