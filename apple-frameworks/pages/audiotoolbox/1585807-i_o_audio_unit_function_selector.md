# I/O Audio Unit Function Selectors (Swift)

**Framework:** Audio Toolbox  
**Kind:** API Collection

Audio unit component selectors, specific to I/O audio units, that correspond to functions in the audio unit API.

## Topics

### Constants

- [kAudioOutputUnitRange](kaudiooutputunitrange.md): The start of the numerical range for I/O audio unit function selectors.
- [kAudioOutputUnitStartSelect](kaudiooutputunitstartselect.md): Used by the system to start an I/O audio unit when you call the [AudioOutputUnitStart(\_:)](audiooutputunitstart%28__%29.md) function.
- [kAudioOutputUnitStopSelect](kaudiooutputunitstopselect.md): Used by the system to stop an I/O audio unit when you call the [AudioOutputUnitStop(\_:)](audiooutputunitstop%28__%29.md) function.
