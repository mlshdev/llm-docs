# kSystemSoundID_FlashScreen (Swift)

**Framework:** Audio Toolbox  
**Kind:** Global Variable  
**Availability:** macOS

On the desktop, use this constant with the [AudioServicesPlayAlertSound(\_:)](audioservicesplayalertsound%28__%29.md) function to display a flash of light on the screen.
