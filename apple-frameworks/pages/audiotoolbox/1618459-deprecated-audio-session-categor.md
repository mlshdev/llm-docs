# Deprecated Audio Session Categories

**Interface languages:** Swift, Objective-C

**Framework:** Audio Toolbox  
**Kind:** API Collection

Deprecated category identifiers for audio sessions. Do not use for new development.

## Topics

### Constants

- [kAudioSessionCategory_UserInterfaceSoundEffects](kaudiosessioncategory_userinterfacesoundeffects.md): Deprecated. For sound effects such as touch feedback, explosions, and so on.
- [kAudioSessionCategory_LiveAudio](kaudiosessioncategory_liveaudio.md): Deprecated. For live performance of music, such as for an app that simulates a piano.
