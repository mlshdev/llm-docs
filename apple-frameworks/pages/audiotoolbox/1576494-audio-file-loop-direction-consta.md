# Audio File Loop Direction Constants

**Interface languages:** Swift, Objective-C

**Framework:** Audio Toolbox  
**Kind:** API Collection

The playback direction of a looped segment of an audio file.

## Topics

### Constants

- [kAudioFileLoopDirection_NoLooping](kaudiofileloopdirection_nolooping.md): The segment is not looped.
- [kAudioFileLoopDirection_Forward](kaudiofileloopdirection_forward.md): Play the segment forward.
- [kAudioFileLoopDirection_Backward](kaudiofileloopdirection_backward.md): Play the segment backward.
- [kAudioFileLoopDirection_ForwardAndBackward](kaudiofileloopdirection_forwardandbackward.md): Play the segment forward and backward.
