# kFxLightType_Directional (Swift)

**Framework:** Professional Video Applications  
**Kind:** Global Variable  
**Availability:** FxPlug 3.1+

Light that comes from a particular direction, but which is infinitely far away.

## Declaration

```swift
var kFxLightType_Directional: Int { get }
```

<a id="discussion"></a>

## Discussion

This type of light is often used to simulate the sun, and it casts parallel light rays at every point in space.

## See Also

### Constants

- [kFxLightType_Ambient](kfxlighttype_ambient.md): Light that illuminates all objects in the scene evenly.
- [kFxLightType_Point](kfxlighttype_point.md): Light which exists at a point and illuminates in all directions.
- [kFxLightType_Spot](kfxlighttype_spot.md): Light which has a limiting cone, and which can be positioned and pointed in a particular direction.
