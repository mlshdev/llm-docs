# FxModifierKeys (Swift)

**Framework:** Professional Video Applications  
**Kind:** Type Alias  
**Availability:** FxPlug 3.1+

Specifies flags that identify modifier keys held down while an event is generated.

```swift
typealias FxModifierKeys = Int
```
