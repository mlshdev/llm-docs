# kKey_Character (Swift)

**Framework:** Professional Video Applications  
**Kind:** Global Variable  
**Availability:** FxPlug 4.1+

The character the user must press to invoke the command.

## Declaration

```swift
let kKey_Character: String
```

<a id="discussion"></a>

## Discussion

If this value is `0`, then there is no key assigned to this command.
