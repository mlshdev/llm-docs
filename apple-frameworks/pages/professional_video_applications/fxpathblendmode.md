# FxPathBlendMode (Swift)

**Framework:** Professional Video Applications  
**Kind:** Type Alias  
**Availability:** FxPlug 3.1+

The type of blending the user selects for the mask that a particular path describes.

## Declaration

```swift
typealias FxPathBlendMode = Int
```

## Topics

### Constants

- [kFxPathBlendMode_Add](kfxpathblendmode_add.md): The mask will blend using the additive mode.

- [kFxPathBlendMode_Replace](kfxpathblendmode_replace.md): The mask will blend replacing the existing content.
- [kFxPathBlendMode_Intersect](kfxpathblendmode_intersect.md): The mask will blend using an intersection.
