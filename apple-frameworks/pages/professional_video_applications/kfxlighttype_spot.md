# kFxLightType_Spot (Swift)

**Framework:** Professional Video Applications  
**Kind:** Global Variable  
**Availability:** FxPlug 3.1+

Light which has a limiting cone, and which can be positioned and pointed in a particular direction.

## Declaration

```swift
var kFxLightType_Spot: Int { get }
```

<a id="discussion"></a>

## Discussion

This type of light is directly analogous to a spot light in real life.

## See Also

### Constants

- [kFxLightType_Ambient](kfxlighttype_ambient.md): Light that illuminates all objects in the scene evenly.
- [kFxLightType_Directional](kfxlighttype_directional.md): Light that comes from a particular direction, but which is infinitely far away.
- [kFxLightType_Point](kfxlighttype_point.md): Light which exists at a point and illuminates in all directions.
