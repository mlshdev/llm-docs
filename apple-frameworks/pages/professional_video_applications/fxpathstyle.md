# FxPathStyle (Swift)

**Framework:** Professional Video Applications  
**Kind:** Type Alias  
**Availability:** FxPlug 3.1+

The style of the path, which is linear, bezier, or b-spline.

## Declaration

```swift
typealias FxPathStyle = Int
```

<a id="discussion"></a>

## Discussion

This is used by the `styleOfPath:error:` method and the [FxVertex](fxvertex.md) structure.

## Topics

### Constants

- [kFxPathStyle_Linear](kfxpathstyle_linear.md): The path is linear style.
- [kFxPathStyle_Bezier](kfxpathstyle_bezier.md): The path is bezier style.
- [kFxPathStyle_XSpline](kfxpathstyle_xspline.md): The path is b-spline style.
