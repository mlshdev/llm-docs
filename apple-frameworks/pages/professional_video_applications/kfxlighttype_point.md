# kFxLightType_Point (Swift)

**Framework:** Professional Video Applications  
**Kind:** Global Variable  
**Availability:** FxPlug 3.1+

Light which exists at a point and illuminates in all directions.

## Declaration

```swift
var kFxLightType_Point: Int { get }
```

<a id="discussion"></a>

## Discussion

Unlike ambient light, light eminating from a point light can be occluded.

## See Also

### Constants

- [kFxLightType_Ambient](kfxlighttype_ambient.md): Light that illuminates all objects in the scene evenly.
- [kFxLightType_Directional](kfxlighttype_directional.md): Light that comes from a particular direction, but which is infinitely far away.
- [kFxLightType_Spot](kfxlighttype_spot.md): Light which has a limiting cone, and which can be positioned and pointed in a particular direction.
