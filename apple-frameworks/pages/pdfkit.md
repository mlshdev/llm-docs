# PDFKit

**Interface languages:** Swift, Objective-C

**Framework:** PDFKit  
**Kind:** Framework  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 11.0+ · macOS 10.4+ · visionOS 1.0+

Display and manipulate PDF documents in your apps.

## Topics

### Views

- [PDFView](pdfkit/pdfview.md): An object that encapsulates the functionality of PDF Kit into a single widget that you can add to your application using Interface Builder.
- [PDFThumbnailView](pdfkit/pdfthumbnailview.md): An object that contains a set of thumbnails, each of which represents a page in a PDF document.

### Content Model

- [PDFDocument](pdfkit/pdfdocument.md): An object that represents PDF data or a PDF file and defines methods for writing, searching, and selecting PDF data.
- [PDFPage](pdfkit/pdfpage.md): `PDFPage`, a subclass of `NSObject`, defines methods used to render PDF pages and work with annotations, text, and selections.
- [PDFOutline](pdfkit/pdfoutline.md): A `PDFOutline` object is an element in a tree-structured hierarchy that can represent the structure of a PDF document.
- [PDFSelection](pdfkit/pdfselection.md): A `PDFSelection` object identifies a contiguous or noncontiguous selection of text in a PDF document.

### Annotations

- [Adding Widgets to a PDF Document](pdfkit/adding-widgets-to-a-pdf-document.md): Add text, button, and choice widgets to a PDF document.
- [Adding Custom Graphics to a PDF](pdfkit/adding-custom-graphics-to-a-pdf.md): Create and add custom annotation and page graphics to your PDF document.
- [Custom Graphics](pdfkit/custom-graphics.md): Demonstrates adding a watermark to a PDF page.
- [PDF Widgets](pdfkit/pdf-widgets.md): Demonstrates adding widgets—interactive form elements—to a PDF document.
- [PDFAnnotation](pdfkit/pdfannotation.md): An annotation in a PDF document.
