# AVAssetExportPreset3840x2160 (Swift)

**Framework:** AVFoundation  
**Kind:** Global Variable  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.10+ · tvOS 9.0+ · visionOS 1.0+

A preset to export a 3840 by 2160 movie that contains H.264 video and AAC audio.

## Declaration

```swift
let AVAssetExportPreset3840x2160: String
```

<a id="Discussion"></a>

## Discussion

The system doesn’t scale movies up from a smaller size.
