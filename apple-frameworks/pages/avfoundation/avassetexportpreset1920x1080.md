# AVAssetExportPreset1920x1080 (Swift)

**Framework:** AVFoundation  
**Kind:** Global Variable  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+ · macOS 10.7+ · tvOS 9.0+ · visionOS 1.0+

A preset to export a 1920 by 1080 movie that contains H.264 video and AAC audio.

## Declaration

```swift
let AVAssetExportPreset1920x1080: String
```

<a id="Discussion"></a>

## Discussion

The system doesn’t scale movies up from a smaller size.
