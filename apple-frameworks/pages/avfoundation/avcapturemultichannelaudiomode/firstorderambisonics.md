# AVCaptureMultichannelAudioMode.firstOrderAmbisonics (Swift)

**Framework:** AVFoundation  
**Kind:** Case  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · macOS 15.0+ · tvOS 18.0+

An audio mode that indicates the recording uses first-order ambisonics.

## Declaration

```swift
case firstOrderAmbisonics
```

<a id="Discussion"></a>

## Discussion

When recording a QuickTime movie file, the system records a stereo audio track with the first-order ambisonics track for backward playback compatibility.

## See Also

### Modes

- [AVCaptureMultichannelAudioMode.none](none.md): A mode that indicates there’s no multichannel audio.
- [AVCaptureMultichannelAudioMode.stereo](stereo.md): A mode that indicates the recording uses stereo audio.
