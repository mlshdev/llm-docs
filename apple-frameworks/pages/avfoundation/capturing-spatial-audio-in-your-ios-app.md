# Capturing Spatial Audio in your iOS app

**Interface languages:** Swift, Objective-C

**Framework:** AVFoundation  
**Kind:** Sample Code  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · Xcode 26.0+

Enhance your app’s audio recording capabilities by supporting Spatial Audio capture.

<a id="Overview"></a>

## Overview

> **Note**

> This sample code project is associated with WWDC25 session 251: [Enhance your app’s audio recording capabilities](https://developer.apple.com/videos/play/wwdc2025/251).

<a id="Configure-the-sample-code-project"></a>

### Configure the sample code project

Run this sample code on a device that supports Spatial Audio capture, like an iPhone 16 Pro or later.
