# removeBackgroundColorInRange:

**Interface language:** Objective-C

**Framework:** AVFoundation  
**Kind:** Instance Method  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS

Removes a background color from a range of text.

## Declaration

```objectivec
- (void) removeBackgroundColorInRange:(NSRange) range;
```

## Parameters

- `range`: The range from which the system removes the background color.
