# Encoder bit rate strategy values

**Interface languages:** Swift, Objective-C

**Framework:** AVFoundation

The constants that represent the possible bit rate strategy values.

<a id="overview"></a>

## Overview

You use these values with [AVEncoderBitRateStrategyKey](../avfaudio/avencoderbitratestrategykey.md).

## Topics

### Strategies

- [AVAudioBitRateStrategy_Constant](../avfaudio/avaudiobitratestrategy_constant.md): A value that represents a constant bit rate strategy.
- [AVAudioBitRateStrategy_LongTermAverage](../avfaudio/avaudiobitratestrategy_longtermaverage.md): A value that represents an average bit rate strategy.
- [AVAudioBitRateStrategy_VariableConstrained](../avfaudio/avaudiobitratestrategy_variableconstrained.md): A value that represents a constrained variable bit rate strategy.
- [AVAudioBitRateStrategy_Variable](../avfaudio/avaudiobitratestrategy_variable.md): A value that represents a variable bit rate strategy.
