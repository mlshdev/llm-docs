# init(url:)

**Framework:** AVFoundation  
**Kind:** Initializer  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 4.0+ · macOS 10.7+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 1.0+

Creates an asset that models the media at the specified URL.

## Declaration

```swift
convenience init(url: URL)
```

## Parameters

- `url`: A URL to a local, remote, or HTTP Live Streaming media resource.
