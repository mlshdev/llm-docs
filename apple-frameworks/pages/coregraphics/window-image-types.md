# Window Image Types (Swift)

**Framework:** Core Graphics  
**Kind:** API Collection

Specifies the options for capturing an image of a window.

## Topics

### Constants

- [boundsIgnoreFraming](cgwindowimageoption/boundsignoreframing.md)
- [shouldBeOpaque](cgwindowimageoption/shouldbeopaque.md)
- [onlyShadows](cgwindowimageoption/onlyshadows.md)
- [bestResolution](cgwindowimageoption/bestresolution.md): When capturing the window, return the best image resolution. The returned image size may be different than the screen size.
- [nominalResolution](cgwindowimageoption/nominalresolution.md): When capturing the window, return the nominal image resolution. The returned image size is the same as the screen size.
