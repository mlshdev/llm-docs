# kCGPDFContextSubject (Swift)

**Framework:** Core Graphics  
**Kind:** Global Variable  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.1+ · macOS 10.5+ · tvOS · visionOS 1.0+ · watchOS 2.0+

## Declaration

```swift
let kCGPDFContextSubject: CFString
```

<a id="Discussion"></a>

## Discussion

The subject of a document. Optional; if present, the value of this key must be a [CFString](../corefoundation/cfstring.md) object.
