# CGEventSource (Swift)

**Framework:** Core Graphics  
**Kind:** Class  
**Availability:** Mac Catalyst · macOS

Defines an opaque type that represents the source of a Quartz event.

## Declaration

```swift
class CGEventSource
```

<a id="overview"></a>

## Overview

A Quartz event source is an object that contains accumulated state related to event generation and event posting. Every event source has an associated global event state table called a source state. When you call [init(stateID:)](cgeventsource/init%28stateid_%29.md) to create an event source, you specify which source state to use. For more information about source states, see [CGEventSourceStateID](cgeventsourcestateid.md).

A typical use of an event source would be to obtain the source from a Quartz event received by an event tap callback function, and then to use that source for any new events created as a result of the received event. This has the effect of marking the events as being related.

This opaque type is derived from CFType and inherits the properties that all Core Foundation types have in common. For more information, see [CFTypeRef](../corefoundation/cftyperef.md).
