# CGEventTapProxy (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

Defines an opaque type that represents state within the client application that’s associated with an event tap.

## Declaration

```swift
typealias CGEventTapProxy = OpaquePointer
```

<a id="Discussion"></a>

## Discussion

An event tap proxy object is passed to your event tap callback function when it receives a new Quartz event. Your callback function needs the proxy to post Quartz events using the function [tapPostEvent(\_:)](cgevent/tappostevent%28__%29.md).
