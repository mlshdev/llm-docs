# CGGetLastMouseDelta()

**Framework:** Core Graphics  
**Kind:** Function  
**Availability:** macOS 10.9+

Reports the change in mouse position since the last mouse movement event received by the application.

## Declaration

```swift
func CGGetLastMouseDelta() -> (x: Int32, y: Int32)
```

<a id="return-value"></a>

## Return Value

A tuple whose `x` and `y` members represent the horizontal and vertical change in the mouse position since the last mouse movement event.

<a id="Discussion"></a>

## Discussion

This function is not recommended for general use. Instead, you should use the mouse-tracking functions provided by the [NSEvent](https://developer.apple.com/documentation/appkit/nsevent) class.
