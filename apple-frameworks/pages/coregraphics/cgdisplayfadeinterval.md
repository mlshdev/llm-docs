# CGDisplayFadeInterval (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

The duration in seconds of a fade operation or a fade hardware reservation.

## Declaration

```swift
typealias CGDisplayFadeInterval = Float
```

<a id="Discussion"></a>

## Discussion

Quartz uses this data type to specify the duration of both fade-out and fade-in operations. Values may range from 0 to `kCGMaxDisplayReservationInterval` seconds. A 0 value means fade immediately—see [CGDisplayFade(\_:\_:\_:\_:\_:\_:\_:\_:)](cgdisplayfade%28________________%29.md).
