# CGEventTimestamp (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

Defines the elapsed time in nanoseconds since startup that a Quartz event occurred.

## Declaration

```swift
typealias CGEventTimestamp = UInt64
```

<a id="Discussion"></a>

## Discussion

You set an event’s timestamp with [CGEventSetTimestamp](cgeventsettimestamp.md), and access it later with `CGEvent`’s [timestamp](cgevent/timestamp.md) property.
