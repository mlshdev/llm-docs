# Event Source Token (Swift)

**Framework:** Core Graphics  
**Kind:** API Collection

Specifies any input event type.

<a id="overview"></a>

## Overview

This constant is typically used with the function [secondsSinceLastEventType(\_:eventType:)](cgeventsource/secondssincelasteventtype%28__eventtype_%29.md) to specify that you want the elapsed time since the last input event of any type.
