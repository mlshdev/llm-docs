# CGGammaValue (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

A value used to map a color generated in software to a color supported by the display hardware.

## Declaration

```swift
typealias CGGammaValue = Float
```

<a id="Discussion"></a>

## Discussion

In macOS, the Display panel in System Preferences is used to set the default gamma for a display. Quartz also allows an application to provide its own custom gamma information, using functions such as [CGSetDisplayTransferByTable(\_:\_:\_:\_:\_:)](cgsetdisplaytransferbytable%28__________%29.md) and [CGSetDisplayTransferByFormula(\_:\_:\_:\_:\_:\_:\_:\_:\_:\_:)](cgsetdisplaytransferbyformula%28____________________%29.md).

These functions take `CGGammaValue` arguments that specify:

- A set of gamma table entries ranging from 0 to 1
- The positive real coefficients in a gamma equation
