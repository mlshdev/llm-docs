# CGRefreshRate (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

A display’s refresh rate in frames per second.

## Declaration

```swift
typealias CGRefreshRate = Double
```

<a id="Discussion"></a>

## Discussion

When requesting a new display mode, you can specify a desired refresh rate as a hint to Quartz. For example, see the function [CGDisplayBestModeForParametersAndRefreshRate(\_:\_:\_:\_:\_:\_:)](cgdisplaybestmodeforparametersandrefreshrate%28____________%29.md).

<a id="Special-Considerations"></a>

### Special Considerations

Most applications should never need this data type. Starting in OS X v10.6, the `CGDisplayBestMode` functions are deprecated and the new display mode API does not use this type.
