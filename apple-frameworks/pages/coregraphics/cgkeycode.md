# CGKeyCode (Swift)

**Framework:** Core Graphics  
**Kind:** Type Alias  
**Availability:** Mac Catalyst · macOS

Represents the virtual key codes used in keyboard events.

## Declaration

```swift
typealias CGKeyCode = UInt16
```

<a id="Discussion"></a>

## Discussion

In macOS, the hardware scan codes generated by keyboards are mapped to a set of virtual key codes that are hardware-independent. Pressing a given key always generates the same virtual key code on any supported keyboard.

As keys are pressed, the system uses the virtual key codes to create low-level keyboard events. For information on how to simulate a keyboard event, see the function [init(keyboardEventSource:virtualKey:keyDown:)](cgevent/init%28keyboardeventsource_virtualkey_keydown_%29.md).
