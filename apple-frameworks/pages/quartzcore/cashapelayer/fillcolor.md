# fillColor (Swift)

**Framework:** Core Animation  
**Kind:** Instance Property  
**Availability:** iOS 3.0+ · iPadOS 3.0+ · Mac Catalyst 13.1+ · macOS 10.6+ · tvOS 9.0+ · visionOS 1.0+

The color used to fill the shape’s path. Animatable.

## Declaration

```swift
var fillColor: CGColor? { get set }
```

<a id="Discussion"></a>

## Discussion

Setting `fillColor` to `nil` results in no fill being rendered.

Default is opaque black.
