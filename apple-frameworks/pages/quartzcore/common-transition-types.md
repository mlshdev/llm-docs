# Common Transition Types (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

These constants specify the transition types that can be used with the [type](catransition/type.md) property.

## Topics

### Constants

- [fade](catransitiontype/fade.md): The layer’s content fades as it becomes visible or hidden.
- [moveIn](catransitiontype/movein.md): The layer’s content slides into place over any existing content.
- [push](catransitiontype/push.md): The layer’s content pushes any existing content as it slides into place.
- [reveal](catransitiontype/reveal.md): The layer’s content is revealed gradually in the direction specified by the transition subtype.

## See Also

### Constants

- [Common Transition Subtypes](common-transition-subtypes.md): These constants specify the direction of motion-based transitions. They are used with the [subtype](catransition/subtype.md) property.
