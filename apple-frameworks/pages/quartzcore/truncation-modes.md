# Truncation modes (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

These constants are used by the [truncationMode](catextlayer/truncationmode.md) property.

## Topics

### Constants

- [none](catextlayertruncationmode/none.md): Each line is displayed so that the text is either wrapped or clipped.
- [start](catextlayertruncationmode/start.md): Each line is displayed so that the end fits in the container and the missing text is indicated by some kind of ellipsis glyph.
- [end](catextlayertruncationmode/end.md): Each line is displayed so that the beginning fits in the container and the missing text is indicated by some kind of ellipsis glyph.
- [middle](catextlayertruncationmode/middle.md): Each line is displayed so that the beginning and end fit in the container and the missing text is indicated by some kind of ellipsis glyph in the middle.
