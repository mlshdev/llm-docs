# Line Join Values (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

These constants specify the shape of the joints between connected segments of a stroked path.

<a id="overview"></a>

## Overview

Used by [lineJoin](cashapelayer/linejoin.md). The following figure shows the appearance of the available line join styles.

![](https://developer.apple.com/images/com.apple.quartzcore/media-1965771.gif)

## Topics

### Constants

- [miter](cashapelayerlinejoin/miter.md): Specifies a miter line shape of the joints between connected segments of a stroked path.
- [round](cashapelayerlinejoin/round.md): Specifies a round line shape of the joints between connected segments of a stroked path.
- [bevel](cashapelayerlinejoin/bevel.md): Specifies a bevel line shape of the joints between connected segments of a stroked path.

## See Also

### Constants

- [Shape Fill Mode Values](shape-fill-mode-values.md): These constants specify the possible fill modes for [fillRule](cashapelayer/fillrule.md).
- [Line Cap Values](line-cap-values.md): These constants specify the shape of endpoints for an open path when stroked.
