# Gradient Types (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

The style of gradient drawn by the layer.

## Topics

### Constants

- [axial](cagradientlayertype/axial.md): An axial gradient (also called a linear gradient) varies along an axis between two defined end points. All points that lie on a line perpendicular to the axis have the same color value.
