# Horizontal alignment modes (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

These constants are used by the [alignmentMode](catextlayer/alignmentmode.md) property.

## Topics

### Constants

- [natural](catextlayeralignmentmode/natural.md): Use the natural alignment of the text’s script.
- [left](catextlayeralignmentmode/left.md): Text is visually left aligned.
- [right](catextlayeralignmentmode/right.md): Text is visually right aligned.
- [center](catextlayeralignmentmode/center.md): Text is visually center aligned.
- [justified](catextlayeralignmentmode/justified.md): Text is justified.
