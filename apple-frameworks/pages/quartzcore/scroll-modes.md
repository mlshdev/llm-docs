# Scroll Modes (Swift)

**Framework:** Core Animation  
**Kind:** API Collection

These constants describe the supported scroll modes used by the [scrollMode](cascrolllayer/scrollmode.md) property.

## Topics

### Constants

- [none](cascrolllayerscrollmode/none.md): The receiver is unable to scroll.
- [vertically](cascrolllayerscrollmode/vertically.md): The receiver is able to scroll vertically.
- [horizontally](cascrolllayerscrollmode/horizontally.md): The receiver is able to scroll horizontally.
- [both](cascrolllayerscrollmode/both.md): The receiver is able to scroll both horizontally and vertically.
