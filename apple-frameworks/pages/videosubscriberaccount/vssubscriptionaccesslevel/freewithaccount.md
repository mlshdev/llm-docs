# VSSubscriptionAccessLevel.freeWithAccount (Swift)

**Framework:** Video Subscriber Account  
**Kind:** Case  
**Availability:** iOS 11.0+ (deprecated in 18.0) · iPadOS 11.0+ (deprecated in 18.0) · Mac Catalyst 11.0+ (deprecated in 18.0) · macOS · tvOS 11.0+ (deprecated in 18.0) · visionOS 1.0+ (deprecated in 2.0)

The user has access to free content with a valid account.

> Use VSUserAccount and VSUserAccountType instead.

## Declaration

```swift
case freeWithAccount
```

<a id="Discussion"></a>

## Discussion

This value corresponds to content in your availability feed with the *account* offering type.
