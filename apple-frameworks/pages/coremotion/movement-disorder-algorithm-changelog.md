# Movement disorder algorithm changelog (Swift)

**Framework:** Core Motion  
**Kind:** Article

A chronological log of notable changes to the movement disorder algorithm.

<a id="overview"></a>

## Overview

The movement disorder algorithm measures and records tremors and dyskinetic symptoms for Parkinson’s disease. For more information on receiving and using this data, see [Getting movement disorder symptom data](getting-movement-disorder-symptom-data.md).

<a id="Unreleased"></a>

### Unreleased

- The [version()](cmmovementdisordermanager/version%28%29.md) method for checking the algorithm’s current version is available in watchOS 9.

<a id="100-2018-07-17"></a>

### 1.0.0 — 2018-07-17

<a id="Added"></a>

#### Added

- Released the algorithm used in watchOS 5 and later.

## See Also

### Movement disorder

- [Getting movement disorder symptom data](getting-movement-disorder-symptom-data.md): Retrieve data from the Apple Watch’s movement disorder manager.
- [Adhering to the movement disorder data collection requirements](adhering-to-the-movement-disorder-data-collection-requirements.md): Ensure that your users understand and have control over the data your app collects.
- [CMMovementDisorderManager](cmmovementdisordermanager.md): A manager for recording and querying movement disorder data.
- [CMTremorResult](cmtremorresult.md): A result object that contains data about the presence and strength of tremors during a one-minute interval.
- [CMDyskineticSymptomResult](cmdyskineticsymptomresult.md): A result object that contains data about the likely presence of dyskinetic symptoms during a one-minute interval.
