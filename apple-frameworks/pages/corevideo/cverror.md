# CVError

**Framework:** Core Video  
**Kind:** Structure  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

`CVError` wraps `CVReturn` values to present them as Swift Error values. This type is used for all errors thrown in the CoreVideo framework. All `CVReturn` values are provided as static constants.

## Declaration

```swift
@frozen struct CVError
```

### Type Properties

- [allocationFailed](cverror/allocationfailed.md): The allocation for a buffer or buffer pool failed. Most likely because of lack of resources.
- [internalError](cverror/internalerror.md): Error with an undetermined cause.
- [invalidArgument](cverror/invalidargument.md): At least one of the arguments passed in is not valid. Either out of range or the wrong type.
- [invalidPixelBufferAttributes](cverror/invalidpixelbufferattributes.md): A CVBuffer cannot be created with the given attributes.
- [invalidPixelFormat](cverror/invalidpixelformat.md): The requested pixel format is not supported for the CVBuffer type.
- [invalidPoolAttributes](cverror/invalidpoolattributes.md): A CVBufferPool cannot be created with the given attributes.
- [invalidSize](cverror/invalidsize.md): The requested size (most likely too big) is not supported for the CVBuffer type.
- [pixelBufferNotMetalCompatible](cverror/pixelbuffernotmetalcompatible.md): The Buffer cannot be used with Metal as either its size, pixel format or attributes are not supported by Metal.
- [poolAllocationFailed](cverror/poolallocationfailed.md): The allocation for the buffer pool failed. Most likely because of lack of resources. Check if your parameters are in range.
- [retry](cverror/retry.md): A scan hasn’t completely traversed the CVBufferPool due to a concurrent operation. The client can retry the scan.
- [unsupported](cverror/unsupported.md): This operation is unsupported on this data type.
- [wouldExceedAllocationThreshold](cverror/wouldexceedallocationthreshold.md): The allocation request failed because it would have exceeded a specified allocation threshold (see kCVPixelBufferPoolAllocationThresholdKey).

### Type Methods

- [check(\_:)](cverror/check%28__%29.md): Throws an instance of `CVError` if `status` is not `kCVReturnSuccess`
