# kCVImageBufferDisplayMaskRectangle_RectangleLeftKey (Swift)

**Framework:** Core Video  
**Kind:** Global Variable  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

Specifies the horizontal pixel offset of the rectangle from the left of the bounding raster.

## Declaration

```swift
let kCVImageBufferDisplayMaskRectangle_RectangleLeftKey: CFString
```

<a id="Discussion"></a>

## Discussion

The left offset value is a [CFNumber](../corefoundation/cfnumber.md) of an unsigned 16-bit integer that’s less than the reference raster width value.
