# kCVImageBufferDisplayMaskRectangle_RectangleHeightKey (Swift)

**Framework:** Core Video  
**Kind:** Global Variable  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

Specifies the height of the rectangle starting at the rectangle’s top offset toward the rectangle’s bottom edge.

## Declaration

```swift
let kCVImageBufferDisplayMaskRectangle_RectangleHeightKey: CFString
```

<a id="Discussion"></a>

## Discussion

The height value is a [CFNumber](../corefoundation/cfnumber.md) of an unsigned 16-bit integer.
