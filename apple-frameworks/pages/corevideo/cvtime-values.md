# CVTime Values (Swift)

**Framework:** Core Video  
**Kind:** API Collection

Keys that represent Core Video time values.

## Topics

### Constants

- [kCVZeroTime](kcvzerotime.md): Zero time or duration. For example, [CVDisplayLinkGetOutputVideoLatency(\_:)](cvdisplaylinkgetoutputvideolatency%28__%29.md) returns `kCVZeroTime` for zero video latency.
- [kCVIndefiniteTime](kcvindefinitetime.md): An unknown or indefinite time. For example, [CVDisplayLinkGetNominalOutputVideoRefreshPeriod(\_:)](cvdisplaylinkgetnominaloutputvideorefreshperiod%28__%29.md) returns `kCVIndefiniteTime` if the display link specified is not valid.
