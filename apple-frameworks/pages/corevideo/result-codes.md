# Result Codes (Swift)

**Framework:** Core Video  
**Kind:** API Collection

Describes the result codes generated by Core Video operations.

## Topics

### Common

Result codes related to a number of Core Video operations.

- [kCVReturnAllocationFailed](kcvreturnallocationfailed.md): Memory allocation for a buffer or buffer pool failed.
- [kCVReturnError](kcvreturnerror.md): An otherwise undefined error occurred.
- [kCVReturnInvalidArgument](kcvreturninvalidargument.md): Invalid function parameter. For example, out of range or the wrong type.
- [kCVReturnSuccess](kcvreturnsuccess.md): Indicates the operation completed successfully.
- [kCVReturnUnsupported](kcvreturnunsupported.md)
- [kCVReturnLast](kcvreturnlast.md): Placeholder to mark the end of Core Video result codes (not returned by any functions).
- [kCVReturnFirst](kcvreturnfirst.md): Placeholder to mark the beginning of Core Video result codes (not returned by any functions).

### Pixel Buffer

Result codes related to [CVPixelBuffer](cvpixelbuffer-q2e.md) operations.

- [kCVReturnInvalidPixelBufferAttributes](kcvreturninvalidpixelbufferattributes.md): A buffer cannot be created with the specified attributes.
- [kCVReturnInvalidPixelFormat](kcvreturninvalidpixelformat.md): The buffer does not support the specified pixel format.
- [kCVReturnInvalidSize](kcvreturninvalidsize.md): The buffer cannot support the requested buffer size (usually too big).
- [kCVReturnPixelBufferNotMetalCompatible](kcvreturnpixelbuffernotmetalcompatible.md): The pixel buffer is not compatible with Metal due to an unsupported buffer size, pixel format, or attribute.
- [kCVReturnPixelBufferNotOpenGLCompatible](kcvreturnpixelbuffernotopenglcompatible.md): The pixel buffer is not compatible with OpenGL due to an unsupported buffer size, pixel format, or attribute.

### Buffer Pool

Result codes related to [CVPixelBufferPool](cvpixelbufferpool-77o.md) operations.

- [kCVReturnRetry](kcvreturnretry.md): A scan hasn’t completely traversed the `CVBufferPool` due to a concurrent operation.
- [kCVReturnInvalidPoolAttributes](kcvreturninvalidpoolattributes.md): A buffer pool cannot be created with the specified attributes.
- [kCVReturnPoolAllocationFailed](kcvreturnpoolallocationfailed.md): Allocation for a buffer pool failed, most likely due to a lack of resources. Check to make sure your parameters are in range.
- [kCVReturnWouldExceedAllocationThreshold](kcvreturnwouldexceedallocationthreshold.md): Allocation for a pixel buffer failed because the threshold value set for the [kCVPixelBufferPoolAllocationThresholdKey](kcvpixelbufferpoolallocationthresholdkey.md) key in the [CVPixelBufferPoolCreatePixelBufferWithAuxAttributes(\_:\_:\_:\_:)](cvpixelbufferpoolcreatepixelbufferwithauxattributes%28________%29.md) function would be surpassed.

### Display Link

Result codes related to [CVDisplayLink](cvdisplaylink-k0k.md) operations.

- [kCVReturnInvalidDisplay](kcvreturninvaliddisplay.md): The display specified when creating a display link is invalid.
- [kCVReturnDisplayLinkAlreadyRunning](kcvreturndisplaylinkalreadyrunning.md): The specified display link is already running.
- [kCVReturnDisplayLinkNotRunning](kcvreturndisplaylinknotrunning.md): The specified display link is not running.
- [kCVReturnDisplayLinkCallbacksNotSet](kcvreturndisplaylinkcallbacksnotset.md): No callback registered for the specified display link. You must set either the output callback or both the render and display callbacks.

## See Also

### Core Video Error Constants

- [Data Types](data-types.md): Common data types used by the Core Video framework.
- [CVError](cverror.md): `CVError` wraps `CVReturn` values to present them as Swift Error values. This type is used for all errors thrown in the CoreVideo framework. All `CVReturn` values are provided as static constants.
