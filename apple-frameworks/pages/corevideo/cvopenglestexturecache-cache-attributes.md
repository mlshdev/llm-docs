# Cache Attributes (Swift)

**Framework:** Core Video  
**Kind:** API Collection

Attributes for the texture cache.

## Topics

### Constants

- [kCVOpenGLESTextureCacheMaximumTextureAgeKey](kcvopenglestexturecachemaximumtextureagekey.md): Deprecated. By default, textures will age out after one second. Setting a maximum texture age of zero will disable the age-out mechanism completely. The [CVOpenGLESTextureCacheFlush(\_:\_:)](cvopenglestexturecacheflush%28____%29.md) function can be used to force eviction in either case.
