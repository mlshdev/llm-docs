# HMCharacteristicTypeNightVision (Swift)

**Framework:** HomeKit  
**Kind:** Global Variable  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · tvOS 10.0+ · visionOS 1.0+ · watchOS 3.0+

An indicator of whether night vision is enabled on a video Real-time Transport Protocol (RTP) service.

## Declaration

```swift
let HMCharacteristicTypeNightVision: String
```

<a id="Discussion"></a>

## Discussion

The corresponding value is a Boolean. Set the value to `true` to enable night vision. Set it to `false` to disable night vision.
