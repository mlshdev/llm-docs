# Characteristic Properties (Swift)

**Framework:** HomeKit  
**Kind:** API Collection

The properties that characteristics can have.

<a id="overview"></a>

## Overview

Check to see if a characteristic’s [properties](hmcharacteristic/properties.md) array contains any of these constants to learn something about the corresponding characteristic ([HMCharacteristic](hmcharacteristic.md)).

## Topics

### Properties of Characteristics

- [HMCharacteristicPropertyReadable](hmcharacteristicpropertyreadable.md): The characteristic is readable.
- [HMCharacteristicPropertyWritable](hmcharacteristicpropertywritable.md): The characteristic is writable.
- [HMCharacteristicPropertyHidden](hmcharacteristicpropertyhidden.md): The characteristic should be hidden from the user.

## See Also

### Reading characteristic properties

- [properties](hmcharacteristic/properties.md): An array of properties that describe the characteristic.
