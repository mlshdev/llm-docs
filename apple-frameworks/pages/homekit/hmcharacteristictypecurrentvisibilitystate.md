# HMCharacteristicTypeCurrentVisibilityState (Swift)

**Framework:** HomeKit  
**Kind:** Global Variable  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · tvOS 18.0+ · visionOS 2.0+ · watchOS 11.0+

The current visibility state for a service.

## Declaration

```swift
let HMCharacteristicTypeCurrentVisibilityState: String
```

<a id="Overview"></a>

## Overview

This variable indicates if applications show or hide the service. The corresponding value is one of the constants in the [HMCharacteristicValueCurrentVisibilityState](hmcharacteristicvaluecurrentvisibilitystate.md) enumeration.
