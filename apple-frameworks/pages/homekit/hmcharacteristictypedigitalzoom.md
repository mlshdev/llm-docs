# HMCharacteristicTypeDigitalZoom (Swift)

**Framework:** HomeKit  
**Kind:** Global Variable  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 10.0+ · tvOS 10.0+ · visionOS 1.0+ · watchOS 3.0+

The digital zoom of a video Real-time Transport Protocol (RTP) service.

## Declaration

```swift
let HMCharacteristicTypeDigitalZoom: String
```

<a id="Discussion"></a>

## Discussion

The corresponding value is a floating point number used as a multiplier on the image sourced by the video RTP service.
