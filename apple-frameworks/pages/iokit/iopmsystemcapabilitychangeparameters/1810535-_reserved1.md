# \__reserved1

**Interface language:** Objective-C

**Framework:** Kernel

Set to zero.

## See Also

### Fields

- [notifyRef](https://developer.apple.com/documentation/kernel/iopmsystemcapabilitychangeparameters/1522218-notifyref): An identifier for this message notification. Clients with pending I/O can signal completion by calling `allowPowerChange()` with this value as the argument. Clients that are able to process the notification synchronously should ignore this field.
- [maxWaitForReply](https://developer.apple.com/documentation/kernel/iopmsystemcapabilitychangeparameters/1522348-maxwaitforreply): A return value to the caller indicating the maximum time in microseconds to wait for the `allowPowerChange()` call. The default value is zero, which indicates the client processing has finished, and power management should not wait for an `allowPowerChange()` call.
- [changeFlags](https://developer.apple.com/documentation/kernel/iopmsystemcapabilitychangeparameters/1522278-changeflags): Flags will be set to indicate whether the notification precedes the capability change (`kIOPMSystemCapabilityWillChange`), or after the capability change has occurred (`kIOPMSystemCapabilityDidChange`).
- [fromCapabilities](https://developer.apple.com/documentation/kernel/iopmsystemcapabilitychangeparameters/1522166-fromcapabilities): The system capabilities at the start of the transition.
- [toCapabilities](https://developer.apple.com/documentation/kernel/iopmsystemcapabilitychangeparameters/1522492-tocapabilities): The system capabilities at the end of the transition.
