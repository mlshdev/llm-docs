# save

**Interface language:** Objective-C

**Framework:** IOKit  
**Kind:** Instance Property  
**Availability:** Mac Catalyst 18.4+ · macOS 10.6+

This array stores the color values of the region underneath the cursor in its last drawn position.

## Declaration

```objectivec
unsigned int save[256];
```

## See Also

### Fields

- [image](1589157-image.md): This array defines the cursor color values and transparency. The array is two dimensional and its first index is the cursor frame and the second index is the cursor pixel. The lower 24 bits of a pixel's value contain the RGB color, while the upper 8 bits contain the alpha value.
