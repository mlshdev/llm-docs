# Ethernet Bond Status Constants

**Interface languages:** Swift, Objective-C

**Framework:** System Configuration  
**Kind:** API Collection

## Topics

### Constants

- [kSCBondStatusDeviceAggregationStatus](kscbondstatusdeviceaggregationstatus.md): Device is aggregating. See [Ethernet Bond Aggregation Status](1546981-ethernet-bond-aggregation-status.md) for a list of possible values.
- [kSCBondStatusDeviceCollecting](kscbondstatusdevicecollecting.md): Can be `0` or `1`.
- [kSCBondStatusDeviceDistributing](kscbondstatusdevicedistributing.md): Can be `0` or `1`.
