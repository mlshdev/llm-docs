# Selection Options Dictionary Keys (Swift)

**Framework:** System Configuration  
**Kind:** API Collection

Keys used with the [SCNetworkConnectionCopyUserPreferences(\_:\_:\_:)](scnetworkconnectioncopyuserpreferences%28______%29.md) selection options dictionary.

## Topics

### Constants

- [kSCNetworkConnectionSelectionOptionOnDemandHostName](kscnetworkconnectionselectionoptionondemandhostname.md): The key associated with a host name used to select the “best” network connection.
- [kSCNetworkConnectionSelectionOptionOnDemandRetry](kscnetworkconnectionselectionoptionondemandretry.md): The key associated with a Boolean value used to indicate whether a DNS query has already been issued for the specified on-demand host name.
