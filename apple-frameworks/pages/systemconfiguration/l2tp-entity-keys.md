# L2TP Entity Keys

**Interface languages:** Swift, Objective-C

**Framework:** System Configuration  
**Kind:** API Collection

Keys that correspond to values in the `kSCEntNetL2TP` dictionary.

## Topics

### Constants

- [kSCPropNetL2TPIPSecSharedSecret](kscpropnetl2tpipsecsharedsecret-swift.var.md): The L2TP key `IPSecSharedSecret`, whose value is of type `CFString`.
- [kSCPropNetL2TPIPSecSharedSecretEncryption](kscpropnetl2tpipsecsharedsecretencryption-swift.var.md): The L2TP key `IPSecSharedSecretEncryption`, whose value is of type `CFString`.
- [kSCPropNetL2TPTransport](kscpropnetl2tptransport-swift.var.md): The L2TP key `Transport`, whose value is of type `CFString`.

### L2TP Shared Secret Encryption Values

- [kSCValNetL2TPIPSecSharedSecretEncryptionKeychain](kscvalnetl2tpipsecsharedsecretencryptionkeychain-swift.var.md): The constant value Keychain.

### Transport Values

- [kSCValNetL2TPTransportIP](kscvalnetl2tptransportip-swift.var.md): The constant value IP.
- [kSCValNetL2TPTransportIPSec](kscvalnetl2tptransportipsec-swift.var.md): The constant value IPSec.
