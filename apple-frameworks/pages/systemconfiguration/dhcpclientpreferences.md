# DHCPClientPreferences

**Interface language:** Objective-C

**Framework:** System Configuration  
**Kind:** API Collection

<a id="Overview"></a>

## Overview

The `DHCPClientPreferences` programming interface allows applications to get and update DHCP preferences. DHCP preferences are in the form of DHCP option codes, which are defined in RFC 2132.

## Topics

### Group

- [DHCPClientPreferencesCopyApplicationOptions](dhcpclientpreferencescopyapplicationoptions.md): Returns the list of options for the specified application ID.
- [DHCPClientPreferencesSetApplicationOptions](dhcpclientpreferencessetapplicationoptions.md): Updates the DHCP client preferences to include the specified list of options for the specified application ID.
