# DNS Entity Keys

**Interface languages:** Swift, Objective-C

**Framework:** System Configuration  
**Kind:** API Collection

Keys that correspond to values in the `kSCEntNetDNS` dictionary.

## Topics

### Constants

- [kSCPropNetDNSDomainName](kscpropnetdnsdomainname-swift.var.md): The DNS key `DomainName`, whose value is of type `CFString`.
- [kSCPropNetDNSOptions](kscpropnetdnsoptions-swift.var.md): The DNS key `Options`, whose value is of type `CFString`.
- [kSCPropNetDNSSearchDomains](kscpropnetdnssearchdomains-swift.var.md): The DNS key `SearchDomains`, whose value is of type `CFArray`, containing elements of type `CFString`.
- [kSCPropNetDNSSearchOrder](kscpropnetdnssearchorder-swift.var.md): The DNS key `SearchOrder`, whose value is of type `CFNumber`.
- [kSCPropNetDNSServerAddresses](kscpropnetdnsserveraddresses-swift.var.md): The DNS key `ServerAddresses`, whose value is of type `CFArray`, containing elements of type `CFString`.
- [kSCPropNetDNSServerPort](kscpropnetdnsserverport-swift.var.md): The DNS key `ServerPort`, whose value is of type `CFNumber`.
- [kSCPropNetDNSServerTimeout](kscpropnetdnsservertimeout-swift.var.md): The DNS key `ServerTimeout`, whose value is of type `CFNumber`.
- [kSCPropNetDNSSortList](kscpropnetdnssortlist-swift.var.md): The DNS key `SortList`, whose value is of type `CFArray`, containing elements of type `CFString`.
- [kSCPropNetDNSSupplementalMatchDomains](kscpropnetdnssupplementalmatchdomains-swift.var.md): The DNS key `SupplementalMatchDomains`, whose value is of type `CFArray`, containing elements of type `CFString`.
- [kSCPropNetDNSSupplementalMatchOrders](kscpropnetdnssupplementalmatchorders-swift.var.md): The DNS key `SupplementalMatchOrders`, whose value is of type `CFArray`, containing elements of type `CFNumber`.
