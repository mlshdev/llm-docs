# Statistics Dictionary Keys (Swift)

**Framework:** System Configuration  
**Kind:** API Collection

Keys associated with values in the statistics dictionary.

## Topics

### Constants

- [kSCNetworkConnectionBytesIn](kscnetworkconnectionbytesin.md): The key associated with the number of bytes going up into the network stack for any networking protocol without the PPP headers and trailers.
- [kSCNetworkConnectionBytesOut](kscnetworkconnectionbytesout.md): The key associated with the number of bytes coming out of the network stack for any networking protocol without the PPP headers and trailers.
- [kSCNetworkConnectionPacketsIn](kscnetworkconnectionpacketsin.md): The key associated with the number of packets going up into the network stack for any networking protocol without the PPP headers and trailers.
- [kSCNetworkConnectionPacketsOut](kscnetworkconnectionpacketsout.md): The key associated with the number of packets coming out of the network stack for any networking protocol without the PPP headers and trailers.
- [kSCNetworkConnectionErrorsIn](kscnetworkconnectionerrorsin.md): The key associated with the number of errors going up into the network stack for any networking protocol without the PPP headers and trailers.
- [kSCNetworkConnectionErrorsOut](kscnetworkconnectionerrorsout.md): The key associated with the number of errors coming out of the network stack for any networking protocol without the PPP headers and trailers.

## See Also

### Constants

- [SCNetworkConnectionStatus](scnetworkconnectionstatus.md): The current status of the network connection.
- [SCNetworkConnectionPPPStatus](scnetworkconnectionpppstatus.md): The PPP-specific status of the network connection.
