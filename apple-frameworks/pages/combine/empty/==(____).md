# ==(\_:\_:)

**Framework:** Combine  
**Kind:** Operator  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · macOS 10.15+ · tvOS 13.0+ · visionOS 1.0+ · watchOS 6.0+

Returns a Boolean value that indicates whether two publishers are equivalent.

## Declaration

```swift
static func == (lhs: Empty<Output, Failure>, rhs: Empty<Output, Failure>) -> Bool
```

## Parameters

- `lhs`: An `Empty` instance to compare.
- `rhs`: Another `Empty` instance to compare.

<a id="return-value"></a>

## Return Value

`true` if the two publishers have equal `completeImmediately` properties; otherwise `false`.
