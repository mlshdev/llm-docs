# MIDI Networking

**Interface languages:** Swift, Objective-C

**Framework:** Core MIDI  
**Kind:** API Collection

Create and manage devices connected over a local network.

## Topics

### Networking

- [MIDINetworkHost](midinetworkhost.md): An object that represents the host’s network address.
- [MIDINetworkConnection](midinetworkconnection.md): An object that connects a session to a host.
- [MIDINetworkSession](midinetworksession.md): An object that represents a pairing of a source and destination.
