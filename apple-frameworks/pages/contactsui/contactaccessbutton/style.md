**Framework:** Contacts UI

<a id="overview"></a>

## Overview

This type accounts for a contact access button’s visual traits like color and sizing of the contact image. Set the style of a contact access button with the [contactAccessButtonStyle(\_:)](https://developer.apple.com/documentation/swiftui/view/contactaccessbuttonstyle%28_:%29) view modifier.
