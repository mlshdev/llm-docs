# cancel() (Swift)

**Framework:** Safari Services  
**Kind:** Instance Method  
**Availability:** iOS 11.0+ (deprecated in 12.0) · iPadOS 11.0+ (deprecated in 12.0) · Mac Catalyst 13.1+ (deprecated in 13.1)

Cancels the currently running session when the consent dialog is up or when the webpage is up. This is how applications stop the login process.

## Declaration

```swift
func cancel()
```
