# Functions that convert between noninteger planar buffers (Swift)

**Framework:** Accelerate  
**Kind:** API Collection

Convert the bit depths and formats of planar fixed- and floating-point image data.

## Topics

### Converting from floating-point 16-bit-per-channel buffers

- [vImageConvert_16Fto16Q12(\_:\_:\_:)](vimageconvert_16fto16q12%28______%29.md): Converts a floating-point 16-bit planar buffer to a fixed-point 16-bit planar buffer.
- [vImageConvert_Planar16FtoPlanarF(\_:\_:\_:)](vimageconvert_planar16ftoplanarf%28______%29.md): Converts a floating-point 16-bit planar buffer to a floating-point 32-bit planar buffer.

### Converting from fixed-point 16-bit-per-channel buffers

- [vImageConvert_16Q12to16F(\_:\_:\_:)](vimageconvert_16q12to16f%28______%29.md): Converts a fixed-point 16-bit planar buffer to a floating-point 16-bit planar buffer.
- [vImageConvert_16Q12toF(\_:\_:\_:)](vimageconvert_16q12tof%28______%29.md): Converts a fixed-point 16-bit planar buffer to a floating-point 32-bit planar buffer.

### Converting from floating-point 32-bit-per-channel buffers

- [vImageConvert_PlanarFtoPlanar16F(\_:\_:\_:)](vimageconvert_planarftoplanar16f%28______%29.md): Converts a floating-point 32-bit planar buffer to a floating-point 16-bit planar buffer.
- [vImageConvert_Fto16Q12(\_:\_:\_:)](vimageconvert_fto16q12%28______%29.md): Converts a floating-point 32-bit planar buffer to a fixed-point 16-bit planar buffer.
