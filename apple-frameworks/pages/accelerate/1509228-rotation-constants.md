# Rotation constants

**Interface languages:** Swift, Objective-C

**Framework:** Accelerate  
**Kind:** API Collection

The number of degrees to rotate an image.

## Topics

### Constants

- [kRotate0DegreesClockwise](krotate0degreesclockwise.md): A constant that specifies rotation by 0° (that is, copy without rotating).
- [kRotate90DegreesClockwise](krotate90degreesclockwise.md): A constant that specifies rotation by 90° clockwise.
- [kRotate180DegreesClockwise](krotate180degreesclockwise.md): A constant that specifies rotation by 180° clockwise.
- [kRotate270DegreesClockwise](krotate270degreesclockwise.md): A constant that specifies rotation by 270° clockwise.
- [kRotate0DegreesCounterClockwise](krotate0degreescounterclockwise.md): A constant that specifies rotation by 0° (that is, copy without rotating).
- [kRotate90DegreesCounterClockwise](krotate90degreescounterclockwise.md): A constant that specifies rotation by 90° counterclockwise.
- [kRotate180DegreesCounterClockwise](krotate180degreescounterclockwise.md): A constant that specifies rotation by 180° counterclockwise.
- [kRotate270DegreesCounterClockwise](krotate270degreescounterclockwise.md): A constant that specifies rotation by 270° counterclockwise.
