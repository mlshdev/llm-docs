# Phase computation functions (Swift)

**Framework:** Accelerate  
**Kind:** API Collection

Calculate the element-wise phase values, in radians, of a complex vector.

## Topics

### Single-Vector Phase Computation

The functions in this group compute the phase values of each element in a complex vector.

- [phase(\_:result:)](vdsp/phase%28__result_%29-1ve4y.md): Calculates the single-precision element-wise phase values, in radians, of the supplied complex vector.
- [phase(\_:result:)](vdsp/phase%28__result_%29-56qb1.md): Calculates the double-precision element-wise phase values, in radians, of the supplied complex vector.
