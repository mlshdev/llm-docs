# Functions that convert from integer planar buffers to noninteger planar buffers (Swift)

**Framework:** Accelerate  
**Kind:** API Collection

Convert planar integer image data to fixed- and floating-point format.

- [vImageConvert_8to16Q12(\_:\_:\_:)](vimageconvert_8to16q12%28______%29.md): Converts an 8-bit planar buffer to a fixed-point 16-bit planar buffer.

- [vImageConvert_Planar8toPlanarF(\_:\_:\_:\_:\_:)](vimageconvert_planar8toplanarf%28__________%29.md): Converts an 8-bit planar buffer to a floating-point 32-bit planar buffer.

- [vImageConvert_16SToF(\_:\_:\_:\_:\_:)](vimageconvert_16stof%28__________%29.md): Converts a signed 16-bit planar buffer to a floating-point 32-bit planar buffer.

### Converting from unsigned 16-bit-per-channel buffers

- [vImageConvert_16Uto16F(\_:\_:\_:)](vimageconvert_16uto16f%28______%29.md): Converts an unsigned 16-bit planar buffer to a floating-point 16-bit planar buffer.
- [vImageConvert_16Uto16Q12(\_:\_:\_:)](vimageconvert_16uto16q12%28______%29.md): Converts an unsigned 16-bit planar buffer to a fixed-point 16-bit planar buffer.
- [vImageConvert_16UToF(\_:\_:\_:\_:\_:)](vimageconvert_16utof%28__________%29.md): Converts an unsigned 16-bit planar buffer to a floating-point 32-bit planar buffer.
