# Conversion to decibel equivalents (Swift)

**Framework:** Accelerate  
**Kind:** API Collection

Convert vectors that contain power or amplitude data to decibels.

## Topics

### Converting single-precision power or amplitude values to decibel values

- [amplitudeToDecibels(\_:zeroReference:)](vdsp/amplitudetodecibels%28__zeroreference_%29-88bpy.md): Returns single-precision amplitude values converted to decibels.
- [powerToDecibels(\_:zeroReference:)](vdsp/powertodecibels%28__zeroreference_%29-861j5.md): Returns single-precision power values converted to decibel values.
- [convert(amplitude:toDecibels:zeroReference:)](vdsp/convert%28amplitude_todecibels_zeroreference_%29-83uy1.md): Converts single-precision amplitude values to decibel values.
- [convert(power:toDecibels:zeroReference:)](vdsp/convert%28power_todecibels_zeroreference_%29-5u3vs.md): Converts single-precision power values to decibel values.

### Converting double-precision power or amplitude values to decibel values

- [amplitudeToDecibels(\_:zeroReference:)](vdsp/amplitudetodecibels%28__zeroreference_%29-2cgik.md): Returns double-precision amplitude values converted to decibel values.
- [powerToDecibels(\_:zeroReference:)](vdsp/powertodecibels%28__zeroreference_%29-4b0qz.md): Returns double-precision power values converted to decibel values.
- [convert(amplitude:toDecibels:zeroReference:)](vdsp/convert%28amplitude_todecibels_zeroreference_%29-4io4p.md): Converts double-precision amplitude values to decibel values.
- [convert(power:toDecibels:zeroReference:)](vdsp/convert%28power_todecibels_zeroreference_%29-3aiv4.md): Converts double-precision power values to decibel values.
