# CLKComplicationRingStyle.closed (Swift)

**Framework:** ClockKit  
**Kind:** Case  
**Availability:** watchOS 2.0+ (deprecated in 27.0)

A ring in which the values increase clockwise, starting at 12 o’clock, to create a closed circle.

> On watchOS 9.0 or later, use WidgetKit instead

## Declaration

```swift
case closed
```

<a id="Discussion"></a>

## Discussion

Use this style when you want to convey a value that’s a percentage of a whole. For example, use it to represent the completed percentage of some task.

## See Also

### Constants

- [CLKComplicationRingStyle.open](open.md): Deprecated. A ring in which the values increase clockwise, starting in the lower-left corner, leaving an opening at the bottom of the circle.
