# tintColor (Swift)

**Framework:** ClockKit  
**Kind:** Instance Property  
**Availability:** watchOS 2.0+ (deprecated in 27.0)

The tint color to use for text.

> On watchOS 9.0 or later, use WidgetKit instead

## Declaration

```swift
var tintColor: UIColor { get set }
```

## Discussion
