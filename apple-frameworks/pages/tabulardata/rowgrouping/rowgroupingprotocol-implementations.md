# RowGroupingProtocol Implementations

**Framework:** TabularData  
**Kind:** API Collection

## Topics

### Instance Methods

- [randomSplit(by:seed:)](randomsplit%28by_seed_%29.md): Conforms when `GroupingKey` conforms to `Hashable`. Generates two row groupings by randomly splitting the original with a proportion and a seed number.
- [summary()](summary%28%29.md): Conforms when `GroupingKey` conforms to `Hashable`. Generates a group summaries instance for the columns of the row grouping.
- [summary(of:)](summary%28of_%29.md): Conforms when `GroupingKey` conforms to `Hashable`. Generates a group summaries instance for the columns you select by name.
