# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a typed column inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](column/startindex.md): The index of the initial element in the column.
- [endIndex](column/endindex.md): The index of the final element in the column.
- [index(before:)](column/index%28before_%29.md): Returns the index immediately before an element index.
- [index(after:)](column/index%28after_%29.md): Returns the index immediately after an element index.
