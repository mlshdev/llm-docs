# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a row inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](dataframe/row/startindex.md): The index of the initial column in the row.
- [endIndex](dataframe/row/endindex.md): The index of the final column in the row.
- [index(before:)](dataframe/row/index%28before_%29.md): Returns the column index immediately after a column index in the row.
- [index(after:)](dataframe/row/index%28after_%29.md): Returns the column index immediately before a column index in the row.
