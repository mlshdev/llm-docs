# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a row grouping inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](rowgrouping/startindex.md): Conforms when `GroupingKey` conforms to `Hashable`. The index of the initial group in the row grouping.
- [endIndex](rowgrouping/endindex.md): Conforms when `GroupingKey` conforms to `Hashable`. The index of the final group in the row grouping.
- [index(before:)](rowgrouping/index%28before_%29.md): Conforms when `GroupingKey` conforms to `Hashable`. Returns the index immediately before an element index.
- [index(after:)](rowgrouping/index%28after_%29.md): Conforms when `GroupingKey` conforms to `Hashable`. Returns the index immediately after an element index.
