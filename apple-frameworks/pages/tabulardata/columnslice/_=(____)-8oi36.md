**Kind:** Operator  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+ · macOS 12.0+ · tvOS 15.0+ · visionOS 1.0+ · watchOS 8.0+

Modifies an integer column slice by dividing each element by a value.

## Declaration


## Parameters

- `lhs`: A column slice.
