# Data Frame-Generating Methods

**Framework:** TabularData  
**Kind:** API Collection

Create data frames by sorting, joining, or splitting other data frames.

## Topics

### Selecting Columns

- [subscript(\_:)](dataframe/subscript%28__%29-4war.md): Generates a data frame that includes the columns in a sequence of column names.
- [selecting(columnNames:)](dataframe/selecting%28columnnames_%29-pp1o.md): Generates a data frame that includes the columns you select with a list of names.
- [selecting(columnNames:)](dataframe/selecting%28columnnames_%29-3kms8.md): Generates a data frame that includes the columns you select with a sequence of names.
