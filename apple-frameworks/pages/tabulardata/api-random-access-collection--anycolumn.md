# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a type-erased column inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](anycolumn/startindex.md): The index of the initial element in the column.
- [endIndex](anycolumn/endindex.md): The index of the final element in the column.
- [index(before:)](anycolumn/index%28before_%29.md): Returns the index immediately before an element index.
- [index(after:)](anycolumn/index%28after_%29.md): Returns the index immediately after an element index.
