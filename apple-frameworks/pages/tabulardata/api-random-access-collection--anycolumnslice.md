# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a type-erased column slice inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](anycolumnslice/startindex.md): The index of the initial element in the column slice.
- [endIndex](anycolumnslice/endindex.md): The index of the final element in the column slice.
- [index(before:)](anycolumnslice/index%28before_%29.md): Returns the index immediately before an element index.
- [index(after:)](anycolumnslice/index%28after_%29.md): Returns the index immediately after an element index.
