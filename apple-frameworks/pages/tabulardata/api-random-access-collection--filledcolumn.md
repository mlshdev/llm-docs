# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a filled column inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](filledcolumn/startindex.md): The index of the initial element in the column.
- [endIndex](filledcolumn/endindex.md): The index of the final element in the column.
- [index(before:)](filledcolumn/index%28before_%29.md): Returns the row index immediately before a row index.
- [index(after:)](filledcolumn/index%28after_%29.md): Returns the position immediately after an index.
