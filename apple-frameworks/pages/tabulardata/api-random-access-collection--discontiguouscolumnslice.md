# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a discontiguous column slice inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](discontiguouscolumnslice/startindex.md): The index of the initial element in the column slice.
- [endIndex](discontiguouscolumnslice/endindex.md): The index of the final element in the column slice.
- [index(before:)](discontiguouscolumnslice/index%28before_%29.md): Returns the index immediately before an element index.
- [index(after:)](discontiguouscolumnslice/index%28after_%29.md): Returns the index immediately after an element index.
