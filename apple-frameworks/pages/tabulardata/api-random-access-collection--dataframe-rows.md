# Random Access Collection Methods

**Framework:** TabularData  
**Kind:** API Collection

Methods a row collection inherits from the random access collection protocol.

## Topics

### Retrieving an Index

- [startIndex](dataframe/rows-swift.struct/startindex.md): The index of the initial row in the collection.
- [endIndex](dataframe/rows-swift.struct/endindex.md): The index of the final row in the collection.
- [index(before:)](dataframe/rows-swift.struct/index%28before_%29.md): Returns the row index immediately before a row index.
- [index(after:)](dataframe/rows-swift.struct/index%28after_%29.md): Returns the row index immediately after a row index.
