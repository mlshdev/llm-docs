# SiriTipViewStyle

**Framework:** AppIntents  
**Kind:** Structure  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · tvOS 16.0+ · visionOS · watchOS 9.0+

The styles to apply to the tip views you use to display spoken phrases.

## Declaration

```swift
struct SiriTipViewStyle
```

<a id="overview"></a>

## Overview

Specify a [SiriTipViewStyle](siritipviewstyle.md) value when you add a [SiriTipUIView](siritipuiview.md) or [SiriTipView](siritipview.md) type to your interface. For the [SiriTipView](siritipview.md) type, specify the style using the [siriTipViewStyle(\_:)](https://developer.apple.com/documentation/swiftui/view/siritipviewstyle%28_:%29) modifier.
