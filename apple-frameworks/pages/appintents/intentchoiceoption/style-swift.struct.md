**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

## Declaration

## Overview

The system uses the style to render the option appropriately in the user interface.

## Topics

### Type Properties

- [cancel](style-swift.struct/cancel.md): Apply a style that indicates the option cancels the operation and leaves things unchanged.
- [default](style-swift.struct/default.md): Apply the default style to the option’s button.
- [destructive](style-swift.struct/destructive.md): Apply a style that indicates the option might change or delete data.
