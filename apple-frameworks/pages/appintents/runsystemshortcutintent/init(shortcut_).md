# init(shortcut:)

**Framework:** App Intents  
**Kind:** Initializer  
**Availability:** iOS 27.0+ · iPadOS 27.0+ · Mac Catalyst 27.0+

Creates an intent that performs a person’s configured action.

## Declaration

```swift

```

## Parameters

- `shortcut`: The metadata that represents a person’s configured action.
