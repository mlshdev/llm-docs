# AppSchema.SpreadsheetIntent

**Framework:** App Intents  
**Kind:** Protocol  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · macOS 15.0+ · visionOS 2.0+

Identifies intent schemas in the spreadsheet domain.

## Declaration

```swift
protocol SpreadsheetIntent : AppSchema.Kind
```

## Topics

### Instance Properties

- [addAudioToSheet](spreadsheetintent/addaudiotosheet.md): An intent schema that adds an audio clip to a sheet.

- [addImageToSheet](spreadsheetintent/addimagetosheet.md): An intent schema that adds an image to a sheet.

- [addVideoToSheet](spreadsheetintent/addvideotosheet.md): An intent schema that adds a video to a sheet.
- [addWebVideoToSheet](spreadsheetintent/addwebvideotosheet.md): An intent schema that adds a web video to a sheet.
- [create](spreadsheetintent/create.md): An intent schema that opens the app for composing a new spreadsheet.
- [createSheet](spreadsheetintent/createsheet.md): An intent schema that creates a new sheet in a spreadsheet.
- [delete](spreadsheetintent/delete.md): An intent schema that deletes existing spreadsheets.
- [deleteSheet](spreadsheetintent/deletesheet.md): An intent schema that deletes sheets in a spreadsheet.
- [open](spreadsheetintent/open.md): An intent schema that opens the app into an existing spreadsheet.

- [update](spreadsheetintent/update.md): An intent schema that renames an existing spreadsheet.
- [updateSheet](spreadsheetintent/updatesheet.md): An intent schema that updates an existing sheet.
