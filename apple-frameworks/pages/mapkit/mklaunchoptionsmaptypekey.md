# MKLaunchOptionsMapTypeKey (Swift)

**Framework:** MapKit  
**Kind:** Global Variable  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · visionOS 1.0+

The type of map (standard, satellite, or hybrid) to display.

## Declaration

```swift
let MKLaunchOptionsMapTypeKey: String
```

<a id="Discussion"></a>

## Discussion

The value of this key is an [NSNumber](../foundation/nsnumber.md) object whose value is an integer corresponding to an [MKMapType](mkmaptype.md) value.
