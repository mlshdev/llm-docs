# MKAnnotationView.DragState.ending (Swift)

**Framework:** MapKit  
**Kind:** Case  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · visionOS 1.0+

An annotation view ends dragging.

## Declaration

```swift
case ending
```

<a id="Discussion"></a>

## Discussion

A user action indicates the user dropped the view. The map view automatically moves annotation views to this state in response to appropriate user actions.
