# MKAddressRepresentations.ContextStyle.full (Swift)

**Framework:** MapKit  
**Kind:** Case  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

The value that represents the full context style.

## Declaration

```swift
case full
```

<a id="Discussion"></a>

## Discussion

The value that tells the framework to include all relevant context. For example, when used with [cityWithContext(\_:)](../citywithcontext%28__%29.md) MapKit always includes the region name if the device is in that region.
