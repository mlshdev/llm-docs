# init(feature:)

**Framework:** MapKit  
**Kind:** Initializer  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · visionOS

Creates a new map item request with the specified map feature.

## Declaration

```swift
convenience init(feature: MapFeature)
```

## Parameters

- `feature`: The [MapFeature](../mapfeature.md) to use to initialize the map item request.
