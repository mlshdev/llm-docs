# MKOverlayLevel.aboveRoads (Swift)

**Framework:** MapKit  
**Kind:** Case  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · macOS 10.9+ · tvOS 9.2+ · visionOS 1.0+ · watchOS 10.0+

Place the overlay above roadways but below map labels, shields, or point-of-interest icons.

## Declaration

```swift
case aboveRoads
```

<a id="Discussion"></a>

## Discussion

[MKMapView](../mkmapview.md) displays graphics in layers. The value [MKOverlayLevel.aboveRoads](aboveroads.md) places a layer in the map view above roadways but below map labels.

## See Also

### Constants

- [MKOverlayLevel.aboveLabels](abovelabels.md): Place the overlay above map labels, shields, or point-of-interest icons but below annotations and 3D projections of buildings.
