# abort

**Interface language:** Data

**Framework:** TVMLKit JS, WebKit JS  
**Kind:** Instance Method  
**Availability:** tvOS 9.0+ · Safari Desktop 4.0+ · Safari Mobile 3.0+

Cancels any network activity.

## Declaration

```
void abort();
```
