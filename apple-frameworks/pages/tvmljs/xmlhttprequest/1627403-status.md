# status

**Interface language:** Data

**Framework:** TVMLKit JS, WebKit JS  
**Kind:** Instance Property  
**Availability:** tvOS 9.0+ · Safari Desktop 10.0+ · Safari Mobile 10.0+

The HTTP status code.

## Declaration

```
readonly attribute int status;
```

```
readonly attribute unsigned short status;
```

<a id="discussion"></a>

## Discussion

If the current state of the request is `unsent` or `opened`, then this attribute’s value is `0`.
