# removeData

**Interface language:** Data

**Framework:** TVMLKit JS  
**Kind:** Instance Method  
**Availability:** tvOS 10.0+

Removes the data associated with a particular key.

## Declaration

```

    in String key
```

## Parameters

- `key`: The key for the data to be removed.
