# getData

**Interface language:** Data

**Framework:** TVMLKit JS  
**Kind:** Instance Method  
**Availability:** tvOS 10.0+

Returns the data associated with a particular key.

## Declaration

```
String getData(
    in String key
);
```

## Parameters

- `key`: The key for data to be retrieved.

<a id="return_value"></a>

## Return Value

The retrieved data.

## See Also

### Modifying User Defaults

- [removeData](1682085-removedata.md): Removes the data associated with a particular key.
- [setData](1682089-setdata.md): Stores the data for a given key.
