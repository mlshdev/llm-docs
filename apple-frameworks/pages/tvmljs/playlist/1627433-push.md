# push

**Interface language:** Data

**Framework:** TVMLKit JS  
**Kind:** Instance Method  
**Availability:** tvOS 9.0+

Adds a media item to the end of a playlist.

## Declaration

```
void push(
    in MediaItem object
);
```

## Parameters

- `object`: The [MediaItem](../mediaitem.md) object to be placed at the end of the playlist.
