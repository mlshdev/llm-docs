# pause

**Interface language:** Data

**Framework:** TVMLKit JS  
**Kind:** Instance Method  
**Availability:** tvOS 9.0+

Pauses the currently playing media item.

## Declaration

```
void pause();
```

<a id="discussion"></a>

## Discussion

The player UI remains onscreen while the media item is paused.
