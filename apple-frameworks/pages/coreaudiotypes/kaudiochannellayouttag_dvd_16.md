# kAudioChannelLayoutTag_DVD_16 (Swift)

**Framework:** Core Audio Types  
**Kind:** Global Variable  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.0+ · macOS 10.2+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 3.0+

A DVD 4.1-channel audio layout.

## Declaration

```swift
var kAudioChannelLayoutTag_DVD_16: AudioChannelLayoutTag { get }
```

<a id="Discussion"></a>

## Discussion

This tag is equivalent to [kAudioChannelLayoutTag_DVD_11](kaudiochannellayouttag_dvd_11.md). Your channels must be laid out in the following order:

- Left
- Right
- Center
- Low-frequency effects
- Center surround
