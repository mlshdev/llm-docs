# kAudioChannelLayoutTag_DTS_6_1_C (Swift)

**Framework:** Core Audio Types  
**Kind:** Global Variable  
**Availability:** iOS 4.0+ · iPadOS 4.0+ · Mac Catalyst 13.0+ · macOS 10.7+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 3.0+

A Blu-ray Disc audio layout, defined by DTS (Digital Theater Systems Ltd.).

## Declaration

```swift
var kAudioChannelLayoutTag_DTS_6_1_C: AudioChannelLayoutTag { get }
```

<a id="Discussion"></a>

## Discussion

Your channel layout must be in the following order:

- Center
- Center surround
- Left
- Right
- Left rear surround
- Right rear surround
- Low-frequency effects
