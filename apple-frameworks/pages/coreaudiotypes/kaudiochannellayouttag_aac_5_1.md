# kAudioChannelLayoutTag_AAC_5_1 (Swift)

**Framework:** Core Audio Types  
**Kind:** Global Variable  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.0+ · macOS 10.3+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 3.0+

An AAC 5.1-channel surround-based layout.

## Declaration

```swift
var kAudioChannelLayoutTag_AAC_5_1: AudioChannelLayoutTag { get }
```

<a id="Discussion"></a>

## Discussion

Your channels must be laid out in the following order:

- Center
- Left
- Right
- Left surround
- Right surround
- Low-frequency effects
