**Framework:** Metal  
**Kind:** Enumeration  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · macOS 10.14+ · tvOS 9.0+ · visionOS 1.0+

Filtering options for controlling an MSAA depth resolve operation.

## Declaration

```swift
enum MTLMultisampleDepthResolveFilter
```

## Topics

### Depth resolve filters

- [MTLMultisampleDepthResolveFilter.sample0](mtlmultisampledepthresolvefilter/sample0.md): No filter is applied.
- [MTLMultisampleDepthResolveFilter.min](mtlmultisampledepthresolvefilter/min.md): The GPU compares all depth samples in the pixel and selects the sample with the smallest value.
