# MTLFeatureSet.macOS_GPUFamily2_v1 (Swift)

**Framework:** Metal  
**Kind:** Case  
**Availability:** macOS 10.14+ (deprecated in 13.0)

The GPU family 2, version 1 feature set for macOS.

## Declaration

```swift
case macOS_GPUFamily2_v1
```

<a id="discussion"></a>

## Discussion

This feature set corresponds with macOS 10.14 and the following GPUs:

- Intel Iris Graphics 5xx
- Intel Iris Plus Graphics 6xx
- Intel HD Graphics 5xx
- Intel HD Graphics 6xx
- AMD FirePro Dxxx
- AMD Radeon R9 M2xx
- AMD Radeon R9 M3xx
- AMD Radeon Pro 4xx
- AMD Radeon Pro 5xx
- AMD Radeon Pro Vega
