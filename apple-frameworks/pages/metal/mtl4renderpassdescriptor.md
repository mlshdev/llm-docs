# MTL4RenderPassDescriptor (Swift)

**Framework:** Metal  
**Kind:** Class  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+

Describes a render pass.

## Declaration

```swift
class MTL4RenderPassDescriptor
```

<a id="overview"></a>

## Overview

You use render pass descriptors to create instances of [MTL4RenderCommandEncoder](mtl4rendercommandencoder.md) and encode draw commands into instances of [MTL4CommandBuffer](mtl4commandbuffer.md).

To create render command encoders, you typically call [renderCommandEncoderWithDescriptor:](mtl4commandbuffer/rendercommandencoderwithdescriptor_.md). The [makeRenderCommandEncoder(descriptor:options:)](mtl4commandbuffer/makerendercommandencoder%28descriptor_options_%29.md) variant of this method allows you to specify additional options to encode a render pass in parallel from multiple CPU cores by creating *suspending* and *resuming* render passes.

## Topics

### Instance Properties

- [colorAttachments](mtl4renderpassdescriptor/colorattachments.md): Accesses the array of state information for render attachments that store color data.
- [defaultRasterSampleCount](mtl4renderpassdescriptor/defaultrastersamplecount.md): Sets the default raster sample count for the render pass when it references no attachments.
- [depthAttachment](mtl4renderpassdescriptor/depthattachment.md): Accesses state information for a render attachment that stores depth data.
- [imageblockSampleLength](mtl4renderpassdescriptor/imageblocksamplelength.md): Assigns the per-sample size, in bytes, of the largest explicit imageblock layout in the render pass.
- [rasterizationRateMap](mtl4renderpassdescriptor/rasterizationratemap.md): Assigns an optional variable rasterization rate map that Metal uses in the render pass.
- [renderTargetArrayLength](mtl4renderpassdescriptor/rendertargetarraylength.md): Assigns the number of layers that all attachments this descriptor references have.
- [renderTargetHeight](mtl4renderpassdescriptor/rendertargetheight.md): Sets the height, in pixels, to which Metal constrains the render target.
- [renderTargetWidth](mtl4renderpassdescriptor/rendertargetwidth.md): Sets the width, in pixels, to which Metal constrains the render target.
- [samplePositions](mtl4renderpassdescriptor/samplepositions.md): Configures the custom sample positions to use in MSAA rendering.
- [stencilAttachment](mtl4renderpassdescriptor/stencilattachment.md): Accesses state information for a render attachment that stores stencil data.
- [supportColorAttachmentMapping](mtl4renderpassdescriptor/supportcolorattachmentmapping.md): Controls if the render pass supports color attachment mapping.
- [threadgroupMemoryLength](mtl4renderpassdescriptor/threadgroupmemorylength.md): Assigns the per-tile size, in bytes, of the persistent threadgroup memory allocation of this render pass.
- [tileHeight](mtl4renderpassdescriptor/tileheight.md): The height of the tiles, in pixels, a render pass you create with this descriptor applies to its attachments.
- [tileWidth](mtl4renderpassdescriptor/tilewidth.md): The width of the tiles, in pixels, a render pass you create with this descriptor applies to its attachments.
- [visibilityResultBuffer](mtl4renderpassdescriptor/visibilityresultbuffer.md): Configures a buffer into which Metal writes counts of fragments (pixels) passing the depth and stencil tests.
- [visibilityResultType](mtl4renderpassdescriptor/visibilityresulttype.md): Determines if Metal accumulates visibility results between render encoders or resets them.
