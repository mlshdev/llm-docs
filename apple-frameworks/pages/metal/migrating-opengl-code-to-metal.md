**Interface languages:** Swift, Objective-C

**Framework:** Metal  
**Kind:** Sample Code  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · macOS 14.0+ · Xcode 26.3+
