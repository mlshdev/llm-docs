**Framework:** Objective-C Runtime  
**Kind:** Instance Property  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · visionOS 2.0+

@MainActor var accessibilityPreviousTextNavigationElement: Any? { get set }

<a id="discussion"></a>

## Discussion
