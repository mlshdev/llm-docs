# accessibilityArrayAttributeCount(\_:) (Swift)

**Framework:** Objective-C Runtime  
**Kind:** Instance Method  
**Availability:** macOS

Returns the count of the specified accessibility array attribute.

> Use [NSAccessibilityProtocol](https://developer.apple.com/documentation/appkit/nsaccessibilityprotocol) instead.

## Declaration

```swift
func accessibilityArrayAttributeCount(_ attribute: NSAccessibility.Attribute) -> Int
```

## Parameters

- `attribute`: The accessibility array attribute.

<a id="return-value"></a>

## Return Value

The number of items in the specified array attribute.

<a id="Discussion"></a>

## Discussion

If `attribute` is not an array, an exception is raised.
