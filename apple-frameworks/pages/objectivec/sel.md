# SEL

**Interface language:** Objective-C

**Framework:** Objective-C Runtime  
**Kind:** Type Alias  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · tvOS · visionOS · watchOS

Defines an opaque type that represents a method selector.

## Declaration

```objectivec
typedef struct objc_selector * SEL;
```

<a id="Discussion"></a>

## Discussion

Method selectors are used to represent the name of a method at runtime. A method selector is a C string that has been registered (or “mapped”) with the Objective-C runtime. Selectors generated by the compiler are automatically mapped by the runtime when the class is loaded.

You can add new selectors at runtime and retrieve existing selectors using the function [sel_registerName](sel_registername%28__%29.md).

When using selectors, you must use the value returned from [sel_registerName](sel_registername%28__%29.md) or the Objective-C compiler directive `@selector()`. You cannot simply cast a C string to `SEL`.
