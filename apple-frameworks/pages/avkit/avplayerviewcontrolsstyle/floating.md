# AVPlayerViewControlsStyle.floating (Swift)

**Framework:** AVKit  
**Kind:** Case  
**Availability:** macOS 10.9+

The view displays playback controls in a floating window over the video content.

## Declaration

```swift
case floating
```

<a id="Discussion"></a>

## Discussion

This style matches the look of QuickTime Player’s playback controls.

## See Also

### Controls Styles

- [AVPlayerViewControlsStyle.none](none.md): The view displays no playback controls.
- [AVPlayerViewControlsStyle.inline](inline.md): The view displays playback controls in a bar along the view’s bottom edge.
- [AVPlayerViewControlsStyle.minimal](minimal.md): The view presents basic controls to play and pause playback.
- [default](default.md): The view’s default controls style.
