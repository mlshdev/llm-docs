# default (Swift)

**Framework:** AVKit  
**Kind:** Type Property  
**Availability:** macOS 10.9+

The view’s default controls style.

## Declaration

```swift
static var `default`: AVPlayerViewControlsStyle { get }
```

<a id="Discussion"></a>

## Discussion

The default controls style is [AVPlayerViewControlsStyle.inline](inline.md).

## See Also

### Controls Styles

- [AVPlayerViewControlsStyle.none](none.md): The view displays no playback controls.
- [AVPlayerViewControlsStyle.inline](inline.md): The view displays playback controls in a bar along the view’s bottom edge.
- [AVPlayerViewControlsStyle.floating](floating.md): The view displays playback controls in a floating window over the video content.
- [AVPlayerViewControlsStyle.minimal](minimal.md): The view presents basic controls to play and pause playback.
