# showsTimecodes (Swift)

**Framework:** AVKit  
**Kind:** Instance Property  
**Availability:** macOS 10.15+

A Boolean value that determines whether the player view displays timecodes, if available.

## Declaration

```swift
var showsTimecodes: Bool { get set }
```

<a id="Discussion"></a>

## Discussion
