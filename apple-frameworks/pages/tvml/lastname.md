# lastName

**Kind:** Article

Adds a person’s last name to an element.

<a id="Overview"></a>

## Overview

Here’s an example that sets the last name for a monogram.

```xml
<monogramLockup>
    <monogram firstName="Anne" lastName="Johnson"/>
    <title>Anne Johnson</title>
    <subtitle>Actor</subtitle>
</monogramLockup>
```

<a id="Values-for-lastName"></a>

### Values for lastName

- **String**: The last name of a person.

<a id="Elements-that-Use-lastName"></a>

### Elements that Use lastName

- [monogram](monogram.md)
