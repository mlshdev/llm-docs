# PKPaymentButtonStyle.automatic (Swift)

**Framework:** PassKit (Apple Pay and Wallet)  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · macOS 11.0+ · visionOS 1.0+ · watchOS 7.0+

A button that automatically changes its appearance when the user switches between Light Mode and Dark Mode.

## Declaration

```swift
case automatic
```

<a id="Discussion"></a>

## Discussion

The button uses the [PKPaymentButtonStyle.white](white.md) style in Dark Mode and the [PKPaymentButtonStyle.black](black.md) style in Light Mode.

## See Also

### Payment button styles

- [PKPaymentButtonStyle.white](white.md): A white button with black lettering.
- [PKPaymentButtonStyle.whiteOutline](whiteoutline.md): A white button with black lettering and a black outline.
- [PKPaymentButtonStyle.black](black.md): A black button with white lettering.
