# PKPaymentButtonType.order (Swift)

**Framework:** PassKit (Apple Pay and Wallet)  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · macOS 11.0+ · visionOS 1.0+ · watchOS 7.0+

An Apple Pay button useful for placing orders for such as like meals or flowers.

## Declaration

```swift
case order
```

<a id="Discussion"></a>

## Discussion

This button looks like:

![A button with the text “Order with” and the Apple Pay logo.](https://developer.apple.com/images/com.apple.passkit/media-3667467@2x.png)

For design guidance, see [Human Interface Guidelines \> Apple Pay \> Buttons and Marks](https://developer.apple.com/design/human-interface-guidelines/apple-pay/overview/buttons-and-marks/).
