# SKReceiptPropertyIsExpired (Swift)

**Framework:** StoreKit  
**Kind:** Global Variable  
**Availability:** iOS 7.0+ (deprecated in 18.0) · iPadOS 7.0+ (deprecated in 18.0) · Mac Catalyst 13.1+ (deprecated in 18.0) · macOS 10.9+ (deprecated in 15.0) · tvOS  (deprecated in 18.0) · visionOS 1.0+ (deprecated in 2.0) · watchOS 6.2+ (deprecated in 11.0)

A key with a value that indicates whether the receipt is in an expired state.

> No longer supported.

## Declaration

```swift
let SKReceiptPropertyIsExpired: String
```

<a id="Discussion"></a>

## Discussion

This key’s value is an instance of [NSNumber](../foundation/nsnumber.md) that the system interprets as a Boolean value that indicates whether the receipt is in an expired state.
