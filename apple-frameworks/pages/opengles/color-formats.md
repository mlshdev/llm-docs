# Color Formats

**Interface languages:** Swift, Objective-C

**Framework:** OpenGL ES  
**Kind:** API Collection

Color formats that can be specified under the `kEAGLDrawablePropertyColorFormat` key.

## Topics

### Constants

- [kEAGLColorFormatRGB565](keaglcolorformatrgb565.md): Deprecated. Specifies a 16-bit RGB format that corresponds to the OpenGL ES `GL_RGB565` format.
- [kEAGLColorFormatRGBA8](keaglcolorformatrgba8.md): Deprecated. Specifies a 32-bit RGBA format that corresponds to the OpenGL ES `GL_RGBA8888` format.
