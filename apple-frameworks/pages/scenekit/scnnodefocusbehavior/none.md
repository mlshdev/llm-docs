# SCNNodeFocusBehavior.none (Swift)

**Framework:** SceneKit  
**Kind:** Case  
**Availability:** iOS 8.0+ (deprecated in 26.0) · iPadOS 8.0+ (deprecated in 26.0) · Mac Catalyst 13.1+ (deprecated in 26.0) · macOS 10.8+ (deprecated in 26.0) · tvOS 9.0+ (deprecated in 26.0) · visionOS 1.0+ (deprecated in 26.0) · watchOS 3.0+ (deprecated in 26.0)

Node is not focusable.

## Declaration

```swift
case none
```

<a id="Discussion"></a>

## Discussion

This behavior is the default for a node.

## See Also

### Enumeration Cases

- [SCNNodeFocusBehavior.occluding](occluding.md): Node is not focusable and prevents nodes that it visually obscures from becoming focusable.
- [SCNNodeFocusBehavior.focusable](focusable.md): Node is focusable and prevents nodes that it visually obscures from becoming focusable.
