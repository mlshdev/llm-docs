# SCNAntialiasingMode.multisampling4X (Swift)

**Framework:** SceneKit  
**Kind:** Case  
**Availability:** iOS 8.0+ (deprecated in 26.0) · iPadOS 8.0+ (deprecated in 26.0) · Mac Catalyst 13.1+ (deprecated in 26.0) · macOS 10.8+ (deprecated in 26.0) · tvOS 9.0+ (deprecated in 26.0) · visionOS 1.0+ (deprecated in 26.0) · watchOS 3.0+ (deprecated in 26.0)

Enables multisample antialiasing, with four samples per screen pixel.

## Declaration

```swift
case multisampling4X
```

<a id="Discussion"></a>

## Discussion

This is the default antialiasing mode in macOS.

## See Also

### Constants

- [SCNAntialiasingMode.none](none.md): Disables antialiased rendering.
- [SCNAntialiasingMode.multisampling2X](multisampling2x.md): Enables multisample antialiasing, with two samples per screen pixel.
- [SCNAntialiasingMode.multisampling8X](multisampling8x.md): Enables multisample antialiasing, with eight samples per screen pixel.
- [SCNAntialiasingMode.multisampling16X](multisampling16x.md): Enables multisample antialiasing, with sixteen samples per screen pixel.
