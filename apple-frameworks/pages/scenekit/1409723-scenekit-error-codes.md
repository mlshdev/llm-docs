# SceneKit Error Codes (Swift)

**Framework:** SceneKit  
**Kind:** API Collection

<a id="Discussion"></a>

## Discussion

Constants for the [code](../foundation/nserror/code.md) property of [NSError](../foundation/nserror.md) objects produced by the SceneKit framework.

## Topics

### Constants

- [SCNProgramCompilationError](scnprogramcompilationerror.md): An error in compiling GLSL shader source code for use with the [SCNProgram](scnprogram.md) class.

## See Also

### Handling Shader Compilation Errors

- [program(\_:handleError:)](scnprogramdelegate/program%28__handleerror_%29.md): Tells the delegate that an error occurred when compiling GLSL source code.
- [SCNErrorDomain](scnerrordomain.md): Identifies an error type defined by the SceneKit framework.
