# kVTVideoEncoderList_CodecType (Swift)

**Framework:** Video Toolbox  
**Kind:** Global Variable  
**Availability:** iOS 8.0+ · iPadOS 8.0+ · Mac Catalyst 13.1+ · macOS 10.8+ · tvOS 10.2+ · visionOS 1.0+

The encoder’s codec type key.

## Declaration

```swift
let kVTVideoEncoderList_CodecType: CFString
```

<a id="Discussion"></a>

## Discussion

The associated value is a [CFNumber](../corefoundation/cfnumber.md) for a four-character code such as `avc1` or `h263`.
