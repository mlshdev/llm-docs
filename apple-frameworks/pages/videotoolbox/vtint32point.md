# VTInt32Point (Swift)

**Framework:** Video Toolbox  
**Kind:** Structure  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · Mac Catalyst 13.0+ · macOS 10.8+ · tvOS 10.2+ · visionOS 1.0+

A structure that represents a 32-bit integer point value.

## Declaration

```swift
struct VTInt32Point
```

## Overview

Use this structure to represent a point at an (x, y) location.
