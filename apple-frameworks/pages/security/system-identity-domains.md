# System Identity Domains (Swift)

**Framework:** Security  
**Kind:** API Collection

Set or obtain a system identity for domains.

<a id="overview"></a>

## Overview

These constants can be used with the [SecIdentitySetSystemIdentity(\_:\_:)](secidentitysetsystemidentity%28____%29.md) and [SecIdentityCopySystemIdentity(\_:\_:\_:)](secidentitycopysystemidentity%28______%29.md) functions.

## Topics

### Constants

- [kSecIdentityDomainDefault](ksecidentitydomaindefault.md): The system-wide default identity.
- [kSecIdentityDomainKerberosKDC](ksecidentitydomainkerberoskdc.md): Kerberos Key Distribution Center (KDC) identity.
