# SecCredentialType.default (Swift)

**Framework:** Security  
**Kind:** Case  
**Availability:** macOS 10.3+ (deprecated in 12.0)

The default setting for determining whether to present UI is used.

> No longer supported

## Declaration

```swift
case `default`
```

<a id="Discussion"></a>

## Discussion

The default setting can be changed with a call to [SecKeychainSetUserInteractionAllowed(\_:)](../seckeychainsetuserinteractionallowed%28__%29.md).
