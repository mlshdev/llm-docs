# SecCredentialType.noUI (Swift)

**Framework:** Security  
**Kind:** Case  
**Availability:** macOS 10.3+ (deprecated in 12.0)

Keychain operations on keys that have this credential are not allowed to present UI, and will fail if UI is required.

> No longer supported

## Declaration

```swift
case noUI
```
