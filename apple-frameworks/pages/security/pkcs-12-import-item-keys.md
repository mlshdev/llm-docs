# PKCS #12 Import Item Keys (Swift)

**Framework:** Security  
**Kind:** API Collection

Recognized the dictionary keys returned by an import operation.

<a id="overview"></a>

## Overview

These keys appear in the dictionary returned by the [SecPKCS12Import(\_:\_:\_:)](secpkcs12import%28______%29.md) function.

## Topics

### Constants

- [kSecImportItemLabel](ksecimportitemlabel.md): Item label.
- [kSecImportItemKeyID](ksecimportitemkeyid.md): Key ID.
- [kSecImportItemTrust](ksecimportitemtrust.md): Trust management object.
- [kSecImportItemCertChain](ksecimportitemcertchain.md): Certificate list.
- [kSecImportItemIdentity](ksecimportitemidentity.md): Identity object.
