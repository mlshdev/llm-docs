# Professional Video Applications Data Types

**Interface languages:** Swift, Objective-C

**Framework:** Professional Video Applications  
**Kind:** API Collection

## Topics

### Data Types

- [FxImageOrigin](../professional_video_applications/fximageorigin.md): Deprecated. These constants define the orientation of an image’s coordinate system. Images in Motion have a bottom-left origin. Images in Final Cut have a top-left origin.
- [FxPathStyle](../professional_video_applications/fxpathstyle.md): The style of the path, which is linear, bezier, or b-spline.
- [FxPixelTransformSupport](../professional_video_applications/fxpixeltransformsupport.md): Deprecated. Constants that define the support for pixel transforms.
