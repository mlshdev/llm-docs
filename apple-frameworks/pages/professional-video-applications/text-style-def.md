# text-style-def

**Interface languages:** Swift, Objective-C

**Framework:** Professional Video Applications  
**Kind:** Article

Defines a set of text style attributes that can be shared with (referenced by) multiple `text-style` elements.

<a id="overview"></a>

## Overview

Use a `text-style-def` element to define a set of text attributes shared by multiple text-style elements. A `text-style-def` contains a single `text-style` element with a set of text style attributes, such as font, fontSize, fontColor, etc. The `text-style-def` element has the following attributes:

| Attribute | Description |
| --- | --- |
| `id` | The local identifier for this text-style definition. |
| `name` | The name for this text-style definition. |
