# storefrontId

**Interface language:** Data

**Framework:** App Store Server API  
**Kind:** Type  
**Availability:** App Store Server API 1.8+

An Apple-defined value that uniquely identifies an App Store storefront.

## Declaration

```
string storefrontId
```

## Mentioned In

- [App Store Server API changelog](app-store-server-api-changelog.md)

## Discussion

This value is the same as the [id](../storekit/storefront/id.md) value in StoreKit.

## See Also

### Storefront information

- [storefront](storefront.md): The three-letter code that represents the country or region associated with the App Store storefront of the purchase.
