# UITableView.Style.grouped (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS

A table view where sections have distinct groups of rows.

## Declaration

```swift
case grouped
```

<a id="Discussion"></a>

## Discussion
