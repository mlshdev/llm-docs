# UISpringLoadedInteractionEffectState.activated (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 13.1+ · visionOS 1.0+

An interaction state that indicates that the view was spring loaded.

## Declaration

```swift
case activated
```

<a id="Discussion"></a>

## Discussion

The interaction view is styled with the default effect, and the activation handler for the [UISpringLoadedInteraction](../uispringloadedinteraction.md) object is called.

- [UISpringLoadedInteractionEffectState.inactive](inactive.md): An interaction state that indicates that spring loading is not engaged.
- [UISpringLoadedInteractionEffectState.possible](possible.md): An interaction state that indicates that spring loading is available.
