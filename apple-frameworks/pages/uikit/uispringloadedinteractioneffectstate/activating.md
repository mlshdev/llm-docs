# UISpringLoadedInteractionEffectState.activating (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 13.1+ · visionOS 1.0+

An interaction state that indicates that spring loading is about to start.

## Declaration

```swift
case activating
```

<a id="Discussion"></a>

## Discussion
