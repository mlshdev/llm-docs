# UIViewAnimatingPosition.start (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 10.0+ · iPadOS 10.0+ · Mac Catalyst 13.1+ · tvOS 10.0+ · visionOS 1.0+

The beginning of the animation. Use this constant when you want the starting values for any animatable properties—that is, the values of the properties before you applied any animations.

## Declaration

```swift
case start
```

## See Also

### Constants

- [UIViewAnimatingPosition.end](end.md): The end point of the animation. Use this constant when you want the final values for any animatable properties—that is, you want to refer to the values you specified in your animation blocks.
- [UIViewAnimatingPosition.current](current.md): The current position. Use this constant when you want the most recent value set by an animator object.
