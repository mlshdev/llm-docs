# UITouch.TouchType.indirect (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · tvOS 9.0+ · visionOS 1.0+

A touch that doesn’t result from contact with the screen.

## Declaration

```swift
case indirect
```

<a id="Discussion"></a>

## Discussion

Indirect touches are generated by touch input devices that are separate from the screen. For example, the trackpad of an Apple TV remote generates indirect touches.

## See Also

### Touch types

- [UITouch.TouchType.direct](direct.md): A touch resulting from direct contact with the screen.
- [UITouch.TouchType.pencil](pencil.md): A touch from Apple Pencil.
- [UITouch.TouchType.indirectPointer](indirectpointer.md): A touch resulting from a button-based, indirect input device that describes the input sequence from button press to button release.
