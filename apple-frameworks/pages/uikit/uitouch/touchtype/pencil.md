# UITouch.TouchType.pencil (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 9.1+ · iPadOS 9.1+ · Mac Catalyst 13.1+ · tvOS 9.0+ · visionOS 1.0+

A touch from Apple Pencil.

## Declaration

```swift
case pencil
```

<a id="Discussion"></a>

## Discussion

A pencil touch occurs when Apple Pencil interacts with the device’s screen.

## See Also

### Touch types

- [UITouch.TouchType.direct](direct.md): A touch resulting from direct contact with the screen.
- [UITouch.TouchType.indirect](indirect.md): A touch that doesn’t result from contact with the screen.
- [UITouch.TouchType.indirectPointer](indirectpointer.md): A touch resulting from a button-based, indirect input device that describes the input sequence from button press to button release.
