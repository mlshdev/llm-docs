# UIDatePickerStyle.compact (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 13.4+ · iPadOS 13.4+ · Mac Catalyst 13.4+ · visionOS 1.0+

A style indicating that the date picker displays as a label that when tapped displays a calendar-style editor.

## Declaration

```swift
case compact
```

<a id="Discussion"></a>

## Discussion

You can’t use this style with the [UIDatePicker.Mode.countDownTimer](../uidatepicker/mode/countdowntimer.md) mode.

## See Also

### Styles

- [UIDatePickerStyle.automatic](automatic.md): A style indicating that the system picks the concrete style based on the current platform and date picker mode.
- [UIDatePickerStyle.inline](inline.md): A style indicating that the date pickers displays as an inline, editable field.
- [UIDatePickerStyle.wheels](wheels.md): A style indicating that the date picker displays as a wheel picker.
