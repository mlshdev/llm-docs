# NSToolbarItemIdentifier

**Interface language:** Objective-C

**Framework:** UIKit  
**Kind:** API Collection

UIKit-specific constants for the standard toolbar items that the system provides.

<a id="Overview"></a>

## Overview

UIKit defines these constants that you use to configure an [NSToolbarItem](https://developer.apple.com/documentation/appkit/nstoolbaritem). For more information, see [NSToolbarItemIdentifier](https://developer.apple.com/documentation/appkit/nstoolbaritem/identifier).

## Topics

### Getting the standard item identifiers

- [NSToolbarPrimarySidebarTrackingSeparatorItemIdentifier](nstoolbarprimarysidebartrackingseparatoritemidentifier.md): The identifier for a toolbar item that displays a tracking separator aligned with the primary divider in a split view.
- [NSToolbarSupplementarySidebarTrackingSeparatorItemIdentifier](nstoolbarsupplementarysidebartrackingseparatoritemidentifier.md): The identifier for a toolbar item that displays a tracking separator aligned with the secondary divider in a split view.
