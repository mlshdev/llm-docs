# centeredVertically (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS

Scroll so that the item is centered vertically in the collection view.

## Declaration

```swift
static var centeredVertically: UICollectionView.ScrollPosition { get }
```

<a id="Discussion"></a>

## Discussion

This option is mutually exclusive with the [top](top.md) and [bottom](bottom.md) options.

## See Also

### Constants

- [top](top.md): Scroll so that the item is positioned at the top of the collection view’s bounds.
- [bottom](bottom.md): Scroll so that the item is positioned at the bottom of the collection view’s bounds.
- [left](left.md): Scroll so that the item is positioned at the left edge of the collection view’s bounds.
- [centeredHorizontally](centeredhorizontally.md): Scroll so that the item is centered horizontally in the collection view.
- [right](right.md): Scroll so that the item is positioned at the right edge of the collection view’s bounds.
