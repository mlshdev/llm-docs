# right (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS

Scroll so that the item is positioned at the right edge of the collection view’s bounds.

## Declaration

```swift
static var right: UICollectionView.ScrollPosition { get }
```

<a id="Discussion"></a>

## Discussion

This option is mutually exclusive with the [left](left.md) and [centeredHorizontally](centeredhorizontally.md) options.

## See Also

### Constants

- [top](top.md): Scroll so that the item is positioned at the top of the collection view’s bounds.
- [centeredVertically](centeredvertically.md): Scroll so that the item is centered vertically in the collection view.
- [bottom](bottom.md): Scroll so that the item is positioned at the bottom of the collection view’s bounds.
- [left](left.md): Scroll so that the item is positioned at the left edge of the collection view’s bounds.
- [centeredHorizontally](centeredhorizontally.md): Scroll so that the item is centered horizontally in the collection view.
