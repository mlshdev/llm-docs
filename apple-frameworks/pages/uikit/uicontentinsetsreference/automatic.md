# UIContentInsetsReference.automatic (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · tvOS 14.0+ · visionOS 1.0+

Content insets use the system default reference point.

## Declaration

```swift
case automatic
```

<a id="Discussion"></a>

## Discussion

When you set this value on a section in a collection view, the section defaults to using the content insets reference value of the collection view.

## See Also

### Constants

- [UIContentInsetsReference.none](none.md): Content insets don’t have a reference point in relation to other insets.

- [UIContentInsetsReference.layoutMargins](layoutmargins.md): Content insets use a reference point in relation to the layout margins.
