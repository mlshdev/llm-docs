# bouncesVertically (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS 17.4+ · iPadOS 17.4+ · Mac Catalyst 17.4+ · tvOS 17.4+ · visionOS 1.1+

A Boolean value that determines whether the scroll view bounces when it reaches the ends of its vertical axis.

## Declaration

```swift
var bouncesVertically: Bool { get set }
```
