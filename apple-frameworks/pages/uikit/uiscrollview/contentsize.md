# contentSize (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+

The size of the content view.

## Declaration

```swift
var contentSize: CGSize { get set }
```

## Mentioned In

- [Estimating the height of a table’s scrolling area](../estimating-the-height-of-a-table-s-scrolling-area.md)

<a id="Discussion"></a>

## Discussion

The unit of size is points. The default size is [CGSizeZero](../../coregraphics/cgsizezero.md).

## See Also

### Managing the content size and offset

- [contentOffset](contentoffset.md): The point at which the origin of the content view is offset from the origin of the scroll view.
- [setContentOffset(\_:animated:)](setcontentoffset%28__animated_%29.md): Sets the point at which the origin of the content view is offset from the origin of the scroll view.
