# UICellConfigurationDropStateTargeted

**Interface language:** Objective-C

**Framework:** UIKit  
**Kind:** Enumeration Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · visionOS 1.0+

The cell is the drop target for a drag session.

```objectivec
UICellConfigurationDropStateTargeted
```
