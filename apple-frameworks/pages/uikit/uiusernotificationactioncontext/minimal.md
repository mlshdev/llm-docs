# UIUserNotificationActionContext.minimal (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 8.0+ (deprecated in 10.0) · iPadOS 8.0+ (deprecated in 10.0) · Mac Catalyst 13.1+ (deprecated in 13.1)

A notification where space is minimal.

> For more information, see [UIUserNotificationCategory](../uiusernotificationcategory.md).

## Declaration

```swift
case minimal
```

<a id="Discussion"></a>

## Discussion

In this context, a minimal UI is displayed for the notification’s alert. You may specify up to two custom actions in this context.

## See Also

### Constants

- [UIUserNotificationActionContext.default](default.md): Deprecated. The default context for displaying the alert.
