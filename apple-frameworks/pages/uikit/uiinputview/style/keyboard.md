# UIInputView.Style.keyboard (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+

Apply both blur and tinting effects to the view to mimic the keyboard background.

## Declaration

```swift
case keyboard
```

<a id="Discussion"></a>

## Discussion

This style makes the input view match the keyboard appearance and can be used to replace or extend the keyboard.

## See Also

### Constants

- [UIInputView.Style.default](default.md): Apply blur behaviors to the view so that it looks like it belongs with the keyboard.
