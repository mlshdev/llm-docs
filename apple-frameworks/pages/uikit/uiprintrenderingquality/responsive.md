# UIPrintRenderingQuality.responsive (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 14.5+ · iPadOS 14.5+ · Mac Catalyst 14.5+ · tvOS 14.5+ · visionOS 1.0+

A constant that reduces rendering quality by the smallest possible amount to increase speed and maintain a responsive user interface.

## Declaration

```swift
case responsive
```

<a id="Discussion"></a>

## Discussion

Use this option if you determine that rendering at the best quality using [UIPrintRenderingQuality.best](best.md) reduces the responsiveness of the user interface.

## See Also

### Constants

- [UIPrintRenderingQuality.best](best.md): A constant that renders the printing at the best possible quality, regardless of speed.
