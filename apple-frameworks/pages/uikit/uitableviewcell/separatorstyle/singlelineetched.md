# UITableViewCell.SeparatorStyle.singleLineEtched (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 2.0+ (deprecated in 11.0) · iPadOS 2.0+ (deprecated in 11.0) · Mac Catalyst 13.1+ (deprecated in 13.1)

The separator cell has double lines running across its width, giving it an etched look.

> Use [UITableViewCell.SeparatorStyle.singleLine](singleline.md) instead.

## Declaration

```swift
case singleLineEtched
```

<a id="Discussion"></a>

## Discussion

This style is currently only supported for grouped-style table views.
