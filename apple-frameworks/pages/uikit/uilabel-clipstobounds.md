# clipsToBounds (Swift)

**Framework:** UIKit  
**Kind:** Article

A Boolean value that determines whether subviews are confined to the bounds of the view.

<a id="overview"></a>

## Overview

`UILabel` inherits this property from the `UIView` parent class. This class changes the default value of this property to [true](https://developer.apple.com/documentation/swift/true).

## See Also

### Accessing additional attributes

- [isUserInteractionEnabled](uilabel/isuserinteractionenabled.md): A Boolean value that determines whether the system ignores and removes user events for this label from the event queue.
