# init()

**Framework:** UIKit  
**Kind:** Initializer  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 13.1+ · tvOS 11.0+ · visionOS 1.0+ · watchOS 4.0+

Creates a directional edge insets structure that contains default values.

## Declaration

```swift
init()
```

<a id="return-value"></a>

## Return Value

An initialized inset structure.

<a id="Discussion"></a>

## Discussion

This method sets all inset margins to `0.0`.
