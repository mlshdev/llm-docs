# UITextDropProposal.ProgressMode.system (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 11.0+ · iPadOS 11.0+ · Mac Catalyst 13.1+ · visionOS 1.0+

A text drop progress mode indicating that the system will show the progress indicator.

## Declaration

```swift
case system
```

<a id="Discussion"></a>

## Discussion

Use this progress mode to have the system show a modal progress indicator while the dropped items are being loaded.

## See Also

### Progress modes

- [UITextDropProposal.ProgressMode.custom](custom.md): A text drop progress mode that indicates that you will provide custom progress indicator during the loading of dropped items.
