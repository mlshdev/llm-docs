# UINavigationBar.NSToolbarSection.none (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · Mac Catalyst 16.0+ · visionOS 1.0+

A constant that disables hosting the navigation bar in the toolbar.

## Declaration

```swift
case none
```

<a id="Discussion"></a>

## Discussion

Use this value to disable [NSToolbar](https://developer.apple.com/documentation/appkit/nstoolbar) hosting. This value is equivalent to setting the [preferredBehavioralStyle](../preferredbehavioralstyle.md) of the navigation bar to [UIBehavioralStyle.pad](../../uibehavioralstyle/pad.md).
