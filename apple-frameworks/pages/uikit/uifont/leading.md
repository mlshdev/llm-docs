# leading (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+ · watchOS 2.0+

The font’s leading information.

## Declaration

```swift
var leading: CGFloat { get }
```

<a id="Discussion"></a>

## Discussion

The leading value represents additional space between lines of text and is measured in points.
