# capHeight (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS 2.0+ · iPadOS 2.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+ · watchOS 2.0+

The font’s cap height information.

## Declaration

```swift
var capHeight: CGFloat { get }
```

<a id="Discussion"></a>

## Discussion

This value measures (in points) the height of a capital character.
