# Deprecated symbols (Swift)

**Framework:** UIKit  
**Kind:** API Collection

Symbols that buttons no longer support.

## Topics

### Title effects

- [reversesTitleShadowWhenHighlighted](uibutton/reversestitleshadowwhenhighlighted.md): Deprecated. A Boolean value that determines whether the title shadow changes when the button is highlighted.

### Button presentation

- [adjustsImageWhenHighlighted](uibutton/adjustsimagewhenhighlighted.md): Deprecated. A Boolean value that determines whether the image changes when the button is highlighted.
- [adjustsImageWhenDisabled](uibutton/adjustsimagewhendisabled.md): Deprecated. A Boolean value that determines whether the image changes when the button is disabled.
- [showsTouchWhenHighlighted](uibutton/showstouchwhenhighlighted.md): Deprecated. A Boolean value that determines whether tapping the button causes it to glow.

### Edge insets

- [contentEdgeInsets](uibutton/contentedgeinsets.md): Deprecated. The inset or outset margins for the rectangle surrounding all of the button’s content.
- [titleEdgeInsets](uibutton/titleedgeinsets.md): Deprecated. The inset or outset margins for the rectangle around the button’s title text.
- [imageEdgeInsets](uibutton/imageedgeinsets.md): Deprecated. The inset or outset margins for the rectangle around the button’s image.

### Dimensions

- [backgroundRect(forBounds:)](uibutton/backgroundrect%28forbounds_%29.md): Deprecated. Returns the rectangle in which the receiver draws its background.
- [contentRect(forBounds:)](uibutton/contentrect%28forbounds_%29.md): Deprecated. Returns the rectangle in which the receiver draws its entire content.
- [titleRect(forContentRect:)](uibutton/titlerect%28forcontentrect_%29.md): Deprecated. Returns the rectangle in which the receiver draws its title.
- [imageRect(forContentRect:)](uibutton/imagerect%28forcontentrect_%29.md): Deprecated. Returns the rectangle in which the receiver draws its image.
