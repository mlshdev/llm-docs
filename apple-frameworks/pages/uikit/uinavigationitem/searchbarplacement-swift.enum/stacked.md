# UINavigationItem.SearchBarPlacement.stacked (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · Mac Catalyst 16.0+ · visionOS 1.0+

A constant that stacks the search bar vertically below the other content in the navigation bar.

## Declaration

```swift
case stacked
```

<a id="Discussion"></a>

## Discussion

This value reflects the traditional search bar layout available in versions of iOS earlier than iOS 16.

## See Also

### Constants

- [UINavigationItem.SearchBarPlacement.automatic](automatic.md): A constant that places the search bar according to the current layout.
- [inline](inline.md): Deprecated. A constant that places the search bar on the trailing edge of the navigation bar, inline with the other content.
