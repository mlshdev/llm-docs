# characterSet (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS 7.0+ · iPadOS 7.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+ · watchOS 2.0+

The character set attribute.

## Declaration

```swift
static let characterSet: UIFontDescriptor.AttributeName
```

<a id="Discussion"></a>

## Discussion

The value is an [NSCharacterSet](../../../foundation/nscharacterset.md) instance that represents the set of Unicode characters that the font covers. The font supplies the default value.
