# UISemanticContentAttribute.unspecified (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 9.0+ · iPadOS 9.0+ · Mac Catalyst 13.1+ · tvOS 9.0+ · visionOS 1.0+

The default value for views.

## Declaration

```swift
case unspecified
```

<a id="Discussion"></a>

## Discussion

The view is flipped when switching between left-to-right and right-to-left layouts.

## See Also

### Constants

- [UISemanticContentAttribute.playback](playback.md): A view representing the playback controls, such as Play, Rewind, or Fast Forward buttons or playhead scrubbers.
- [UISemanticContentAttribute.spatial](spatial.md): A view representing a directional control, such as a segment control for text alignment, or a D-pad control for a game.
- [UISemanticContentAttribute.forceLeftToRight](forcelefttoright.md): A view that’s always displayed using a left-to-right layout.
- [UISemanticContentAttribute.forceRightToLeft](forcerighttoleft.md): A view that’s always displayed using a right-to-left layout.
