# init()

**Framework:** UIKit  
**Kind:** Initializer  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS · watchOS 2.0+

Initializes the edge insets structure to default values.

## Declaration

```swift
init()
```

<a id="return-value"></a>

## Return Value

An initialized inset structure.

<a id="Discussion"></a>

## Discussion

This initializer sets all inset margins to `0.0`.
