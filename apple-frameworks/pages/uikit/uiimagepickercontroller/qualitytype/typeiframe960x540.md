# UIImagePickerController.QualityType.typeIFrame960x540 (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+

If recording, specifies that you want to use 960x540 iFrame format.

## Declaration

```swift
case typeIFrame960x540
```

<a id="Discussion"></a>

## Discussion

The Apple iFrame format supports video editing by keeping content in its native recorded format while editing.
