# UIImagePickerController.SourceType.camera (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst

Specifies the device’s built-in camera as the source for the image picker controller.

## Declaration

```swift
case camera
```
