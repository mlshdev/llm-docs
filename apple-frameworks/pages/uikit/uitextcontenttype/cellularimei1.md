# cellularIMEI1 (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS 27.0+ · iPadOS 27.0+ · Mac Catalyst 27.0+ · tvOS 27.0+ · visionOS 27.0+

A property that defines the content in a text input area to contain the International Mobile Equipment Identity (IMEI) for an eSIM.

## Declaration

```swift
static let cellularIMEI1: UITextContentType
```

<a id="Discussion"></a>

## Discussion.

On single SIM devices, this is the equivalent of [cellularIMEI](cellularimei.md).

## See Also

### Setting communication details

- [emailAddress](emailaddress.md): A property that defines the content in a text input area as an email address.
- [telephoneNumber](telephonenumber.md): A property that defines the content in a text input area as a telephone number.
- [cellularEID](cellulareid.md): A property that defines the content in a text input area to contain an embedded identity document number for an eSIM.
- [cellularIMEI](cellularimei.md): A property that defines the content in a text input area to contain the device’s primary International Mobile Equipment Identity (IMEI) number for an eSIM.
- [cellularIMEI2](cellularimei2.md): A property that defines the content in a text input area to contain the second International Mobile Equipment Identity (IMEI) for an eSIM.
- [cellularNAL](cellularnal.md): A property that defines the content in a text input area for use when activating a SIM, and applies only to China.
