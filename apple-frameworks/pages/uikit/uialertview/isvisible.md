# isVisible (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS 2.0+ (deprecated in 9.0) · iPadOS 2.0+ (deprecated in 9.0) · Mac Catalyst 13.1+ (deprecated in 13.1)

A Boolean value that indicates whether the receiver is displayed.

> For more information, see [UIAlertView](../uialertview.md).

## Declaration

```swift
var isVisible: Bool { get }
```

<a id="Discussion"></a>

## Discussion

If [true](https://developer.apple.com/documentation/swift/true), the receiver is displayed; otherwise, [false](https://developer.apple.com/documentation/swift/false).
