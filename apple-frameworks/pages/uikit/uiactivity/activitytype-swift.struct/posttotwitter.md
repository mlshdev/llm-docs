# postToTwitter (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · Mac Catalyst 13.1+ · visionOS 1.0+

A type of activity that posts the provided content to the user’s Twitter feed.

## Declaration

```swift
static let postToTwitter: UIActivity.ActivityType
```
