# UIUserInterfaceLayoutDirection (Swift)

**Framework:** UIKit  
**Kind:** Enumeration  
**Availability:** iOS 5.0+ · iPadOS 5.0+ · Mac Catalyst 13.1+ · tvOS · visionOS 1.0+

Constants that specify the directional flow of the user interface.

## Declaration

```swift
enum UIUserInterfaceLayoutDirection
```

<a id="overview"></a>

## Overview

One of these constants is returned by the [userInterfaceLayoutDirection](uiapplication/userinterfacelayoutdirection.md) property. It indicates the directionality of the language in the user interface of the app.

## Topics

### Constants

- [UIUserInterfaceLayoutDirection.leftToRight](uiuserinterfacelayoutdirection/lefttoright.md): The layout direction is left to right.
- [UIUserInterfaceLayoutDirection.rightToLeft](uiuserinterfacelayoutdirection/righttoleft.md): The layout direction right to left.
