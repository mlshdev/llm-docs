# vertical (Swift)

**Framework:** UIKit  
**Kind:** Instance Property  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS · watchOS 2.0+

The amount of vertical offset from a position.

## Declaration

```swift
var vertical: CGFloat
```

<a id="Discussion"></a>

## Discussion

Positive values indicate an offset downward, and negative values indicate an offset upward.
