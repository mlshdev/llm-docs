# Pasteboard Data Type Representations (Swift)

**Framework:** UIKit  
**Kind:** API Collection

Pasteboard-item representation types, as for a given object value.

## Topics

### Constants

- [typeListString](uipasteboard/typeliststring.md): An array of pasteboard-item representation types for string-type uniform type identifiers (UTIs), including the `kUTTypeUTF8PlainText` and `kUTTypeText` types. Related [UIPasteboard](uipasteboard.md) properties are [string](uipasteboard/string.md) and [strings](uipasteboard/strings.md).
- [typeListURL](uipasteboard/typelisturl.md): An array of pasteboard-item representation types for URL-type uniform type identifiers (UTIs), including `kUTTypeURL`. Related [UIPasteboard](uipasteboard.md) properties are [url](uipasteboard/url.md) and [urls](uipasteboard/urls.md).
- [typeListImage](uipasteboard/typelistimage.md): An array of pasteboard-item representation types for image-type uniform type identifiers (UTIs), including `kUTTypePNG` and `kUTTypeJPEG`. Related [UIPasteboard](uipasteboard.md) properties are [image](uipasteboard/image.md) and [images](uipasteboard/images.md).
- [typeListColor](uipasteboard/typelistcolor.md): An array of pasteboard-item representation types for colors. Related [UIPasteboard](uipasteboard.md) properties are [color](uipasteboard/color.md) and [colors](uipasteboard/colors.md).
- [typeAutomatic](uipasteboard/typeautomatic.md): An array of pasteboard-item representation types with automatically-determined uniform type identifiers (UTIs).
