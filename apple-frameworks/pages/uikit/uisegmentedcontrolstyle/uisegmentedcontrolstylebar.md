# UISegmentedControlStyleBar

**Interface language:** Objective-C

**Framework:** UIKit  
**Kind:** Enumeration Case  
**Availability:** iOS 2.0+ (deprecated in 7.0) · iPadOS 2.0+ (deprecated in 7.0) · Mac Catalyst 13.1+ (deprecated in 13.1)

The small toolbar style for segmented controls.

## Declaration

```objectivec
UISegmentedControlStyleBar
```

<a id="Discussion"></a>

## Discussion

Segmented controls in this style can have a tint color (see `tintColor`).
