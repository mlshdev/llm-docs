# UISplitViewController.DisplayModeButtonVisibility.always (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 14.5+ · iPadOS 14.5+ · Mac Catalyst 14.5+ · tvOS 14.5+ · visionOS 1.0+

A constant that allows the display mode button to always appear.

## Declaration

```swift
case always
```

<a id="Discussion"></a>

## Discussion

With this behavior, the display mode button can appear even if [presentsWithGesture](../presentswithgesture.md) is [false](https://developer.apple.com/documentation/swift/false).

- [UISplitViewController.DisplayModeButtonVisibility.never](never.md): A constant that prevents the display mode button from appearing.
