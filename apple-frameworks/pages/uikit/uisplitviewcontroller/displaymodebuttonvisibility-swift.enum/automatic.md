# UISplitViewController.DisplayModeButtonVisibility.automatic (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 14.5+ · iPadOS 14.5+ · Mac Catalyst 14.5+ · tvOS 14.5+ · visionOS 1.0+

A constant that automatically determines the visibility of the display mode button.

## Declaration

```swift
case automatic
```

<a id="Discussion"></a>

## Discussion

With this behavior, setting [presentsWithGesture](../presentswithgesture.md) to [false](https://developer.apple.com/documentation/swift/false) hides the display mode button. This behavior is the default.

## See Also

### Constants

- [UISplitViewController.DisplayModeButtonVisibility.never](never.md): A constant that prevents the display mode button from appearing.
- [UISplitViewController.DisplayModeButtonVisibility.always](always.md): A constant that allows the display mode button to always appear.
