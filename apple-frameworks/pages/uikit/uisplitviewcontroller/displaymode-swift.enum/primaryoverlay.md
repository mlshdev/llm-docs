# primaryOverlay (Swift)

**Framework:** UIKit  
**Kind:** Type Property  
**Availability:** iOS 8.0+ (deprecated in 14.0) · iPadOS 8.0+ (deprecated in 14.0) · Mac Catalyst 13.1+ (deprecated in 14.0) · tvOS  (deprecated in 14.0)

The primary view controller is layered on top of the secondary view controller, leaving the secondary view controller partially visible.

> Use [UISplitViewController.DisplayMode.oneOverSecondary](oneoversecondary.md) instead.
