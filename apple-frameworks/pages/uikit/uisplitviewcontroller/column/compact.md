# UISplitViewController.Column.compact (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · tvOS 14.0+ · visionOS 1.0+

The column for the view controller that’s shown when the split view controller is collapsed.

## Declaration

```swift
case compact
```

<a id="Discussion"></a>

## Discussion

If a view controller is set for this column, that view controller is shown when [isCollapsed](../iscollapsed.md) is [true](https://developer.apple.com/documentation/swift/true).
