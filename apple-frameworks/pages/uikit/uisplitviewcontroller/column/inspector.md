# UISplitViewController.Column.inspector (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+

The column for the inspector, or trailing, view controller.

## Declaration

```swift
case inspector
```

<a id="Overview"></a>

## Overview

By default, the split view controller hides the `inspector` column. To show the `inspector` column, call [show(\_:)](../show%28__%29.md).
