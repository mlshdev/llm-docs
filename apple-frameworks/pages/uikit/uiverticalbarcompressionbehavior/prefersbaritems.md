# UIVerticalBarCompressionBehavior.prefersBarItems (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 27.1+ beta · iPadOS 27.1+ beta · Mac Catalyst 27.1+

A compression behavior that prefers keeping bar items visible.

## Declaration

```swift
case prefersBarItems
```

<a id="discussion"></a>

## Discussion
