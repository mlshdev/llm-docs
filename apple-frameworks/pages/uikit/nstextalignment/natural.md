# NSTextAlignment.natural (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · Mac Catalyst 13.1+ · tvOS 9.0+ · visionOS 1.0+ · watchOS 2.0+

Text uses the default alignment for the current localization of the app.

## Declaration

```swift
case natural
```

<a id="Discussion"></a>

## Discussion

The default alignment for left-to-right scripts is [NSTextAlignment.left](left.md), and the default alignment for right-to-left scripts is [NSTextAlignment.right](right.md).

## See Also

### Constants

- [NSTextAlignment.left](left.md): Text is left-aligned.
- [NSTextAlignment.right](right.md): Text is right-aligned.
- [NSTextAlignment.center](center.md): Text is center-aligned.
- [NSTextAlignment.justified](justified.md): Text is justified.
