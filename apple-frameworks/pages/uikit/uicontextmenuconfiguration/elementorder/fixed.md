# UIContextMenuConfiguration.ElementOrder.fixed (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · Mac Catalyst 16.0+ · tvOS 17.0+ · visionOS 1.0+

A constant that displays menu elements in a fixed order.

## Declaration

```swift
case fixed
```

<a id="Discussion"></a>

## Discussion

This ordering strategy displays the menu elements in the order they appear in the [children](../../uimenu/children.md) array of the [UIMenu](../../uimenu.md).
