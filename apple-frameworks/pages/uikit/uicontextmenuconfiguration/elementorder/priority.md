# UIContextMenuConfiguration.ElementOrder.priority (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 16.0+ · iPadOS 16.0+ · Mac Catalyst 16.0+ · tvOS 17.0+ · visionOS 1.0+

A constant that displays menu elements according to their priority.

## Declaration

```swift
case priority
```

<a id="Discussion"></a>

## Discussion

This ordering strategy displays the first menu element in the [UIMenu](../../uimenu.md) closest to the location of the user interaction.
