# UIWritingToolsCoordinator.ContextScope.visibleArea (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 18.2+ · iPadOS 18.2+ · Mac Catalyst 18.2+ · visionOS 2.4+

An option to provide only the text in the currently visible portion of your view.

## Declaration

```swift
case visibleArea
```

<a id="discussion"></a>

## Discussion

With this option, include only the currently visible text, along with some additional text before and after the visible text.
