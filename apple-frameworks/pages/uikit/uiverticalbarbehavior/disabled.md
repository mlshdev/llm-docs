# UIVerticalBarBehavior.disabled (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS 27.1+ beta · iPadOS 27.1+ beta

The vertical bar is disabled.

## Declaration

```swift
case disabled
```

<a id="discussion"></a>

## Discussion

Bar content falls back to the standard horizontal top and bottom bars, and the vertical status bar reverts to the horizontal axis.

## See Also

### Specifying vertical bar behavior

- [UIVerticalBarBehavior.automatic](automatic.md): Beta. The system determines whether the vertical bar is rendered.
