# UITextField.ViewMode.unlessEditing (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS

The overlay view is displayed only when text is not being edited.

## Declaration

```swift
case unlessEditing
```
