# UITextField.ViewMode.whileEditing (Swift)

**Framework:** UIKit  
**Kind:** Case  
**Availability:** iOS · iPadOS · Mac Catalyst · tvOS · visionOS

The overlay view is displayed only while text is being edited in the text field.

## Declaration

```swift
case whileEditing
```

## See Also

### Constants

- [UITextField.ViewMode.never](never.md): The overlay view never appears.
- [UITextField.ViewMode.unlessEditing](unlessediting.md): The overlay view is displayed only when text is not being edited.
- [UITextField.ViewMode.always](always.md): The overlay view is always displayed if the text field contains text.
