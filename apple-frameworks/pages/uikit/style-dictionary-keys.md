# Style dictionary keys (Swift)

**Framework:** UIKit  
**Kind:** API Collection

A dictionary that contains properties that define text style characteristics.

<a id="overview"></a>

## Overview

The style [NSDictionary](../foundation/nsdictionary.md) object is used for providing styling information for marked text ([markedTextStyle](uitextinput/markedtextstyle.md) property) and for providing text-styling information at a certain position ([textStyling(at:in:)](uitextinput/textstyling%28at_in_%29.md) method).

- [UITextInputTextFontKey](uitextinputtextfontkey.md): Deprecated. The font of the text.
