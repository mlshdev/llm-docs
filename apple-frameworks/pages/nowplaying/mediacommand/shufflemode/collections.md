# MediaCommand.ShuffleMode.collections

**Framework:** Now Playing  
**Kind:** Case  
**Availability:** iOS 27.0+ · iPadOS 27.0+ · Mac Catalyst 27.0+ · macOS 27.0+ · tvOS 27.0+ · visionOS 27.0+ · watchOS 27.0+

The player shuffles collections during playback (for example, albums).

```swift
case collections
```

## Discussion

When you use this mode, the player shuffles albums or other collection types while maintaining the original order within each collection.
