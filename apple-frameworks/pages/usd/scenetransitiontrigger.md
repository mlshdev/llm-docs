# SceneTransitionTrigger

A trigger that fires during scene transitions.

<a id="overview"></a>

## Overview

Use this trigger to perform actions after a scene loads. For more information about scenes, see [sceneLibrary](scenelibrary.md).

<a id="Declaration"></a>

### Declaration

```other
class Preliminary_Trigger "SceneTransitionTrigger"
```

## Topics

### Properties

- [info:id](info-id.md): The action’s unique identifier.
- [type](type.md): An option that controls the order in which the actions execute.
