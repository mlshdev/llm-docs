# Write Operations (Swift)

**Framework:** PDFKit  
**Kind:** API Collection

Operations that let you write document data to different locations.

## Topics

### Writing Out the PDF Data

- [write(toFile:)](pdfdocument/write%28tofile_%29.md): Writes the document to a file at the specified path.
- [write(toFile:withOptions:)](pdfdocument/write%28tofile_withoptions_%29.md): Writes the document to a file at the specified path with the specified options.
- [write(to:)](pdfdocument/write%28to_%29.md): Writes the document to a location specified by the passed-in URL.
- [write(to:withOptions:)](pdfdocument/write%28to_withoptions_%29.md): Writes the document to the specified URL with the specified options.
- [Data Representations](data-representations.md): Operations to represent PDF documents as data objects.

### Printing Documents for macOS

- [printOperation(for:scalingMode:autoRotate:)](pdfdocument/printoperation%28for_scalingmode_autorotate_%29.md): Returns a print operation suitable for printing the PDF document.
- [PDFPrintScalingMode](pdfprintscalingmode.md): The type of scaling to be used when printing a page (see [PDFDocument](pdfdocument.md)).

## See Also

### Reading and Writing PDFs

- [Read Operations](read-operations.md): Operations that let you access documents and pages, manage document security, and work with searching and selections.
