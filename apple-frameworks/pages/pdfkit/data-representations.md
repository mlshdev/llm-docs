# Data Representations (Swift)

**Framework:** PDFKit  
**Kind:** API Collection

Operations to represent PDF documents as data objects.

## Topics

### Creating Data Representations

- [dataRepresentation()](pdfdocument/datarepresentation%28%29.md): Returns a representation of the document as an `NSData` object.
- [dataRepresentation(options:)](pdfdocument/datarepresentation%28options_%29.md): Returns a representation of the document as an `NSData` object with additional options applied, such as filters.

## See Also

### Writing Out the PDF Data

- [write(toFile:)](pdfdocument/write%28tofile_%29.md): Writes the document to a file at the specified path.
- [write(toFile:withOptions:)](pdfdocument/write%28tofile_withoptions_%29.md): Writes the document to a file at the specified path with the specified options.
- [write(to:)](pdfdocument/write%28to_%29.md): Writes the document to a location specified by the passed-in URL.
- [write(to:withOptions:)](pdfdocument/write%28to_withoptions_%29.md): Writes the document to the specified URL with the specified options.
