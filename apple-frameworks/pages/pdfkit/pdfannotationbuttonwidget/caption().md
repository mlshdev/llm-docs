# caption() (Swift)

**Framework:** PDFKit  
**Kind:** Instance Method  
**Availability:** macOS 10.4+ (deprecated in 10.12)

Returns the text of the label on a push button control.

## Declaration

```swift
func caption() -> String!
```

<a id="return-value"></a>

## Return Value

The label drawn on a push button control.

<a id="Discussion"></a>

## Discussion

This method applies only to the label drawn on a control of type [PDFAnnotationButtonWidget](../pdfannotationbuttonwidget.md).

## See Also

### Related Documentation

- [PDFAnnotationButtonWidget](../pdfannotationbuttonwidget.md): Deprecated. A `PDFAnnotationButtonWidget` object provides user interactivity on a page of a PDF document. There are three types of buttons available: push button, radio button, and checkbox.

### Getting and Setting the Control Label Text

- [setCaption(\_:)](setcaption%28__%29.md): Deprecated. Sets the text of the label on a push button control.
