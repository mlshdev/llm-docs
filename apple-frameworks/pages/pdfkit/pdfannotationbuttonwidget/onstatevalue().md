# onStateValue() (Swift)

**Framework:** PDFKit  
**Kind:** Instance Method  
**Availability:** macOS 10.4+ (deprecated in 10.12)

Returns the string associated with the on state of a radio button or checkbox control.

## Declaration

```swift
func onStateValue() -> String!
```

<a id="return-value"></a>

## Return Value

The string associated with the on state of a radio button or checkbox control.

<a id="Discussion"></a>

## Discussion

This is a required string for controls of types [PDFAnnotationButtonWidget](../pdfannotationbuttonwidget.md) and [PDFAnnotationButtonWidget](../pdfannotationbuttonwidget.md). The off state is always labeled “Off”.

## See Also

### Related Documentation

- [PDFAnnotationButtonWidget](../pdfannotationbuttonwidget.md): Deprecated. A `PDFAnnotationButtonWidget` object provides user interactivity on a page of a PDF document. There are three types of buttons available: push button, radio button, and checkbox.
