# Additional Display Configurations

**Interface languages:** Swift, Objective-C

**Framework:** PDFKit  
**Kind:** API Collection

Operations for setting up page breaks, a display box, and display direction.

## Topics

### Defining Display Box

- [displayBox](pdfview/displaybox.md): The current style of display box.

### Defining Page Breaks

- [displaysPageBreaks](pdfview/displayspagebreaks.md): A Boolean value indicating whether the view is displaying page breaks.
- [pageBreakMargins](pdfview/pagebreakmargins.md): The spacing between pages as defined by the top, bottom, left, and right margins.

### Defining Display Direction

- [displayDirection](pdfview/displaydirection.md): The layout direction, either vertical or horizontal, for the given display mode.
- [displaysRTL](pdfview/displaysrtl.md): The presentation of pages from right-to-left.
