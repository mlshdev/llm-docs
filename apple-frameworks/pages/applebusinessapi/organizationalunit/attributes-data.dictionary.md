# OrganizationalUnit.Attributes

**Interface language:** Data

**Framework:** Apple Business API  
**Kind:** Object  
**Availability:** Apple Business API 2.4+

Attributes that describe an organizational unit resource.

## Declaration

```
object OrganizationalUnit.Attributes
```

## Properties

- `name` — `string`: The name of the organizational unit.
- `description` — `string`: A description of the organizational unit.
- `createdDateTime` — `date-time`: The date and time the organizational unit was created.
- `updatedDateTime` — `date-time`: The date and time the organizational unit was last modified.
