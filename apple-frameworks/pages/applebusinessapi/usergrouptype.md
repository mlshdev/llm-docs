# UserGroupType

**Interface language:** Data

**Framework:** Apple Business API  
**Kind:** Type  
**Availability:** Apple Business API 2.4+

Strings that represent user group types.

## Declaration

```
string UserGroupType
```

## Possible Values

- `STANDARD`:
- `SMART`:

<a id="discussion"></a>

## Discussion

- Possible Values

  - STANDARD: A standard user group with manually assigned members.
  - SMART: A smart user group with dynamically assigned members based on criteria.
