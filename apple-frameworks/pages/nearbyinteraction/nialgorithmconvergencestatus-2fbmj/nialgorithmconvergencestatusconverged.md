# NIAlgorithmConvergenceStatusConverged

**Interface language:** Objective-C

**Framework:** Nearby Interaction  
**Kind:** Enumeration Case  
**Availability:** iOS · iPadOS · Mac Catalyst · macOS · watchOS

A status that indicates the framework’s Camera Assistance feature is operational.

## Declaration

```objectivec
NIAlgorithmConvergenceStatusConverged
```

<a id="Discussion"></a>

## Discussion

In this state, the app doesn’t need to coach the user and receives all the benefits of Camera Assistance as described in [cameraAssistanceEnabled](../ninearbypeerconfiguration/iscameraassistanceenabled.md).
