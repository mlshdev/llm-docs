# NIMotionActivityState.unknown (Swift)

**Framework:** Nearby Interaction  
**Kind:** Case  
**Availability:** iOS 15.0+ · iPadOS 15.0+ · Mac Catalyst 15.0+

A value that indicates the accessory’s motion state is unknown.

## Declaration

```swift
case unknown
```

<a id="discussion"></a>

## Discussion

Update the session with this state when you’re unsure whether the accessory is moving.

## See Also

### Specifying the motion state

- [NIMotionActivityState.stationary](stationary.md): A value that indicates the accessory isn’t moving.
- [NIMotionActivityState.moving](moving.md): A value that indicates the accessory is moving.
