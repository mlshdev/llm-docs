# Playing Haptics on Game Controllers

**Interface languages:** Swift, Objective-C

**Framework:** Core Haptics  
**Kind:** Sample Code  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · Xcode 12.0+

Add haptic feedback to supported game controllers by using Core Haptics.

<a id="Overview"></a>

## Overview

> **Note**

> This sample code project is associated with WWDC20 session [10614: Advancements in Game Controllers](https://developer.apple.com/videos/play/wwdc2020/10614/).

This sample code project must be run on a physical device and requires a Bluetooth-connected game controller.
