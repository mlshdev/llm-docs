# Pass.EventTicket

**Interface language:** Data

**Framework:** Wallet Passes  
**Kind:** Object  
**Availability:** iOS 6.0+ · iPadOS 6.0+ · watchOS 1.0+

An object that represents the groups of fields that display the information for an event ticket.

## Declaration

```
object Pass.EventTicket
```

<a id="Discussion"></a>

## Discussion

Use the event ticket pass type to give people entry to events like concerts, sporting events, plays and movies.
