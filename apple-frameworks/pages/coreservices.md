# Core Services

**Interface languages:** Swift, Objective-C

**Kind:** Framework  
**Availability:** iOS 12.0+ · iPadOS 12.0+ · Mac Catalyst 13.0+ · macOS 10.0+ · tvOS 12.0+ · visionOS 1.0+ · watchOS 5.0+

Access and manage key operating system services, such as launch and identity services.

<a id="overview"></a>

## Overview

This collection of documents provides the API reference for the Core Services framework, which encompasses many fundamental operating system services used by Carbon applications.

## Topics

### Reference

- [Apple Events](coreservices/apple_events.md): Communicate messages across process boundaries that can be performed and responded to with a reply event.
- [Backup Core](coreservices/backup_core.md): Access low-level details about file and folder settings used by the macOS Backup utility.
- [Dictionary Services](coreservices/dictionary_services.md): Look for words and phrases in system dictionaries.
- [File System Events](coreservices/file_system_events.md): Get notifications when the contents of a directory hierarchy change.
- [Launch Services](coreservices/launch_services.md): Launch and open documents in other apps from your current app process.
- [File Metadata](coreservices/file_metadata.md): Search for files based on data that is part of the file or file system.
- [OS Services](coreservices/os_services.md): Interact with operating system services, including user and group accounts and power management.
- [Search Kit](coreservices/search_kit.md): Index and search natural language documents.
- [Carbon Core](coreservices/carbon_core.md): Deprecated. Interact with legacy technologies.
- [Core Services Constants](coreservices/core_services_constants.md)
