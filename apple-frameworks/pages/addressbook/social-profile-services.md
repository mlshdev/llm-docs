# Social Profile Services (Swift)

**Framework:** Address Book  
**Kind:** API Collection

The predefined constants are used to identify social networking services.

<a id="overview"></a>

## Overview

You may use these constants or any other string.

The value of these constants is undefined until one of the following functions has been called: [ABAddressBookCreate()](abaddressbookcreate%28%29.md), [ABPersonCreate()](abpersoncreate%28%29.md), [ABGroupCreate()](abgroupcreate%28%29.md). Neither developers nor users can add more keys.

## Topics

### Services

- [kABSocialProfileServiceTwitter](kabsocialprofileservicetwitter.md): Twitter social profile service.
- [kABSocialProfileServiceFacebook](kabsocialprofileservicefacebook.md): Facebook social profile service.
- [kABSocialProfileServiceMySpace](kabsocialprofileservicemyspace.md): Myspace social profile service.
- [kABSocialProfileServiceLinkedIn](kabsocialprofileservicelinkedin.md): LinkedIn social profile service.
- [kABSocialProfileServiceFlickr](kabsocialprofileserviceflickr.md): Flickr social profile service.
- [kABSocialProfileServiceSinaWeibo](kabsocialprofileservicesinaweibo.md): Sina Weibo social profile service.

### Keys

The keys used to specify the different fields in a [kABSocialProfileProperty](kabsocialprofileproperty.md) property.

- [kABSocialProfileURLKey](kabsocialprofileurlkey.md): Social profile URL.
- [kABSocialProfileServiceKey](kabsocialprofileservicekey.md): Social profile service.
- [kABSocialProfileUsernameKey](kabsocialprofileusernamekey.md): Social profile username.
- [kABSocialProfileUserIdentifierKey](kabsocialprofileuseridentifierkey.md): Social profile user identifier.

## See Also

### Social Media Constants
