# kABPickerMultipleValueSelection

**Interface language:** Objective-C

**Framework:** Address Book  
**Kind:** Enumeration Case  
**Availability:** macOS

Allows the user to select multiple values.

## Declaration

```objectivec
kABPickerMultipleValueSelection
```
