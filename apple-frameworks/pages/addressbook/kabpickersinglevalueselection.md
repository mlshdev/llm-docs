# kABPickerSingleValueSelection

**Interface language:** Objective-C

**Framework:** Address Book  
**Kind:** Enumeration Case  
**Availability:** macOS

Allows the user to select a single value. This is the default behavior.

## Declaration

```objectivec
kABPickerSingleValueSelection
```
