# Instant Messaging Services

**Interface languages:** Swift, Objective-C

**Framework:** Address Book  
**Kind:** API Collection

The predefined constants are used to identify instant messaging services.

<a id="overview"></a>

## Overview

You may use these constants or any other string.

## Topics

### Constants

- [kABInstantMessageServiceAIM](kabinstantmessageserviceaim.md): AOL Instant Messenger instant message service.
- [kABInstantMessageServiceFacebook](kabinstantmessageservicefacebook.md): Facebook instant message service.
- [kABInstantMessageServiceGaduGadu](kabinstantmessageservicegadugadu.md): Gadu-Gadu instant message service.
- [kABInstantMessageServiceGoogleTalk](kabinstantmessageservicegoogletalk.md): Google Talk instant message service.
- [kABInstantMessageServiceICQ](kabinstantmessageserviceicq.md): ICQ instant message service.
- [kABInstantMessageServiceJabber](kabinstantmessageservicejabber.md): Jabber instant message service.
- [kABInstantMessageServiceMSN](kabinstantmessageservicemsn.md): MSN instant message service.
- [kABInstantMessageServiceQQ](kabinstantmessageserviceqq.md): QQ instant message service.
- [kABInstantMessageServiceSkype](kabinstantmessageserviceskype.md): Skype instant message service.
- [kABInstantMessageServiceYahoo](kabinstantmessageserviceyahoo.md): Yahoo! instant message service.
