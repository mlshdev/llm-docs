# Address Book Errors

**Interface languages:** Swift, Objective-C

**Framework:** Address Book  
**Kind:** API Collection

Errors that can be raised under the Address Book error domain.

## Topics

### Constants

- [kABOperationNotPermittedByStoreError](kaboperationnotpermittedbystoreerror.md): The operation is not allowed by the Address Book database, because the contact’s source does not support it.
- [kABOperationNotPermittedByUserError](kaboperationnotpermittedbyusererror.md): The operation is not allowed because the user denied access to the Address Book database.
