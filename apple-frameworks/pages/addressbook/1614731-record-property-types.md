# Record Property Types (Swift)

**Framework:** Address Book  
**Kind:** API Collection

These constants identify record property types.

<a id="overview"></a>

## Overview

See [ABPropertyType](abpropertytype.md).

## Topics

### Constants

- [kABInvalidPropertyType](kabinvalidpropertytype.md): Invalid property.
- [kABStringPropertyType](kabstringpropertytype.md): String property. Returned as a [CFString](../corefoundation/cfstring.md) object.
- [kABIntegerPropertyType](kabintegerpropertytype.md): Integer property. Returned as a [CFNumber](../corefoundation/cfnumber.md) object.
- [kABRealPropertyType](kabrealpropertytype.md): Real property.
- [kABDateTimePropertyType](kabdatetimepropertytype.md): Date-time property.
- [kABDictionaryPropertyType](kabdictionarypropertytype.md): Dictionary property. Returned as a [CFDictionary](../corefoundation/cfdictionary.md) object.
- [kABMultiStringPropertyType](kabmultistringpropertytype.md): Multistring property.
- [kABMultiIntegerPropertyType](kabmultiintegerpropertytype.md): Multiinteger property. Returned as an [ABMultiValue](abmultivalue-swift.typealias.md) of [CFNumber](../corefoundation/cfnumber.md) objects.
- [kABMultiRealPropertyType](kabmultirealpropertytype.md): Multireal property.
- [kABMultiDateTimePropertyType](kabmultidatetimepropertytype.md): Multi–date-time property. Returned as an [ABMultiValue](abmultivalue-swift.typealias.md) of [CFDate](../corefoundation/cfdate.md) objects.
- [kABMultiDictionaryPropertyType](kabmultidictionarypropertytype.md): Multidictionary property. Returned as an [ABMultiValue](abmultivalue-swift.typealias.md) of [CFDictionary](../corefoundation/cfdictionary.md) objects.
