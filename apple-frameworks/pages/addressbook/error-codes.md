# Error Codes

**Interface languages:** Swift, Objective-C

**Framework:** Address Book  
**Kind:** API Collection

Errors codes used by the Address Book framework.

## Topics

### Errors

- [ABAddRecordsError](abaddrecordserror.md): The records could not be added.
- [ABRemoveRecordsError](abremoverecordserror.md): The records could not be removed.
- [ABPropertyValueValidationError](abpropertyvaluevalidationerror.md): The property value is not valid.
- [ABPropertyUnsupportedBySourceError](abpropertyunsupportedbysourceerror.md): The property is not supported by the source.
- [ABPropertyReadOnlyError](abpropertyreadonlyerror.md): The property is read-only.

### Dictionary Keys

- [ABMultiValueIdentifiersErrorKey](abmultivalueidentifierserrorkey.md): Key used with [ABPropertyValueValidationError](abpropertyvaluevalidationerror.md).
