# People-Picker Selection Behavior (Objective-C)

**Framework:** Address Book  
**Kind:** API Collection

Constants to specify the selection behavior for the values of multi-value properties.

## Topics

### Constants

- [kABPickerSingleValueSelection](kabpickersinglevalueselection.md): Allows the user to select a single value. This is the default behavior.
- [kABPickerMultipleValueSelection](kabpickermultiplevalueselection.md): Allows the user to select multiple values.
- [kABPickerAllowGroupSelection](kabpickerallowgroupselection.md): Allows the user to select entire groups in the groups list. Otherwise at least one record in the group is selected when the user selects a group. The default is not to allow group selection.
- [kABPickerAllowMultipleSelection](kabpickerallowmultipleselection.md): Allows the user to select more than one group or record at a time. The default is to allow multiple selection.
