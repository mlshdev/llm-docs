# Instant Messaging Keys

**Interface languages:** Swift, Objective-C

**Framework:** Address Book  
**Kind:** API Collection

The keys used to specify the different fields in a [kABInstantMessageProperty](kabinstantmessageproperty.md) property.

<a id="overview"></a>

## Overview

Neither developers nor users can add more keys.

## Topics

### Constants

- [kABInstantMessageUsernameKey](kabinstantmessageusernamekey.md): The instant messaging username or handle.
- [kABInstantMessageServiceKey](kabinstantmessageservicekey.md): The instant messaging service.
