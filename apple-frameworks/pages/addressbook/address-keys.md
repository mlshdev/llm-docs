# Address Keys (Swift)

**Framework:** Address Book  
**Kind:** API Collection

The keys used to specify the different fields in a `kABAddressProperty`.

<a id="overview"></a>

## Overview

Neither developers nor users can add more keys.

## Topics

### Constants

- [kABAddressStreetKey](kabaddressstreetkey.md): Street.
- [kABAddressCityKey](kabaddresscitykey.md): City.
- [kABAddressStateKey](kabaddressstatekey.md): State.
- [kABAddressZIPKey](kabaddresszipkey.md): Zip.
- [kABAddressCountryKey](kabaddresscountrykey.md): Country name.
- [kABAddressCountryCodeKey](kabaddresscountrycodekey.md): Country, identified by ISO country code. For a list of these codes, see [ABPerson](abperson.md).
