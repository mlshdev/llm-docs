# Generic Multivalue List Labels (Swift)

**Framework:** Address Book  
**Kind:** API Collection

The generic labels contained in the Address Book database for specifying different values in a multivalue list.

<a id="overview"></a>

## Overview

These labels are especially useful if there is no default label for a property. Users can also add their own labels.

## Topics

### Constants

- [kABWorkLabel](kabworklabel.md): Deprecated. All Work labels match this label.
- [kABHomeLabel](kabhomelabel.md): Deprecated. All Home labels match this label.
- [kABOtherLabel](kabotherlabel.md): Deprecated. All labels other than Home or Work labels match this label.
- [kABMobileMeLabel](kabmobilemelabel.md): MobileMe instant messenger or email values.

- [Default Multivalue List Labels](default-multivalue-list-labels.md): The default labels contained in the Address Book database for specifying different values in a multivalue list. Users can also add their own labels.
