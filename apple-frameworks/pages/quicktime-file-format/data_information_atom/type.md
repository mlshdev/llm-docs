# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'dinf'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this data information atom.
- [Data reference atom](data_reference_atom.md): An atom that contains tabular data that instructs the data handler component how to access the media’s data.
