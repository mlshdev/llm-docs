# Data rate atom

**Framework:** QuickTime File Format  
**Kind:** Data field

A reference movie atom may contain an optional data rate atom.

<a id="Overview"></a>

## Overview

Only one data rate atom can be present. See [Data rate atom](../data_rate_atom.md) for more information.
