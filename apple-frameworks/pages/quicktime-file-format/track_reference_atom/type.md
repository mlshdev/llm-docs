# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'tref'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this track reference atom.
- [Track reference type atom](track_reference_type_atom.md): A list of track reference type atoms containing the track reference information.
