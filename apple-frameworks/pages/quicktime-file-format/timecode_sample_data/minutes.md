# Minutes

**Framework:** QuickTime File Format  
**Kind:** Data field

A 7-bit integer that contains the starting number of minutes.

### Data fields

- [Negative](negative.md): A 1-bit value indicating the time’s sign.
- [Seconds](seconds.md): An 8-bit unsigned integer indicating the starting number of seconds.
- [Frames](frames.md): An 8-bit unsigned integer that specifies the starting number of frames.
