# Frames

**Framework:** QuickTime File Format  
**Kind:** Data field

An 8-bit unsigned integer that specifies the starting number of frames.

<a id="Overview"></a>

## Overview

This field’s value cannot exceed the value of the number of frames field in the timecode sample description.

## See Also

### Data fields

- [Hours](hours.md): An 8-bit unsigned integer that indicates the starting number of hours.
- [Negative](negative.md): A 1-bit value indicating the time’s sign.
- [Minutes](minutes.md): A 7-bit integer that contains the starting number of minutes.
