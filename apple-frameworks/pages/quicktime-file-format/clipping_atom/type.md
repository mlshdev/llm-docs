# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'clip'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this clipping atom.
- [Clipping region atom](clipping_region_atom.md): An atom that specifies the clipping region.
