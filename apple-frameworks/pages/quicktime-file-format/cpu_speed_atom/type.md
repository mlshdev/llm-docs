# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

The type of this atom.

<a id="Overview"></a>

## Overview

This field must be set to `'rmcs'`.

## See Also

### Data fields

- [Size](size.md): The number of bytes in this CPU speed atom.
- [Flags](flags.md): A 32-bit integer that is always 0.
- [CPU speed](cpu_speed.md): A relative ranking of required computer speed, expressed as a 32-bit integer divisible by 100, with larger numbers indicating higher speed.
