# Region boundary box

**Framework:** QuickTime File Format  
**Kind:** Data field

The region boundary box part of a QuickDraw region.

<a id="Overview"></a>

## Overview

The region size, region boundary box, and clipping region data fields constitute a QuickDraw region.

## See Also

### Data fields

- [Type](type.md): A 32-bit integer that identifies the atom type.

- [Clipping region data](clipping_region_data.md): The clipping region data part of a QuickDraw region.
