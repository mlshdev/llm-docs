# nameAtomID

**Framework:** QuickTime File Format  
**Kind:** Data field

The ID of the string atom that contains the name of the scene.

<a id="Overview"></a>

## Overview

That atom should be a sibling of the VR world header atom. The value of this field is `0` if no name string atom exists.
