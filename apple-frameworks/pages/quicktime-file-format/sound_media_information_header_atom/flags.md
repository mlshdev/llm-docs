# Flags

**Framework:** QuickTime File Format  
**Kind:** Data field

A 3-byte space for sound media information flags.

<a id="Overview"></a>

## Overview

Set this field to `0`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this sound media information header atom.
- [Type](type.md): A 32-bit integer that identifies the atom type.
- [Version](version.md): A 1-byte specification of the version of this sound media information header atom.
- [Balance](balance.md): A 16-bit integer that specifies the sound balance of this sound media.
- [Reserved](reserved.md): Reserved for use by Apple.
