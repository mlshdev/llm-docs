# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'edts'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this edit atom.
- [Edit list atom](edit_list_atom.md): An atom that maps from a time in a movie to a time in a media, and ultimately to media data.
