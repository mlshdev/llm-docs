# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'matt'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this track matte atom.
- [Compressed matte atom](compressed_matte_atom.md): An atom that specifies the image description structure and the matte data associated with a particular matte atom.
