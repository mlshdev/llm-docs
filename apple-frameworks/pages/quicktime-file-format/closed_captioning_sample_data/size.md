# Size

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that specifies the number of bytes in this closed captioning media data atom.

## See Also

### Data fields

- [Type](type.md): A 32-bit integer that identifies the atom type.
- [Sample data](sample_data.md): An array of one or more byte pairs for data channel 1/field 1 (“CC1”) of a CEA-608 data stream, each byte pair corresponding to a video frame.
