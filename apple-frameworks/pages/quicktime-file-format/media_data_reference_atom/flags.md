# Flags

**Framework:** QuickTime File Format  
**Kind:** Data field

A 3-byte space for data reference flags.

<a id="Overview"></a>

## Overview

Set this field to `0`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this data reference atom.
- [Type](type.md): A 32-bit integer that identifies the atom type.
- [Version](version.md): A 1-byte specification of the version of this data reference atom.
- [Number of entries](number_of_entries.md): A 32-bit integer containing the count of data references that follow.
- [Data references](data_references.md): An array of data references.
