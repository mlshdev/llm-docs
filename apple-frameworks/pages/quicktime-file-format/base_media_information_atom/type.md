# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit integer that identifies the atom type.

<a id="Overview"></a>

## Overview

This field must be set to `'minf'`.

## See Also

### Data fields

- [Size](size.md): A 32-bit integer that specifies the number of bytes in this base media information atom.
- [Base media information header atom](base_media_information_header_atom.md): An atom that indicates that this media information atom pertains to a base media.
