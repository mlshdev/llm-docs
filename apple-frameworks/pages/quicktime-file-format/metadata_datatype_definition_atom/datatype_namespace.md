# Datatype namespace

**Framework:** QuickTime File Format  
**Kind:** Data field

A 32-bit identifier describing how to interpret the data type for the value.

<a id="Overview"></a>

## Overview

New namespace types should be registered with Apple.

## See Also

### Data fields

- [Size](size.md): A 32-bit unsigned integer that indicates the size in bytes of the atom structure.
- [Type](type.md): A 32-bit unsigned integer value.
- [Datatype array](datatype_array.md): An array of unsigned 8-bit bytes holding the data type designation for values in timed metadata media samples having this key.
