# Text size

**Framework:** QuickTime File Format  
**Kind:** Data field

A 16-bit word that specifies the length (number of bytes) of the subtitle text.

## See Also

### Data fields

- [Text](text.md): The subtitle text.
- [Sample extensions](sample_extensions.md): One or more atoms containing additional information for selecting and drawing the subtitle.
