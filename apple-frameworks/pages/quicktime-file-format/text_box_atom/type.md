# Type

**Framework:** QuickTime File Format  
**Kind:** Data field

An unsigned 32-bit field.

<a id="Overview"></a>

## Overview

Contains the four-character code `'tbox'`.

## See Also

### Data fields

- [Size](size.md): An unsigned 32-bit integer holding the size of the subtitle style atom.
- [Text box](text_box.md): A 64-bit rectangle that specifies an area to receive text (each 16 bits indicate top, left, bottom, and right, respectively) within the subtitle track.
