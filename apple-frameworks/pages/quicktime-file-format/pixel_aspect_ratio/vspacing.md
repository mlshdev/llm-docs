# vSpacing

**Framework:** QuickTime File Format  
**Kind:** Data field

An unsigned 32-bit integer specifying the vertical spacing of pixels, such as video picture lines.

## See Also

### Data fields

- [Size](size.md): An unsigned 32-bit integer holding the size of the pixel aspect ratio atom.
- [Type](type.md): An unsigned 32-bit field.
- [hSpacing](hspacing.md): An unsigned 32-bit integer specifying the horizontal spacing of pixels, such as luma sampling instants for Y´CbCr or YUV video.
