# Additional data

**Framework:** QuickTime File Format  
**Kind:** Data field

A variable length field containing data pointed to by the entries in the data table.

## See Also

### Data fields

- [Entry count](entry_count.md): A 16-bit unsigned integer indicating the number of packet entries in the table.
- [Reserved](reserved.md): Two bytes.
- [Packet entry table](packet_entry_table.md): A variable length table containing packet entries.
