# Upgrade Grafana

We recommend that you upgrade Grafana often to stay current with the latest fixes and enhancements. You can upgrade to any of the supported releases from any supported release.

Because Grafana upgrades are backward compatible, the upgrade process is straightforward, and dashboards and graphs will not change.

To learn what's available in a Grafana release, refer to [What's New](https://grafana.com/docs/grafana/v13.3/whatsnew/).

Refer to any of the following upgrade guides:

- [Upgrade strategies](https://grafana.com/docs/grafana/v13.3/upgrade-guide/when-to-upgrade/)
- [Upgrade to v13](https://grafana.com/docs/grafana/v13.3/upgrade-guide/upgrade-v13/)
- [Upgrade to v12](https://grafana.com/docs/grafana/v13.3/upgrade-guide/upgrade-v12/)
- [Upgrade to v11](https://grafana.com/docs/grafana/v13.3/upgrade-guide/upgrade-v11/)

Upgrade guides for Grafana v10.4 and earlier are available in the documentation archive: [v10.4](https://archive.grafana.com/docs/grafana/v10.4/upgrade-guide/upgrade-v10.4/), [v10.3](https://archive.grafana.com/docs/grafana/v10.3/upgrade-guide/upgrade-v10.3/), [v10.2](https://archive.grafana.com/docs/grafana/v10.2/upgrade-guide/upgrade-v10.2/), [v10.1](https://archive.grafana.com/docs/grafana/v10.1/upgrade-guide/upgrade-v10.1/), [v10.0](https://archive.grafana.com/docs/grafana/v10.0/upgrade-guide/upgrade-v10.0/), [v9.5](https://archive.grafana.com/docs/grafana/v9.5/upgrade-guide/upgrade-v9.5/).
