# Guides

Guides in the Grafana Alerting documentation provide best practices and practical recommendations to help you move from a basic alerting setup to real-world use cases.

These guides cover topics such as:

- [Best practices](https://grafana.com/docs/grafana/v13.2/alerting/guides/best-practices/)
- [Handle connectivity errors in alerts](https://grafana.com/docs/grafana/v13.2/alerting/guides/connectivity-errors/)
- [Handle missing data in Grafana Alerting](https://grafana.com/docs/grafana/v13.2/alerting/guides/missing-data/)
- [When SLOs reduce alert noise](https://grafana.com/docs/grafana/v13.2/alerting/guides/when-slos-reduce-alert-noise/)
- [Alerting on forecasts](https://grafana.com/docs/grafana/v13.2/alerting/guides/alerting-on-forecasts/)

For more hands-on examples, refer to [Examples](https://grafana.com/docs/grafana/v13.2/alerting/examples/) and [Tutorials](https://grafana.com/docs/grafana/v13.2/alerting/examples/tutorials/).
