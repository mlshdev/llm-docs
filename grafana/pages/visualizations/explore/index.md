# Explore

Use Explore to query, collect, and analyze data for detailed real-time data analysis.

***

## Overview

Explore is your starting point for querying, analyzing, and aggregating data in Grafana. You can quickly begin creating queries to start analyzing data without having to create a dashboard or customize a visualization.

## Explore

- [Get started with Explore](https://grafana.com/docs/grafana/v13.2/visualizations/explore/get-started-with-explore/): Get started using Explore to create queries and do real-time analysis on your data.
- [Query management](https://grafana.com/docs/grafana/v13.2/visualizations/explore/query-management/): Learn how to manage queries in Explore.
- [Query inspector in Explore](https://grafana.com/docs/grafana/v13.2/visualizations/explore/explore-inspector/): Learn how to use the Query inspector to troubleshoot issues with your queries.
- [Logs in Explore](https://grafana.com/docs/grafana/v13.2/visualizations/explore/logs-integration/): Learn about working with logs and log data in Explore.
- [Traces in Explore](https://grafana.com/docs/grafana/v13.2/visualizations/explore/trace-integration/): Learn about working with traces and tracing data in Explore.
- [Correlations editor in Explore](https://grafana.com/docs/grafana/v13.2/visualizations/explore/correlations-editor-in-explore/): Learn how to create and use Correlations.
