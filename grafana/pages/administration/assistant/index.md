# Grafana Assistant and other AI tools

Starting in Grafana v13, you can use Grafana Assistant on-premise by installing the Assistant app in your self-hosted Grafana deployment and connecting it to a Grafana Cloud stack.

Grafana Assistant on-premise keeps the Assistant experience inside your Grafana deployment. After setup, you can use Assistant to work with metrics, logs, traces, profiles, and databases, create and update dashboards, generate queries, and navigate Grafana resources from natural language prompts. However, it doesn’t include every Grafana Cloud feature.

> **Tip**
>
> For more information about Assistant and other AI tools, refer to the [AI tools](https://grafana.com/docs/grafana/v13.3/ai-tools/) section.
