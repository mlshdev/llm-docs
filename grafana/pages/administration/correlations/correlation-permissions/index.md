# Permissions

Users with [Viewer base role](https://grafana.com/docs/grafana/v13.3/administration/roles-and-permissions/) or with [datasources:query RBAC role](https://grafana.com/docs/grafana/v13.3/administration/roles-and-permissions/access-control/) can:

- Use correlations in Explore’s visualizations.
- List all available correlations in read-only mode.

Users with [Admin base role](https://grafana.com/docs/grafana/v13.3/administration/roles-and-permissions/) or with [datasources:write RBAC role](https://grafana.com/docs/grafana/v13.3/administration/roles-and-permissions/access-control/) can:

- Add, edit and delete correlations.
