# Get the process uptime in nanoseconds

Use `Bun.nanoseconds()` to get the total number of nanoseconds the `bun` process has been alive.

```ts
Bun.nanoseconds();
```

***

See [Utils](https://bun.com/docs/runtime/utils) for more utilities.
