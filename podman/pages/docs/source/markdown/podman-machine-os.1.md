# podman-machine-os

## NAME

podman-machine-os - Manage a Podman virtual machine's OS

## SYNOPSIS

**podman machine os** *subcommand*

## DESCRIPTION

`podman machine os` is a set of subcommands that manage a Podman virtual machine's operating system.
