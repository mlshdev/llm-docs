# Workflows <a id="workflows"></a>

A workflow[^1] is a collection of nodes connected together to automate a process. [Create](https://docs.n8n.io/build/understand-workflows/create-and-run-workflows) a workflow, or use a [workflow template](https://docs.n8n.io/build/ways-of-building-workflows/use-templates) to help you get started. Once it's running, you can [share](https://docs.n8n.io/build/manage-workflows/share-with-others) it with others.

If it's your first time building a workflow, you may want to use the [quickstart guide](https://docs.n8n.io/get-started/build-your-first-workflow) to quickly try out n8n features.

## In this section

- [Create and run workflows](https://docs.n8n.io/build/understand-workflows/create-and-run-workflows): create, run, and publish workflows.
- [Save and publish workflows](https://docs.n8n.io/build/understand-workflows/save-and-publish-workflows): save, publish, unpublish, and name workflow versions.
- [Create and edit credentials](https://docs.n8n.io/build/understand-workflows/create-and-edit-credentials): securely store the authentication details your workflows need.
- [Use Gateway credits](https://docs.n8n.io/build/understand-workflows/use-gateway-credits): run supported AI models and services without setting up your own credentials.
- [Workflow components](https://docs.n8n.io/build/understand-workflows/workflow-components): the building blocks of a workflow, such as nodes and connections.
- [Understand executions](https://docs.n8n.io/build/understand-workflows/understand-executions): what an execution is, and how to view, filter, and debug them.

[^1]: An n8n workflow is a collection of nodes that automate a process. Workflows begin execution when a trigger condition occurs and execute sequentially to achieve complex tasks.
