# User management <a id="user-management"></a>

User management in n8n allows you to invite people to work in your n8n instance. It includes:

- Login and password management
- Adding and removing users
- Three built-in [instance roles](https://docs.n8n.io/administer/manage-users-and-access/understand-instance-roles): **Owner**, **Admin**, and **Member** (**Admin** is available on n8n Cloud Pro, Enterprise, and self-hosted Enterprise), plus custom instance roles

> **Info**
> **Privacy**
>
> The user management feature doesn't send personal information, such as email or username, to n8n.

## Setup guides <a id="setup-guides"></a>

This section contains most usage information for user management, and the [Cloud setup guide](https://docs.n8n.io/administer/manage-users-and-access/set-up-for-cloud). If you self-host n8n, there are extra steps to configure your n8n instance. Refer to the [Self-hosted guide](https://docs.n8n.io/deploy/host-n8n/configure-n8n/user-management).

This section includes guides to configuring [LDAP](https://docs.n8n.io/administer/manage-users-and-access/verify-user-identity/connect-ldap) and [SAML](https://docs.n8n.io/administer/manage-users-and-access/verify-user-identity/use-saml) in n8n.
