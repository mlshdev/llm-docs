# Plan a node <a id="plan-a-node"></a>

This section provides guidance on designing your node, including key technical decisions such as choosing your node building style.

When building a node, there are design choices you need to make before you start:

- Which [node type](https://docs.n8n.io/connect/create-nodes/plan-your-node/choose-a-node-type) you need to build.
- Which [node building style](https://docs.n8n.io/connect/create-nodes/plan-your-node/choose-a-node-building-style) to use.
- Your [UI design and UX principles](https://docs.n8n.io/connect/create-nodes/plan-your-node/node-ui-design)
- Your node's [file structure](https://docs.n8n.io/connect/create-nodes/plan-your-node/choose-node-file-structure).
