# Deploy a node <a id="deploy-a-node"></a>

This section contains details on how to deploy and share your node.

You can choose to:

- [Submit your node to the community node repository](https://docs.n8n.io/connect/create-nodes/deploy-your-node/submit-community-nodes). This makes it available for everyone to use, and allows you to [install and use it](https://docs.n8n.io/integrations/community-nodes/installation-and-management) like any other community node. This is the only way to use custom nodes on cloud.
- Install the node into your n8n instance as a [private node](https://docs.n8n.io/connect/create-nodes/deploy-your-node/install-private-nodes).
