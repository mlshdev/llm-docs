# Test a node <a id="test-a-node"></a>

This section contains information about testing your node.

There are two ways to test your node:

- Manually, by [running it on your own machine](https://docs.n8n.io/connect/create-nodes/test-your-node/run-your-node-locally) within a local n8n instance.
- Automatically, using the [linter](https://docs.n8n.io/connect/create-nodes/test-your-node/node-linter).

You should use both methods before publishing your node.
