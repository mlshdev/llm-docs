# WooCommerce Trigger node <a id="woocommerce-trigger-node"></a>

[WooCommerce](https://woocommerce.com/) is a customizable, open-source e-commerce plugin for WordPress.

> **Info**
> **Credentials**
>
> You can find authentication information for this node [here](https://docs.n8n.io/integrations/builtin/credentials/woocommerce).
