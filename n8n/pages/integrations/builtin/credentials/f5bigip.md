# F5 Big-IP credentials <a id="f5-big-ip-credentials"></a>

You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest) to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes).

## Prerequisites <a id="prerequisites"></a>

Create an [F5 Big-IP](https://www.f5.com/products/big-ip-services) account.

## Authentication methods <a id="authentication-methods"></a>

- Account login

## Related resources <a id="related-resources"></a>

Refer to [F5 Big-IP's API documentation](https://clouddocs.f5.com/products/big-iq/mgmt-api/v0.0/) for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes) to learn more. View [example workflows and related content](https://n8n.io/integrations/f5-big-ip/) on n8n's website.

## Using account login <a id="using-account-login"></a>

To configure this credential, you'll need:

- A **Username**: Use the username you use to log in to F5 Big-IP.
- A **Password**: Use the user password you use to log in to F5 Big-IP.
