# Sysdig Management credentials <a id="sysdig-management-credentials"></a>

You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest) to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes).

## Prerequisites <a id="prerequisites"></a>

Create a [Sysdig](https://sysdig.com) account or configure a local instance.

## Supported authentication methods <a id="supported-authentication-methods"></a>

- Access Key

## Related resources <a id="related-resources"></a>

Refer to [Sysdig's documentation](https://docs.sysdig.com/en/docs/developer-tools/sysdig-api/) for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes) to learn more.

## Using API access key <a id="using-api-access-key"></a>

To configure this credential, you'll need:

- An **Access Key**

Refer to the [Sysdig Agent Access Keys documentation](https://docs.sysdig.com/en/docs/administration/agent_access_key/) for instructions on obtaining the Access Key from the application.
