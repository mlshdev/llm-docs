# Recorded Future credentials <a id="recorded-future-credentials"></a>

You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest) to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes).

## Prerequisites <a id="prerequisites"></a>

Create a [Recorded Future](https://www.recordedfuture.com) account.

## Supported authentication methods <a id="supported-authentication-methods"></a>

- API access token

## Related resources <a id="related-resources"></a>

Refer to [Recorded Future's documentation](https://api.recordedfuture.com/index.html) for more information about the service. The rest of Recorded Future's help center requires a paid account.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes) to learn more. View [example workflows and related content](https://n8n.io/integrations/recorded-future/) on n8n's website.

## Using API access token <a id="using-api-access-token"></a>

To configure this credential, you'll need:

- An API **Access Token**

Refer to the [Recorded Future APIs documentation](https://support.recordedfuture.com/hc/en-us/categories/16372120363539-Recorded-Future-APIs) for more information on getting your API access token.
