# DFIR-IRIS credentials <a id="dfir-iris-credentials"></a>

You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest) to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes).

## Prerequisites <a id="prerequisites"></a>

An accessible instance of [DFIR-IRIS](https://docs.dfir-iris.org/latest/getting_started/).

## Related resources <a id="related-resources"></a>

Refer to [DFIR-IRIS's API documentation](https://docs.dfir-iris.org/operations/api/) for more information about authenticating with the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes) to learn more. View [example workflows and related content](https://n8n.io/integrations/iris-dfir/) on n8n's website.

## Using API Key <a id="using-api-key"></a>

To configure this credential, you'll need:

- An **API Key**: Refer to [DFIR-IRIS's API documentation](https://docs.dfir-iris.org/operations/api/) for instructions on getting your API key.
- The **Base URL** of your DFIR-IRIS instance.
