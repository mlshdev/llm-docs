# Coda node <a id="coda-node"></a>

Use the Coda node to automate work in Coda, and integrate Coda with other applications. n8n has built-in support for a wide range of Coda features, including creating, getting, and deleting controls, formulas, tables, and views.

On this page, you'll find a list of operations the Coda node supports and links to more resources.

> **Info**
> **Credentials**
>
> Refer to [Coda credentials](https://docs.n8n.io/integrations/builtin/credentials/coda) for guidance on setting up authentication.

## Operations <a id="operations"></a>

- Control
  - Get a control
  - Get all controls
- Formula
  - Get a formula
  - Get all formulas
- Table
  - Create/Insert a row
  - Delete one or multiple rows
  - Get all columns
  - Get all the rows
  - Get a column
  - Get a row
  - Pushes a button
- View
  - Delete view row
  - Get a view
  - Get all views
  - Get all views columns
  - Get all views rows
  - Update row
  - Push view button
