# Set the Cloud instance timezone <a id="set-the-cloud-instance-timezone"></a>

You can change the timezone for your n8n instance. This affects the [Schedule Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.scheduletrigger) and [Date & Time node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.datetime). Users can configure the timezone for individual workflows in [Workflow settings](https://docs.n8n.io/build/manage-workflows/configure-workflow-settings).

1. On your dashboard, select **Manage**.
2. Change the **Timezone** dropdown to the timezone you want.
