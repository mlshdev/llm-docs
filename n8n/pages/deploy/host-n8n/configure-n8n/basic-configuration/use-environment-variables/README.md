# Environment variables overview <a id="environment-variables-overview"></a>

This section lists the environment variables that you can use to change n8n's configuration settings when self-hosting n8n.

> **Info**
> **File-based configuration**
>
> You can provide a [configuration file](https://docs.n8n.io/deploy/host-n8n/configure-n8n/basic-configuration) for n8n. You can also append `_FILE` to certain variables to provide their configuration in a separate file.
