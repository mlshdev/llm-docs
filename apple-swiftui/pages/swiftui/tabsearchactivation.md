# TabSearchActivation

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

Configures the activation behavior of search in the search tab.

## Declaration

```swift
struct TabSearchActivation
```

## Overview

You can configure this for a particular [TabView](tabview.md) by using the [tabViewSearchActivation(\_:)](view/tabviewsearchactivation%28__%29.md) modifier.

## Topics

### Type Properties

- [automatic](tabsearchactivation/automatic.md): The default search activation behavior.
- [searchTabSelection](tabsearchactivation/searchtabselection.md): Links the search tab’s selection to search activation.
