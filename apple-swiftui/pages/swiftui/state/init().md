# init()

**Framework:** SwiftUI  
**Kind:** Initializer  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · macOS 10.15+ · tvOS 13.0+ · visionOS 1.0+ · watchOS 6.0+

Creates a state property without an initial value.

## Declaration

```swift
init()
```

<a id="discussion"></a>

## Discussion

This initializer behaves like the [init(wrappedValue:)](init%28wrappedvalue_%29.md) initializer with an input of `nil`. See that initializer for more information.
