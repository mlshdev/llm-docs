# Building a document-based app using SwiftData (Swift)

**Framework:** SwiftUI  
**Kind:** Sample Code  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · macOS 14.0+ · Xcode 15.0+

Code along with the WWDC presenter to transform an app with SwiftData.

<a id="Overview"></a>

## Overview

Learn how to use [`@Query`](https://developer.apple.com/documentation/swiftdata/query), [`@Bindable`](bindable.md), [`.modelContainer`](view/modelcontainer%28__%29.md), the [`.modelContext`](environmentvalues/modelcontext.md) environment variable, and [`DocumentGroup`](documentgroup.md) to integrate with the [`SwiftData`](https://developer.apple.com/documentation/swiftdata) framework.

> **Note**

> This sample code project is associated with WWDC23 session 10154: [Build an app with SwiftData](https://developer.apple.com/wwdc23/10154/).
