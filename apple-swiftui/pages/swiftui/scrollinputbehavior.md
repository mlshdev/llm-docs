# ScrollInputBehavior

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · macOS 15.0+ · tvOS 18.0+ · visionOS 2.0+ · watchOS 11.0+

A type that defines whether input should scroll a view.

## Declaration

```swift
struct ScrollInputBehavior
```

## Topics

### Type Properties

- [automatic](scrollinputbehavior/automatic.md): Indicates that the system should determine whether the associated input scrolls a view.
- [disabled](scrollinputbehavior/disabled.md): Indicates that the associated input should not scroll a view.
- [enabled](scrollinputbehavior/enabled.md): Indicates that the associated input should scroll a view.
