# Text.Case.uppercase

**Framework:** SwiftUI  
**Kind:** Case  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · macOS 11.0+ · tvOS 14.0+ · visionOS 1.0+ · watchOS 7.0+

Displays text in all uppercase characters.

## Declaration

```swift
case uppercase
```

<a id="discussion"></a>

## Discussion

For example, “Hello” would be displayed as “HELLO”.
