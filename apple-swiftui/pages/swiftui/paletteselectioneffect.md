## Overview

You can configure the selection effect of a palette item by using the [paletteSelectionEffect(\_:)](view/paletteselectioneffect%28__%29.md) view modifier.

## Topics

### Getting palette selection effects

- [automatic](paletteselectioneffect/automatic.md): Applies the system’s default effect when selected.
- [custom](paletteselectioneffect/custom.md): Does not apply any system effect when selected.
- [symbolVariant(\_:)](paletteselectioneffect/symbolvariant%28__%29.md): Applies the specified symbol variant when selected.
