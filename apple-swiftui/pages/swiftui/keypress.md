## Topics

### Getting the keypress

- [key](keypress/key.md): The key equivalent value for the pressed key.
- [characters](keypress/characters.md): The characters generated by the pressed key as if no modifier key applies.
- [modifiers](keypress/modifiers.md): The set of modifier keys the user held in addition to the pressed key.

### Getting the phase of the keypress

- [phase](keypress/phase.md): The phase of the key-press event (`.down`, `.repeat`, or `.up`).
- [KeyPress.Phases](keypress/phases.md): Options for matching different phases of a key-press event.

### Getting the result

- [KeyPress.Result](keypress/result.md): A result value returned from a key-press action that indicates whether the action consumed the event.
