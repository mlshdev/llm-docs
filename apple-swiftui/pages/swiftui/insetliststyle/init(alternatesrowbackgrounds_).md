# init(alternatesRowBackgrounds:)

**Framework:** SwiftUI  
**Kind:** Initializer  
**Availability:** macOS 12.0+ (deprecated in 27.2)

Creates an inset list style with optional alternating row backgrounds.

> Use the [inset](../liststyle/inset.md) style and add the [alternatingRowBackgrounds(\_:)](../view/alternatingrowbackgrounds%28__%29.md) view modifier instead.
