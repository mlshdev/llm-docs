# EmptyHoverEffect

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 18.0+ · iPadOS 18.0+ · Mac Catalyst 18.0+ · tvOS 18.0+ · visionOS 2.0+

A base hover effect used to build additional effects.

## Declaration

```swift
struct EmptyHoverEffect
```

<a id="overview"></a>

## Overview

`EmptyHoverEffect` does not change a view on hover.
