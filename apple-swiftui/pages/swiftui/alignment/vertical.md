# vertical

**Framework:** SwiftUI  
**Kind:** Instance Property  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · macOS 10.15+ · tvOS 13.0+ · visionOS 1.0+ · watchOS 6.0+

The alignment on the vertical axis.

## Declaration

```swift
var vertical: VerticalAlignment
```

<a id="discussion"></a>

## Discussion

Set this value when you initialize an alignment using the [init(horizontal:vertical:)](init%28horizontal_vertical_%29.md) method. Use one of the built-in [VerticalAlignment](../verticalalignment.md) guides, like [center](../verticalalignment/center.md), or a custom guide that you create.

For information about creating custom guides, see [AlignmentID](../alignmentid.md).
