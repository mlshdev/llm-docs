# BorderedTextFieldStyle

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 27.0+ · iPadOS 27.0+ · Mac Catalyst 27.0+ · macOS 27.0+ · tvOS 27.0+ · visionOS 27.0+ · watchOS 27.0+

A text field style with a system-defined border.

## Declaration

```swift
struct BorderedTextFieldStyle
```

<a id="overview"></a>

## Overview

The shape of the border is determined by the [textInputBorderShape(\_:)](view/textinputbordershape%28__%29.md) modifier.

You can also use [bordered](textfieldstyle/bordered.md) to construct this style.
