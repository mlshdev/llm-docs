# NavigationBarItem

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · tvOS 13.0+ · visionOS 1.0+ · watchOS 6.0+

A configuration for a navigation bar that represents a view at the top of a navigation stack.

## Declaration

```swift
struct NavigationBarItem
```

<a id="overview"></a>

## Overview

Use one of the [NavigationBarItem.TitleDisplayMode](navigationbaritem/titledisplaymode.md) values to configure a navigation bar title’s display mode with the [navigationBarTitleDisplayMode(\_:)](view/navigationbartitledisplaymode%28__%29.md) view modifier.
