# coexist

**Framework:** SwiftUI  
**Kind:** Type Property  
**Availability:** visionOS 26.0+

A behavior that keeps the system’s immersive environment as is when opening a scene.

## Declaration

```swift
static var coexist: ImmersiveEnvironmentBehavior { get }
```

<a id="discussion"></a>

## Discussion

Use this value with the [immersiveEnvironmentBehavior(\_:)](../scene/immersiveenvironmentbehavior%28__%29.md) scene modifier to define that the system should allow the system’s immersive environment to co-exist with the scene.
