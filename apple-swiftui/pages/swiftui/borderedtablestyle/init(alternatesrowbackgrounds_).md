# init(alternatesRowBackgrounds:)

**Framework:** SwiftUI  
**Kind:** Initializer  
**Availability:** macOS 12.0+ (deprecated in 27.0)

Creates an inset table style with optional alternating row backgrounds.

> Use the [bordered](../liststyle/bordered.md) style and add the [alternatingRowBackgrounds(\_:)](../view/alternatingrowbackgrounds%28__%29.md) view modifier instead.

## Declaration

```swift
nonisolated init(alternatesRowBackgrounds: Bool)
```
