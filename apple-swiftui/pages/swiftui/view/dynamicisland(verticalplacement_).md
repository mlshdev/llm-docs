# dynamicIsland(verticalPlacement:)

**Framework:** SwiftUI  
**Kind:** Instance Method  
**Availability:** iOS 16.1+ · iPadOS 16.1+

Specifies the vertical placement for a view of an expanded Live Activity that appears in the Dynamic Island.


## Parameters
