# WheelPickerStyle

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 13.0+ · iPadOS 13.0+ · Mac Catalyst 13.0+ · visionOS 1.0+ · watchOS 6.0+

A picker style that presents the options in a scrollable wheel that shows the selected option and a few neighboring options.


### Supporting types
