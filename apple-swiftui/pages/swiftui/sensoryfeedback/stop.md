# stop

**Framework:** SwiftUI  
**Kind:** Type Property  
**Availability:** iOS 17.0+ · iPadOS 17.0+ · Mac Catalyst 17.0+ · macOS 14.0+ · tvOS 17.0+ · visionOS 26.0+ · watchOS 10.0+

Indicates that an activity stopped.

## Declaration

```swift
static let stop: SensoryFeedback
```

<a id="discussion"></a>

## Discussion

Use this haptic when stopping a timer or other activity that was previously started.

Only plays feedback on watchOS.
