# SensoryFeedback.SelectionFeedback

**Framework:** SwiftUI  
**Kind:** Structure  
**Availability:** iOS 26.0+ · iPadOS 26.0+ · Mac Catalyst 26.0+ · macOS 26.0+ · tvOS 26.0+ · visionOS 26.0+ · watchOS 26.0+

Feedback that can be played in response to a specific UI element’s values changing.

## Topics

### Type Properties

- [maximum](selectionfeedback/maximum.md): Indicates that a control’s maximum value has been reached, such as when a slider’s thumb is dragged to the slider’s maximum value.
- [minimum](selectionfeedback/minimum.md): Indicates that a control’s minimum value has been reached, such as when a slider’s thumb is dragged to the slider’s minimum value.
- [off](selectionfeedback/off.md): Indicates that a control’s value has changed to off, such as when a toggle is released and turned off.
- [on](selectionfeedback/on.md): Indicates that a control’s value has changed to on, such as when a toggle is tapped to turn on.
