# LibraryPlaylistFolders.Attributes

**Interface language:** Data

**Framework:** Apple Music API  
**Kind:** Object  
**Availability:** Apple Music 1.0+

A resource object that represents the attributes for a library playlist folder.

## Declaration

```
object LibraryPlaylistFolders.Attributes
```

## Properties

- `dateAdded` — `string`: The date this content added to the user’s library in ISO-8601 format.
- `name` — `string` (required): The (potentially) censored name of the content.
