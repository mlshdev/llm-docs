# textBaseline Constants

**Interface language:** Data

**Framework:** WebKit JS  
**Kind:** API Collection

Constants used to set the `textBaseline` property that specify the vertical alignment of the bounding box relative to its y-coordinate.

## Topics

### Constants

- [top](textbaseline_constants/1805390-top.md): Aligns the y-coordinate of the bounding box with top of text glyphs.
- [hanging](textbaseline_constants/1805396-hanging.md): Aligns the y-coordinate of the bounding box just below the top of text glyphs.
- [middle](textbaseline_constants/1805398-middle.md): Aligns the y-coordinate of the bounding box with the middle of text glyphs.
- [alphabetic](textbaseline_constants/1805402-alphabetic.md): Aligns the y-coordinate of the bounding box with the bottom of alphabetic text glyphs without descenders.
- [ideographic](textbaseline_constants/1805407-ideographic.md): Aligns the y-coordinate of the bounding box with the bottom of ideographic text glyphs.
- [bottom](textbaseline_constants/1805412-bottom.md): Aligns the y-coordinate of the bounding box with the bottom of text glyphs with descenders.
