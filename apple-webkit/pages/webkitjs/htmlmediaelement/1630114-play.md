# play

**Interface language:** Data

**Framework:** WebKit JS  
**Kind:** Instance Method  
**Availability:** Safari Desktop 3.1+ · Safari Mobile 3.0+

Begins playing the media resource.

## Declaration

```
Promise <void> play();
```

<a id="discussion"></a>

## Discussion

If the media resource is not available for playback, this method loads it.

### Controlling Playback

- [canPlayType](1630268-canplaytype.md): Returns whether the media element supports the specified MIME type.
- [load](1629903-load.md): Starts loading the media resource.
- [pause](1633571-pause.md): Pauses the media playback if in progress.
