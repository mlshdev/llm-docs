# ondeviceorientation

**Interface language:** Data

**Framework:** WebKit JS  
**Kind:** Instance Property  
**Availability:** Safari Desktop 10.1+ · Safari Mobile 4.2+

The event listener that is called while the device orientation changes around the x, y, and z axes.
