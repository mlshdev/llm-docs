# PointsOfInterest

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.73+

Prioritizes loading of the full standard map, with rendered POIs.

## Declaration

```
readonly PointsOfInterest: "PointsOfInterest";
```

## See Also

### Prioritizations

- [LandCover](landcover.md): Prioritizes loading of the map land cover and borders, without POIs or labels.
- [None](none.md): Signifies no preference for what to prioritize when loading the map.
