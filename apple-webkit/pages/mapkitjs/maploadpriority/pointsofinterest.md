# PointsOfInterest

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.73+

Prioritizes loading of the full standard map, with rendered POIs.

```
readonly PointsOfInterest: "PointsOfInterest";
```
