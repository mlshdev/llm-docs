# copy()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Returns a copy of the map size object.

## Declaration

```
copy(): MapSize;
```

<a id="return-value"></a>

## Return Value

A MapSize object that is a copy of the original.
