# tintColor

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The CSS color that MapKit JS uses for the user interface controls on the map.

## Declaration

```
tintColor?: string;
```

<a id="Discussion"></a>

## Discussion

Use [tintColor](tintcolor.md) to color the outline of the controls, text, and glyphs. Use any valid [CSS color value](https://www.w3.org/TR/css-color-3/).
