# overlays

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

An array that contains all of the map’s overlays.

## Declaration

```
overlays?: Overlay[];
```

<a id="Discussion"></a>

## Discussion

The default value is `[]` (empty array).
