# showsUserLocation

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that determines whether to show the user’s location on the map.

## Declaration

```
showsUserLocation?: boolean;
```

<a id="Discussion"></a>

## Discussion

The default value is `false`.

## See Also

### Enabling user location

- [tracksUserLocation](tracksuserlocation.md): A Boolean value that determines whether to center the map on the user’s location.
- [showsUserLocationControl](showsuserlocationcontrol.md): A Boolean value that determines whether the user location control is visible.
