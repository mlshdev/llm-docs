# rotation

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The map’s rotation, in degrees.

## Declaration

```
rotation?: number;
```

## Discussion

The default value is `0.`
