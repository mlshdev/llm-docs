# copy()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Returns a copy of a map rectangle.

## Declaration

```
copy(): MapRect;
```

<a id="return-value"></a>

## Return Value

A MapRect object that is a copy of the original.
