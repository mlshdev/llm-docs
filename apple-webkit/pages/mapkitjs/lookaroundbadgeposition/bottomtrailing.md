# BottomTrailing

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.79+

Places the badge on the bottom trailing corner of the Look Around preview.

## Declaration

```
readonly BottomTrailing: "bottomTrailing";
```
