# data

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Property  
**Availability:** MapKit JS 5.0+

Custom data to associate with the overlay.

## Declaration

```
get data(): {};
set data(data: {});
```

<a id="Discussion"></a>

## Discussion

You choose the data to assign to the overlay. It can be any JavaScript value.
