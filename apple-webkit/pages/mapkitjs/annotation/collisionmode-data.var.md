# CollisionMode

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Static Property  
**Availability:** MapKit JS 5.0+ (deprecated in 6.0)

A static property that allows you to access the annotation’s collision mode enumeration values.

> Please use mapkit.AnnotationCollisionMode instead.
