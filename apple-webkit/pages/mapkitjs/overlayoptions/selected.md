# selected

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that indicates whether the overlay is in a selected state.

## Declaration

```
selected?: boolean;
```

<a id="Discussion"></a>

## Discussion

The default value is `false`.
