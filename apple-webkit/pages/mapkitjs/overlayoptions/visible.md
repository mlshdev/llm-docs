# visible

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that determines if an overlay is visible.

## Declaration

```
visible?: boolean;
```

<a id="Discussion"></a>

## Discussion

The default value is `true`.
