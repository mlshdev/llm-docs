# places

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A list of places that match the search query.

## Declaration

```
places: Place[];
```

<a id="Discussion"></a>

## Discussion

The [places](places.md) array is empty if there is no match.
