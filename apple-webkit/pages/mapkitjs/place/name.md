# name

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Property  
**Availability:** MapKit JS 5.0+

The name of the place.

## Declaration

```
name: string | null;
```

<a id="Discussion"></a>

## Discussion

For example, the name for a specific place in Golden Gate Park in San Francisco, California, is `"Lindley Meadow"`.
