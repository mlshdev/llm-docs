# dependentLocalities

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Property  
**Availability:** MapKit JS 5.41.1+

Common names for the local area or neighborhood of the place.

## Declaration

```
dependentLocalities: string[] | null;
```

<a id="Discussion"></a>

## Discussion

For example, dependent localities for Golden Gate Park in San Francisco, CA are `["Golden Gate Park"].`
