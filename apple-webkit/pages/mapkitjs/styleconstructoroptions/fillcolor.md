# fillColor

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The fill color of a shape.

## Declaration

```
fillColor?: string;
```

<a id="Discussion"></a>

## Discussion

This can be any valid CSS color value. Set to `null` for no fill. The default fill color is `rgb(0, 122, 255)`.
