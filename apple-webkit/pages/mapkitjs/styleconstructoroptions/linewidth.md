# lineWidth

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The width of a line’s stroke, in CSS pixels.

## Declaration

```
lineWidth?: number;
```

<a id="Discussion"></a>

## Discussion

The default line width is `1`.
