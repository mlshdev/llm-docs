# center

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.45+

Sets the center point of the request represented as latitude and longitude.

## Declaration

```
center?: CoordinateData;
```
