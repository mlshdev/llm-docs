# collisionMode

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Property  
**Availability:** MapKit JS 5.74.1+

A value that determines how the map handles collisions between annotations.

## Declaration

```
get collisionMode(): AnnotationCollisionMode;
```

## Discussion

You can’t set the collision mode property of the map feature annotation.
