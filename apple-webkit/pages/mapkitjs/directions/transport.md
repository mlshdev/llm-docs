# Transport

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Static Property  
**Availability:** MapKit JS 5.0+ (deprecated in 6.0)

A static property that refers to an object that describes the available transport type values.

> Please use mapkit.TransportType instead.

## Declaration

```
static get Transport(): typeof TransportType;
```
