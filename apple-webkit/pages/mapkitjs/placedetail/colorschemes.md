# ColorSchemes

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Static Property  
**Availability:** MapKit JS 5.78.1+ (deprecated in 6.0)

A static property that allows you to access the Look Around color scheme enumeration.

> Please use mapkit.ColorScheme instead.

## Declaration

```
static get ColorSchemes(): typeof ColorScheme;
```
