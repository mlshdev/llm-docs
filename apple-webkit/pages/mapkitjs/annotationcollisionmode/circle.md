# Circle

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.0+

Uses a circle inscribed in the collision frame rectangle to detect collisions.

## Declaration

```
readonly Circle: "circle";
```

<a id="discussion"></a>

## Discussion

The circle inscribed in the bounding box is used for collision detection.

## See Also

### Collision modes

- [Rectangle](rectangle.md): Uses the full collision frame rectangle to detect collisions.
- [None](none.md): A collision mode in which the annotation doesn’t collide with other annotations.
