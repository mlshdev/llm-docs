# Rectangle

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.0+

Uses the full collision frame rectangle to detect collisions.

## Declaration

```
readonly Rectangle: "rectangle";
```

<a id="discussion"></a>

## Discussion

The bounding box of the annotation is used for collision detection.

## See Also

### Collision modes

- [Circle](circle.md): Uses a circle inscribed in the collision frame rectangle to detect collisions.
- [None](none.md): A collision mode in which the annotation doesn’t collide with other annotations.
