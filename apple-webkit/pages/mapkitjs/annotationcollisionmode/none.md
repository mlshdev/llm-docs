# None

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.50+

A collision mode in which the annotation doesn’t collide with other annotations.

## Declaration

```
readonly None: "none";
```

## Mentioned In

- [MapKit JS 5](../mapkit-js-5.md)

<a id="discussion"></a>

## Discussion

The annotation does not collide with other annotations.

### Collision modes

- [Rectangle](rectangle.md): Uses the full collision frame rectangle to detect collisions.
