# destroy()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Removes the map’s element from the DOM and releases internal references to the map to free up memory.

## Declaration

```
destroy(): void;
```

## Return Value

This method returns no value.
