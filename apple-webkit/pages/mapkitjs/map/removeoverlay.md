# removeOverlay(overlay)

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Removes an overlay from the map.

## Declaration

```
removeOverlay(overlay: Overlay): Overlay;
```

## Parameters

- `overlay`: The overlay to remove.

<a id="return-value"></a>

## Return Value

Returns the overlay.
