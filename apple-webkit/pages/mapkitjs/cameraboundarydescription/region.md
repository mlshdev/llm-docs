# region

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.23+

A rectangular area on a map, defined by coordinates of the rectangle’s northeast and southwest corners.

## Declaration

```
region: CoordinateRegion;
```

<a id="Discussion"></a>

## Discussion

The region property is an instance of [CoordinateRegion](../coordinateregion.md)
