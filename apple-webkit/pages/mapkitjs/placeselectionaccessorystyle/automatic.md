# Automatic

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.78.1+

A style that MapKit automatically chooses based on the size of the map view.

## Declaration

```
readonly Automatic: "automatic";
```
