# Callout

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Enumeration Case  
**Availability:** MapKit JS 5.78.1+

A style that selects between a full and compact presentation based on the map’s size.

## Declaration

```
readonly Callout: "callout";
```

## See Also

### Style values

- [Automatic](automatic.md): A style that MapKit automatically chooses based on the size of the map view.
- [CompactCallout](compactcallout.md): A style that displays a compact, space-saving presentation.
- [FullCallout](fullcallout.md): A style that displays a rich, detailed presentation.
- [OpenInMaps](openinmaps.md): A style that displays a caption to open in Maps.
