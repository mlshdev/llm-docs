# color

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Property  
**Availability:** MapKit JS 5.74+

The color of the place.

## Declaration

```
get color(): string;
```

<a id="Discussion"></a>

## Discussion

Not all places have a color. You can’t set the color property of the place annotation.
