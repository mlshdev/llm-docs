# subtitle

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The text to display as a subtitle on the second line of an annotation’s callout.

## Declaration

```
subtitle?: string;
```

<a id="Discussion"></a>

## Discussion

The default value is `null`.
