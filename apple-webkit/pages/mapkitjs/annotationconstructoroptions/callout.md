# callout

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A delegate that enables you to customize the annotation’s callout.

## Declaration

```
callout?: AnnotationCalloutDelegate | null;
```

<a id="Discussion"></a>

## Discussion

The default value is `null`. See [AnnotationCalloutDelegate](../annotationcalloutdelegate.md) for details.

## See Also

### Creating callouts

- [calloutEnabled](calloutenabled.md): A Boolean value that determines whether the map shows a callout.
- [calloutOffset](calloutoffset.md): The offset, in CSS pixels, of a callout from the top center of the element.
