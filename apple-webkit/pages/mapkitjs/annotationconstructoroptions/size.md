# size

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

The desired dimensions of the annotation, in CSS pixels.

## Declaration

```
size?: Size;
```

<a id="Discussion"></a>

## Discussion

The desired dimensions (width × height) of the annotation, in CSS pixels.
