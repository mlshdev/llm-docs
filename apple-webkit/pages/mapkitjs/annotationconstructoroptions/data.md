# data

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

Data that you define and assign to the annotation.

## Declaration

```
data?: object;
```

<a id="Discussion"></a>

## Discussion

Custom data to associate with this annotation. The default value is `{}.`
