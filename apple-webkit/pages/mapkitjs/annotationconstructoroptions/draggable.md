# draggable

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that determines whether the user can drag the annotation.

## Declaration

```
draggable?: boolean;
```

<a id="Discussion"></a>

## Discussion

The default value is `false`.
