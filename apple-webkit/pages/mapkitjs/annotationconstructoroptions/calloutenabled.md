# calloutEnabled

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that determines whether the map shows a callout.

## Declaration

```
calloutEnabled?: boolean;
```

<a id="Discussion"></a>

## Discussion

The default value is `true`.

## See Also

### Creating callouts

- [callout](callout.md): A delegate that enables you to customize the annotation’s callout.
- [calloutOffset](calloutoffset.md): The offset, in CSS pixels, of a callout from the top center of the element.
