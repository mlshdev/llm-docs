# displayPriority

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A hint the map uses to prioritize displaying the annotation.

## Declaration

```
displayPriority?: AnnotationDisplayPriority;
```
