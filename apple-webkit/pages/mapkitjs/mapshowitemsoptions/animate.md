# animate

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

A Boolean value that determines whether the map animates as the map region changes to show the items.

## Declaration

```
animate?: boolean;
```
