# padding

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

Spacing that the framework adds around the computed map region when showing items.

## Declaration

```
padding?: PaddingData;
```

## See Also

### Show item options

- [animate](animate.md): A Boolean value that determines whether the map animates as the map region changes to show the items.
- [minimumSpan](minimumspan.md): The minimum longitudinal and latitudinal span the map displays.
- [cameraDistance](cameradistance.md): The distance from the center of the map to the camera, when showing the items.
