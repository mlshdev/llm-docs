# toCoordinateRegion()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Returns the coordinate region that corresponds to the calling bounding region.

## Declaration

```
toCoordinateRegion(): CoordinateRegion;
```
