# copy()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Returns a copy of the calling bounding region.

## Declaration

```
copy(): BoundingRegion;
```

<a id="return-value"></a>

## Return Value

A [BoundingRegion](../boundingregion.md) that is a copy of the calling bounding region.
