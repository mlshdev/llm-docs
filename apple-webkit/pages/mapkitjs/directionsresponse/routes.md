# routes

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Interface Property  
**Availability:** MapKit JS 5.0+

An array of route objects.

## Declaration

```
routes: Route[];
```

<a id="Discussion"></a>

## Discussion

The server returns up to three [Route](../route.md) objects in the array.
