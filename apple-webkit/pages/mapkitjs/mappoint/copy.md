# copy()

**Interface language:** Data

**Framework:** MapKit JS  
**Kind:** Instance Method  
**Availability:** MapKit JS 5.0+

Returns a copy of the location.

## Declaration

```
copy(): MapPoint;
```

<a id="return-value"></a>

## Return Value

A MapPoint object that is a copy of the map location.
