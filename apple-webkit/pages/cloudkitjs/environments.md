# Environments

**Interface language:** Data

**Framework:** CloudKit JS  
**Kind:** API Collection

Constants to use when configuring the environment of containers.

## Topics

### Constants

- [DEVELOPMENT_ENVIRONMENT](cloudkit/development_environment.md): The container environment is not accessible by apps available on the store.
- [PRODUCTION_ENVIRONMENT](cloudkit/production_environment.md): The container environment is accessible by both development apps and apps available on the store.
