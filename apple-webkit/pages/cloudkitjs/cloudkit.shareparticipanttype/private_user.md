# PRIVATE_USER

**Interface language:** Data

**Framework:** CloudKit JS  
**Kind:** Enumeration Case  
**Availability:** CloudKit JS 1.0+

Participants who were invited to share the record by the owner.

## Declaration

```
const String PRIVATE_USER;
```

## See Also

### Enumeration Cases

- [OWNER](owner.md): The owner of the shared record who can add private users but not add public users.
- [PUBLIC_USER](public_user.md): Participants who accepted a shared record by accessing the share URL.
- [UNKNOWN](unknown.md): Unknown type of participant.
