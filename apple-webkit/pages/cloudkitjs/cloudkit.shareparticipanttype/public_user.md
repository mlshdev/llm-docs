# PUBLIC_USER

**Interface language:** Data

**Framework:** CloudKit JS  
**Kind:** Enumeration Case  
**Availability:** CloudKit JS 1.0+

Participants who accepted a shared record by accessing the share URL.

## Declaration

```
const String PUBLIC_USER;
```
