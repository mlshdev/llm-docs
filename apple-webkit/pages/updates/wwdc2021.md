# WWDC21

**Framework:** Updates

Highlights of new technologies introduced at WWDC21.

<a id="Overview"></a>

## Overview

Newer documentation highlights are available in [WWDC22](wwdc2022.md). This page is an archive from WWDC21.

Check out a selection of documentation for new technologies, frameworks, and APIs introduced at WWDC21. Existing frameworks have added significant functionality, and you’ll find new ways to enhance your apps targeting the latest platform release.

## Topics

### Xcode Cloud

- [Xcode Cloud](https://developer.apple.com/documentation/xcode/xcode-cloud): Automatically build, test, and distribute your apps with Xcode Cloud to verify changes and create high-quality apps.
- [About continuous integration and delivery with Xcode Cloud](https://developer.apple.com/documentation/xcode/about-continuous-integration-and-delivery-with-xcode-cloud): Learn how continuous integration and delivery with Xcode Cloud helps you create high-quality apps and frameworks.
- [Configuring your first Xcode Cloud workflow](https://developer.apple.com/documentation/xcode/configuring-your-first-xcode-cloud-workflow): Set up your project or workspace to use Xcode Cloud and adopt continuous integration and delivery.

### SwiftUI

- [Building a great Mac app with SwiftUI](https://developer.apple.com/documentation/swiftui/building-a-great-mac-app-with-swiftui): Create engaging SwiftUI Mac apps by incorporating side bars, tables, toolbars, and several other popular user interface elements.
- [Add rich graphics to your SwiftUI app](https://developer.apple.com/documentation/swiftui/add-rich-graphics-to-your-swiftui-app): Make your apps stand out by adding background materials, vibrancy, custom graphics, and animations.
- [TimelineView](https://developer.apple.com/documentation/swiftui/timelineview): A view that updates according to a schedule that you provide.
- [AsyncImage](https://developer.apple.com/documentation/swiftui/asyncimage): A view that asynchronously loads and displays an image.
- [FocusState](https://developer.apple.com/documentation/swiftui/focusstate): A property wrapper type that can read and write a value that SwiftUI updates as the placement of focus within the scene changes.
- [Table](https://developer.apple.com/documentation/swiftui/table): A container that presents rows of data arranged in one or more columns, optionally providing the ability to select one or more members.
- [Canvas](https://developer.apple.com/documentation/swiftui/canvas): A view type that supports immediate mode drawing.
- [Material](https://developer.apple.com/documentation/swiftui/material): A background material type.
- [swipeActions(edge:allowsFullSwipe:content:)](https://developer.apple.com/documentation/swiftui/view/swipeactions%28edge:allowsfullswipe:content:%29): Adds custom swipe actions to a row in a list.
- [badge(\_:)](https://developer.apple.com/documentation/swiftui/view/badge%28_:%29-84e43): Generates a badge for the view from a localized string key.
- [searchable(text:placement:prompt:)](https://developer.apple.com/documentation/swiftui/view/searchable%28text:placement:prompt:%29-18a8f): Marks this view as searchable, which configures the display of a search field.
- [listRowSeparatorTint(\_:edges:)](https://developer.apple.com/documentation/swiftui/view/listrowseparatortint%28_:edges:%29): Sets the tint color associated with a row.
- [previewInterfaceOrientation(\_:)](https://developer.apple.com/documentation/swiftui/view/previewinterfaceorientation%28_:%29): Deprecated. Overrides the orientation of the preview.
- [symbolVariant(\_:)](https://developer.apple.com/documentation/swiftui/view/symbolvariant%28_:%29): Makes symbols within the view show a particular variant.
- [symbolRenderingMode(\_:)](https://developer.apple.com/documentation/swiftui/view/symbolrenderingmode%28_:%29): Sets the rendering mode for symbol images within this view.

### App Store

- [StoreKit](https://developer.apple.com/documentation/storekit): Support In-App Purchases and interactions with the App Store.

- [Transaction](https://developer.apple.com/documentation/storekit/transaction): Information that represents the customer’s purchase of a product in your app.
- [App Store Connect API](../appstoreconnectapi.md): The data structure that represents an app store connect api resource.

- [App Store Server API](https://developer.apple.com/documentation/appstoreserverapi): Manage your customers’ App Store transactions from your server.
