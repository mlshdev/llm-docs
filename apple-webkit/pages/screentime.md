# Screen Time (Swift)

**Framework:** Screen Time  
**Kind:** Framework  
**Availability:** iOS 14.0+ · iPadOS 14.0+ · Mac Catalyst 14.0+ · macOS 11.0+

Share and manage web-usage data, and observe changes made by a parent or guardian.

<a id="Overview"></a>

## Overview

The Screen Time framework gives you the tools you need to help parents and guardians supervise their children’s web usage. Use this framework to:

- Report web-usage data.
- Delete history.
- Take action when a parent or guardian blocks a URL or begins enforcing child restrictions.

> **Note**

> In a compatible iPad or iPhone app running in visionOS, the APIs of this framework do nothing.

## Topics

### Essentials

- [STWebpageController](screentime/stwebpagecontroller.md): The controller you use to report web usage and block restricted webpages.

### Configuration queries

- [STScreenTimeConfigurationObserver](screentime/stscreentimeconfigurationobserver.md): The object you use to observe changes to the current configuration.
- [STScreenTimeConfiguration](screentime/stscreentimeconfiguration.md): The configuration for this device.

### Web-Usage data deletion

- [STWebHistory](screentime/stwebhistory.md): The object you use to delete web-usage data.
