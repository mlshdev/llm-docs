# Web History Dictionary Keys

**Interface languages:** Swift, Objective-C

**Framework:** WebKit  
**Kind:** API Collection

The key for accessing the web history items stored in a notification’s user information dictionary.

<a id="overview"></a>

## Overview

This string is used as the key in the `userInfo` dictionary passed as the argument to the [WebHistoryAllItemsRemovedNotification](webhistoryallitemsremovednotification.md), [WebHistoryItemsAddedNotification](webhistoryitemsaddednotification.md), and [WebHistoryItemsRemovedNotification](webhistoryitemsremovednotification.md) notifications.

## Topics

### Constants

- [WebHistoryItemsKey](webhistoryitemskey.md): Deprecated. The key to access an array containing the added or removed web history items.
