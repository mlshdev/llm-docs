# plugInsEnabled (Swift)

**Framework:** WebKit  
**Kind:** Instance Property  
**Availability:** macOS 10.10+ (deprecated in 10.15)

A Boolean value that indicates whether plug-ins are enabled.

> Plug-ins are no longer supported

## Declaration

```swift

```

<a id="Discussion"></a>

## Discussion
