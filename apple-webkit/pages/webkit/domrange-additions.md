# DOMRange Additions

**Interface languages:** Swift, Objective-C

**Framework:** WebKit  
**Kind:** API Collection

Additions to the `DOMRange` class facilitate communication between the DOM API and WebKit and help convert web content into standard markup form.

## Topics

### Creating archives

- [webArchive](domrange/webarchive.md): A web archive of the content in the range.

### Formatting content ranges

- [markupString](domrange/markupstring.md): A string in markup format corresponding to the content in the range.
