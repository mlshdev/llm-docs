# canMakeTextSmaller (Swift)

**Framework:** WebKit  
**Kind:** Instance Property  
**Availability:** macOS

A Boolean that indicates whether the text can be made smaller.

## Declaration

```swift
var canMakeTextSmaller: Bool { get }
```

<a id="Discussion"></a>

## Discussion

[true](https://developer.apple.com/documentation/swift/true) if able to make the text smaller; otherwise, [false](https://developer.apple.com/documentation/swift/false).
