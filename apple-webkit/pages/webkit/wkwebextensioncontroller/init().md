# init() (Swift)

**Framework:** WebKit  
**Kind:** Initializer  
**Availability:** iOS 18.4+ · iPadOS 18.4+ · Mac Catalyst 18.4+ · macOS 15.4+ · visionOS 2.4+

Returns a web extension controller initialized with the default configuration.

## Declaration

```swift
init()
```

<a id="return-value"></a>

## Return Value

An initialized web extension controller, or nil if the object could not be initialized.

<a id="discussion"></a>

## Discussion

This is a designated initializer. You can use [init(configuration:)](init%28configuration_%29.md) to initialize an instance with a configuration.
