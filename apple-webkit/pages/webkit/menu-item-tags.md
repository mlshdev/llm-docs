# Menu Item Tags (Swift)

**Framework:** WebKit  
**Kind:** API Collection

Tags that define the types of default menu items passed to the [webView(\_:contextMenuItemsForElement:defaultMenuItems:)](webuidelegate/webview%28__contextmenuitemsforelement_defaultmenuitems_%29.md) method.

<a id="overview"></a>

## Overview

These tags define common actions a user might want to take with elements in a page. You can use the tags to differentiate between the different types of menu items.
