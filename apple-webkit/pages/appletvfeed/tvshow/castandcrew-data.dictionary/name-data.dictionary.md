# TvShow.CastAndCrew.Name

**Interface language:** Data

**Framework:** Apple TV Feed  
**Kind:** Object  
**Availability:** AppleTVFeed 1.0+

A mapping of locale to localized names for the cast or crew member.

## Declaration

```
object TvShow.CastAndCrew.Name
```

## Properties

- `locale` — `string`: The locale in IETF language tag format, or `default` to indicate the default value.
- `name` — `string`: The localized name.
