# SportingEvent.Competitor.Name

**Interface language:** Data

**Framework:** Apple TV Feed  
**Kind:** Object  
**Availability:** AppleTVFeed 1.0+

A mapping of locale to localized names for the competitor.

## Declaration

```
object SportingEvent.Competitor.Name
```

## Properties

- `locale` — `string`: The locale in IETF language tag format, or `default` to indicate the default value.
- `competitorName` — `string`: The localized name of the competitor.
