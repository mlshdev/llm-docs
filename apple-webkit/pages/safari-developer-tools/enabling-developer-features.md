# Enabling features for web developers

**Framework:** Safari Developer Features  
**Kind:** Article

Enable features and settings for web developers in Safari.

## 

Safari on macOS has several tools for web developers, including the [Develop menu](develop-menu.md), [Web Inspector](web-inspector.md), and [WebDriver](webdriver.md), which are turned off by default. To enable these tools:

1. From the menu bar, choose **Safari**.
2. Select **Settings…** (⌘,).
3. Go to the **Advanced** pane.
4. Check the **Show features for web developers** checkbox.

![Safari’s Advanced Settings Pane with “Show features for web developers” highlighted at the bottom of the window.](https://developer.apple.com/images/com.apple.safari.developer-tools/EnablingToolsForWebDevelopers-SafariAdvancedSettings@2x.png)
