# Subscription Introductory Offers

**Interface language:** Data

**Framework:** App Store Connect API  
**Kind:** API Collection

Create, modify, and delete introductory offers for auto-renewable subscriptions.

## Topics

### Endpoints

- [Create an introductory offer](post-v1-subscriptionintroductoryoffers.md): Create an introductory offer for an auto-renewable subscription.
- [Modify an introductory offer](patch-v1-subscriptionintroductoryoffers-_id_.md): Update a specific introductory offer for an auto-renewable subscription.
- [Delete an introductory offer for a subscription](delete-v1-subscriptionintroductoryoffers-_id_.md): Delete a specific introductory offer for an auto-renewable subscription.

### Objects

- [SubscriptionIntroductoryOfferCreateRequest](subscriptionintroductoryoffercreaterequest.md): The request body you use to create a subscription introductory offer.
- [SubscriptionIntroductoryOfferInlineCreate](subscriptionintroductoryofferinlinecreate.md): An inline object for specifying an introductory offer when creating or updating a subscription.
- [SubscriptionIntroductoryOfferResponse](subscriptionintroductoryofferresponse.md): The response body for endpoints that create, read, or modify a single subscription introductory offer.
- [SubscriptionIntroductoryOfferUpdateRequest](subscriptionintroductoryofferupdaterequest.md): The request body you use to update a subscription introductory offer update request.
