# Apple Ads Platform API Changelog

**Interface language:** Data

**Framework:** Apple Ads Platform API  
**Kind:** Article

A log of changes to the Apple Ads Platform API.

<a id="overview"></a>

## Overview

> **Important**

> The Apple Ads Platform API supersedes the [Apple Ads Campaign Management API](https://developer.apple.com/documentation/apple_ads/apple-search-ads-campaign-management-api-5), which will be sunset on January 26, 2027.

API 1.0 is the current version.

<a id="10"></a>

### 1.0

Released in August, 2026

Initial release of the Apple Ads Platform API, including [Advertising Your App on the App Store](journey-app-store-ads.md) and [Advertising Your Business on Apple Maps](journey-apple-maps-brand-ads.md).
