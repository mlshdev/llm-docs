# Geo Targeting Data Types

**Interface language:** Data

**Framework:** Apple Ads Platform API  
**Kind:** API Collection  
**Availability:** Apple Ads Platform API 1.0+

Reference the enumerations and scalar types for geo targeting.

## Topics

- [GeoEntityType](geoentitytype.md): The geographic granularity (dimension) of a geo entity, from country down to postal code.
- [SearchSupplySourceType](searchsupplysourcetype.md): The supply source context (App Store or Apple Maps) used to scope a geo location search.
