# AssetType

**Interface language:** Data

**Framework:** Apple Ads Platform API  
**Kind:** Type  
**Availability:** Apple Ads Platform API 1.0+

The media type of an asset.

## Declaration

```
string AssetType
```

## Possible Values

- `IMAGE`:

<a id="discussion"></a>

## Discussion

Currently `assetType` supports a single value:

| Value | Description |
| --- | --- |
| `IMAGE` | A static image file. See [ImageType](imagetype.md) for the full list of supported formats. |
