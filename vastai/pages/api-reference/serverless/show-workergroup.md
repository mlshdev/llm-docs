# show workergroup

`GET /api/v0/workergroups`

Retrieves the list of workergroups associated with the authenticated user.

CLI Usage: `vastai show workergroups`

**Responses**

- `200`: Success response
- `400`: Bad Request
- `401`: Unauthorized
- `429`: Too Many Requests
