# get workergroup logs

`POST /get_workergroup_logs`

Retrieves logs for a specific workergroup by ID.

CLI Usage: `vastai get workergroup logs <id> [--tail <num_lines>]`

**Responses**

- `200`: Logs successfully retrieved.
