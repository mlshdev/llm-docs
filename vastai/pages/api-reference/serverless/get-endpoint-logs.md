# get endpoint logs

`POST /get_endpoint_logs`

Retrieves logs for a specific endpoint by name.

CLI Usage: `vastai get endpoint logs <endpoint_name> [--tail <num_lines>]`

**Request body**

**Responses**

- `200`: Successfully retrieved endpoint logs.
