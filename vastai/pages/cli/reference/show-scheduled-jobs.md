# vastai show scheduled-jobs

Display the list of scheduled jobs

## Usage

```bash
vastai show scheduled-jobs [--api-key API_KEY] [--raw]
```

## Examples

```bash
vastai show scheduled-jobs
```

## Global Options

| `--url URL`     | Server REST API URL                                   |
| `--retry N`     | Retry limit                                           |
| `--raw`         | Output machine-readable JSON                          |
