# NetBird REST API

Use the NetBird Public API to manage users, peers, network rules and more from inside your application or scripts to automate the setup of your mesh network.&#x20;

[Quickstart](https://docs.netbird.io/api/guides/quickstart)

## Getting started&#x20;

To get started, it is recommended to create a [service user](https://docs.netbird.io/manage/public-api#creating-a-service-user), that can later be used to communicate with the NetBird API.
To be able to send requests to our API you need to [authenticate](https://docs.netbird.io/api/guides/authentication) on each request. This can be done either by Bearer token from your identity provider or by creating a [personal access token](https://docs.netbird.io/api/guides/authentication#using-personal-access-tokens) in the NetBird dashboard.

[Get your personal access token](https://docs.netbird.io/manage/public-api#creating-an-access-token)
