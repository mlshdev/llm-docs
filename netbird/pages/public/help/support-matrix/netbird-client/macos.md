# macOS

The NetBird client supports the macOS versions listed below. The floor moves whenever NetBird upgrades its Go toolchain and Go drops an older macOS release.

> **Warning**
>
> The version cutoffs below are derived from the [Go toolchain's minimum OS requirements](https://go.dev/wiki/MinimumRequirements) for each NetBird release's Go version. NetBird may have stricter requirements than Go, so confirm with the team before relying on them.

## macOS versions

| Version                               | Architectures  | Version Supported |
| ------------------------------------- | -------------- | ----------------- |
| macOS 12 Monterey and newer           | x86\_64, arm64 | NetBird latest    |
| macOS 11 Big Sur                      | x86\_64, arm64 | ≤ v0.62.1         |
| macOS 10.15 Catalina                  | x86\_64        | ≤ v0.29.1         |
| macOS 10.13 High Sierra, 10.14 Mojave | x86\_64        | ≤ v0.25.3         |

## Reporting compatibility issues

See [Report bugs and issues](https://docs.netbird.io/help/report-bug-issues). Include your macOS version, hardware architecture, and NetBird client version (`netbird version`).
