# Troubleshooting

Something not working as expected? Check the common issues below, or browse by area.

## Common issues

The problems support sees most often.

| Symptom                                                                                                                    | Start here                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The dashboard shows **Waiting for Approval** after you sign in                                                             | [Pending approval and account invitations](https://docs.netbird.io/help/troubleshooting-account-access)                                                                                                                                                              |
| Inviting a user fails with `409`, or IdP sync never adds them                                                              | [User already belongs to another NetBird account](https://docs.netbird.io/help/troubleshooting-user-in-another-account)                                                                                                                                              |
| The client keeps asking you to log in again, or a peer shows `Login required`                                              | [Peer session expiration](https://docs.netbird.io/manage/settings/enforce-periodic-user-authentication)                                                                                                                                                              |
| A peer shows `Relayed` instead of `P2P`                                                                                    | [Troubleshooting relayed connections](https://docs.netbird.io/help/troubleshooting-relayed-connections)                                                                                                                                                              |
| The tunnel works but is slow, or takes long to connect                                                                     | [Troubleshooting performance](https://docs.netbird.io/help/troubleshooting-performance)                                                                                                                                                                              |
| A service behind a routing peer is unreachable, or a new resource never shows up                                           | [Troubleshooting resource connectivity](https://docs.netbird.io/help/troubleshooting-resource-connectivity)                                                                                                                                                          |
| A network or host firewall blocks NetBird, or traffic stops at a security product such as a SASE or SSL-inspection service | [Ports & firewalls](https://docs.netbird.io/about-netbird/ports-and-firewalls)  On the peer itself: [Symptoms of host-based firewall issues](https://docs.netbird.io/about-netbird/ports-and-firewalls#symptoms-of-host-based-firewall-issues)                       |
| Names do not resolve, or DNS stops working after NetBird disconnects                                                       | [DNS troubleshooting](https://docs.netbird.io/manage/dns/troubleshooting)                                                                                                                                                                                            |
| A NetBird Reverse Proxy service returns `502`, times out, or its certificate is never issued                               | [Reverse proxy troubleshooting](https://docs.netbird.io/manage/reverse-proxy/troubleshooting)  Certificate: [Certificate is not issued after verification](https://docs.netbird.io/manage/reverse-proxy/custom-domains#certificate-is-not-issued-after-verification) |
